### 新增

- 账号钱包新增用量与消费趋势、赠送金明细、兑换码兑换、充值记录及支付状态查询，并支持查看媒体任务、消耗记录和模型价格目录。
- 账号支持创建和管理调用凭证，可设置可用额度与有效期，并搜索、显示或复制凭证。
- 插件市场新增本地插件上传与审核，支持查看审核状态和意见、更新已发布版本、修改后重新提交，以及删除自己上传的插件。
- 首页探索开放作品发布，支持上传作品视频与封面，并可选择公开项目，提交后等待审核；公开项目 ZIP 最大支持 512 MB。
- 媒体供应商支持通过 HTTP/HTTPS 的 .ts 源码直链导入，文件最大支持 1 MB；也可重新编辑已有供应商代码，或让 AI 基于当前代码继续修改。
- 媒体供应商新增模型测试，可在 AI 编辑面板或模型编辑列表中测试图片、视频和音频模型，查看生成结果与请求日志，并将失败信息发回 AI 继续修改。
- Agent 新增对话分支，可从已保存的消息创建独立会话，保留截至该消息的历史、附件及提及。
- Agent 支持通过 @ 提及尚无输出的画布节点，方便指定要操作的节点。
- Agent 新增节点工具控制，可分别允许或关闭图片、视频、音频生成，并将自定义节点的工具名称加入相应类别统一控制；设置对所有对话生效，不影响手动生成及已开始的任务。
- 图片、视频和音频生成节点支持保存并恢复任务状态，重新打开画布后可继续查询原任务；APIMart、秘塔和优云智算的相关异步任务支持在服务重启后恢复查询，局部重绘也可继续完成蒙版合成；复制节点时不继承原任务。
- 音频节点支持填写采样率、声道数和采样格式后预览裸 PCM，并进行变速、截取与拼接。
- 素材库支持将本地多个文件上传至当前文件夹，单个文件最大支持 100 MB。
- 画布节点全部移出当前视窗时显示提示，可点击「返回节点」适应视图。
- 首页新增横幅与侧栏信息轮播，支持关闭横幅、暂停轮播。

### 优化

- 重做快速开始与「账号与余额」页面，登录、注册和找回密码可直接在应用内完成；登录后自动配置 Toonflow 账号模型，第三方模型独立管理。
- 移除旧 TF-Router 内置接入及配置；使用该接入的用户升级后需登录 Toonflow 账号并重新选择模型。
- 升级时自动禁用已安装的旧版独立媒体生成工具一次；之后手动启用或重新安装的选择会保留。
- 整理设置分类，将界面外观与默认打开方式整合至通用设置，隐私入口移至「关于」。
- 加宽图片、视频和音频生成面板的模型显示区域；统一 Agent、文本、媒体生成、拉片、3D 导演及图片编辑等入口的模型图标与官方标识，未知型号使用通用图标。
- 模型列表统一将 Toonflow 置顶，新建节点或尚未选择模型时优先选择可用的 Toonflow 模型；保留已有选择，原模型暂不可用时显示选择提示。
- 新建 Agent 对话时沿用当前选中的模型，没有当前选择时优先使用可用的 Toonflow 模型。
- 为「适应视图」「适合屏幕」和「返回节点」增加 250 毫秒的平移、缩放过渡。
- 改进媒体任务的中断与失败反馈，复查中断任务时保留原始错误，区分查询中断和供应商明确失败，支持重新查询或明确放弃；下载链接失效时重新查询原任务，减少重复生成。
- 统一节点、素材库、历史记录、引用缩略图、聊天附件及剪辑入口的兼容媒体预览，支持 TIFF 图片转换预览；兼容转换最大支持 100 MB，通过 FFmpeg 生成临时预览并保留原文件及引用，完善远程连接下的转码等待。
- 技能菜单同时显示技能名称、调用标识和说明，支持按名称、标识或说明搜索。
- 调整 Agent 默认模型选择规则，未指定供应商时优先使用实际可用且符合需求的 Toonflow 模型。
- 补齐账号与余额、插件上传、供应商测试、任务状态等新增宿主界面在 21 种语言中的文案，完善动态提示和表单校验翻译。
- 完善浏览器操作与节点工具的参数说明、校验和错误反馈，方便 Agent 修正无效调用；改进 FFmpeg 媒体信息解析。
- 插件效果演示在打开插件详情后播放，减少列表加载时的资源占用。
- 桌面客户端开发者工具统一从开发者设置打开，完善 Windows 安装包与辅助程序的版本信息。

### 修复

- 修复部分 HEVC／H.265 10-bit 视频有时长却没有画面的问题，自动生成兼容预览，保留原视频分辨率。
- 修复组内节点尺寸变化后分组边界未同步更新的问题，避免生成竖图等内容时超出分组范围，并同步更新嵌套分组；拖动或缩放期间的尺寸变化会在操作结束后补算。
- 修复打开侧边栏后双击聚焦节点时的位置偏移与缩放不准的问题。
- 修复 Windows 桌面客户端粘贴剪贴板图片时，部分系统图片格式无法正确识别的问题。
- 修复克隆项目后无法显示原有 Agent 历史会话的问题。
- 修复 Toonflow 视频生成请求漏传引用素材对应关系的问题，避免提示词引用编号与实际素材失配或导致生成失败。
- 统一媒体拖入与上传的格式识别，修复同一文件在不同入口无法使用的问题。
- 修复插件市场更新时的版本判断，按市场发布版本检查可用更新。
- 修复部分自定义媒体供应商因 Base64 编解码函数 atob、btoa 未定义而执行失败的问题。
- 修复 Windows 安装过程中中文错误信息乱码的问题。
