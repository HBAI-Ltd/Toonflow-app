### 新增

- 新增 Windows ARM64 安装包，需安装 .NET Framework 4.8.1。
- 新增 Linux x64／ARM64 的 DEB 安装包，适用于 Debian／Ubuntu，需 glibc 2.39 及以上，通过系统包管理器更新。
- Windows 和 macOS 新增「闪退请双击我兼容运行」入口，正常启动失败时可尝试兼容方式。
- Agent 与 MCP 支持搜索插件市场，并在本机 Toonflow 确认后安装插件。
- 内置插件开发工具，可让 Agent 制作并安装自定义节点和工具插件。
- 自定义文本供应商支持配置请求头，兼容更多鉴权方式。
- Agent 支持调整图片、视频和音频生成节点的更多模型参数。

### 优化

- Windows 安装包更小，首次安装需联网下载必要运行时，支持暂停续传和切换下载源。
- macOS 客户端要求 macOS 14 及以上；旧版 Intel Mac 客户端首次升级需下载完整 DMG 覆盖安装。
- 模型设置可直接查看 Toonflow 模型目录与加载状态，并改善小屏浏览体验。
- 首页项目操作统一收纳至「更多操作」菜单。
- 点击画布小地图可平滑定位，并保留当前缩放比例。

### 修复

- 修复 Agent 停止卡住、@ 提及信息未及时更新及部分聊天链接无法打开的问题。
- 修复部分 Anthropic 供应商地址导致模型调用失败的问题。
- 修复保存画布中断逐帧拉片，以及图片打光、多角度生成期间无法保存或切换画布的问题。
- 改进媒体任务失败、取消或过期时的状态识别，查询异常仍可复查。
- 修复探索作品列表和赠送金明细的分页异常。
- 修复 Windows 部分磁盘新建文件失败，以及系统通知名称和图标异常的问题。
