### 新增

- 新增 Android 客户端（实验性，ARM64），可在手机本机使用项目、画布和 Agent，支持系统文件导入导出、横屏显示及界面缩放。
- 新增设备互联，桌面端和 Android 客户端可通过扫码、二维码图片或配对码连接另一台电脑，使用对方的项目、模型配置和计算能力。
- 设备互联支持局域网和自行配置的 HTTPS 公网连接，可管理共享目录、查看在线设备和撤销授权；连接异常时可重试或切回本机。
- 新增网页浏览器工具，桌面 Agent 可操作本机 Chrome 或 Edge，实时显示网页画面，支持放大查看、手动操作和地址导航。
- 新增全局素材管理工具，Agent 可查找、读取和整理素材，将生成结果归档到素材库，或把素材复制到当前工作区使用。
- 媒体供应商支持 AI 辅助接入，可通过对话读取接口文档、生成配置，预览模型与源码后使用或下载（需配置文本模型并启用网页浏览器工具）。
- 画布列表支持目录树和搜索，可新建文件夹、移动画布与文件夹、重命名及删除空文件夹。
- 插件市场支持启停内置节点、工具和全局技能，并可卸载不需要的全局技能。
- 新增图片打光工具，可调整主光与轮廓光的方向、强度和颜色，选择光影预设或输入描述，调用图片模型生成新的光影效果。
- 新增图片多角度工具，可调整水平环绕、垂直俯仰、拍摄距离与镜头类型，调用图片模型生成新视角。
- 新增 360° 环绕图和 720° 全景图生成入口，支持旋转预览、画面校正，以及截取单张、四宫格或十二宫格图片并添加到画布。

### 优化

- 局部重绘确认后先创建独立的图片生成节点，可继续调整模型、参数和参考图，再执行生成。
- Agent 对话中的网络图片会保存到工作区后预览，图片链接支持缩略图；工作区工具也可下载网络图片作为素材。
- Agent 可引用工作区子文件夹中的画布，便于按目录整理项目后继续对话操作。
- 媒体供应商配置支持更多自定义表单字段，供应商列表补充图标显示。
- 完善媒体模型列表刷新，补充图片模型，并同步尺寸、比例、时长和分辨率等能力参数。
- 同一轮 Agent 浏览器操作共用预览画面，减少重复卡片；改善长时间回复和媒体生成的连接稳定性。
- 桌面更新显示下载进度和准备阶段，便于查看更新状态。
- 视频节点加载后生成封面预览，改善暂停状态下的画面显示。

### 修复

- 修复 Agent 流式回复换行时列表高度和自动滚动不同步造成的画面跳动。
- 修复删除 Agent 回复后，同一轮的部分回复仍残留在列表中的问题。
- 修复通过 Agent 重命名子文件夹内画布后，后续操作丢失目录路径的问题。
- 修复模型选择初始化时意外重置思考强度的问题。
- 修复引用式 Markdown 图片显示异常，以及部分工具结果无法正确预览工作区图片的问题。
- 修复编辑文本供应商时丢失原有扩展信息的问题。
- 修复隐藏画布连线后，选中或拖动节点时相关连线与连接点仍不可见的问题。
- 修复图片处理组件打包后部分资源缺失，导致图片处理功能无法加载的问题。
