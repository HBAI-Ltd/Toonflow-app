### 新增

- 新增内置「白模预演 TrumanMap」节点，可用 AI、一键布景的常见影视景、粘贴剧本或素材库搭建三维白模场景，并用画笔铺设地形、道路和河流。
- 白模预演支持拖动画出人物走位，或让 AI 安排表演与动作；可自动排机位分镜或按对白分镜，在取景窗中调整景别、焦段和运镜，并一键切换日戏、黄昏、夜戏、阴天和雨夜光照。
- 白模预演可导出 720p／1080p 预演小样、含每镜截图的镜头表，以及画布中的分镜图片节点；素材库没有合适物件时，AI 可按描述制作新的三维模型。
- 首页新增「白模预演」页面，可新建、打开、重命名和移除白模场景；场景直接全屏编辑，导出内容可保存到素材库。
- 新增葡萄牙语（巴西）界面，支持的界面语言增至 22 种。
- 添加供应商新增「内置供应商」在线列表，内置供应商改为在线获取，不再随安装包附带或自动安装；已添加的供应商继续可用，有新版本时提示升级，文本供应商保留 API Key，媒体供应商保留连接配置。
- 支持将画布中框选的多个节点产出一次添加到素材库。
- 图片、视频、音频和逐帧拉片节点支持从素材库选择文件。
- 未登录时，首页、Agent 和各节点的模型选择列表提示登录 Toonflow，登录后即可使用官方模型，无需配置 API Key。
- 通用设置新增「素材库文件夹默认展开」开关。
- DEB 安装的 Linux 客户端支持应用内更新，优先下载增量补丁，安装前校验安装包并请求系统授权；2.0.10 的 DEB 用户需先手动覆盖安装一次。
- 支持同版本的小补丁更新，版本号不变时也会提示更新。
- 媒体供应商支持在桌面端调用本机命令行；通过文件、粘贴代码、MCP、插件链接或开发者调试添加此类供应商时，都会显示风险警告并需确认。
- 插件开发新增 HTTP 和 WebSocket 服务能力，节点与文件扩展可注册路由并提供访问地址；节点还可声明为全屏项目打开，并使用模型记忆、素材库选择与保存能力。

### 优化

- 首页改为通过侧栏切换首页、项目、探索、素材库和白模预演页面，首页展示项目与探索预览；素材库由弹窗改为独立页面。
- 首页侧栏新增账号菜单，可查看余额、登录或退出，设置、设备连接和 GitHub 入口统一收纳；有新版本时显示提示。
- 画布右上角的 Toonflow 余额可查看本金、赠送金与累计消费，并直接充值。
- 设置中的「第三方模型」分组更名为「模型」；Toonflow 模型卡片新增充值按钮和网页查看入口。
- 媒体生成失败后任务直接结束，可立即重新生成，无需手动复查或放弃；关闭画布时中断的任务，重新打开后仍会自动复查。
- 图片、视频和音频生成节点会记住上次手动选择的模型，新建节点时优先使用。
- 拖动节点、选区或连线靠近画布边缘时自动平移视图。
- 从视频提取的音轨、音频节点的处理结果及逐帧拉片的原音轨改为 MP3 格式。
- 点击提示词输入框的空白处也能直接输入。
- 技能编辑器可直接以可视化方式编辑 Markdown 文件，并保留技能头部信息；Markdown 文档保存时保留未修改段落的原始格式。
- 插件市场所有类型的插件均显示封面，效果演示改在详情页播放，加载失败可重试；以其他名称安装的市场插件也能正确识别并提示更新。
- 文件扩展插件改用 .ext.js 格式，旧版 .umd.js 扩展仍可安装和加载，新旧文件同时存在时优先使用 .ext.js。
- Agent 中文长对话的上下文用量估算更准确；MCP 工具返回内容过长时自动截断，避免占满上下文。
- Agent 分页查询画布出错时给出明确的修正提示，减少无效重试。
- Agent 遇到视频生成失败时会说明失败原因，并告知预扣费用将自动退还。
- 支持识别 DeepSeek V4.1 Flash 的 1M 上下文长度。
- Windows 标题栏跟随应用的深浅色主题；优化启动加载动画，并遵循系统的减少动态效果设置。
- Windows 安装和更新不再联网下载解压工具；安装失败时显示失败步骤和返回码，并写入 %TEMP%\toonflowInstall.log。
- Windows 客户端的 Bun 运行时保留官方数字签名。

### 修复

- 修复 LM Studio 等本地模型引擎无法解析部分工具参数，导致 Agent 调用失败的问题。
- 修复素材库刷新后文件夹展开状态被重置的问题。
- 修复 macOS 和 Linux 客户端下拉选项内容下移被裁切的问题。
- 修复旧版 APIMart 供应商的「请求地区」显示为输入框的问题。
- 修复 Windows 部分系统另存为窗口返回无效路径的问题。
- 修复数据目录位于 ~/.local 等隐藏目录时，Linux 客户端无法加载节点插件的问题。
- 修复 DEB 安装包部分程序文件权限过严，普通用户无法读取的问题。
- 修复 VMware 虚拟机中 Linux Wayland 会话白屏的问题。
