FilmFraylo は、ショートドラマ・マンガドラマ・ショート動画のクリエイター向け AI 制作ツールです。無限キャンバス上で脚本と絵コンテを書き、キャラクターやシーンの素材を管理し、画像と動画を生成できます。公式 FilmFraylo モデルプラットフォームのテキスト・画像・動画・音声モデルを内蔵し、ローカルデプロイとデバイス連携に対応しています。

## 1. 🌟 ハイライト

FilmFraylo は、脚本・素材・動画クリップを同じ 1 枚の無限キャンバスにまとめます。

| 機能 | 説明 |
| --- | --- |
| 🏠 **ローカルデプロイ** | プロジェクトと素材は自分のデバイスやサーバーに保存でき、デスクトップ・Android・Docker・サーバーでの運用に対応します。 |
| 🖼️ **無限キャンバス** | 同じキャンバス上で脚本・キャラクター・シーン・動画クリップを整理できます。 |
| 🔌 **MCP** | MCP を通じて外部ツールやサービスに接続します。 |
| 🤖 **オープン Agent** | プロンプト・ツール・A2A を公開し、カスタム Agent の動作や外部連携に対応します。 |
| 🧠 **モデルサービス内蔵** | 公式 FilmFraylo モデルプラットフォームがテキスト・画像・動画・音声モデルを提供し、API Key を設定すればすぐに使えます。 |
| 🌐 **多言語対応** | 21 種類のインターフェース言語に対応しています。 |

### FilmFraylo で AI ショートドラマ・マンガドラマを制作する方法

1. **脚本と絵コンテを書く**：テキストノードでストーリー・人物設定・カットの説明を整理し、言語モデルに創作を手伝ってもらいながら内容を確認・修正します。
2. **キャラクターとシーンの素材を用意する**：参考画像を読み込むか、画像生成ノードでキャラクター・シーン・絵コンテの画像を作成します。
3. **動画カットを生成する**：テキストと画像の参考を接続し、動画モデルと生成モードを選んで、カットごとに動画クリップを生成します。
4. **プレビュー・整理・ダウンロード**：無限キャンバスで画像と動画クリップをプレビュー・整理し、素材をダウンロードして必要に応じて作業を続けます。

対応する参考素材・動画の長さ・解像度・音声機能は、選択したモデルによって異なります。

### よくある質問

**FilmFraylo は AI ショートドラマ・マンガドラマ制作のどの工程に使えますか？**

FilmFraylo はテキスト・画像・動画の生成ノードを提供し、脚本と絵コンテの制作、キャラクターやシーンの素材づくり、動画カットの生成、素材のプレビューと整理に活用できます。内容の確認と調整はクリエイター自身が行う必要があり、具体的な生成機能は選択したモデルによって異なります。

**FilmFraylo は無料ですか？モデルの利用に料金はかかりますか？**

FilmFraylo は MIT ライセンスのオープンソースで、自由にデプロイできます。モデルの利用は公式モデルプラットフォームの従量課金で、アプリ内で API Key を設定する必要があります。作例に記載の制作費用はその事例の金額であり、固定価格ではありません。

**自分のモデルを接続できますか？**

現行バージョンは公式モデルプラットフォームを内蔵しており、モデルは公式 FilmFraylo モデルプラットフォームが提供します。サードパーティモデルやローカル ComfyUI ワークフローの接続にはまだ対応していません。

## 3. 🚀 ダウンロードとインストール

### 3.1 クライアントのインストール

| オペレーティングシステム | GitHub                                                       |
| -------- | ------------------------------------------------------------ |
| Windows  | [Release](https://github.com/zechau/filmfraylo-app/releases) |
| macOS    | [Release](https://github.com/zechau/filmfraylo-app/releases) |
| Android ARM64 | [APK のダウンロード](https://github.com/zechau/filmfraylo-app/releases/latest) |

Android 版は ARM64 デバイスのみに対応しています。リリースページから `filmfraylo-版本号-android-arm64.apk` をダウンロードしてインストールしてください。スマートフォンにはローカルの Bun バックエンドが内蔵され、単体で動作します。ホーム画面の「デバイス連携」から QR コードを読み取るか手動で、共有を有効にしたパソコンやリモートバックエンドに接続することもできます（LAN・インターネットに対応）。

Windows インストーラーは WebView2 を自動的に検出してインストールします。インストール後に起動直後にクラッシュする場合は、[WebView2 ダウンロードページ](https://developer.microsoft.com/microsoft-edge/webview2/) からランタイムを手動でインストールしてください。

macOS（Apple Silicon）では、FilmFraylo を「アプリケーション」にドラッグしてそのまま開くだけで、事前にターミナルコマンドを実行する必要はありません。システムのセキュリティ警告が表示された場合は、以下の順に対処してください。

<details>
<summary><strong>macOS でインストールまたは起動できない場合の対処方法</strong></summary>

**1. 「プライバシーとセキュリティ」で FilmFraylo を許可する**

「開発元を確認できません」または「Apple は App に悪意のあるソフトウェアが含まれていないことを確認できません」と表示された場合は、まず FilmFraylo を開いてみてください。その後「システム設定 → プライバシーとセキュリティ」を開き、FilmFraylo がブロックされた通知を見つけて「このまま開く」をクリックし、指示に従って確認します。詳しくは [Apple 公式サポート](https://support.apple.com/zh-cn/102445) をご覧ください。

**2. システムの隔離制限で開けない場合は、隔離属性の削除を試す**

アプリが公式リリースページから取得したもので「アプリケーション」に入っていることを確認したうえで、ターミナルで以下のコマンドを実行し、もう一度開いてください。アプリ名やインストール場所が異なる場合はパスを調整してください。

```bash
sudo xattr -rd com.apple.quarantine /Applications/FilmFraylo.app
```

**3. 最終手段：任意の提供元の App を一時的に許可する**

上記 2 つの方法がいずれも効果がなく、アプリの入手元が信頼できると確認できた場合に、ターミナルで以下を実行できます：

```bash
sudo spctl --master-disable
```

その後「システム設定 → プライバシーとセキュリティ」を開き、「セキュリティ」の「ダウンロードした App の許可」で「どこでも」を選択し（システムにこの項目がある場合）、指示に従って確認します。macOS のバージョンによって、項目やコマンドの対応状況が異なる場合があります。

この操作はすべての App のセキュリティ制限を緩めます。完了後は、許可するダウンロード元を「App Store と確認済みの開発元」に戻すことをおすすめします。

</details>

### 3.2 Docker のインストール

まず Git、[Docker Engine](https://docs.docker.com/engine/install/)、Docker Compose をインストールします。Windows / macOS では Docker Desktop の Linux コンテナモードを利用できます。リポジトリには [Dockerfile](./Dockerfile)、[Compose 設定](./compose.yaml)、[ビルド除外ルール](./.dockerignore) があり、Bun 1.3.14 をベースにビルドされ、イメージには FFmpeg が含まれています。

<details>
<summary><strong>Docker のインストール手順を開く</strong></summary>

ソースをクローンしたら、リポジトリのルートディレクトリで実行します：

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
docker compose up -d --build
```

初回ビルドでは依存関係をインストールし、内蔵ノード・ツール・Web・Server をコンパイルします。起動後は `http://127.0.0.1:3000` にアクセスしてください。リモートホストの場合は、後述の「アクセスとデータについて」にあるとおり SSH トンネルでアクセスできます。初回起動時には内蔵プラグインが初期化され、`myProject` ワークスペースが用意されます。

設定・プラグイン・プロジェクトファイルは Docker の名前付きボリューム `filmfrayloData` に保存され、コンテナの `/app/data/` にマウントされます。ボリュームの実際の名前には Compose プロジェクト名のプレフィックスが付きます。コンテナを停止・再作成してもデータは保持されます。**`docker compose down -v` は使用しないでください。データボリュームが削除されます。**

```sh
docker compose logs -f filmfraylo  # ログを表示
docker compose stop                # サービスを停止
docker compose start               # 再度起動
docker compose down                # コンテナを削除（データボリュームは保持）
```

プロジェクトディレクトリを追加するには、ページの「サーバーの作業ディレクトリを選択」ダイアログで「新しいフォルダ」をクリックします。ダイアログではファイルやフォルダの名前変更・削除もできます。サービス実行中にコマンドラインから作成することもできます：

```sh
docker compose exec filmfraylo mkdir -p /app/data/workspaces/newProject
```

バックアップするときは、先にサービスを停止し、コピー完了後に再起動します：

```sh
docker compose stop
docker compose cp filmfraylo:/app/data ./filmfrayloBackup
docker compose start
```

</details>

### 3.3 サーバーへのインストール

Linux サーバー上で Web と Server を直接実行する場合の手順です。以下は Ubuntu / Debian を例に、プロジェクト指定の [Bun 1.3.14](https://bun.sh/docs/installation) を使用します。

<details>
<summary><strong>サーバーのインストール手順を開く</strong></summary>

実行環境をインストールします：

```sh
sudo apt-get update
sudo apt-get install -y git curl unzip ffmpeg
curl -fsSL https://bun.com/install | bash -s "bun-v1.3.14"
export PATH="$HOME/.bun/bin:$PATH"
bun --version
```

ソースをクローンして起動します：

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
bun install --frozen-lockfile

# 内蔵ノード・ツール・Web・Server をビルド
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

「服务启动成功」（サービスが正常に起動しました）と表示されたら、サーバー上で `http://127.0.0.1:3000` にアクセスできます。上記のコマンドはフォアグラウンドで実行されるため、`Ctrl+C` で停止します。起動時の自動開始とプロセス管理が必要な場合は、[Bun の systemd デプロイガイド](https://bun.sh/guides/ecosystem/systemd) を参考に、作業ディレクトリをリポジトリのディレクトリに、起動コマンドを Bun の絶対パスに `run start:server` を付けたものに設定し、そのディレクトリへの読み書き権限を持つユーザーで実行してください。

</details>

### 3.4 アクセスとデータについて

- 現在のサービスは固定ポート `3000` を使用しており、業務ページと API に独立したログイン認証はありません。サーバーにインストールする場合は、ファイアウォールやセキュリティグループで `3000` ポートへのアクセス元を制限してください。インターネット経由でアクセスする場合は、認証付きのリバースプロキシが必要です。
- 個人でリモート利用する場合は、ご自身のパソコンで `ssh -N -L 3000:127.0.0.1:3000 ユーザー名@サーバーアドレス` を実行し、接続を維持したまま `http://127.0.0.1:3000` を開きます。サーバーの `3000` ポートをインターネットに公開する必要はありません。
- 直接インストールした場合、設定・プラグイン・ワークスペースは既定でリポジトリの `data/` に保存されます。Docker インストールの場合はデータボリューム内の `/app/data/` に保存されます。移行やバックアップの際は、これらをそっくり保持してください。ページを開いたら、サーバーワークスペース内の `myProject` を選択します。プロジェクトを増やす場合は、対応する `workspaces/` の下にサブディレクトリを作成します。
- どちらのインストール方法にもシステムの FFmpeg が含まれます。モデルサービスの API Key は引き続きページ内で設定する必要があります。
