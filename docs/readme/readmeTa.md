### FilmFraylo மூலம் AI சிறு நாடகங்களையும் கார்ட்டூன் நாடகங்களையும் உருவாக்குவது எப்படி

1. **திரைக்கதையும் காட்சிப்பிரிவுகளும் எழுதுதல்**: உரை முனைகளில் கதை, கதாபாத்திர அமைப்புகள் மற்றும் கேமரா விவரங்களை ஒழுங்கமைத்து, மொழி மாதிரியின் உதவியுடன் படைத்து, பின்னர் உள்ளடக்கத்தை மதிப்பாய்வு செய்து திருத்தவும்.
2. **கதாபாத்திரங்கள் மற்றும் காட்சிப் பொருட்களைத் தயாரித்தல்**: குறிப்புப் படங்களை இறக்குமதி செய்யவும், அல்லது படம் உருவாக்கும் முனைகள் மூலம் கதாபாத்திரங்கள், காட்சிகள் மற்றும் காட்சிப்பிரிவுப் படங்களை உருவாக்கவும்.
3. **வீடியோக் காட்சிகளை உருவாக்குதல்**: உரை மற்றும் படக் குறிப்புகளை இணைத்து, வீடியோ மாதிரியையும் உருவாக்கும் முறையையும் தேர்ந்தெடுத்து, காட்சி வாரியாக வீடியோப் பகுதிகளை உருவாக்கவும்.
4. **முன்னோட்டம், ஒழுங்கமைப்பு மற்றும் பதிவிறக்கம்**: எல்லையற்ற கேன்வாஸில் படங்களையும் வீடியோப் பகுதிகளையும் முன்னோட்டம் செய்து ஒழுங்கமைத்து, பொருட்களைப் பதிவிறக்கிய பிறகு படைப்புத் தேவைக்கேற்பத் தொடர்ந்து செயலாக்கவும்.

ஆதரவளிக்கும் குறிப்புப் பொருட்கள், வீடியோ கால அளவு, ரெசல்யூஷன் மற்றும் ஒலி திறன்கள் தேர்ந்தெடுக்கப்பட்ட மாதிரியைப் பொறுத்தது.

### அடிக்கடி கேட்கப்படும் கேள்விகள்

**AI சிறு நாடகங்கள் மற்றும் கார்ட்டூன் நாடகங்கள் தயாரிப்பின் எந்தெந்த பகுதிகளில் FilmFraylo பயன்படுத்தலாம்?**

FilmFraylo உரை, படம் மற்றும் வீடியோ உருவாக்க முனைகளை வழங்குகிறது. இவை திரைக்கதை மற்றும் காட்சிப்பிரிவு படைப்பு, கதாபாத்திரங்கள் மற்றும் காட்சிப் பொருட்கள் தயாரிப்பு, வீடியோக் காட்சி உருவாக்கம், மேலும் பொருட்களின் முன்னோட்டம் மற்றும் ஒழுங்கமைப்புக்குப் பயன்படுகின்றன. படைப்பாளர்கள் உள்ளடக்கத்தை மதிப்பாய்வு செய்து சரிசெய்ய வேண்டும்; குறிப்பிட்ட உருவாக்கத் திறன்கள் தேர்ந்தெடுக்கப்பட்ட மாதிரியைப் பொறுத்தது.

**FilmFraylo இலவசமா? மாதிரி அழைப்புகளுக்குக் கட்டணம் செலுத்த வேண்டுமா?**

FilmFraylo MIT திறந்த மூல உரிமத்தைப் பயன்படுத்துகிறது; நீங்களே நிறுவிக் கொள்ளலாம். மாதிரி அழைப்புகளுக்கு அதிகாரப்பூர்வ மாதிரி தளம் பயன்பாட்டு அளவின் அடிப்படையில் கட்டணம் வசூலிக்கிறது; முதலில் பயன்பாட்டினுள் API Key அமைக்க வேண்டும். படைப்பு உதாரணங்களில் குறிப்பிடப்பட்டுள்ள தயாரிப்புச் செலவு அந்த எடுத்துக்காட்டுக்கு மட்டுமே பொருந்தும்; அது நிலையான விலை அல்ல.

**சொந்த மாதிரிகளை இணைக்க முடியுமா?**

<details>
<summary><strong>macOS இல் நிறுவவோ திறக்கவோ முடியாதபோது கையாளும் முறை</strong></summary>

**1. “தனியுரிமை மற்றும் பாதுகாப்பு” அமைப்புகளில் FilmFraylo ஐ அனுமதித்தல்**

**2. கணினி தனிமைப்படுத்தல் கட்டுப்பாட்டால் இன்னும் திறக்க முடியவில்லை என்றால், தனிமைப்படுத்தல் பண்புக்கூறை நீக்குதல்**

பயன்பாடு அதிகாரப்பூர்வ வெளியீட்டுப் பக்கத்திலிருந்து வந்தது என்பதை உறுதிப்படுத்தி, “பயன்பாடுகள்” கோப்புறையில் வைத்த பிறகு, டெர்மினலில் கீழ்க்கண்ட கட்டளையை இயக்கி, மீண்டும் திறக்கவும். பயன்பாட்டின் பெயர் அல்லது நிறுவல் இடம் வேறுபட்டால், பாதையை மாற்றவும்.

```bash
sudo xattr -rd com.apple.quarantine /Applications/FilmFraylo.app
```

**3. கடைசி வழி: எந்த மூலத்திலிருந்தும் வரும் App களை தற்காலிகமாக அனுமதித்தல்**

முதல் இரண்டு முறைகளும் பயனளிக்கவில்லை என்றால், பயன்பாட்டின் மூலம் நம்பகமானது என உறுதிப்படுத்திய பிறகு, டெர்மினலில் இதை இயக்க முயற்சிக்கலாம்:

```bash

```

பிறகு “கணினி அமைப்புகள் → தனியுரிமை மற்றும் பாதுகாப்பு” ஐத் திறந்து, “பாதுகாப்பு” பிரிவில் “கீழ்க்கண்ட இடங்களிலிருந்து பதிவிறக்கிய App களை அனுமதி” என்பதற்கு “எந்த மூலமும்” என்பதைத் தேர்ந்தெடுத்து (கணினி அந்த விருப்பத்தை வழங்கினால்), திரையில் காட்டப்படும் வழிகாட்டுதலின்படி உறுதிப்படுத்தவும். macOS பதிப்புகளுக்கு ஏற்ப விருப்பங்களும் கட்டளை ஆதரவும் மாறுபடலாம்.

### 3.2 Docker நிறுவல்

முதலில் Git, [Docker Engine](https://docs.docker.com/engine/install/) மற்றும் Docker Compose ஆகியவற்றை நிறுவவும்; Windows / macOS இல் Docker Desktop இன் Linux கொள்கலன் முறையைப் பயன்படுத்தலாம். களஞ்சியத்தில் [Dockerfile](./Dockerfile), [Compose அமைப்பு](./compose.yaml) மற்றும் [கட்டுமான விலக்கு விதிகள்](./.dockerignore) வழங்கப்பட்டுள்ளன; Bun 1.3.14 அடிப்படையில் கட்டமைக்கப்பட்டு, இமேஜில் FFmpeg உள்ளடங்கியுள்ளது.

<details>
<summary><strong>Docker நிறுவல் படிகளை விரிவாக்கு</strong></summary>

மூலக் குறியீட்டை குளோன் செய்த பிறகு, களஞ்சியத்தின் முதன்மைக் கோப்புறையில் இயக்கவும்:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
docker compose up -d --build
```

முதல் கட்டுமானம் சார்புகளை நிறுவி, உள்ளமைக்கப்பட்ட முனைகள், கருவிகள், Web மற்றும் Server ஆகியவற்றைத் தொகுக்கும். தொடங்கிய பிறகு `http://127.0.0.1:3000` ஐ அணுகவும்; தொலை ஹோஸ்ட்களுக்கு கீழே உள்ள “அணுகல் மற்றும் தரவு விளக்கம்” படி SSH சுரங்கப்பாதை வழியாக அணுகலாம். முதல் தொடக்கத்தில் உள்ளமைக்கப்பட்ட செருகுநிரல்கள் துவக்கப்பட்டு, `myProject` பணிக்கோப்புறையும் வழங்கப்படும்.

அமைப்புகள், செருகுநிரல்கள் மற்றும் திட்டக் கோப்புகள் Docker பெயரிடப்பட்ட தொகுதி `filmfrayloData` இல் சேமிக்கப்படுகின்றன; இது கொள்கலனின் `/app/data/` இல் மவுண்ட் செய்யப்படுகிறது. தொகுதியின் உண்மையான பெயரில் Compose திட்ட முன்னொட்டு இருக்கும்; கொள்கலனை நிறுத்தியோ மீண்டும் உருவாக்கியோ தரவு தக்கவைக்கப்படும்; **`docker compose down -v` ஐப் பயன்படுத்த வேண்டாம் — அந்தக் கட்டளை தரவுத் தொகுதியை நீக்கிவிடும்**.

```sh
docker compose logs -f filmfraylo  # 查看日志
docker compose stop                # 停止服务
docker compose start               # 再次启动
docker compose down                # 删除容器，保留数据卷
```

கூடுதல் திட்டக் கோப்புறைகள் தேவைப்பட்டால், பக்கத்தில் உள்ள “சேவையக பணிக்கோப்புறையைத் தேர்ந்தெடு” சாளரத்தில் “புதிய கோப்புறை” என்பதைக் கிளிக் செய்யலாம். அந்தச் சாளரம் கோப்புகள் மற்றும் கோப்புறைகளை மறுபெயரிடுதல், நீக்குதல் ஆகியவற்றையும் ஆதரிக்கிறது. சேவை இயங்கும் நேரத்திலும் கட்டளை வரி மூலம் உருவாக்கலாம்:

```sh
docker compose exec filmfraylo mkdir -p /app/data/workspaces/newProject
```

காப்புப்பிரதி எடுக்கும்போது முதலில் சேவையை நிறுத்தவும்; நகல் முடிந்த பிறகு மீண்டும் தொடங்கவும்:

```sh
docker compose stop
docker compose cp filmfraylo:/app/data ./filmfrayloBackup
docker compose start
```

</details>

### 3.3 சேவையக நிறுவல்

Linux சேவையகத்தில் நேரடியாக Web மற்றும் Server ஐ இயக்குவதற்குப் பொருந்தும். கீழே Ubuntu / Debian உதாரணமாக எடுத்துக்கொள்ளப்பட்டு, திட்டத்தால் குறிப்பிடப்பட்ட [Bun 1.3.14](https://bun.sh/docs/installation) பயன்படுத்தப்படுகிறது.

<details>
<summary><strong>சேவையக நிறுவல் படிகளை விரிவாக்கு</strong></summary>

இயக்கச் சூழலை நிறுவவும்:

```sh
sudo apt-get update
sudo apt-get install -y git curl unzip ffmpeg
curl -fsSL https://bun.com/install | bash -s "bun-v1.3.14"
export PATH="$HOME/.bun/bin:$PATH"
bun --version
```

மூலக் குறியீட்டை குளோன் செய்து தொடங்கவும்:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
bun install --frozen-lockfile

# 构建内置节点、工具、Web 与 Server
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

“சேவை வெற்றிகரமாகத் தொடங்கியது” என்று கண்ட பிறகு, சேவையகத்திலேயே `http://127.0.0.1:3000` ஐ அணுகலாம். மேற்கூறிய கட்டளைகள் முன்புற முறையில் இயங்கும்; நிறுத்த `Ctrl+C` அழுத்தவும்; துவக்கத்தில் தானாக இயங்குவதும் செயலி நிர்வாகமும் தேவைப்பட்டால், [Bun இன் systemd வழிகாட்டி](https://bun.sh/guides/ecosystem/systemd) ஐப் பார்க்கவும் — பணிக் கோப்புறையை களஞ்சியக் கோப்புறையாகவும், தொடக்கக் கட்டளையை Bun இன் முழுப் பாதையுடன் `run start:server` ஆகவும் அமைத்து, அந்தக் கோப்புறையில் படிக்க/எழுத அனுமதியுள்ள பயனரால் இயக்கவும்.

</details>

### 3.4 அணுகல் மற்றும் தரவு விளக்கம்

- தற்போதைய சேவை நிலையான `3000` துறையைப் பயன்படுத்துகிறது; வணிகப் பக்கங்களுக்கும் API க்கும் தனி உள்நுழைவு அங்கீகாரம் இல்லை. சேவையக நிறுவலில், ஃபயர்வால் அல்லது பாதுகாப்புக் குழு மூலம் `3000` துறையின் அணுகல் மூலங்களைக் கட்டுப்படுத்தவும்; பொதுஇணைய அணுகலுக்கு அங்கீகாரம் கொண்ட தலைகீழ் ப்ராக்ஸியை அமைக்க வேண்டும்.
- தனிநபர் தொலைப் பயன்பாட்டுக்கு, உங்கள் சொந்தக் கணினியில் `ssh -N -L 3000:127.0.0.1:3000 用户名@服务器地址` ஐ இயக்கி, இணைப்பைத் தக்கவைத்து `http://127.0.0.1:3000` ஐத் திறக்கலாம்; சேவையகத்தின் `3000` துறையை பொதுஇணையத்திற்குத் திறக்கத் தேவையில்லை.
- நேரடி நிறுவலில், அமைப்புகள், செருகுநிரல்கள் மற்றும் பணியிடங்கள் இயல்பாக களஞ்சியத்தின் `data/` இல் சேமிக்கப்படும்; Docker நிறுவலில் தரவுத் தொகுதிக்குள் உள்ள `/app/data/` இல் சேமிக்கப்படும். இடமாற்றம் அல்லது காப்புப்பிரதியின்போது இவற்றை முழுமையாகத் தக்கவைக்கவும். பக்கத்திற்குள் சென்று சேவையக பணியிடத்தில் உள்ள `myProject` ஐத் தேர்ந்தெடுக்கவும்; கூடுதல் திட்டங்களை அதற்குரிய `workspaces/` இல் துணைக் கோப்புறைகளாக உருவாக்கலாம்.
- இரு நிறுவல் முறைகளிலும் சிஸ்டம் FFmpeg உள்ளடங்கும். மாதிரி சேவையின் API Key இன்னும் பக்கத்திற்குள் அமைக்க வேண்டும்.
