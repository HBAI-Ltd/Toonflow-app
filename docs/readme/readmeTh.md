## 1. 🌟 จุดเด่น

FilmFraylo รวมบท แอสเซ็ต และคลิปวิดีโอไว้ในแคนวาสไร้ขีดจำกัดเดียวกัน

| ความสามารถ | รายละเอียด |
| --- | --- |
| 🏠 **ติดตั้งใช้งานในเครื่อง** | จัดเก็บโปรเจกต์และแอสเซ็ตบนอุปกรณ์หรือเซิร์ฟเวอร์ของคุณเอง รองรับการติดตั้งบนเดสก์ท็อป, Android, Docker และเซิร์ฟเวอร์ |
| 🖼️ **แคนวาสไร้ขีดจำกัด** | จัดระเบียบบท ตัวละคร ฉาก และคลิปวิดีโอในแคนวาสเดียว |
| 🔌 **MCP** | เชื่อมต่อเครื่องมือและบริการภายนอกผ่าน MCP |
| 🤖 **Agent เปิด** | เปิดพรอมป์ต์ เครื่องมือ และ A2A รองรับการปรับแต่งพฤติกรรมของ Agent และการทำงานร่วมกับภายนอก |
| 🧠 **บริการโมเดลในตัว** | แพลตฟอร์มโมเดล FilmFraylo อย่างเป็นทางการให้บริการโมเดลข้อความ ภาพ วิดีโอ และเสียง ตั้งค่า API Key แล้วใช้งานได้ทันที |
| 🌐 **รองรับหลายภาษา** | รองรับ 21 ภาษาของอินเทอร์เฟซ |

### วิธีสร้างละครสั้นและละครการ์ตูน AI ด้วย FilmFraylo

1. **เขียนบทและสตอรีบอร์ด**: เรียบเรียงเรื่องราว การตั้งค่าตัวละคร และคำอธิบายภาพในโหนดข้อความ ใช้โมเดลภาษาช่วยสร้างสรรค์ แล้วตรวจทานและแก้ไขเนื้อหา
2. **เตรียมแอสเซ็ตตัวละครและฉาก**: นำเข้าภาพอ้างอิง หรือสร้างตัวละคร ฉาก และภาพสตอรีบอร์ดผ่านโหนดสร้างภาพ
3. **สร้างช็อตวิดีโอ**: เชื่อมต่อข้อความและภาพอ้างอิง เลือกโมเดลวิดีโอและโหมดการสร้าง แล้วสร้างคลิปวิดีโอทีละช็อต
4. **ดูตัวอย่าง จัดระเบียบ และดาวน์โหลด**: ดูตัวอย่างและจัดระเบียบภาพและคลิปวิดีโอบนแคนวาสไร้ขีดจำกัด ดาวน์โหลดแอสเซ็ตเพื่อนำไปประมวลผลต่อตามความต้องการ

แอสเซ็ตอ้างอิง ระยะเวลาวิดีโอ ความละเอียด และความสามารถด้านเสียงที่รองรับ ขึ้นอยู่กับโมเดลที่เลือก

### คำถามที่พบบ่อย

**FilmFraylo ใช้ในขั้นตอนใดของการผลิตละครสั้นและละครการ์ตูน AI ได้บ้าง?**

FilmFraylo มีโหนดสร้างข้อความ ภาพ และวิดีโอ ใช้ได้ตั้งแต่การเขียนบทและสตอรีบอร์ด การสร้างแอสเซ็ตตัวละครและฉาก การสร้างช็อตวิดีโอ ไปจนถึงการดูตัวอย่างและจัดระเบียบแอสเซ็ต ผู้สร้างควรตรวจทานและปรับปรุงเนื้อหา ความสามารถในการสร้างขึ้นอยู่กับโมเดลที่เลือก

**FilmFraylo ใช้ฟรีไหม การเรียกใช้โมเดลต้องจ่ายเงินหรือไม่?**

FilmFraylo ใช้สัญญาอนุญาตโอเพนซอร์ส MIT ติดตั้งใช้งานได้ด้วยตัวเอง การเรียกใช้โมเดลคิดค่าบริการตามการใช้งานโดยแพลตฟอร์มโมเดลอย่างเป็นทางการ และต้องตั้งค่า API Key ในแอปก่อน ค่าใช้จ่ายในการผลิตในตัวอย่างผลงานเป็นเพียงกรณีนั้น ไม่ใช่ราคาคงที่

**เชื่อมต่อโมเดลของตัวเองได้ไหม?**

เวอร์ชันปัจจุบันมีแพลตฟอร์มโมเดลอย่างเป็นทางการในตัว โดยมีโมเดลจากแพลตฟอร์มโมเดล FilmFraylo อย่างเป็นทางการ ยังไม่รองรับการเชื่อมต่อโมเดลของบุคคลที่สามหรือเวิร์กโฟลว์ ComfyUI ในเครื่อง

ตัวติดตั้ง Windows จะตรวจหาและติดตั้ง WebView2 โดยอัตโนมัติ หากติดตั้งแล้วเปิดแอปแล้วปิดทันที ให้ไปที่ [หน้าดาวน์โหลด WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) เพื่อติดตั้งรันไทม์ด้วยตนเอง

บน macOS (Apple Silicon) เพียงลาก FilmFraylo ไปไว้ใน “แอปพลิเคชัน” แล้วเปิดได้เลย ไม่ต้องรันคำสั่งในเทอร์มินัลก่อน หากพบคำเตือนความปลอดภัยของระบบ ให้ดำเนินการตามลำดับต่อไปนี้

<details>
<summary><strong>วิธีจัดการเมื่อติดตั้งหรือเปิด FilmFraylo บน macOS ไม่ได้</strong></summary>

**1. อนุญาต FilmFraylo ใน “ความเป็นส่วนตัวและความปลอดภัย”**

หากพบข้อความ “ไม่สามารถตรวจสอบผู้พัฒนา” หรือ “Apple ไม่สามารถตรวจสอบได้ว่าแอปมีมัลแวร์หรือไม่” ให้ลองเปิด FilmFraylo ก่อน จากนั้นไปที่ “การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย” ค้นหาข้อความที่ระบุว่า FilmFraylo ถูกบล็อก คลิก “เปิดอยู่ดี” แล้วยืนยันตามที่ระบบแจ้ง ดูรายละเอียดได้ที่ [คำแนะนำอย่างเป็นทางการของ Apple](https://support.apple.com/zh-cn/102445)

**2. หากยังเปิดไม่ได้เพราะข้อจำกัดการแยกไฟล์ของระบบ ให้ลองลบแอตทริบิวต์การแยกไฟล์**

ตรวจสอบว่าแอปมาจากหน้าเผยแพร่อย่างเป็นทางการและอยู่ใน “แอปพลิเคชัน” แล้ว จากนั้นรันคำสั่งต่อไปนี้ในเทอร์มินัลและเปิดแอปอีกครั้ง หากชื่อแอปหรือตำแหน่งติดตั้งต่างออกไป ให้ปรับพาธตามจริง

```bash
sudo xattr -rd com.apple.quarantine /Applications/FilmFraylo.app
```

**3. ทางเลือกสุดท้าย: อนุญาตแอปจากทุกแหล่งชั่วคราว**

หากสองวิธีแรกไม่ได้ผลและมั่นใจว่าแอปมาจากแหล่งที่เชื่อถือได้ ลองรันคำสั่งนี้ในเทอร์มินัล:

```bash
sudo spctl --master-disable
```

จากนั้นเปิด “การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย” ในหัวข้อ “ความปลอดภัย” ตั้งค่า “อนุญาตแอปที่ดาวน์โหลดจาก” เป็น “ทุกที่” (หากระบบมีตัวเลือกนี้) แล้วยืนยันตามที่แจ้ง ตัวเลือกและคำสั่งที่รองรับอาจแตกต่างกันในแต่ละเวอร์ชันของ macOS

การทำเช่นนี้จะผ่อนปรนข้อจำกัดความปลอดภัยของแอปทั้งหมด เมื่อเสร็จแล้วแนะนำให้คืนค่าแหล่งที่อนุญาตเป็น “App Store และนักพัฒนาที่รู้จัก”

</details>

### 3.2 การติดตั้งด้วย Docker

ติดตั้ง Git, [Docker Engine](https://docs.docker.com/engine/install/) และ Docker Compose ก่อน บน Windows / macOS ใช้โหมดคอนเทนเนอร์ Linux ของ Docker Desktop ได้ รีโปมี [Dockerfile](./Dockerfile), [การตั้งค่า Compose](./compose.yaml) และ [กฎการยกเว้นตอนบิลด์](./.dockerignore) ให้ พร้อมสร้างบน Bun 1.3.14 และอิมเมจมี FFmpeg มาด้วย

<details>
<summary><strong>ขยายขั้นตอนการติดตั้ง Docker</strong></summary>

หลังโคลนซอร์สโค้ด ให้รันที่รากของรีโป:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
docker compose up -d --build
```

การบิลด์ครั้งแรกจะติดตั้งดีเพนเดนซีและคอมไพล์โหนด เครื่องมือ Web และ Server ที่มีมาให้ เปิดใช้งานแล้วเข้าที่ `http://127.0.0.1:3000`; สำหรับเซิร์ฟเวอร์ระยะไกล ดูหัวข้อ “การเข้าถึงและข้อมูล” ด้านล่างเพื่อเข้าผ่าน SSH tunnel การเปิดครั้งแรกจะเริ่มต้นปลั๊กอินที่มีมาให้และเตรียมโฟลเดอร์ทำงาน `myProject`

คอนฟิก ปลั๊กอิน และไฟล์โปรเจกต์ถูกเก็บในวอลุ่มของ Docker ชื่อ `filmfrayloData` ซึ่งเมานต์ไว้ที่ `/app/data/` ในคอนเทนเนอร์ ชื่อวอลุ่มจริงจะมีคำนำหน้าของโปรเจกต์ Compose การหยุดหรือสร้างคอนเทนเนอร์ใหม่จะเก็บข้อมูลไว้ **ห้ามใช้ `docker compose down -v` เพราะคำสั่งนี้จะลบวอลุ่มข้อมูล**

```sh
docker compose logs -f filmfraylo  # ดูบันทึก
docker compose stop                # หยุดบริการ
docker compose start               # เริ่มอีกครั้ง
docker compose down                # ลบคอนเทนเนอร์ เก็บวอลุ่มข้อมูลไว้
```

หากต้องการเพิ่มโฟลเดอร์โปรเจกต์ คลิก “สร้างโฟลเดอร์ใหม่” ในหน้าต่าง “เลือกโฟลเดอร์ทำงานของเซิร์ฟเวอร์” หน้าต่างนี้ยังรองรับการเปลี่ยนชื่อและลบไฟล์หรือโฟลเดอร์ หรือจะสร้างผ่านบรรทัดคำสั่งขณะบริการทำงานอยู่ก็ได้:

```sh
docker compose exec filmfraylo mkdir -p /app/data/workspaces/newProject
```

การสำรองข้อมูลให้หยุดบริการก่อน คัดลอกเสร็จแล้วค่อยเริ่มใหม่:

```sh
docker compose stop
docker compose cp filmfraylo:/app/data ./filmfrayloBackup
docker compose start
```

</details>

### 3.3 การติดตั้งบนเซิร์ฟเวอร์

เหมาะสำหรับรัน Web และ Server บนเซิร์ฟเวอร์ Linux โดยตรง ตัวอย่างด้านล่างใช้ Ubuntu / Debian กับ [Bun 1.3.14](https://bun.sh/docs/installation) ตามที่โปรเจกต์กำหนด

<details>
<summary><strong>ขยายขั้นตอนการติดตั้งบนเซิร์ฟเวอร์</strong></summary>

ติดตั้งสภาพแวดล้อมการทำงาน:

```sh
sudo apt-get update
sudo apt-get install -y git curl unzip ffmpeg
curl -fsSL https://bun.com/install | bash -s "bun-v1.3.14"
export PATH="$HOME/.bun/bin:$PATH"
bun --version
```

โคลนซอร์สโค้ดและเริ่มทำงาน:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
bun install --frozen-lockfile

# คอมไพล์โหนด เครื่องมือ Web และ Server ที่มีมาให้
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

เมื่อเห็นข้อความ “บริการเริ่มทำงานสำเร็จ” จะเข้าถึง `http://127.0.0.1:3000` ได้จากเครื่องเซิร์ฟเวอร์เอง คำสั่งข้างต้นรันแบบเบื้องหน้า กด `Ctrl+C` เพื่อหยุด หากต้องการเริ่มอัตโนมัติเมื่อบูตและจัดการโปรเซส ดู [คู่มือติดตั้ง systemd ของ Bun](https://bun.sh/guides/ecosystem/systemd) โดยตั้งไดเรกทอรีทำงานเป็นไดเรกทอรีของรีโป คำสั่งเริ่มต้นเป็นพาธแบบเต็มของ Bun ตามด้วย `run start:server` และรันด้วยผู้ใช้ที่มีสิทธิ์อ่านเขียนไดเรกทอรีนั้น

</details>

### 3.4 การเข้าถึงและข้อมูล

- บริการปัจจุบันใช้พอร์ตคงที่ `3000` หน้าธุรกิจและ API ไม่มีระบบล็อกอินแยก หากติดตั้งบนเซิร์ฟเวอร์ โปรดจำกัดแหล่งเข้าถึงพอร์ต `3000` ด้วยไฟร์วอลล์หรือ security group; การเข้าถึงจากอินเทอร์เน็ตต้องตั้ง reverse proxy ที่มีการยืนยันตัวตน
- การใช้งานระยะไกลส่วนตัวสามารถรัน `ssh -N -L 3000:127.0.0.1:3000 username@server-address` บนคอมพิวเตอร์ของคุณ เปิดการเชื่อมต่อค้างไว้แล้วเข้า `http://127.0.0.1:3000` โดยไม่ต้องเปิดพอร์ต `3000` ของเซิร์ฟเวอร์สู่อินเทอร์เน็ต
- เมื่อติดตั้งโดยตรง คอนฟิก ปลั๊กอิน และเวิร์กสเปซจะถูกเก็บใน `data/` ของรีโป; หากติดตั้งด้วย Docker จะอยู่ใน `/app/data/` ของวอลุ่มข้อมูล โปรดเก็บรักษาให้ครบถ้วนเมื่อย้ายหรือสำรองข้อมูล หลังเข้าสู่หน้าเว็บ ให้เลือก `myProject` ในเวิร์กสเปซของเซิร์ฟเวอร์ และสร้างโฟลเดอร์ย่อยเพิ่มใน `workspaces/` เพื่อสร้างโปรเจกต์เพิ่มเติม
- ทั้งสองวิธีติดตั้งมี FFmpeg ของระบบมาด้วย ส่วน API Key ของบริการโมเดลยังต้องตั้งค่าในหน้าเว็บ
