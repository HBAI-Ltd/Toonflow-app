## 2. 🌟 Fitur Unggulan

Toonflow adalah platform kreasi AI sumber terbuka untuk drama pendek, komik animasi, dan video pendek yang menyatukan naskah, aset, serta klip video di satu kanvas tanpa batas.

| Kemampuan | Deskripsi |
| --- | --- |
| 🏠 **Penerapan lokal** | Simpan proyek dan aset di perangkat atau server Anda sendiri, dengan pilihan penerapan desktop, Android, Docker, dan server. |
| 🖼️ **Kanvas tanpa batas** | Tata naskah, karakter, adegan, dan klip video di kanvas yang sama. |
| 🔌 **MCP** | Hubungkan alat dan layanan eksternal melalui MCP. |
| 🧩 **Marketplace plugin** | Tambahkan node, alat, dan kemampuan kreatif melalui [Marketplace Plugin](https://api.toonflow.net/console/plugIn). |
| 🤖 **Agent terbuka** | Akses terbuka ke prompt, alat, dan A2A untuk menyesuaikan perilaku Agent serta berkolaborasi dengan Agent eksternal. |
| 🔧 **Integrasi model yang fleksibel** | Konfigurasikan API pihak ketiga atau hubungkan instans ComfyUI dan LLM lokal. |
| 🌐 **Dukungan multibahasa** | Mendukung 21 bahasa antarmuka. |

## 4. 🚀 Unduh dan Instal

### 4.1 Instalasi Aplikasi

| Sistem Operasi | GitHub |
| --- | --- |
| Windows | [Rilis](https://github.com/HBAI-Ltd/Toonflow-app/releases) |
| macOS | [Rilis](https://github.com/HBAI-Ltd/Toonflow-app/releases) |
| Android ARM64 | [Unduh APK](https://github.com/HBAI-Ltd/Toonflow-app/releases/latest) |

Aplikasi Android hanya mendukung perangkat ARM64. Unduh dan instal `toonflow-VERSION-android-arm64.apk` dari halaman rilis. Aplikasi menyertakan backend Bun lokal dan dapat berjalan mandiri. Anda juga dapat menggunakan Koneksi perangkat di halaman utama untuk memindai kode QR atau terhubung secara manual ke komputer atau backend yang telah mengaktifkan berbagi koneksi di jaringan lokal maupun internet.

Penginstal Windows mendeteksi dan memasang WebView2 secara otomatis. Jika aplikasi langsung tertutup setelah instalasi, unduh dan pasang runtime secara manual dari [halaman unduhan WebView2](https://developer.microsoft.com/microsoft-edge/webview2/).

Di macOS (Apple Silicon), seret Toonflow ke Applications lalu buka langsung. Tidak perlu menjalankan perintah terminal terlebih dahulu. Jika macOS menampilkan peringatan keamanan, ikuti langkah berikut secara berurutan.

<details>
<summary><strong>Jika Toonflow tidak dapat diinstal atau dibuka di macOS</strong></summary>

**1. Izinkan Toonflow di Privasi & Keamanan**

Jika muncul peringatan bahwa pengembang tidak dapat diverifikasi atau Apple tidak dapat memeriksa perangkat lunak berbahaya dalam aplikasi, coba buka Toonflow terlebih dahulu. Lalu masuk ke Pengaturan Sistem → Privasi & Keamanan, cari pesan bahwa Toonflow diblokir, klik Tetap Buka, dan konfirmasikan sesuai petunjuk. Lihat [petunjuk resmi Apple](https://support.apple.com/zh-cn/102445).

**2. Jika pembatasan karantina masih mencegah aplikasi dibuka, coba hapus atribut karantina**

Setelah memastikan bahwa aplikasi berasal dari halaman rilis resmi dan berada di Applications, jalankan perintah berikut di Terminal lalu coba buka kembali. Sesuaikan jalurnya jika nama aplikasi atau lokasi instalasi berbeda.

```bash
sudo xattr -rd com.apple.quarantine /Applications/toonflow.app
```

**3. Pilihan terakhir: izinkan sementara aplikasi dari mana saja**

Jika kedua cara sebelumnya tidak berhasil dan Anda memercayai sumber aplikasinya, coba jalankan:

```bash
sudo spctl --master-disable
```

Lalu buka Pengaturan Sistem → Privasi & Keamanan. Di bagian Keamanan, ubah “Izinkan aplikasi yang diunduh dari” menjadi “Di Mana Saja” jika opsi tersebut tersedia, lalu konfirmasikan sesuai petunjuk. Opsi yang tersedia dan dukungan perintah dapat berbeda antarversi macOS.

Tindakan ini melonggarkan pembatasan keamanan untuk semua aplikasi. Setelah selesai, kami menyarankan agar pengaturan dikembalikan ke “App Store dan pengembang teridentifikasi”.

</details>

Untuk petunjuk lebih lanjut, lihat [Panduan Pengguna](https://qcn7xdsqgc4z.feishu.cn/docx/RXFqdgR2Xo0dXZxGfd0cZCGgnwf).

### 4.2 Instalasi Docker

Instal Git, [Docker Engine](https://docs.docker.com/engine/install/), dan Docker Compose terlebih dahulu. Di Windows dan macOS, Anda dapat menggunakan Docker Desktop dalam mode kontainer Linux. Repositori ini menyertakan [Dockerfile](../../Dockerfile), [konfigurasi Compose](../../compose.yaml), dan [daftar pengecualian build](../../.dockerignore). Image dibangun dengan Bun 1.3.14 dan sudah menyertakan FFmpeg.

<details>
<summary><strong>Tampilkan langkah instalasi Docker</strong></summary>

Kloning kode sumber dan jalankan perintah berikut dari direktori utama repositori:

```sh
git clone https://github.com/HBAI-Ltd/Toonflow-app.git
cd Toonflow-app
docker compose up -d --build
```

Build pertama memasang dependensi dan membangun node, alat, Web, serta Server yang disertakan. Setelah berjalan, buka `http://127.0.0.1:3000`. Untuk host jarak jauh, gunakan terowongan SSH sebagaimana dijelaskan dalam bagian “Akses dan Data” di bawah. Saat pertama kali dijalankan, plugin bawaan diinisialisasi dan direktori kerja `myProject` disediakan.

Pengaturan, plugin, dan berkas proyek disimpan dalam volume bernama Docker `toonflowData`, yang dipasang di `/app/data/` di dalam kontainer. Nama volume sebenarnya menyertakan awalan proyek Compose. Menghentikan atau membangun ulang kontainer tidak menghapus data Anda. **Jangan gunakan `docker compose down -v`: perintah ini menghapus volume data.**

```sh
docker compose logs -f toonflow  # View logs
docker compose stop             # Stop the service
docker compose start            # Start it again
docker compose down             # Remove containers, retaining the data volume
```

Untuk menambahkan direktori proyek, klik “Folder Baru” di dialog “Pilih Direktori Kerja Server”. Dialog ini juga mendukung penggantian nama serta penghapusan berkas dan folder. Sebagai alternatif, buat direktori melalui baris perintah saat layanan sedang berjalan:

```sh
docker compose exec toonflow mkdir -p /app/data/workspaces/newProject
```

Untuk mencadangkan data, hentikan layanan terlebih dahulu, salin data, lalu jalankan kembali layanan:

```sh
docker compose stop
docker compose cp toonflow:/app/data ./toonflowBackup
docker compose start
```

</details>

### 4.3 Instalasi Server

Gunakan opsi ini untuk menjalankan Web dan Server langsung di server Linux. Contoh berikut menggunakan Ubuntu / Debian dan versi yang ditentukan proyek, yaitu [Bun 1.3.14](https://bun.sh/docs/installation).

<details>
<summary><strong>Tampilkan langkah instalasi server</strong></summary>

Instal lingkungan runtime:

```sh
sudo apt-get update
sudo apt-get install -y git curl unzip ffmpeg
curl -fsSL https://bun.com/install | bash -s "bun-v1.3.14"
export PATH="$HOME/.bun/bin:$PATH"
bun --version
```

Kloning kode sumber dan mulai layanan:

```sh
git clone https://github.com/HBAI-Ltd/Toonflow-app.git
cd Toonflow-app
bun install --frozen-lockfile

# Build bundled nodes, tools, Web, and Server
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

Ketika muncul “服务启动成功” (layanan berhasil dimulai), buka `http://127.0.0.1:3000` di server itu sendiri. Perintah di atas berjalan di latar depan; tekan `Ctrl+C` untuk menghentikannya. Untuk menjalankan layanan saat boot dan mengelola proses, lihat [panduan penerapan systemd Bun](https://bun.sh/guides/ecosystem/systemd). Atur direktori kerja ke direktori repositori dan perintah mulai ke jalur absolut Bun, diikuti dengan `run start:server`. Jalankan sebagai pengguna yang memiliki izin baca dan tulis untuk direktori tersebut.

</details>

### 4.4 Akses dan Data

- Layanan saat ini menggunakan port tetap `3000`. Antarmuka web dan API tidak memiliki autentikasi masuk tersendiri. Untuk instalasi server, batasi akses ke port `3000` melalui firewall atau grup keamanan. Akses publik memerlukan reverse proxy dengan autentikasi.
- Untuk akses jarak jauh pribadi, jalankan `ssh -N -L 3000:127.0.0.1:3000 username@server-address` di komputer Anda sendiri. Biarkan koneksi tetap terbuka, lalu kunjungi `http://127.0.0.1:3000`. Anda tidak perlu membuka port `3000` server ke internet publik.
- Pada instalasi langsung, pengaturan, plugin, dan ruang kerja secara bawaan disimpan dalam direktori `data/` repositori. Dengan Docker, semuanya disimpan di `/app/data/` di dalam volume data. Pertahankan seluruh direktori saat migrasi atau pencadangan. Setelah membuka halaman, pilih `myProject` di ruang kerja server. Buat subdirektori di dalam direktori `workspaces/` yang sesuai untuk proyek tambahan.
- Kedua metode instalasi sudah menyertakan FFmpeg sistem. Anda tetap perlu mengonfigurasi kunci API layanan model melalui antarmuka.
