FilmFraylo adalah alat kreasi AI untuk pembuat drama pendek, drama komik, dan video pendek. Tulis naskah dan storyboard, kelola aset karakter dan latar, serta hasilkan gambar dan video di kanvas tanpa batas. Dilengkapi model teks, gambar, video, dan audio dari platform model resmi FilmFraylo, serta dukungan deployment lokal dan Koneksi Perangkat.

## 1. 🌟 Keunggulan

FilmFraylo menyatukan naskah, aset, dan klip video dalam satu kanvas tanpa batas.

| Kemampuan | Penjelasan |
| --- | --- |
| 🏠 **Deployment lokal** | Proyek dan aset disimpan di perangkat atau server Anda sendiri; mendukung deployment desktop, Android, Docker, dan server. |
| 🖼️ **Kanvas tanpa batas** | Atur naskah, karakter, latar, dan klip video dalam satu kanvas. |
| 🔌 **MCP** | Hubungkan alat dan layanan eksternal melalui MCP. |
| 🤖 **Agent terbuka** | Prompt, alat, dan A2A terbuka; mendukung kustomisasi perilaku Agent dan kolaborasi eksternal. |
| 🧠 **Layanan model bawaan** | Platform model resmi FilmFraylo menyediakan model teks, gambar, video, dan audio; cukup konfigurasi API Key lalu langsung pakai. |
| 🌐 **Dukungan multibahasa** | Mendukung 21 bahasa antarmuka. |

### Cara membuat drama pendek dan drama komik AI dengan FilmFraylo

1. **Menulis naskah dan storyboard**: Susun cerita, pengaturan karakter, dan deskripsi shot di node teks; gunakan model bahasa untuk membantu berkarya, lalu tinjau dan revisi isinya.
2. **Menyiapkan aset karakter dan latar**: Impor gambar referensi, atau buat karakter, latar, dan gambar storyboard melalui node pembuatan gambar.
3. **Menghasilkan shot video**: Sambungkan teks dan referensi gambar, pilih model video dan mode pembuatan, lalu hasilkan klip video per shot.
4. **Pratinjau, penyusunan, dan unduhan**: Pratinjau dan atur gambar serta klip video di kanvas tanpa batas; unduh aset untuk diproses lebih lanjut sesuai kebutuhan.

Aset referensi, durasi video, resolusi, dan kemampuan audio yang didukung bergantung pada model yang dipilih.

### Pertanyaan umum

**Untuk tahap pembuatan apa saja FilmFraylo bisa dipakai dalam produksi drama pendek dan drama komik AI?**

FilmFraylo menyediakan node pembuatan teks, gambar, dan video untuk penulisan naskah dan storyboard, pembuatan aset karakter dan latar, pembuatan shot video, hingga pratinjau dan penataan aset. Kreator perlu meninjau dan menyesuaikan hasil; kemampuan pembuatan bergantung pada model yang dipilih.

**Apakah FilmFraylo gratis? Apakah pemanggilan model berbayar?**

FilmFraylo memakai lisensi open source MIT dan bisa Anda deployment sendiri. Pemanggilan model ditagih sesuai pemakaian oleh platform model resmi dan perlu konfigurasi API Key di aplikasi lebih dulu; biaya produksi pada contoh karya hanya berlaku untuk kasus itu, bukan harga tetap.

**Bisakah saya menghubungkan model saya sendiri?**

Versi saat ini sudah menyertakan platform model resmi, dengan model dari platform model resmi FilmFraylo; model pihak ketiga atau alur kerja ComfyUI lokal belum didukung.

## 3. 🚀 Unduhan dan instalasi

### 3.1 Instalasi aplikasi

| Sistem operasi | GitHub                                                       |
| -------- | ------------------------------------------------------------ |
| Windows  | [Release](https://github.com/zechau/filmfraylo-app/releases) |
| macOS    | [Release](https://github.com/zechau/filmfraylo-app/releases) |
| Android ARM64 | [Unduh APK](https://github.com/zechau/filmfraylo-app/releases/latest) |

Versi Android hanya mendukung perangkat ARM64; unduh dan pasang `filmfraylo-版本号-android-arm64.apk` dari halaman rilis. Ponsel sudah menyertakan backend Bun lokal dan bisa berjalan mandiri; Anda juga bisa memindai kode QR atau menyambung secara manual dari “Koneksi Perangkat” di beranda ke komputer atau backend jarak jauh yang sudah mengaktifkan berbagi (mendukung jaringan lokal dan internet).

Penginstal Windows otomatis mendeteksi dan memasang WebView2; jika setelah dipasang aplikasi terbuka lalu langsung tertutup, buka [halaman unduhan WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) untuk memasang runtime secara manual.

Di macOS (Apple Silicon), seret FilmFraylo ke “Aplikasi” lalu buka; tidak perlu menjalankan perintah Terminal lebih dulu. Jika muncul peringatan keamanan sistem, ikuti urutan berikut.

<details>
<summary><strong>Cara mengatasi macOS yang tidak bisa memasang atau membuka FilmFraylo</strong></summary>

**1. Izinkan FilmFraylo di “Privasi & Keamanan”**

Jika muncul pesan “Pengembang tidak dapat diverifikasi” atau “Apple tidak dapat memeriksa apakah aplikasi mengandung malware”, coba buka FilmFraylo lebih dulu, lalu buka “Pengaturan Sistem → Privasi & Keamanan”, temukan pemberitahuan bahwa FilmFraylo diblokir, klik “Tetap Buka”, dan konfirmasi sesuai petunjuk. Lihat [penjelasan resmi Apple](https://support.apple.com/zh-cn/102445).

**2. Jika masih tidak bisa dibuka karena pembatasan karantina sistem, coba hapus atribut karantina**

Pastikan aplikasi berasal dari halaman rilis resmi dan sudah ditempatkan di “Aplikasi”, lalu jalankan perintah berikut di Terminal dan buka kembali aplikasinya. Jika nama aplikasi atau lokasi pemasangan berbeda, sesuaikan jalurnya.

```bash
sudo xattr -rd com.apple.quarantine /Applications/FilmFraylo.app
```

**3. Langkah terakhir: sementara izinkan aplikasi dari mana saja**

Jika dua cara sebelumnya tidak berhasil dan sumber aplikasi sudah Anda yakini, coba jalankan di Terminal:

```bash
sudo spctl --master-disable
```

Lalu buka “Pengaturan Sistem → Privasi & Keamanan”; di bagian “Keamanan”, pilih “Di Mana Saja” pada “Izinkan aplikasi dari” (jika sistem menyediakan opsi ini), lalu konfirmasi sesuai petunjuk. Opsi dan dukungan perintah bisa berbeda antar versi macOS.

Tindakan ini melonggarkan batas keamanan untuk semua aplikasi. Setelah selesai, sebaiknya kembalikan sumber yang diizinkan ke “App Store dan pengembang tepercaya”.

</details>

### 3.2 Instalasi dengan Docker

Pasang Git, [Docker Engine](https://docs.docker.com/engine/install/), dan Docker Compose terlebih dahulu; di Windows / macOS bisa memakai mode kontainer Linux dari Docker Desktop. Repositori menyediakan [Dockerfile](./Dockerfile), [konfigurasi Compose](./compose.yaml), dan [aturan pengecualian build](./.dockerignore), dibangun di atas Bun 1.3.14 dengan FFmpeg di dalam image.

<details>
<summary><strong>Buka langkah instalasi Docker</strong></summary>

Setelah mengkloning kode sumber, jalankan di akar repositori:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
docker compose up -d --build
```

Build pertama akan memasang dependensi dan mengompilasi node, alat, Web, dan Server bawaan. Setelah berjalan, akses `http://127.0.0.1:3000`; untuk server jarak jauh, lihat bagian “Akses dan data” di bawah untuk masuk lewat SSH tunnel. Peluncuran pertama akan menginisialisasi plugin bawaan dan menyediakan direktori kerja `myProject`.

Konfigurasi, plugin, dan file proyek disimpan di volume bernama `filmfrayloData` milik Docker yang di-mount ke `/app/data/` pada kontainer. Nama volume sebenarnya memiliki awalan proyek Compose; menghentikan atau membuat ulang kontainer tetap menyimpan data, **jangan gunakan `docker compose down -v` karena perintah itu menghapus volume data**.

```sh
docker compose logs -f filmfraylo  # Lihat log
docker compose stop                # Hentikan layanan
docker compose start               # Jalankan lagi
docker compose down                # Hapus kontainer, simpan volume data
```

Untuk menambah direktori proyek, klik “Folder Baru” di dialog “Pilih Direktori Kerja Server” pada halaman. Dialog juga mendukung penggantian nama dan penghapusan file serta folder. Anda juga bisa membuatnya lewat baris perintah saat layanan berjalan:

```sh
docker compose exec filmfraylo mkdir -p /app/data/workspaces/newProject
```

Saat mencadangkan, hentikan layanan dulu, lalu jalankan lagi setelah penyalinan selesai:

```sh
docker compose stop
docker compose cp filmfraylo:/app/data ./filmfrayloBackup
docker compose start
```

</details>

### 3.3 Instalasi di server

Cocok untuk menjalankan Web dan Server langsung di server Linux. Contoh berikut memakai Ubuntu / Debian dengan [Bun 1.3.14](https://bun.sh/docs/installation) sesuai ketentuan proyek.

<details>
<summary><strong>Buka langkah instalasi server</strong></summary>

Pasang lingkungan runtime:

```sh
sudo apt-get update
sudo apt-get install -y git curl unzip ffmpeg
curl -fsSL https://bun.com/install | bash -s "bun-v1.3.14"
export PATH="$HOME/.bun/bin:$PATH"
bun --version
```

Kloning kode sumber dan jalankan:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
bun install --frozen-lockfile

# Kompilasi node, alat, Web, dan Server bawaan
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

Setelah muncul pesan “layanan berhasil dijalankan”, akses `http://127.0.0.1:3000` dari server itu sendiri. Perintah di atas berjalan di latar depan; tekan `Ctrl+C` untuk berhenti. Untuk mulai otomatis saat boot dan pengelolaan proses, lihat [panduan deployment systemd dari Bun](https://bun.sh/guides/ecosystem/systemd); atur direktori kerja ke direktori repositori, perintah mulai menjadi path absolut Bun ditambah `run start:server`, dan jalankan sebagai pengguna yang punya akses baca-tulis ke direktori itu.

</details>

### 3.4 Akses dan data

- Layanan saat ini memakai port tetap `3000`; halaman bisnis dan API tidak punya autentikasi login terpisah. Saat memasang di server, batasi sumber akses port `3000` lewat firewall atau security group; akses dari internet perlu reverse proxy dengan autentikasi.
- Untuk pemakaian pribadi jarak jauh, jalankan `ssh -N -L 3000:127.0.0.1:3000 username@server-address` di komputer Anda, biarkan koneksi terbuka, lalu buka `http://127.0.0.1:3000`; port `3000` server tidak perlu dibuka ke internet.
- Pada instalasi langsung, konfigurasi, plugin, dan workspace secara default tersimpan di `data/` repositori; pada instalasi Docker, di `/app/data/` dalam volume data. Jaga semuanya utuh saat migrasi atau pencadangan. Setelah masuk halaman, pilih `myProject` di workspace server; buat subdirektori baru di `workspaces/` untuk menambah proyek.
- Kedua cara instalasi sudah menyertakan FFmpeg sistem. API Key layanan model tetap perlu dikonfigurasi di halaman.
