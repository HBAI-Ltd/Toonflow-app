## 1. 🌟 Ключевые возможности

FilmFraylo объединяет сценарии, материалы и видеоклипы на одном бесконечном холсте.

| Возможность | Описание |
| --- | --- |
| 🏠 **Локальное развёртывание** | Проекты и материалы хранятся на вашем устройстве или сервере; поддерживается развёртывание на десктопе, Android, в Docker и на сервере. |
| 🖼️ **Бесконечный холст** | Организуйте сценарии, персонажей, сцены и видеоклипы на одном холсте. |
| 🔌 **MCP** | Подключение внешних инструментов и сервисов через MCP. |
| 🤖 **Открытый Agent** | Открытые промпты, инструменты и A2A: настраивайте поведение Agent и внешнее взаимодействие. |
| 🧠 **Встроенный сервис моделей** | Официальная платформа моделей FilmFraylo предоставляет текстовые, графические, видео- и аудиомодели: настройте API Key и сразу приступайте к работе. |
| 🌐 **Мультиязычность** | Поддерживается 21 язык интерфейса. |

### Как создавать AI-мини-сериалы и комиксы с помощью FilmFraylo

1. **Пишите сценарии и раскадровки**: собирайте историю, образы персонажей и описания кадров в текстовых узлах, используйте языковые модели как помощника в творчестве, затем проверяйте и правьте содержимое.
2. **Готовьте материалы персонажей и сцен**: импортируйте референсные изображения или создавайте изображения персонажей, сцен и раскадровок с помощью узлов генерации изображений.
3. **Генерируйте видеокадры**: подключайте текстовые и графические референсы, выбирайте видеомодель и режим генерации, создавайте видеоклипы кадр за кадром.
4. **Просматривайте, упорядочивайте и скачивайте**: просматривайте и организуйте изображения и видеоклипы на бесконечном холсте, скачивайте материалы и продолжайте работу по мере необходимости.

Поддерживаемые референсные материалы, длительность видео, разрешение и работа со звуком зависят от выбранной модели.

### Частые вопросы

**Для каких этапов создания AI-мини-сериалов и комиксов подходит FilmFraylo?**

FilmFraylo предоставляет узлы генерации текста, изображений и видео: они подходят для работы над сценарием и раскадровкой, подготовки материалов персонажей и сцен, генерации видеокадров, а также просмотра и упорядочивания материалов. Автору нужно проверять и корректировать содержимое; конкретные возможности генерации зависят от выбранной модели.

**FilmFraylo бесплатен? Нужно ли платить за вызовы моделей?**

FilmFraylo распространяется по открытой лицензии MIT, его можно развернуть самостоятельно. Вызовы моделей тарифицируются официальной платформой моделей по фактическому использованию; сначала нужно настроить API Key в приложении. Стоимость производства в примере работы относится только к этому случаю и не является фиксированной ценой.

**Можно ли подключить собственные модели?**

В текущей версии встроена официальная платформа моделей FilmFraylo, которая предоставляет модели; подключение сторонних моделей или локальных рабочих процессов ComfyUI пока не поддерживается.

<details>
<summary><strong>Что делать, если macOS не позволяет установить или открыть FilmFraylo</strong></summary>

**1. Разрешите FilmFraylo в «Конфиденциальность и безопасность»**

Если появилось сообщение «не удалось проверить разработчика» или «Apple не может проверить приложение на наличие вредоносного ПО», сначала попробуйте открыть FilmFraylo, затем перейдите в «Системные настройки → Конфиденциальность и безопасность», найдите уведомление о блокировке FilmFraylo, нажмите «Всё равно открыть» и подтвердите по подсказкам. Подробнее см. [официальную инструкцию Apple](https://support.apple.com/zh-cn/102445).

**2. Если из-за системного карантина приложение всё ещё не открывается, попробуйте снять атрибут карантина**

Убедитесь, что приложение получено со страницы официального релиза и помещено в «Программы», затем выполните в терминале следующую команду и попробуйте открыть его снова. Если имя приложения или место установки отличаются, измените путь.

```bash
sudo xattr -rd com.apple.quarantine /Applications/FilmFraylo.app
```

**3. Крайняя мера: временно разрешить приложения из любого источника**

Если первые два способа не помогли и вы уверены в надёжности источника приложения, можно выполнить в терминале:

```bash
sudo spctl --master-disable
```

Затем откройте «Системные настройки → Конфиденциальность и безопасность» и в разделе «Безопасность» для параметра «Разрешить приложения, загруженные из» выберите «Любого источника» (если система предоставляет такой вариант), и подтвердите по подсказкам. Доступные варианты и поддержка команд могут различаться в разных версиях macOS.

Эта операция ослабляет ограничения безопасности для всех приложений. После завершения рекомендуется вернуть разрешённый источник в «App Store и подтверждённые разработчики».

### 3.2 Установка через Docker

Сначала установите Git, [Docker Engine](https://docs.docker.com/engine/install/) и Docker Compose; в Windows / macOS можно использовать режим контейнеров Linux в Docker Desktop. В репозитории есть [Dockerfile](./Dockerfile), [конфигурация Compose](./compose.yaml) и [правила исключения при сборке](./.dockerignore); сборка основана на Bun 1.3.14, образ включает FFmpeg.

<details>
<summary><strong>Разверните шаги установки Docker</strong></summary>

Склонируйте исходный код и выполните в корне репозитория:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
docker compose up -d --build
```

При первой сборке устанавливаются зависимости и компилируются встроенные узлы, инструменты, Web и Server. После запуска откройте `http://127.0.0.1:3000`; для удалённого хоста подключайтесь через SSH-туннель, как описано ниже в разделе «Доступ и данные». При первом запуске инициализируются встроенные плагины и создаётся рабочий каталог `myProject`.

Настройки, плагины и файлы проектов хранятся в именованном томе Docker `filmfrayloData`, смонтированном в контейнере по пути `/app/data/`. Фактическое имя тома включает префикс Compose-проекта; остановка или пересоздание контейнера сохраняет данные, **не используйте `docker compose down -v` — эта команда удаляет том с данными**.

```sh
docker compose logs -f filmfraylo  # Просмотр журнала
docker compose stop                # Остановка сервиса
docker compose start               # Повторный запуск
docker compose down                # Удаление контейнеров с сохранением тома данных
```

Чтобы добавить каталог проекта, нажмите «Новая папка» в диалоге «Выбор рабочего каталога сервера» на странице. Диалог также поддерживает переименование и удаление файлов и папок. Можно создать каталог и из командной строки, пока сервис работает:

```sh
docker compose exec filmfraylo mkdir -p /app/data/workspaces/newProject
```

Для резервной копии сначала остановите сервис, затем скопируйте данные и снова запустите его:

```sh
docker compose stop
docker compose cp filmfraylo:/app/data ./filmfrayloBackup
docker compose start
```

</details>

### 3.3 Установка на сервере

Подходит для запуска Web и Server напрямую на Linux-сервере. Ниже приведён пример для Ubuntu / Debian с использованием указанного в проекте [Bun 1.3.14](https://bun.sh/docs/installation).

<details>
<summary><strong>Разверните шаги установки на сервере</strong></summary>

Установите среду выполнения:

```sh
sudo apt-get update
sudo apt-get install -y git curl unzip ffmpeg
curl -fsSL https://bun.com/install | bash -s "bun-v1.3.14"
export PATH="$HOME/.bun/bin:$PATH"
bun --version
```

Склонируйте исходный код и запустите сервис:

```sh
git clone https://github.com/zechau/filmfraylo-app.git
cd filmfraylo-app
bun install --frozen-lockfile

# Сборка встроенных узлов, инструментов, Web и Server
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

Увидев сообщение «服务启动成功» (сервис успешно запущен), откройте `http://127.0.0.1:3000` на самом сервере. Приведённые команды выполняются на переднем плане, для остановки нажмите `Ctrl+C`. Для автозапуска при загрузке и управления процессом см. [руководство по развёртыванию Bun в systemd](https://bun.sh/guides/ecosystem/systemd): укажите рабочим каталогом каталог репозитория, командой запуска — абсолютный путь к Bun плюс `run start:server`, и запускайте от пользователя с правами чтения и записи этого каталога.

</details>

### 3.4 Доступ и данные

- Сервис использует фиксированный порт `3000`, а страницы и API не имеют отдельной аутентификации при входе. При установке на сервере ограничьте источники доступа к порту `3000` через брандмауэр или группу безопасности; для доступа из интернета требуется обратный прокси с аутентификацией.
- Для личного удалённого использования выполните на своём компьютере `ssh -N -L 3000:127.0.0.1:3000 имя-пользователя@адрес-сервера`, оставьте соединение открытым и откройте `http://127.0.0.1:3000`; открывать порт `3000` сервера в интернет не нужно.
- При прямой установке настройки, плагины и рабочие области по умолчанию хранятся в каталоге `data/` репозитория; при установке через Docker — в `/app/data/` внутри тома данных. При переносе или резервном копировании сохраняйте их полностью. После входа на страницу выберите `myProject` в рабочей области сервера; дополнительные проекты можно создавать как подкаталоги в соответствующем `workspaces/`.
- Оба способа установки включают системный FFmpeg. API Key сервиса моделей по-прежнему настраивается на странице.
