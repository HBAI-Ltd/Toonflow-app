01 · 服务、模型与鉴权

站点根地址：https://api.safillu.com。本手册覆盖当前线上对外 AI 调用接口、兼容协议和任务读取接口；后台账号、渠道、充值及管理员 API 不属于此接入手册。

核对日期：2026-10-12（Asia/Shanghai）。线上 5 个启用渠道提供以下 4 个模型。所有示例使用自己的站点 API Token。

Content-Type: application/json

GET/HEAD 不需要请求体。创建、查询和鉴权下载使用同一账号的有效令牌，令牌的模型、分组、IP 等限制仍适用。把密钥放在环境变量中；本分发文档不嵌入有效密钥。

GET /v1/models 返回当前令牌模型列表。列表中的 supported_endpoint_types 属于主机标签，不能据此推断每个模型都支持聊天、同步生图或语音协议。实际调用路径以本手册为准。

curl "https://api.safillu.com/v1/models" -H "Authorization: Bearer $SAFILLU_API_KEY"

04 · Z-Image 文生图

POST /runninghub-image/v1/generations · model=Z-Image-Base · $0.02/张。

字段类型必填取值与说明
modelstring是固定 Z-Image-Base
promptstring是最长 12000
negative_promptstring否最长 12000；默认
ratiostring否1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 3:2 / 2:3 / 21:9；默认 1:1
resolutionstring否1K / 2K；默认 1K；长边为 1024 或 2048 像素；短边按比例四舍五入到 16 的倍数
ninteger否最小 1；最大 4；默认 1
seedinteger否最小 0；最大 9007199254740991

prompt 为非空字符串；正负提示词分别最多 12000 UTF-16 code units。resolution 不区分大小写。1K 长边 1024、2K 长边 2048；短边按比例四舍五入到 16 的倍数。例：1K 16:9 → 1024×576；2K 9:16 → 1152×2048。非空负面提示词使用 CFG=2，否则 CFG=1；负面提示词不保证绝对排除指定内容。

{
  "model": "Z-Image-Base",
  "prompt": "海边灯塔，温暖夕阳，海浪，自然细节，电影摄影",
  "negative_prompt": "文字，水印，模糊，低质量",
  "ratio": "16:9",
  "resolution": "1K",
  "n": 2,
  "seed": 42
}
{
  "status": "pending",
  "task_id": "task_example"
}

查询：GET /runninghub-image/v1/tasks/{task_id}。

{
  "task_id": "task_example",
  "status": "success",
  "image_count": 2,
  "data": [
    {
      "url": "https://cdn.example/1.png",
      "format": "png"
    },
    {
      "url": "https://cdn.example/2.png",
      "format": "png"
    }
  ]
}

pending 继续查询；failed 时读取 error。提交按 n 预扣，成功后按有效成品张数结算。此插件不支持任意工作流/节点透传，也没有挂载 /v1/images/generations。下载 data[].url 时不附带本站密钥。

05 · 音色设计与语音生成

POST /runninghub-audio/v1/voice-design · model=Qwen3-TTS-VoiceDesign · $0.05/次。

字段类型必填取值与说明
modelstring是固定 Qwen3-TTS-VoiceDesign
textstring是最长 4000；要朗读的文本；最长 4000 UTF-16 code units
voice_promptstring是最长 4000；音色、语气、口音和风格描述；最长 4000 UTF-16 code units
speednumber否最小 0.5；最大 2；默认 0.9
seedinteger否最小 0；最大 9007199254740991；可选随机种子；省略时按任务 ID 生成。0 有效；相同种子不保证跨环境完全一致

text 是要朗读的文本，voice_prompt 是音色/语言/情绪描述；两者均非空且最多 4000 UTF-16 code units。它直接生成语音，不返回可持久复用的 voice_id。当前不支持音频克隆上传或流式语音。工作流生成长度仍受模型的 2048 token 上限约束，长文本应按完整句子拆分。

{
  "model": "Qwen3-TTS-VoiceDesign",
  "text": "你好，欢迎来到影幻。愿温暖的声音，陪你开启美好的一天。",
  "voice_prompt": "温柔自然的成年女声，标准普通话，咬字清晰，语气亲切放松",
  "speed": 0.9,
  "seed": 42
}

提交返回 pending 和 task_id，查询/下载流程与下节 BGM 共用。

06 · BGM 纯音乐生成与音频查询

POST /runninghub-audio/v1/bgm · model=YuE2-BGM · $0.05/次。

字段类型必填取值与说明
modelstring是固定 YuE2-BGM
promptstring是最长 4000；音乐风格描述，建议明确乐器、氛围和 no vocals
durationinteger否最小 1；最大 120；默认 10；请求的音乐最大时长，单位秒；不是实际成品时长保证
seedinteger否最小 0；最大 9007199254740991；可选随机种子；省略时按任务 ID 生成。0 有效；相同种子不保证跨环境完全一致

prompt 非空且最多 4000 UTF-16 code units，建议描述乐器、速度、风格、氛围和 no vocals。duration 是请求的音乐最大时长，默认 10 秒，整数 1～120；最终时长以成品为准，不按秒收费。接口只返回去人声处理后的最终节点音频。

{
  "model": "YuE2-BGM",
  "prompt": "Instrumental chill pop with warm electric piano, gentle drums and soft bass. Relaxed, bright and peaceful, no vocals.",
  "duration": 10,
  "seed": 42
}

共用查询

GET /runninghub-audio/v1/tasks/{task_id}

{
  "task_id": "task_example",
  "status": "success",
  "audio_url": "https://cdn.example/audio.mp3",
  "format": "mp3"
}

pending 表示未完成；failed 带 error 字段。音色设计实测输出 MP3，BGM 实测 FLAC；客户端以 format 为准，可能值包含 mp3、wav、flac、ogg、m4a、aac。下载 audio_url 时不附带本站密钥。两个模型各自每次成功收费 $0.05；失败由主机执行退款流程。

7.1 旧版 tfRouter：HTTP(S) 素材

提交 POST /v1/video/generateVideo，查询 POST /v1/video/getVideoStatus，提交/查询的响应封装与新版相同。插件 tfrouter-h3 1.0.0。请求字段同新版，但遵守下面差异。

能力新版 /tfrouter-frames/v1旧版 /v1/video
媒体输入完整 Base64 Data URLHTTP(S) 文件直链，最长 16384 字符，不带账号密码
参考容量5 图 + 3 音频 + 1 视频2 图 + 1 音频 + 1 视频，最多 4 文件
首尾帧必须一对允许只有首帧；尾帧必须有首帧
分辨率参考模式 768P / 1080P / 2K；首尾帧无 1080P768P / 2K
adaptive仅首尾帧模式可用有图片或视频时可用且为默认；否则默认 16:9
{
  "model": "MiniMax-H3",
  "prompt": "保持人物外观，镜头缓慢推进",
  "duration": 5,
  "resolution": "768p",
  "metadata": {
    "ratio": "16:9",
    "references": [
      {
        "role": "reference_image",
        "type": "image_url",
        "image_url": {

7.3 Responses 协议

POST /v1/responses 同样仅用于 MiniMax-H3 视频，媒体能力同 Video 协议。提示词改为 input，参数为 seconds、size、metadata。input 可为字符串，或消息数组中的 input_text / input_image。媒体必须使用可访问的 HTTP(S) 直链。

{
  "model": "MiniMax-H3",
  "input": "日落海岸，海浪自然翻涌，无字幕",
  "seconds": 5,
  "size": "768P",
  "metadata": {
    "ratio": "16:9"
  },
  "background": true,
  "stream": false
}

推荐 background=true、stream=false，立即保存返回的 id（resp_ 前缀）及 metadata.task_id，然后 GET /v1/responses/{response_id}。不传 background 且 stream=false 为同步等待；stream=true 为 SSE，客户端处理 response.created、response.in_progress、response.output_text.delta、response.completed / response.failed 等事件。流式是任务进度和最终文字输出，不是逐帧视频传输。

{
  "id": "resp_example",
  "object": "response",
  "status": "queued",
  "background": true,
  "output": [],
  "metadata": {
    "task_id": "task_example",
    "retrieval_path": "/v1/responses/resp_example"
  }
}

成功时 status=completed，视频标签在 output[].content[] 的 output_text.text 内；其 src 指向站点成品接口。不要直接把其他插件的 task_ ID 改成 resp_ 来查询。同步连接超时或 SSE 断开不表示服务端任务取消；保存已收到的任务 ID，继续查询。

7.4 通用插件提交

POST /v1/tasks/{plugin_key} 是保留的驱动入口，可使用 hailuo、tfrouter-h3、tfrouter-h3-frames、runninghub-audio、runninghub-image。除 hailuo 外，各插件的请求体同各自原生生成请求；hailuo 使用 model/prompt/duration/resolution/metadata，不是 Responses 的 input 或 Video 的 seconds。音频插件根据 model 选择语音或 BGM。生成仍计费。

{
  "id": "task_example",
  "task_id": "task_example",
  "status": "queued",
  "model": "Z-Image-Base",
  "created_at": 1791770000
}

此入口跳过原生解码与响应渲染，建议新集成选用各模型的原生接口。通用提交后用第 8 节通用状态读取；音频/图片成品仍从各自原生查询获取。

H3 成品

GET /v1/tasks/{task_id}/artifacts 返回 artifacts 列表；H3 当前键名为 video。直接使用如下固定站点地址下载：

curl --fail-with-body "https://api.safillu.com/v1/tasks/$TASK_ID/artifacts/video/content" -H "Authorization: Bearer $SAFILLU_API_KEY" --output result.mp4

同路径支持 HEAD。content 成功返回二进制，不是 JSON。该代理不提供永久归档；上游失效后可能无法再下载。

线上现状：artifacts[].content_url 可能以 http://localhost:3000 开头。不要原样交给外部客户端；按上面固定域名和 task_id 构造下载地址并携带 Bearer。短期签名链接属于访问凭据，不要写进公开文档或日志。

图片与音频

目前没有注册 artifacts：图片读取 data[].url，音频读取 audio_url。直接下载这些上游链接，不把 safillu API Key 发送给上游域名。及时保存文件，URL 有效期没有永久保证。

10 · 可直接使用的示例与客户端

附件 examples/ 有图片、语音、BGM、H3 文生、URL、Video、Responses 的请求文件；URL 例子的 your-cdn.example 必须替换成可用文件直链。requests.http 可在支持 HTTP 文件的编辑器中使用；openapi.json 可导入 Apifox/Postman。

Python 客户端仅用标准库，默认不会提交请求；只有执行 submit 才生成并计费。API Key 从 SAFILLU_API_KEY 环境变量读取；服务地址固定为本手册站点。客户端不自动重试提交，并用独占创建方式保存提交回执。

# Bash
export SAFILLU_API_KEY="你的站点令牌"
python client.py submit image examples/image.json --receipt image-task.json
python client.py wait image-task.json --output image-result.json
python client.py download image-result.json --directory downloads

# voice / bgm / h3 / h3-url / video / responses 也可作为 submit 的类型
python client.py submit voice examples/voice.json --receipt voice-task.json
# PowerShell
$env:SAFILLU_API_KEY="你的站点令牌"
python client.py submit bgm examples/bgm.json --receipt bgm-task.json
python client.py wait bgm-task.json --output bgm-result.json
python client.py download bgm-result.json --directory downloads

wait 达到等待上限后保留回执，可以再次 wait 同一文件。submit 失败不会自动创建新任务；receipt 文件已存在时拒绝提交。Responses 客户端要求 background=true 且 stream=false，便于统一轮询。

11 · 错误处理与兼容限制

现象处理
400检查 model、字段类型、范围、素材 MIME、模式组合和路由是否匹配
401 / 403检查令牌有效性、模型/分组/IP 权限和任务所属账号
404确认任务 ID、协议入口、账号；使用创建返回的 ID
413缩小 Base64 素材或核对反代请求体限制
429 / 5xx查询可退避；提交结果不明时先查任务，避免重复生成
HTTP 200 但 failed / error按业务错误处理，不能只判断 HTTP 状态
GET /v1/models/MiniMax-H3 返回 model_not_found当前单模型详情未正确覆盖自定义模型；使用 GET /v1/models
tfRouter 任务拿到 /v1/videos 查询报 500任务插件未声明 openai_video；使用匹配的 tfRouter 查询或通用状态
音频/图片调用 /v1/audio/speech 或 /v1/images/generations当前模型没有声明这些协议；用本文的原生路径
成品 URL 以 localhost 开头使用固定 api.safillu.com 成品代理路径；见第 8 节

错误封装会随路由和网关层不同：H3 原生常见 status=failed/data.failReason；音频/图片校验可能为 error 对象；任务终态 failed 的 error 是字符串。客户端保留 HTTP 状态、任务 ID 和经脱敏的错误文本。
