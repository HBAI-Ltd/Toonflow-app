# 视频生成节点

根据提示词和参考素材生成视频，支持所选模型提供的文生视频、单图、首尾帧或混合参考模式。

## 输入与输出

- 输入支持文本、图片、视频和音频，实际可用的素材组合取决于模型与生成模式。
- 输出生成的视频；播放器还能将当前帧、首帧或尾帧截取为图片节点。

## 使用方法

1. 选中节点，选择视频模型；没有模型时先在设置中添加视频模型。
2. 输入动作、运镜和声音要求，按需连接参考素材并调整引用顺序。
3. 打开生成设置，选择模式、时长、分辨率和画面比例；模型允许时可切换“生成音频”。
4. 使用首尾帧模式时，图片按引用顺序分配；“首帧可选”模式仅有一张图片时，该图片作为尾帧。
5. 点击“生成视频”，需要中止时点击“停止生成”。
6. 完成后可播放、拖动进度、调整音量，或从上方下载和全屏预览。

截帧需要启用图片节点。时长与分辨率选项随模型变化，通用画面比例的实际支持范围由供应商决定。

## 视频编辑替换清单

Agent 可通过 `getConfig` 读取完整 `references` 引用表，再用 `setEditingPlan` 保存原视频、替换对象及时间段、目标素材和保留条件。清单随画布保存，在节点提示词下方展开查看；可通过“清除清单”或 `setEditingPlan({ plan: null })` 清除。普通生成不要求填写清单。

清单每项会自动加入最终 `generationPrompt`，提示词只需补充其他要求。`setPrompt` 会立即将有效的 `{{ref N}}` 绑定为稳定引用，排序后仍指向同一来源。引用移除、素材路径或类型变化、复制节点后，须重新核对并保存清单；同路径覆盖文件无法仅凭引用检测，仍需重新检查内容。

`getConfig` 返回 `editingPlanError`、`promptError` 及实际 `generationPrompt`；错误未解决时不会提交生成。替换清单需要混合参考模式，官方 Seedance 2.5 还须选择“视频编辑（edit）”。官方素材的 `ready: null` 表示状态由服务端在提交时审核，不能当作已通过审核。清单检查只校验结构、引用和配置，不代表视频替换效果已验收。
