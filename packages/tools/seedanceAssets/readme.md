# 官方肖像素材库

本工具对接火山方舟私域真人人像素材库，支持创建真人认证链接、查询素材组与素材、上传已获授权的素材，以及将已就绪素材绑定到火山方舟视频生成节点。真人须本人完成官方认证；素材在官方处理为 Active 后才能用于生成。

在插件设置中填写有对应方舟项目权限的 Access Key ID、Secret Access Key 和项目名称。认证完成后跳转的回调地址需可访问；认证会话只保存在服务进程内，30 分钟后失效，服务重启后需重新发起。上传工作区文件须先安装、启用和配置「阿里云 OSS」插件，本工具使用其 HTTPS 签名地址向方舟提交素材，产生 OSS 存储和流量消耗；本工具不自动删除任何远端文件或素材。

官方会在认证完成后的回调地址附加认证参数；请使用自己控制或信任的地址，不要将包含认证参数的完整回调地址复制到对话中。认证原始链接仅保存在服务端会话中，通过当前工作区的工具卡片打开，不写入 Agent 工具结果。

视频推理使用的接入点、素材库和配置的项目名称需要一致。图片须小于 30 MB，音频不超过 15 MB，工作区视频不超过 100 MB；格式、尺寸、时长及人像审核以官方校验为准。已有公网 URL 可直接提交给官方。素材入库是异步操作，使用 getAsset 查询处理状态。OSS 上传失败时先核对 OSS 对象；方舟素材提交结果未知时先在方舟控制台核对，不要立即重复入库。

选择素材只设置视频节点的引用，不触发视频生成；该操作会替换目标节点整组官方素材引用。工具不提供删除功能。
