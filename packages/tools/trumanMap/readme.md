# 白模预演TrumanMap

在白模预演中，素材库没有合适的物件时，AI 可以按你的描述制作新的三维模型，并根据画面反复修改。

## 使用方式

在白模预演场景编辑器的对话中描述想要的物件，例如：“做一个带雨棚的路边报刊亭”。AI 会生成模型、查看效果并调整，满意后放进场景。

首次使用需要联网下载建模引擎，服务端需要 Node.js 22.2 及以上。

## 说明

- 生成的模型保存在工作区的 `assets/trumanMap/kiln/` 目录，不会覆盖或删除已有作品。
- 单个模型不超过 5 万个三角形，过于复杂的物件需要简化或拆分。
- 建模引擎 Kiln 采用 MIT 许可（Copyright Matthew Kissinger），在首次使用时下载，不随插件打包。
