# 脚本与口播

S1 非叙事类内容的方法：宣传片、广告、知识解说、纪实与活动、包装类片子的脚本怎么写。它们没有"人物被逼着做选择"的主线，靠的是**一句主张 + 一条看得见的证据链**。

本文管所有非叙事类共用的写法；有剧情冲突的段落（品牌微短剧、情景广告）另按剧作方法写，各片型的段落结构与时长占比也不在本文。

## 一、先写一句话

动笔前写出这一句，写不出不进脚本：

| 片型 | 这一句是什么 | 判据 |
|---|---|---|
| 宣传 | 我们干成过哪件事 / 你为什么该来 | 看完能说出"这家（这座城、这个岗位）干成过什么" |
| 广告 | 你为什么现在就该买 / 点 | 看完能说出一个具体的买点，而不是"挺好的" |
| 知识 | 一条可转述的因果 / 一个能照做的步骤 | 看完能用自己的话讲给第三个人 |
| 纪实 | 这件事真实发生过，它意味着什么 | 看完记得住一个人、一个瞬间 |
| 包装 | 让人记住的一个画面或一个节奏 | 关掉之后脑子里还剩一个画面 |

**只准一件。** 用户想说三件，先让他挑一件当主张，其余降成证据或切片。一条片说三件事，观众一件都记不住。

## 二、证据链：每个说法配一个可拍载体

- **形容词测试**：每个形容词后面必须跟一个能拍到的东西。说"研发强"，拍实验室和工程师的手；说"好吸收"，拍溶解的过程。配不上载体的形容词删掉，删完画面仍成立才算过。
- **证据优先于美感**：先保证"这个能力被看见"，再谈光比与运镜。一个真实的交付现场，胜过十秒航拍大楼。
- **数字带出处和年份**，全片口径一致；拿不到出处的数字不写。"研究表明"不带来源，就是空引。
- **相关不写成因果**："喝了以后好了"不等于"喝了所以好了"。

把证据列成表再写稿，表填不满说明还没想清楚：

| 说法 | 载体（拍什么） | 来源 / 真实素材 | 放在第几秒 |
|---|---|---|---|

## 三、开头与结尾

**开头三秒给结果、问题或反常**，不铺垫：

- 不用 logo 开场、大楼航拍、城市空镜、"大家好今天聊聊"。
- 给一个具体结果（一条下线产品、一个交付现场），或一个真实问题（"你家的汤其实没多少钙"），或一个反常画面。
- 背景信息压到后面一句带过；只有自己关心的信息（成立年份、荣誉墙）不进前二十秒。

**结尾只做一件事**：给一个具体行动（联系、到店、下单、报名、关注），或一句能被转述的结论。不加"谢谢观看"，不把全片再念一遍。

## 四、写给耳朵的稿

口播和旁白是听的，不是读的：

- 一句一个意思，短句；能念出口，不写书面长句。
- 中文语速按每秒 4–5 字估，留出换气；一句超过 25 字先试读。
- 术语第一次出现，紧跟一句白话。
- **旁白说为什么，画面说是什么**，两边不重复。旁白说"我们的工艺更稳"，画面给三次同样的焊点；不要旁白和画面同时念"工艺"。
- 真人出镜口播：一句台词一条，方便改口型、换句。
- **采访不写稿**：给受访者三个问题，让他用自己的话说，剪辑时留口音和停顿。背出来的稿子一听就是演的。

## 五、画面分工：真实的拍，生成的补

非叙事片的可信度来自真实。先分清每个镜头的来源：

| 来源 | 用在 | 不用在 |
|---|---|---|
| 实拍 / 用户提供的真实素材 | 真实的人、场所、产品、事件、数据现场 | — |
| 生成 | 空镜、氛围、示意、原理动画、转场、包装 | 冒充真实存在的员工、客户、当事人、现场 |
| 图形 | 数据图表、字幕卡、流程图、标识 | 代替本该被拍到的证据 |

**红线**：不用生成的人脸冒充真实的人；真实素材不够时列补拍清单，交给用户去拍，不虚构场景。

节奏：一镜一信息；画面每 7–10 秒至少换一次（换镜、换图表、换演示都算），连续同一画面不超过 10 秒。

## 六、字幕与静音可读

- 默认全程字幕；多数人静音刷到，静音也要看得懂主张。
- 展会循环、商场大屏这类无声场合，单出一版无解说版，信息全由字幕和画面承担。
- 字幕避开画面底部与右侧边缘区域，不遮脸、不压产品。
- 关键数字和结论单独一屏，停留不少于 2 秒。

## 七、版本矩阵

一版通吃所有场合，必然每处都不合适。开工就定版本：

| 版本 | 时长 | 讲什么 |
|---|---|---|
| 主片 | 按片型规格 | 完整主张 + 全部证据 |
| 切片 | 30–90 秒 | 每条只讲一件事，一条证据 + 行动 |
| 竖版 | 同切片 | 重新构图，不是把横版裁一刀 |
| 无声版 | 同主片或切片 | 字幕承担全部信息 |

投放素材要做 A/B 时，一组只换一个变量（开头、买点、行动语），换两个就说不清哪个起效。

## 八、分寸与事实核对

写稿时逐条核对表述，拿不准的说法改成可当场验证的事实陈述，或删掉：

- 不堆空洞极限词（最、第一、唯一），功效、性能、优惠只写有实测或事实依据的。
- 涉及专业门槛的内容（操作安全、健康、数据），附上生效条件或前提，不夸大承诺。

## 九、常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 看完说不出讲了啥 | 没有那一句话，或一次说了三件 | 回到一，只留一件当主张 |
| 全是"专业、创新、领先" | 没有证据链 | 每个形容词配载体，配不上就删 |
| 画面和旁白说同一件事 | 两边都怕漏信息 | 旁白说为什么，画面说是什么 |
| 开头二十秒在铺垫 | 按"气势"套路写 | 把结果或问题提到第 0 秒 |
| 像念说明书 / 念百科 | 名词解释代替过程 | 把定义换成看得见的过程或因果 |
| 受访者像演员 | 给了稿子让他背 | 给三个问题，用自己的话说 |
| 数据和实际对不上 | 沿用旧资料 | 每个数字回到最新来源核对 |
| 一版用在所有地方 | 没做版本矩阵 | 主片、切片、竖版、无声版分开做 |
| 生成画面被质疑造假 | 用生成冒充真实 | 真实的人和事用实拍；生成只做空镜与示意 |
