# 剧本格式

剧本是给演员、导演和制作看的，不是分镜。它只写**看得见、听得到**的东西，不写机位、焦段、运镜和剪辑点——那些属于镜头设计。本文只管格式与交稿自检，不管戏写得好不好。

## 一、整体结构

```text
第1集

1-1 夜·外 单元楼下
人物：老陈、小周
△老陈把信封折了两折，塞回口袋。
小周：你等了三个钟头，就为了跟我说没有？
△老陈把手从口袋上拿开，转身去按电梯。
老陈：我说的是，这钱不能当着你的面给。

出场人物：老陈、小周
```

| 级 | 写法 | 作用 |
|---|---|---|
| 集 | `第1集` 独占一行 | 分集 |
| 场 | `1-1 夜·外 单元楼下` | 场号 + 时间 + 内外 + 地点 |
| 人物行 | `人物：老陈、小周` | 本场真正出场的人 |
| 动作行 | `△…` | 看得见、也有用的动作与反应 |
| 台词行 | `老陈：…` | 角色名 + 冒号 + 台词 |
| 场末 | `出场人物：老陈、小周` | 给制作汇总 |

剧本正文之后如果还要写备注，先另起一行写 `<!-- 剧本结束 -->`，免得备注里的"第3集"被当成新的一集。

## 二、场次头

格式：`场号 时·内外 地点`

| 项 | 取值 |
|---|---|
| 场号 | `集号-场号`，如 `1-1`；同一集内连续，不跳号、不重复；每集从 1 重新起 |
| 时 | 日 / 夜 / 晨 / 昏 |
| 内外 | 内 / 外；按镜头所在的空间判：楼道、走廊、电梯、车里、店里算内，楼下、街边、天台算外 |
| 地点 | 可用专名，如"单元楼下""售票厅"；同一地点前后叫法一致 |

换景就写新场次头，不用"后来""接着"代替切场。场次头一行写全四项、顺序固定，时与内外之间用 `·`，不加“第一场”“场景：”这类标签。

同一地点在剧本、资产表、提示词里用同一个名字：剧本写“六号楼楼下”，资产表就不叫“六号楼402门口”；两处确实是两个地点，就各开场次、各立资产。

## 三、人物行与场末汇总

- `人物：` 只列本场**真正出场**的人，不写只被提到的角色。
- 场末 `出场人物：` 与本场 `人物：` 一致；制作需要时可加备注（如"儿童演员一名"）。
- 同一个人全剧一个名字；别名、称谓变化在资产表里合并，不在剧本里混用。角色名不超过 12 个字。

## 四、动作行

`△` 开头，一行一件事。**必须满足**：看得见；删掉之后，人物的判断或下一步会变。

可以写：动作与反应（推门、松手、后退半步）；物件与空间（信压在杯子下、门只开了一条缝）；转场（灯灭、车驶出画）；直接服务冲突的细节（签字前停了一秒）。

不要写：心理活动（"他心里一沉"→改成动作或停手）；拍不到的判断（"她意识到他在撒谎"→改成她的反应）；镜头语言（特写、推近、切到）；表演形容词（愤怒地、尴尬地）。抽象情绪一律落成身体与物件的可见变化：把"愤怒"写成"指节捏白，杯底重重磕上桌面"，把"震惊"写成"瞳孔微缩，手里的文件滑落在地"。漫剧里的气场外放、能力触发或夸张反应（仅在该项目画风允许时），同样用 `△` 写成画面里看得见的形态与光影结果，不贴 `【特效】【Q版】` 这类后期标签。

一个 `△` 塞五件事就拆开。

## 五、台词与声源标记

格式：`角色名：台词`

- 写人能念出口的话，不写书面长句。单句别太长，给配音、呼吸和对手反应留空间；快节奏竖屏短剧常态交锋多用 15 字以内的短句（单句硬上限仍按第九节 D01 的 38 字核），一句台词最好同时完成"当场攻防 + 顺带递出信息"。
- 台词里不解释动作；动作归 `△`。一句台词后需要反应，另起一行 `△`。每 3–5 句台词之间宜穿插一次可见动作或反应变化，不连排十几句干对白。
- 语气尽量用动作表达；确实表达不了，才在**角色名后**加短括号：`值班员（低声）：窗口要关了。` 不把括号写进台词正文。
- **独白与现场声克制**：写实短剧慎用 `心声` 与 `旁白`，优先靠动作外化；漫剧可适度用 `心声` 或 `旁白` 加速信息传递（占全集一两成以内），但单次连续不超过 2 句。推动剧情的现场声响（酒杯碎裂、门锁弹开）写进 `△`，配乐留给后期，剧本正文不贴 `【BGM】【音效】` 标签。

**声源标记**写在角色名位置，全剧统一用一套：

| 标记 | 用途 |
|---|---|
| `画外音` | 人不在画面里说话 |
| `旁白` | 叙述者 |
| `心声` | 人物内心独白 |
| `书声` | 画面上的书信、文件被读出 |
| `系统音` | 广播、提示音、电子播报 |
| `画面字` | 屏幕上出现的文字（字幕、招牌、消息） |

屏幕文字用英文双引号引原文，不翻译、不改写：`画面字："明日休息"`。

| 情况 | 写法 |
|---|---|
| 两人同时开口 | `小周、老陈（重叠）：…` |
| 被打断 | 在打断处加 `——`，被截断的台词不加句号 |
| 沉默或停顿 | 用 `△` 写可见的停顿（"△老陈没接话，把杯子转了一圈"），不写"（沉默）" |
| 电话、对讲、广播 | 按声源标记（`画外音` / `系统音`），另一头的反应用 `△` 写 |

## 六、多集写法

- 一集一个 `第N集` 段；每集场号从 1 重新起，不跨集连号。
- **开局前 3 行直接入戏**：首个 `△` 与首句台词直接承接上集钩子或切入当场冲突，不写进门问好、落座寒暄等无效过场。跨集连续的动作，在下一集重复一次起态，不假设读者记得。
- 集尾就是最后一场的最后一行：停在未落下的动作、刚抛出的炸弹台词或骤变的反应上，留出人物下一步不得不面对的问题；不写总结感叹，也不额外加 `【切黑】【卡点】` 或"悬念说明"。

## 七、时长估算

只有梗概、还没细节时用这张表估节奏；已有完整对白与动作时，按实际展开逐项累加估时。可见节拍＝`△`、台词、声源标记各算一拍；台词字数不计标点与括号。

| 片长 | 可见节拍 | 台词字数上限（约） |
|---|---|---|
| 60 秒 | 12–24 | 300 |
| 90 秒 | 18–36 | 440 |
| 120 秒 | 24–48 | 580 |
| 180 秒 | 36–72 | 850 |
| 240 秒 | 48–96 | 1100 |

节拍低于区间，通常是某场被写成了一句话；高于区间，检查是否赶场。连同 `△` 在内，60–120 秒竖屏短剧单集全文常见在 300–550 字（对白约占六到七成），90–180 秒漫剧常见在 400–750 字。

## 八、常见格式错误

| 错误 | 改法 |
|---|---|
| 把分镜写进剧本（镜号、景别、运镜） | 删掉，移到镜头设计；剧本只留可见动作 |
| 台词里夹大段动作 | 拆成 `△` 行 |
| 一个 `△` 写五件事 | 拆成多行，每行一个可见变化 |
| 场号跳号或重复 | 按顺序重排 |
| `人物：` 写了没出场的人 | 只留真正出场的 |
| 用"后来""接着"代替切场 | 写新场次头 |
| 台词正文里写括号表演指导 | 改成动作，或移到角色名后的短括号 |
| 屏幕文字写成意译 | 引号内保留原文 |
| 夹带 `【特写】【BGM】【音效】【卡点】` 或 `（OS）` | 景别运镜移到分镜，配乐留给后期，现场声响写进 `△`，声源统一用第五节六种标记，集尾不打标签 |

## 九、交稿自检

交稿前逐项扫一遍。阈值是提示，不是合格线：剧情需要可以更密或更静，但要知道自己越了哪条。全部通过不等于戏好。

| 编号 | 检查 | 阈值 / 处理 |
|---|---|---|
| S01 | 每场有场次头 | 缺就按 `1-1 日·内 地点` 补 |
| S02 | 单集场次 | 超过 6 场，逐场看价值有没有变，没变就并；有变就保留并承担制作成本 |
| F01 | 每场有 `人物：` | 补齐 |
| F02 | 每场有 `出场人物：`，且与 `人物：` 一致 | 补齐、对齐 |
| V01 | 有 `△` 行 | 整集没有 `△`，补表演、空间或转场的可见依据 |
| V02 | 单条 `△` | 超过约 80 字，拆成更清楚的表演或镜头重点 |
| T01 | 可见节拍低于七节下限 | 刻意留白可忽略，否则补戏 |
| T02 | 可见节拍高于七节上限 | 检查是否赶场 |
| T03 | 台词总字数超七节上限 | 试读确认配音能否放下 |
| D01 | 单句台词 | 超过约 38 字，试读确认配音、呼吸与对手反应空间 |
| D02 | 台词正文里的括号语气 | 改为可见动作，或移到角色名后 |
| C01 | 单场说话人 | 超过 5 位，检查调度、抢话与可懂度 |

另查四项：场号逐集从 1 连续；同一角色全剧同名；同一地点在剧本和资产表里同名（一字不差，“四楼走廊”和“七号楼四楼走廊”算两个名字）；门牌、单号这类号码在剧本和资产表里同一个写法（汉字和阿拉伯数字不混用）。

**自检结果要交出来。** 剧本交稿时，在剧本正文之后另起一行写结果，每项写数字或依据，比如“自检：S01 四场都有场次头；S02 4 场；T01/T02 可见节拍 34（90 秒区间 18–36）；T03 台词约 190 字；D01 最长一句 22 字；F01、F02、C01 未核”。没过的项写原因或已经怎么改；拿不准的写“未核”，不顺手写成“全过”；数字逐行数出来；“约”只用在逐行数过、误差在一成以内的数上，没逐行数就写“未核”，不估一个像样的数。这一行不进剧本正文。

## 十、示例

```text
第2集

2-1 日·内 售票厅
人物：老陈、小周、值班员
△老陈把两张票放在台面上，没有推过去。
小周：你昨晚说没有。
△老陈看了一眼值班员。
老陈：现在有了。
书声："退票须本人持身份证办理"
△小周把票推回去，手指压着票角。
小周：那你自己去退。
△值班员抬头，又低下去。
值班员（低声）：窗口要关了。

出场人物：老陈、小周、值班员
```

这一场示范了：场次头、`人物：`、`△` 写可见反应、`书声` 标记、角色名后的短括号，以及用 `△` 承载停顿。
