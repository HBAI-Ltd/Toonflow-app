# Seedance 提示词结构

Seedance 视频提示词的格式：块序、标签、参考绑定、镜头标记、锁句、容量、多段拼接。只管格式，不管每镜画面怎么决定。

## 一、书写约定

| 部分 | 规则 |
|---|---|
| 正文语言 | 中文 |
| 块标签 | 中文包在【】里：`【场景背景】`；全篇一致。项目已有英文模板时可沿用英文标签，但一条片只用一种 |
| 画风 | 不写。画面风格由参考图带进来（资产图已经按画风出好、固定）；只有这一条完全没有参考图时，才在最前面加一块 `【画风】`，正文是 `AGENTS.md` 的画风文字原样，不计入下面的 13 块 |
| 台词、歌词、屏幕文字 | 保留原语言原文，不翻译 |
| 数字、时间、比例 | 原样写：`47°`、`0:00–0:03`、`2.39:1` |
| 生成参数 | 分辨率、模型在平台设置，不进正文 |

## 二、块序（13 块）

13 块按顺序写，没命中的整块删掉，不留空标题。顺序背后是四层：先立身份（谁、在哪、怎么拍），再写光学与身体（怎么看、怎么动、怎么亮），再写模拟（物理与声音），最后是强制（锁定与约束）。

| # | 块 | 写什么 | 何时可省 |
|---|---|---|---|
| 1 | 场景背景 | 两句：发生什么 + 这一条要交付什么 | 不省 |
| 2 | 激活参考 | 参考汇总 + 逐张职责（见四） | 无参考时省 |
| 3 | 拍摄模式 | 几镜、在哪秒切、总时长；画幅见下 | 不省 |
| 4 | 空间地理 | 地图九项：机位、朝向、前中后景、地标、人物位置、路径、光向 | 单一封闭空间且无走位时可简写 |
| 5 | 开场状态 | 每镜一段：每人的位置、朝向（脸、躯干朝画面哪边；车、门这类有方向的物件朝哪边）、手上有什么、重心；就位锁"所有主体已就位，之后不再有人入画" | 不省 |
| 6 | 光学镜头 | 每镜视角 + 相机距离 + 可见结果 + 镜头锁 | 无镜头语言要求时省 |
| 7 | 风格 | 本条特有的取值：色比、本场质感；不重述画风，参考图已经带出来的不写 | 参考图已覆盖时省 |
| 8 | 运镜 | 逐镜运镜（一镜一条主轴），或"机位固定" | 不省 |
| 9 | 动作时间轴 | 每镜一整段：段首锁机位，段内 2–5 个微事件带秒数，切点单独一行 | 不省 |
| 10 | 光照 | 八项：主光源、方向、相机在光哪一侧、主体明暗面、背景亮度、曝光优先、允许的高光、明暗比 | 不省 |
| 11 | 物理 | 逐材质的行为句：湿与干分开写，接触点、重量、后果留到下一镜 | 静物空镜可省 |
| 12 | 音频 | 底噪 + 带秒数的声事件 + 远近 + 收尾 | 不省（没有声音也写现场声） |
| 13 | 正向锁定 | 本条的失败预防，10–20 条短句，用 `·` 分隔 | 不省 | 本文六、七 |

**画幅写不写**：只有能保证这一行永远与平台输出参数一致时才写进拍摄模式（做成项目常量、和平台设置一起改）；不能保证就删掉，写错比不写更糟。

## 三、条件块

按镜头需要插入，没有就不写：

| 条件块 | 什么时候加 | 插在哪 |
|---|---|---|
| 谁是谁 | 两个角色长得像、容易互换 | 开场状态之前 |
| 表演任务 | 画面里有活人：目标 / 障碍 / 战术 / 潜台词 | 开场状态之后 |
| 台词 | 有人说话：谁说、时间窗、原文、音色块、谁闭嘴 | 动作时间轴之后（或把台词落点并进动作时间轴） |
| 面部细节 | 特写里的眼睛、眨眼、微表情 | 动作时间轴之后 |
| 构图 | 构图有硬要求（对称、前景遮挡、留白） | 光学镜头之后 |
| 材质 | 本条有需要强调的材质或胶片质感 | 物理之前 |
| 连续性 | 承接上一条的服装、伤势、道具状态 | 正向锁定之前 |
| 一镜到底锁 | 单镜不切 | 运镜之后 |
| 负向 | 只在同一症状在三镜以上重复时 | 全篇最后 |

## 四、参考绑定

- 每个参考写 `{{ref N}}`；图片、视频、音频**共用一套编号**，按绑定顺序连号，一个号只用一次。编号每条各自从 `{{ref 1}}` 起，不沿用全片资产表的编号。
- 汇总行：`本段共 {N} 个参考：{{ref 1}} {是什么}、{{ref 2}} {是什么}。`
- 范围句（紧跟汇总行，只写一次）：`图片与视频参考只控制身份、几何与外观，不控制构图、裁切、机位高度与角度。`
- 单张职责，一到三句，写它拥有什么、不拥有什么：
  - 图片：`{{ref N}}——{资产名}参考：只提供 {脸 / 建筑与材质 / 物件结构}；{机位与动作} 由提示词给出。`
  - 视频：`{{ref N}}——{资产名}参考：只提供 {动作节奏 / 运镜}；其余由提示词给出。`
  - 音频：`{{ref N}}——{音频类型}：只提供 {音色 / 节拍}；画面动作与它对位，不反过来。`
- 视频、音频参考注明用法：`复制`（照搬）或 `参考`（只取特征）。
- 优先级：身份 > 空间与动作 > 光学与光 > 风格。地点参考不覆盖本镜机位，风格参考不覆盖身份与光。

## 五、镜头标记、切点与镜头锁

| 元素 | 写法 |
|---|---|
| 镜头编号 | `镜头 1 —`、`镜头 2 —` |
| 时长与切点 | 绝对秒数：`0.0 秒 / 3.5 秒 / 6.5 秒处硬切` |
| 剪切类型 | 只用六种：硬切、冲击切、匹配切、插入切、反打切、甩切 |
| 收尾声明 | `总时长约 {S} 秒。镜头数 {N}。剪切数 {M}。` |
| 量的写法 | 位置用画面百分比（`x36% / y64%`）或三分法；距离用米；色温用 K |

**镜头锁**：每镜开头写 `镜头锁：约 X° 对角视角`，结尾写 `镜头检查：X° 保持，无漂移`，两处 X 同值。换视角只发生在硬切。**镜内不推、不拉、不变焦**：要更宽，只让相机往后退、保持同一焦段；镜头设计里想要的推拉，在这里改成"硬切 + 机位前后移"，或拆成两次生成。

按焦段选一把锁，逐字粘：

| 锁 | 句子 |
|---|---|
| 长焦锁 | 本镜全段锁定长焦，不换镜头、不漂移焦段。要更宽的画面，只把相机往后退，保持同一焦段；背景每一帧都保持压缩与化开。 |
| 广角锁 | 本镜全段锁定广角，任何部分都不变成长焦人像。环境始终围绕主体可见，相机始终贴近，保持广角的空间扩张与纵深。 |
| 标准锁 | 自然人眼透视，平实中性，没有广角畸变，也没有长焦压缩。 |
| 多镜锁 | 全片同一颗镜头，约 X° 对角视角；段内与段间焦段不变。 |

## 六、身份锁与地点锁

身份锁四级，每条只选一级，不叠写：

| 级 | 用在 | 句子 |
|---|---|---|
| 1 | 单镜单参考 | 与参考完全一致。 |
| 2 | 跨镜，全片同一景别 | 与参考完全一致——这张脸属于参考。 |
| 3 | 跨镜且换景别（近景、特写来回） | 与参考完全一致——这张脸属于参考，在每一个景别上都属于它。 |
| 4 | 机位也必须锁死（反打、一镜到底），或参考图构图在抢戏 | 与参考完全一致——参考只拥有这张脸，不拥有机位；机位另写，不从参考继承。 |

地点参考之后一两句内必须跟一句：`机位角度不继承——场景图只提供"这个地方"，不提供相机。` 不写，每镜都会像从同一张地点照裁出来，人物永远同一个朝向。

也可以不用锁句，只靠第四节的逐张职责句锁住同一功能；两种选一种，全片一致。

## 七、正向锁定与负向的位置

- 正向锁定放在 13 块的最后，10–20 条短句，每条一个可检查的事实：谁在哪一侧、光源在哪、物件几个、画面里几个人。
- 写成正面状态："机位始终在两人连线南侧"，不写"不越轴"。
- 负向默认不开块；同一症状在三镜以上重复才开，放在全篇最后，短语用 `·` 分隔，只列本片真实出过的问题。
- 自检用的禁令表、分析、缺陷记录不粘进正文。

## 八、容量（有时效）

下表是写作时的出发值，照它算条数；用户或平台界面给了不同的数，按新的算。

| 项 | 出发值 |
|---|---|
| 单次生成时长 | Seedance 2.0 约 4–15 整秒；Seedance 2.5 约 4–30 整秒 |
| 参考上限 | 以平台界面显示为准；参考视频、音频每段另有时长限制 |
| 参考数与模式 | 1 张图走图生视频，2 张走首尾帧，3 张以上走参考生视频；部分平台可把 1–2 张当参考而非首尾帧 |
| 分辨率 | 480p / 720p / 1080p，按项目偏好取最低档起步 |
| 提示词字数上限 | 以平台界面显示为准；超了按块删减：先删物理细节与可选条件块，开场状态、动作时间轴、光照、正向锁定不删 |
| 画幅 | 16:9、9:16、1:1、4:3、3:4、21:9、自适应 |
| 音频 | 模型支持时同遍生成 |

## 九、多段拼接

成片超过单次上限时按段切：条数＝⌈总时长 ÷ 单次上限⌉。

- **默认每段各写各的**光向、几何与开场状态，靠提示词对齐，不靠接力。
- 拼接点选在动作停顿或切点上，不选在运动中间。
- **尾帧接力是条件式，不是默认**：拆条后确实接不上、而且接头是近景时，才取上一段的末帧作下一段的首帧；宽景接头接力收益很小，改为重写光向与几何。要用之前先问用户。
- 拿资产板或某张图直接当首帧时，图生视频常按原图比例输出，不保证 9:16 或 16:9。要固定画幅，先按目标画幅补画布再生成，或改用首尾帧模式并写明画幅。

## 十、不进正文

| 内容 | 放哪 |
|---|---|
| 分析、目标、平台说明、缺陷记录、修改意见 | 工作稿 |
| 分辨率、模型 | 平台设置 |
| 场号、集数、剧本头 | 工作文档 |
| 自检清单 | 不粘进成稿 |

## 十一、项目已有自定块序时

项目里已经有一套自己的块名与块数（比如用户或团队沉淀的模板），按项目块序写：**整段覆盖 13 块，不混用、不互相映射**；块可以删，顺序不变。稿头注明"本项目按自定块序"。通用 13 块只用来查漏。

## 十二、骨架示例

两镜、10 秒、竖屏短剧的一条。示例只演示格式，不是固定模板；方括号是要按项目替换的内容。

```text
【场景背景】深夜单元楼下，老陈把信封交给小周。这一条要交付：小周发现信封里的钱不够。

【激活参考】本段共 3 个参考：{{ref 1}} 老陈、{{ref 2}} 小周、{{ref 3}} 单元楼下。图片与视频参考只控制身份、几何与外观，不控制构图、裁切、机位高度与角度。
{{ref 1}}——老陈参考：只提供脸、发型、体型与服装；机位与动作由提示词给出。
{{ref 2}}——小周参考：只提供脸、发型、体型与服装；机位与动作由提示词给出。
{{ref 3}}——单元楼下参考：只提供建筑、地面与路灯的位置；机位角度不继承——场景图只提供"这个地方"，不提供相机。

【拍摄模式】2 镜。0.0 秒开始，5.0 秒处硬切，总长 10 秒。

【空间地理】方位以画面为准。单元门在画面右侧，门边一盏路灯。老陈背对单元门站在路灯下；小周在他正对面，相距 1 米。相机在两人连线的南侧，始终在这一侧。路灯在老陈身后右上方，影子朝画面左前方。

【开场状态】镜头 1：老陈在画面右三分之一，躯干朝向小周，右手捏着信封举在胸前；小周在画面左三分之一，双手插在外套口袋里，眼睛看着信封。镜头 2：小周在画面中央偏左，双手拿着拆开的信封，低头看封口。所有主体已就位，之后不再有人入画。

【光学镜头】镜头 1：镜头锁：约 47° 对角视角，相机距两人 4 米，两人全身入画，自然人眼透视。镜头检查：47° 保持，无漂移。镜头 2：镜头锁：约 29° 对角视角，相机距小周 5 米，胸口以上，背景路灯化开。镜头检查：29° 保持，无漂移。

【风格】本条色比：六成钠灯暖橙，三成夜色深蓝，一成信封的白。

【运镜】镜头 1：机位停在原地，画面带一点手持的细微晃动。镜头 2：机位固定。

【动作时间轴】
镜头 1 —（0.0–5.0 秒）机位与构图锁定。0.5 秒 老陈把信封往前递；1.5 秒 小周抽出右手接住，指尖捏住信封一角；2.8 秒 小周用拇指拨开封口往里看；3.6 秒 老陈把手收回口袋，视线移向单元门；4.5 秒 小周的手停住。
5.0 秒硬切，切在小周手停住、还没抬头的那一帧。
镜头 2 —（5.0–10.0 秒）机位与构图锁定。5.5 秒 小周的拇指在钞票边缘数了一下；6.0 秒 小周抬眼看向画外右侧的老陈；7.5 秒 她把信封折回去，手指压着折痕；9.0 秒 她的视线落回信封。

【台词】小周（6.2–7.2 秒，画面中央偏左）："就这些？"老陈在画外，嘴唇闭合、保持安静。

【光照】主光源：老陈身后右上方一盏钠灯路灯，约 2000K。方向：从画面右后上方斜照，影子朝左前方。相机在暗侧。主体明暗面：两人脸的右侧受光，左侧沉进阴影。背景：单元楼墙面压暗到只剩轮廓。曝光优先：按路灯下的亮区曝光，允许脸的暗侧进深阴影。明暗约 4:1。允许的高光：信封边缘、小周眼中一点、电动车把手的金属边。

【物理】信封纸偏软，被捏住的一角微微弯折，松手后慢慢回弹。外套是干的厚棉布，抬手时袖口褶皱堆在肘弯。钞票边缘被拇指拨动时轻轻翻起再落下。

【音频】底噪：远处马路的车流低频，路灯电流轻响。1.2 秒 信封纸摩擦；2.9 秒 封口被拨开的轻响；6.2 秒 台词；8.5 秒 远处一声车喇叭。远近：远处车流，中景衣料，贴身呼吸。除写好的台词外全部为现场同期声，音乐后期添加。

【正向锁定】老陈始终在画面右侧，小周始终在左侧 · 机位始终在两人连线南侧 · 路灯始终在老陈身后右上方 · 信封只有一个 · 画面里只有两个人 · 小周说话时老陈嘴唇闭合 · 两镜同一夜晚同一光向。

总时长约 10 秒。镜头数 2。剪切数 1。
```

## 十三、交稿自查

每条提示词交出去之前逐项核。结果在回复里交代，一项一行，每项写依据（比如“参考编号：本条 1–3 连号，汇总行与正文一致”），拿不准的写“未核”，不写空泛的“全过”，不合成一段话；不粘进提示词正文。“开场｜第一拍”每镜一行，比如：

```
镜头 1｜开场：他跨坐车上，脸朝画面左，手机贴在右耳｜第一拍 0.6 秒：手机从耳边放下
镜头 2｜开场：手机已扣在左腿上｜第一拍 4.5 秒：他抬头看向画面右（手机不再动）
```

- [ ] 整条提示词全文已经存下：画布上的镜头卡文本节点，或项目目录的工作稿文件；不是只在对话里
- [ ] 一个文件里写几条，每条都是能单独拿去用的全文：不写“同上一条”“职责同上”“与上一条同一处”
- [ ] 没有【画风】块，正文也没重述画风（参考图已经带着风格）；只有这一条完全没有参考图时才加【画风】块，且与 `AGENTS.md` 的 `## 画风` 一字不差（这一轮读过 AGENTS.md 再比）
- [ ] 正文没有否定式主句；负向块只在同一症状三镜以上重复时才开
- [ ] 逐镜写一行“开场｜第一拍”对照：开场是动作开始之前的状态，第一拍是从这个状态出发的第一个变化；开场里已经做完的动作（手机已经扣在腿上），时间轴里不再做一遍
- [ ] 台词与剧本一字不差，这一条该覆盖的台词不多不少；剧本里没有的台词不加
- [ ] 每句台词的时间窗够念：字数 ÷ 时间窗秒数不超过 5（35 字至少 7 秒）；逐句算出来写进自查，超了就拆句、拆镜或延长
- [ ] 正向锁定、台词行、动作时间轴里写到的画面位置（左、右、中央）和朝向（脸、躯干、车头朝哪边）彼此一致；锁定里写“始终”的状态，时间轴里不变；“之后不再有人入画”之后没有人或车入画；时间轴里的动作（起身、取下手机），在开场状态或前一拍里有来处
