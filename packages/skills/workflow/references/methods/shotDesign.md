# 镜头设计：组织信息、观看位置与节奏

在把剧本转为片段内镜头、选择构图运镜、处理接戏或调优视频时读取。输入是已确认剧情、人物表演、资产空间与光色；输出直接进入[三部分提示词](../storyboard.md)中的主体定义、镜头正文及必要约束，不另设技术报告关口。

景别、角度、构图和运镜都是选择工具。它们产生的意义取决于表演、声音和前后镜头，不能把“仰视=强者”“推近=悲伤”当作固定翻译。

## 1. 给每个镜头一个观看任务

先用一句话确定：观众这一刻必须看懂什么、先于还是晚于人物知道、应靠近还是保持观察距离。再找承担该信息的动作、脸部、物件或空间关系。

区分三种变化：剧情发生了新事件；人物改变理解或策略；观众获得了新信息。它们可能发生在同一动作中，不必拆成三镜。一个镜头没有增加信息，也可能通过等待或留住结果产生意义，但应说清等的是什么。

选择顺序可从已有画面构想开始，仍要回查：观看对象 → 必须同时看见的内容 → 景别与机位 → 构图 → 是否需要运动 → 从哪个可见状态结束。技术名称不能替代这些决定。

## 2. 用景别控制信息范围

| 景别 | 优先解决的问题 | 使用时核对 |
|---|---|---|
| 大远景 | 地理、规模、人与环境的比例 | 小人物是否仍可定位；不要同时要求可读表情或文字 |
| 远景 | 行动路线、处境、接近或离开的关系 | 环境信息是否真的影响本段，而非无目的铺陈 |
| 全景 | 完整身体动作、站位和空间限制 | 手脚、目标和动作结果是否都留在画面内 |
| 中景 | 对话、双人关系、身体与物件互动 | 需要观察的手与道具有没有被裁掉 |
| 近景 | 反应、视线、呼吸和言语变化 | 已建立足够空间，不用近景掩盖人物换位 |
| 特写 | 脸、手或关键物件的决定性细节 | 明确部位与要读出的信息，保留必要辨识时间 |
| 大特写 | 极少信息的集中观看或有意隐藏整体 | 局部不能承担全场空间说明，必要时另找揭示时点 |

先选能容纳本镜任务的范围，再决定是否靠近。两个动作必须同时证明因果时，不应为了“情绪强烈”自动切成孤立脸部特写；也不强制所有场景先远后近。

## 3. 视角、高度和视点各自回答不同问题

- 景别回答画面包含多少；仰视、俯视、平视回答向主体怎样观看；机位高度说明观察点相对谁或什么地标。三者不能互相代替。
- 平视可用于平等交流，也能冷静观察危险；低位仰视可突出体量，也可能只为看清桌底动作；俯视可暴露空间分布，不自动表示人物软弱。
- 固定的倾斜构图与画面持续旋转是两件事。只有倾斜能服务本镜关系或观看体验时才用，不因题材悬疑便让每镜失衡。
- 主观视点应符合该人物位置、视线与所知；过肩能同时保留观察者和对象关系；客观观察可让观众知道人物尚未察觉的信息。不能在一镜中无说明地互换这些身份。

机位高度可写“与坐着的甲的眼睛齐平”，不凭空填写厘米。多人高度不同或人物坐立改变时说明参照对象；不要求镜头同时与所有人平视。

## 4. 构图如何传递主次与关系

先写一份不带构图术语的画面草案：哪些人和物必须同时出现，分别位于哪个已确定的空间锚点，观众要从它们之间看懂什么。随后从三个角度修改这张草案。

**先检验相互关系。** 如果要看到两人争取同一物件，就不能把关键手部裁出画面；如果一人挡住另一人的去路，前后层次和通道必须可辨。用间距、朝向、大小与遮挡说明关系，必要时换观察位置。人物不应为了满足某种构图比例而无故搬家。

**再模拟观众的视线。** 缩小画面时哪个对象最突出，下一眼是否能找到动作目标，线索会不会被过早发现。需要改变顺序时，可减少竞争色块、调整焦点或等待人物动作引导；并非把所有重要东西摆在同一排就能让观众依次阅读。

**最后让动作在画框里走一遍。** 画面的空处是否容纳了下一步路线，移动后主体会不会被裁掉，停下来时关系是否已改变。也可以有意压缩一侧空间形成局促感，但须保留当前必须理解的动作。位置本身没有固定寓意，屏幕左侧不天然代表过去，倾斜也不天然代表悬疑。

完成这些判断后再选择居中、对称、三分位置或其他布局。三分法可在主体偏置后留出有用环境，但只是候选方法；它不限定题材或情绪强度，也不要求填满交点。留白可以继续为空，不因“缺一个视觉中心”而添人物或威胁。

正式描述保留可执行的位置和观看关系，例如“镜头位于修理台短边，前方空出的台面能看到工具滑向对面手边”。需要表达不安或亲近时，由已写明的行动、距离和遮挡支持这种感受，而不是只贴一个构图名称。

## 5. 先判断是否需要运动

问：固定镜头能否完整呈现这次变化？若能，固定是有效选择。需要运动时，说明运动新增了什么信息、怎样改变观看关系，并明确开始与结束画面。

| 运动选择 | 常见用途与写法 | 要检查的区别 |
|---|---|---|
| 水平摇镜、上摇或下摇 | 从一个已有信息点转向另一个，跟随视线或展开高度关系 | 观察位置不平移；不能借摇镜穿过遮挡 |
| 推近、拉远 | 改变观看距离，集中细节或逐步显露环境 | 说明起止景别与新露出的内容，不只写“情绪慢推” |
| 横移、短距离滑移 | 保持行动关系、绕开已有遮挡、展示前后层次 | 实际观察位置改变，与原地摇镜不同 |
| 跟随、在人物前方后退 | 保留行动路线或边走边说的反应 | 写清跟谁、从哪一侧、走到哪里，路径不能穿墙 |
| 升降、大范围抬升或空中移动 | 从局部转向整体，揭示地理或群体关系 | 说明高度变化与可见结果；不为每场添加宏大航拍 |
| 环绕 | 展示主体周围的关系或揭示原先不可见的方向 | 需要已有空间支撑，结束方位与银幕方向不能丢失 |
| 变焦 | 观察位置不变，改变取景范围与主体画面大小 | 不能把它当作机位移动或借此看到原本被挡住的物件 |
| 移动并反向变焦 | 保持主体大小相对稳定、使背景关系明显变化 | 只有确需这种视觉变化且能力合适时使用，不仅写效果名 |
| 快摇或快速目标切换 | 突发注意力转移或有依据的节奏连接 | 模糊过程不能吞掉必须看清的动作或线索 |
| 轴向旋转 | 持续改变画面朝向，呈现主观或空间变化 | 它不是环绕主体，也不是固定倾斜构图 |

手持、稳定跟随、滑轨等描述的是运动质感或实施方式，不是额外剧情。可以写“轻微自然晃动”或“平稳侧向跟随”，不需要堆设备名。高速跨越复杂地形时描述路线、障碍和目标，不承诺模型实现实体设备或精密运动控制。

长镜头说明连续不切，不能替代路线和信息组织；穿过门口或人群需有实际通路。需要重复轨迹、时间循环或平行空间的作品，先写清每次哪些内容相同、哪些变化，不把“运动控制”当作已具备特效合成能力。

一镜通常保留一个主要运动任务；确需组合时写清先后阶段和转折依据，不同时要求互斥的推拉、左右摇移。动作本身复杂时先减少运动干扰，而非靠更多术语增加刺激。

## 6. 焦点与可读性

确定本镜哪些对象必须同时看清。两人的手和交接物需要共同证明动作时，保留它们的可见细节；不能一面要求浅景深完全虚化，一面要求背景小字准确可读。

转焦用于转移注意力时写明“从什么转到什么、由哪个事件触发、最终留在哪里”。景深、明暗或遮挡不应意外隐藏观众此刻必须理解的信息。

画内文字给足阅读时间和合适范围；只有文字特写仍不能证明观众理解它与人物的关系。与人物反应或持有行为对应，必要时分镜内安排明确前后关系。

## 7. 把真实空间转成每镜画面

1. 从场景地标建立人物、道具、光源与路线的实际关系；[视觉设计](visualDesign.md)负责固定这些依据。
2. 确定本镜观察位置和方向，再转成画面左/右、前/后、画内/画外，不把场景地理方位直接换成屏幕方位。
3. 反打或移动后重新核对视线、进入方向及遮挡。画面位置可以因观看方向改变，真实落位不能无故重排。
4. 需要跨越行动或对话轴线时用可见移动、重新建立空间等方式让观众理解；不为遵守固定角度数字生硬添镜头。
5. 区分人物自身左手与画面左侧。物件换手须有动作，伤处和服装差异不能随反打镜像变化。

身份参考解决是谁，环境参考解决空间基础，正文仍须写本段持物、开合、姿态和行动进度。反过来也不能用文字重新设计实际已确认资产。

## 8. 用四种速度组织节奏

分别判断切镜频率、表演速度、镜头移动速度和画面变速。快移不等于快剪，镜头停留不等于人物不动；它们可以共同强化，也可有意反衬。

切镜的依据可来自信息揭示、动作完成、观察对象变化或关系转折。关键选择、读字和动作结果需要辨识时间；重复交代和无变化的等待可压缩。强情绪不自动要求快切或慢放。

采用慢动作或速度变化时，写清开始于哪个已有动作、让观众看清什么、在哪里恢复常速。镜尾若仍在变速，要把这一状态交给下一段；不能因为慢放让人物获得新能力。

声音参与节奏：对白保持完整与可理解，切到听者时可继续听当前说话人；提前听到下一场声音或延续上一场声音须符合既定剪辑方案。没有音轨/剪辑工具时，这些只是制作计划，不是已合成效果。

在真实单次时长内核算动作、对白、辨识与停顿，区别可以同时发生与必须先后发生的内容。过载先重组观看任务和非必要重复，再重选剧情断点；不靠全程加速或吞对白硬塞。

## 9. 跨片段接戏与画面收束

片段边界优先选在动作结果、话轮反应、信息揭示或阶段目标变化处，不机械填满模型上限。完整交接、接触或决定性反应尽量留在一次生成里。

文字规划先按剧本推导各段预期起止状态，明确标为计划，可以在视频生成前完成整段规划。准备接续生成时，下一段起态改用已采用片段的实际区间或用户反馈核对：位置、朝向、持物、动作进度、状态变化、已知信息和持续声音。将这些状态写成自足正文，不让模型“参考上一段”猜细节。

同场可通过主体、景别或观看对象的有意义变化连接，但不能靠空镜省掉人物下车、物件转交等必须发生的事实。跨时空时按新场景建立起态，不强求每段相同构图。

教学习例：已确认剧情为甲把信放在桌上，乙读后抬眼。可以在乙读完并抬眼后收束第一段，第二段从这个已到达状态开始；不在“手刚碰到信”时切断生成，再凭空让下一段变成已读完。接续生成仍须回查已采用结果是否实际到达这个状态。

## 10. 从结果定位提示词问题

在实际可查看的结果中先指出问题发生位置，再决定改哪一层：

| 观察到的偏差 | 先检查 | 有依据的修订方式 |
|---|---|---|
| 身份、服装或物件不一致 | 采用参考、编号、状态版本及冲突描述 | 修正实际引用或该段状态，保留不变资产 |
| 动作跳步或交接不成立 | 起点、接触、结果是否清楚，是否过载 | 补清因果、减少无关并发或重选分段点 |
| 人物无故换边 | 空间锚点、机位变化与身体侧别 | 重写该镜观察关系，不搬动整个场景补救 |
| 对白缺失、重复或错人 | 全文、说话人、声音类型、时长承载 | 修正具体话轮或调整容量，不改原台词凑秒 |
| 情绪不可读 | 是否缺触发、镜头是否看得见表演 | 调整观看范围或落实反应，不只追加“更悲伤” |
| 光色前后跳变 | 素材、光源关系、调色指令是否冲突 | 按[光色方法](colorAndLight.md)只修出错层 |

文本自检通过但结果仍偏离时，记录为生成偏差，不倒推剧情或宣称改几句就保证成功。只修受影响片段并保留实际生成版本；重生成、采用和核验能力边界继续遵循[状态与交付](../stateAndDelivery.md)。
