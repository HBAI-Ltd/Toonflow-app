# 资产设计

视频的一致性上限由资产决定，不由提示词决定。本文管：**哪些东西值得做成资产、怎么从剧情推导设计、板怎么设计、参考怎么分工、怎么测、怎么改**。

资产只管本色与表面：衣服、毛发、墙体、道具的固有颜色与纹理；镜头里的受光与调色不归资产。

不用读本文的情况：已有资产够用直接复用；单镜、无参考、不需要跨镜一致；纯文生视频。本方法不要求补人物生平、概念册，也不画用不上的视角。

## 一、识别：哪些要做成资产

**三条同时满足才做**：实际入画、参与可见行动、需要复用或单独引用。

不单独立资产：只在对白里被提到的人或物；偶发装饰、背景路人；纯声音角色（只留声音身份，不做肖像）；瞬时表情、转身、局部特写。

- **关键道具由用途定，不由动作定。** 杯子被拿起来不会自动变成资产；剧情靠它传递信息、触发事件或完成关键交互，且后面还要复用，才做。
- **变体什么时候建**：换装、持续伤势、明显污损、身体变化、固定物件遗失——会影响后续辨认的才建。沿剧情记成"原状态 → 触发事件 → 新状态 → 持续区间"。瞬时情绪不建变体。
- **地点什么时候另立**：同一地点多次使用、取景变近、人物跨区域行动，都只需要一张空间母版加子区域；真正发生破损、陈设移动、天气变化时另记状态。不因同属一栋楼就强行合并，也不因换了机位就重做。
- **群像先分级**：一个无名人物、确定人数的小群体、还是数量较大的群体。剧情人数和设计样本数分开记。
- **单集人物**：只在一集里出现、有脸有戏的人，不进素材库。跨两条以上片段出镜，做一张单集参考图（命名带集号，如“客户-第1集”），保证这几条是同一张脸；只在一条里出现，不做图，在提示词里用文字写清外观。出镜几条要等分条定了再数：资产表写在分条之前，单集人物先标“待分条后定”，分条后回资产表按实际条数改掉，不留“待定”。后面几集还会出场的，不算单集人物，按常驻角色做。
- **画面里的号码**：电话、车牌、门牌、楼号、单号这类入画号码，全片在剧本、资产表、提示词里用同一个写法，汉字和阿拉伯数字也算两种写法（“四零三”和“403”），选一种。
- **声音角色**：只以画外音、旁白出现的角色，保留声音身份、台词出处与声线描述（年龄与口音、音高音色、语速与说话方式、情绪怎么变）。有对白不等于必须有外部音色样本：模型支持原生声音时，用已确认的文字声线即可。

## 二、盘点与资产表

盘点时顺手做四件事：合并同一身份的别名；记下出处（场次、事件、片段）与适用范围；标出哪些是原文已有、哪些是提案；标出哪些已有旧图可用。旧图真实可读且够用的，直接复用，不为统一版式重做。不能只为第一条片段准备完，就说全片齐备。

资产表可以并进现有制作文档，每项至少留：

| 字段 | 内容 |
|---|---|
| 标识与名称 | 稳定 ID、名称 |
| 类型与状态 | 角色 / 场景 / 道具；母版或变体 |
| 出处与范围 | 场次、事件、片段，或指定设计用途 |
| 锚点与保持项 | 外观或结构锚点；必须保持的、允许变化的 |
| 已有文件 | 实际位置；缺就写缺 |
| 本次处理 | 复用 / 补图 / 做变体 |
| 状态 | 待设计 / 待生成 / 待验收 / 已采用 |

每项设计压缩成一句话：**对象身份、识别锚点、结构关系、当前状态、允许变化**。推导过程留在资产条目，不整段塞进生成提示词。

## 三、设计：从剧情事实推导

入口不是"给每个人填满外貌字段"，是**观众需要认出什么、人物实际要做什么**。按三层走：

| 层 | 从材料里找 | 怎么用 |
|---|---|---|
| 事实 | 已写明的年龄、外貌、服装、物件、伤势、空间、事件 | 直接继承，留出处 |
| 约束 | 时代、地域、媒介、身份关系、行动方式、能力边界 | 排除不相容的方案，不扩写成新经历 |
| 提案 | 为辨认、行动或制作必须补的轮廓、结构、配色、材质 | 标明是提案和理由，不新增能力、秘密、剧情线索 |

每项设计留一句依据（"短衣摆：便于已写明的攀爬，提案"）。

### 角色

先一句话说清他在当前戏里的功能（"负责带路，却不肯交出钥匙"），不用好人坏人决定长相。然后按顺序推，后一步要能解释前一步：

1. **行为需求**：要跑、爬、躲、久坐还是精细操作；衣摆、袖口、鞋、携带位置撑不撑得住
2. **远处辨认**：比例、轮廓、发型或头部特征，常用景别下认得出
3. **近处辨认**：少量稳定的面部、表皮或毛发特征；不靠堆首饰和伤疤造身份
4. **身份与环境**：服装层次、工艺、使用痕迹符合时代、生活方式、当地环境
5. **同场关系**：常同框的人并排看，轮廓、体量、明度、色块会不会混
6. **媒介适配**：二维保轮廓与色块；三维强调体积与材质差异；写实看剪裁与佩戴是否可信

通常先改善最影响识别的一项，不必同时放大轮廓、提高饱和、加饰物。性格约束选择，不等于身体特征：谨慎不必瘦削，强硬不必方脸。当场紧张、怒视、弯腰归镜头表演，不进资产。

- **出场 3 秒身份可读**：连载短剧与漫剧的主要角色，要在第一次亮相的 3 秒内靠剪影、衣着阶层感、职业痕迹或一件标志配饰让人认出他的处境与身份，不靠字幕条解释。
- **表里反差按状态分层**：角色有"公开身份 vs 隐藏底牌"或表里反差时，常态板只画公开身份的外观，最多留一处不抢戏的细节伏笔（指节旧茧、袖口压痕、不合阶层的旧物）；底牌揭开后的造型另建变体，不把两层身份叠在同一张常态板上。
- **漫剧主色错开、特效不进常态板**：非写实漫剧高度靠发色、主次色块和剪影认人，常驻角色主色互不撞色；能力触发时的发光、气场、特效留给具体镜头或变体状态，不画进常态角色板。

**两个人长得像时**，先做"谁是谁"：用体量、衣着、站位这些可见差异把两人分开，并在资产与提示词里都声明不混、不换。这是最容易换脸的地方。

**动物**按既定身体结构和自然姿态适配，不因套模板长出额外器官。

### 场景

先有**空间母版**，再谈取景。母版固定地点的完整边界、结构与关系；子区域只从母版里取一部分。

1. 列出这场必须发生的进入、停留、交互、离开，找出空间要承担的任务
2. 用稳定锚点定空间：入口、窗、柜台、楼梯、地形边界；多扇门窗给能区分的名称
3. 写锚点的相邻、相对、连通、高差，再落普通陈设，保留必要数量与尺度
4. 检查主行动路径：家具不能堵死必经路线，也不能为方便运镜凭空加门
5. 母版里的局部命名成子区域，记边界、父级、沿用的陈设
6. 真正破损、陈设移动、天气影响时另记状态；取景外的物件继续存在

关系用锚点写（"入口正对柜台，侧窗下有长桌，桌与柜台之间够两人错身"），少用没有参照的左右。换个取景，不能把原来的长桌换成更上镜的圆桌。**一张图只允许一个地点**；地点过宽时声明"本段只出现其中这一部分"。

### 道具

1. 摘出已定功能：观众要认出什么、人物必须怎么用、哪个状态变化推动事件
2. 从使用动作倒推结构：抓握位置、开合关系、连接方式、可见信息区、必要尺度
3. 选与时代、环境、操作相容的材质工艺
4. 使用痕迹放在有理由的部位：常按的按钮、常握的边缘；不均匀撒满划痕
5. 写清完整态与必要的变化态，其余保持一致

先查它是否已在角色造型或场景陈设里出现过，沿用同一设计。只在剧情已给出时写密码、铭文、印章；未知信件的内文不能由美术补成答案。物件显眼程度服从揭示时机，不提前暴露本该藏住的证据。

### 群像

先定共同项：身份、衣着年代、材质工艺、配色范围、与主体的关系；再挑覆盖真实差异的样本（年龄、体量、职责服装）。小群体里每人要持续辨认的，给稳定标识与个人资产；大群体只定义允许出现的外观范围，不让三个样本变成剧情全部人数。

## 四、板怎么设计

三类板各管一件事，混在一起会互相污染：**角色板只交身份，地点板只交空间，道具板只交物件。** 资产图是跨镜长期引用的参考，不是某一镜的首帧；一套资产一个固定版本，全片每镜引用同一张。

### 角色板

默认版式：一张横排板，头部特写、正面全身、右侧 90° 全身、背面全身。设计上的要点：

- 多面板是同一身份、同一状态，换角度还是同一个人。
- 特写给两张：一张无表情、一张微笑，**同一副牙齿与下颌**，否则一笑就换人。
- 写实与三维用中性灰无缝背景、柔和均匀的漫射光；二维用符合画风的平涂背景。不写"影棚"，免得器材和主光被画进画面。
- **板上不要边缘光。** 那圈光会被带进每一个镜头，人物不再对真实光源作反应。
- **双手空着。** 在板里出生的道具永远放不下；每件道具都是独立资产。
- 已经发生换脸时的单例技巧：把全身面板的头去掉，让特写成为脸的唯一来源。默认不这么做，用了要在版式说明里写明例外。

### 地点板

- 用宽的 3/4 视角，不用正面；正面读不出体积，换机位就换房间。
- 留一个可抓的锚点（柱子、灯、歪椅子），让走位有地方挂。
- **一条光逻辑**：一个主光源、一个投影方向。
- 无人、无武器；真实表面（锈、裂缝、胶带、油渍、水痕）。

### 道具板

- 用产品照语言：中性灰背景、柔和均匀光、真实材质。
- 文字只有两种合法处理：给精确文案加字体、字重、颜色；或写成空白、无品牌。含糊的"加文字"会糊；写到品牌名就会被画上去。

### 板不拥有镜头的光与调色

板交的是身份、结构、材质本色与表面。板上的光型、色偏、景深不该被镜头继承——道具板的产品光不能当场景光。光与调色留给具体镜头。

### 图片短，视频长

资产图是"一次外科手术"，一个提示只解决一个目标；视频提示才把空间、光、表演全部写进去。用视频的写法写资产图会稀释指令。画幅由"要完整展示什么"决定：角色板装下全身，地点板装下体积，道具板看清结构。模型选择以项目 `AGENTS.md` 为准；需要帧内文字、多张参考编辑、宽画幅时，先核对当前模型支不支持。

## 五、参考的职责与优先级

| 参考 | 拥有 | 不拥有 |
|---|---|---|
| 角色 | 脸、身体、年龄、比例、服装、独特锚点 | 机位、构图 |
| 地点 | 建筑、材质、地理、地标、光向 | 机位角度、取景、裁切 |
| 道具 | 形状、尺度、材质、状态 | 摆在画面哪里、被谁拿 |
| 载具 | 型号、涂装、车牌、车门、损伤 | 机位与运镜 |
| 风格 | 质感、影调、颗粒、调色 | 身份、走位、动作、光学、光 |

优先级写死：**身份 > 空间与动作 > 光学与光 > 风格**。地点参考不覆盖本镜机位；风格参考不覆盖身份、走位与光。

**参考图是身份的真相，文字只补本镜需要的锚点。** 长段外貌描写会和参考图竞争，最后取平均，越写越不像。一张脸只留一个来源。

## 六、十次测试、采用与验收

一张好看的板什么都证明不了，资产要在运动里活下来才算数。

**十次测试**：不同动作、不同景别、不同地点，生成十次，十次都认得出是同一个。把角色和他的地点放在一起测。角色另加四项压力：**哭、笑、说话、打电话**——平静特写最像，也最会骗人。测试是生成，每一批都要先问用户；可以先测 3 次，通过再补满。

崩了先改词；**同一个问题第二次出现才重建资产**。

验收逐项勾：

- [ ] 身份与结构对
- [ ] 身体完整：不裁头、不截身、不切脚
- [ ] 面板或视图的顺序与状态一致
- [ ] 空间布局走得通
- [ ] 没有夹带主体（角色板里没有房间，地点板里没有人）
- [ ] 剧情反查：角色做得了剧本里的动作，场景走得通，道具用得起来

测试留记录：动作、景别、地点、通过数；结论三选一：**通过 / 改词 / 重建**。

**采用以后**：已采用的与候选分开存；视频只引用资产的身份、空间、结构与本色，不复现板的背景、光、网格与视图数量；记录版本与影响范围，改版时知道哪些片段要跟着重做。

## 七、改资产与变体

**只改变化的部分。** 整板重渲会让身份在模型里再过一遍而退化；第二版还像，第五版就换人了。

**变体从上一状态改，不从母版重造。** 母版只作身份对照；换装、伤口、污损从最近一次状态的图改起。退化只累积、不回退：上一场的伤、脏、破损要带过来。

**变体相对哪张参考图写**：先确定所引用的参考图处于哪个状态，再写相对它的完整差异——此前仍有效的伤势与损坏要写上，否则模型默认复原。例：第 2 场左袖撕裂、第 4 场徽章掉落、第 6 场更衣。第 4–5 场引用基础图时写"左袖裂口保留，胸前徽章已缺失"；只写"去掉徽章"，袖子会被顺手复原。第 6 场更衣能解除衣物破损，治不好同时存在的手背伤口。同一张图只表示一个状态；相邻状态外观完全相同就合并复用。

**改到多大就不叫修图**：只改一处、其余不变 → 修图；要改两处以上，或要动构图、身份、景别 → 回生成重建整板。修图写四行：

1. 一句话目标
2. 只改：这一处，描述精确
3. 严格保持：脸与身份、头发、痣与饰品位置、姿态、构图、服装道具、背景、光向、调色、颗粒
4. 再写一遍只改的这一处，收尾"其余完全相同"

一次只改一个主题。**脸是不可触碰区**：不重塑、不美化、不磨皮、不瘦脸、不改年龄、不重打光——换一件外套就把脸磨平，是最常见的事故。

**新状态给新名字，不覆盖旧文件**。命名按项目 `AGENTS.md`（默认 `角色-状态-版本`）；同一空间的白天、夜晚、雨各是一份资产。
