# 声音

S4 写进视频提示词的声音，和 S6 的配音、音效、配乐、字幕。表演上"话怎么说"不在本文。

## 一、生成音频默认打开

项目 `AGENTS.md` 的生产偏好默认打开视频的同遍音频。打开不等于不用写：提示词里照常写底噪、带秒数的声事件和"不要配乐"，不因为默认打开就省掉声音块。

只有唱歌镜临时关掉，且属失败处置，不是默认：模型唱不好，嘴对不上或拒演。先录好歌轨 → 这一镜关掉生成音频 → 嘴型按歌轨写 → 后期把歌轨铺上。

关之前说清哪几镜关、为什么、关掉后这一段靠什么出声。

## 二、四层：底噪、事件、远近、收尾

一段声音要写得能逐项勾：

- **底噪是声源清单**：日光灯电流、房间低频、屋顶雨声。写得出源，模型才填得满；写"安静"两个字，得到一层空。
- **至少三个带秒数的声事件**，每个落到具体时刻，一条一个可听事件，分号隔开，顺序即时间序。
- **远近三层**：远处走廊的脚步、中景椅子的轻响、贴身的呼吸。只写一层，声音就贴在脸上。
- **全片只有一次"最响的一下"**，落在有动作的那一秒。
- **收尾写声音怎么退**："所有声音退到只剩雨和呼吸"。

## 三、声画共用一根时钟

声音的秒数和动作时间轴同源：滴水声写在 15.7 秒，画面就在 15.7 秒落水。两边对不上，观众听到的和看到的不是一件事。

每段静默都要装进三种功能之一：**评估、决定、拒绝回答**（"这段静默是一次评估：他把回答咽回去，然后开口"）。装不上功能的静默直接剪掉，否则看起来就是掉帧。

## 四、声音身份：一条音色块，逐镜不改

每个有台词的角色**有且只有一条音色块**，一两句，每一镜逐字相同。音高、口音、语速不许逐镜改——同一角色三场戏变声，观众立刻听出换了人。四项齐全：

```text
［年龄］岁的［出身 / 口音］。［音高与音色］；［语速与说话方式］；［情绪特点，以及压力下怎么变］。
```

> 三十多岁的本地口音男声。声音偏低、略沙；说话慢，句尾常常收住不说完；平时压着情绪，被逼急了反而更轻、更慢。

分工：表演段写"说话在戏里怎么表现"（节奏变化、低语、说一半停住）；音色块锁"声音本身"，两者不打架。给台词加"愤怒地说"会和音色块冲突——情绪写进表演段，不改音色块。出场但不说话的角色不写音色块。

## 五、对白纪律

台词块写四个事实：**谁说、什么时间窗、谁闭嘴、混音怎么让路**。

- 说话人与时间窗："甲（0.5–2.0 秒，画面左半）"。
- **只念引号里那句**：逐字照剧本；台词之外只有呼吸与空间声。不写会多出剧本没有的"嘿""等等"。
- **不说话的人嘴唇静止**，只有呼吸与眨眼，台词之间闭合。
- 镜头一开始就说话的，在动作开始后 0.3 秒内起句（片段首尾各 0.5 秒的剪辑余量不算在内，所以一条片段的第一句台词最早落在 0.5–0.8 秒）；需要余韵的，台词前后各留 1 秒以上。前两秒全是动作，台词会被挤到后段截断。
- **一镜一句**，一个说话人一个切分点，回答放进下一镜。抢话可以，关键词保持干净。
- 混音写一句可执行的："环境声在台词下面让路；人声近、干净"，再从声场三选一：隔着门传来 / 贴着麦几乎没有房间感 / 带大空间的短回响。
- 台词保留原语言和原文，不翻译、不显示成字幕、口型对齐。
- 要带上一镜的台词做衔接，只作声音上下文，不点人名物名——点了就会被画出来。

## 六、配乐

- **镜头提示词里默认不写配乐**，只写现场声与画内人声；配乐在 S6 统一铺，写"音乐后期添加"。
- 画内有声源（收音机、街头乐手）时，把"有源声"和"配乐"分开写：有源声进声事件，配乐仍不写。
- 配乐算本镜叙事（卡点、MV、歌词版）时，进项目层定曲目与节拍点，镜头里只写动作与节拍的对位，不让模型自己编曲。
- 音乐来源、TTS 音色在项目 `AGENTS.md` 的生产偏好里定，没定就问。

## 七、剧本声源标记怎么落成声音

| 剧本标记 | 提示词里怎么写 |
|---|---|
| 角色台词 | 台词块：说话人、时间窗、原文；其他人嘴唇静止 |
| `画外音` | 声明说话人不在画面里；画内可见角色嘴唇闭合 |
| `旁白` / `心声` | 默认不进视频生成，S6 后期配；画面里人物嘴唇闭合 |
| `书声` | 画面给文件或书信，声音后期配；不让模型自己念 |
| `系统音` | 作为声事件写进时间轴（"3.2 秒广播提示音响起"） |
| `画面字` | 进画面描述，引号内保留原文 |

## 八、可直接用的写法

**音频块**（按材质逐条铺开，时间点按本镜实际写）：

```text
底噪：屋顶的雨，木屋结构的低频，日光灯电流，远处狗叫两声又停。
0.8 秒 风把窗纸推响一下；3.2 秒 远处有车碾过湿石；7.6 秒 屋檐的水线断开；
12.0 秒 湿外套在椅背上摩擦；15.7 秒 一滴水砸进桌面水洼正中；
21.4 秒 全片最响的一下：门被撞开。
远近：远处街上的雨与人声，中景衣料与椅木，贴身的呼吸。
收尾：所有声音退到只剩雨和呼吸。只有现场声与画内人声，音乐后期添加。
```

**收尾常量**（按本镜选一句，逐字粘贴）：

- 无对白、无音乐、仅现场环境声。
- 除写好的台词外全部为现场同期声，音乐后期添加。
- 台词之外没有人声。

## 九、S6：配音、音效、字幕

- **配音先于口型**：用外部配音或 TTS 时，先定配音时长，再按语音节拍写动作时间轴；口型对不上就只重跑这一条，不整段重来。
- 用原生音频时，S6 只补生成里没有的：旁白、心声、书声、配乐、补强的音效。
- 音效给冲击点和规则触发点；全片响度统一，台词始终压在音乐和环境声之上。写实短剧以现场同期声和台词交锋为主，音效与配乐克制点在反转、冲突峰值或集尾切断处；漫剧更仰赖配音张力、情绪转折处的配乐切入与高频动作反应音效（心跳骤停、器物出鞘、定格重音）托住画面冲击，`心声` 与 `旁白` 混音时可拉开一点近麦或空间感以便一耳朵分清画内开口与内心独白。
- 字幕避开画面底部与右侧边缘区域，不遮脸；剧情片的字幕只放台词，不放设定解释。

## 十、常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 跨镜音色漂移 | 音色块被同义改写 | 音色块逐字冻结，换一个词就算失败 |
| 跨镜环境声不匹配 | 每镜各写一套气氛 | 一条共享气氛，压在连续底噪上 |
| 全片一层底噪、该响的地方一片安静 | 四层没写全 | 补声事件与远近三层 |
| 不该说话的人嘴在动 | 没写其他人嘴唇静止 | 每个台词块写谁闭嘴 |
| 多出一句没人写的话 | 让模型自由发挥 | "只念引号里那句" |
| 台词被截断 | 开头堆了动作 | 0.3 秒内起句，或拆镜 |
| 想要收音机却得到配乐 | 有源声与配乐没分开 | 有源声写进声事件，配乐写"后期添加" |
| 嘴对空、拒演唱歌 | 模型不会唱 | 先录轨、关生成音频、锁嘴型、后期铺轨 |
