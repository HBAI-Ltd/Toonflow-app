# 生成与返修

S5 用：开抽之前定预算和过线标准；一镜不对时归到哪一层、先动哪一处、什么时候止损。具体修法在各对应方法里，本文负责分诊和纪律。

每一次生成都要先问用户：生成什么、几张或几条、用来确认什么。

## 一、开抽之前：预算与过线标准

开抽之前就写下"抽几次、什么算过"，别抽到一半凭心情决定。问用户要授权时，把这两样一起说清。

| 镜头 | 预算 |
|---|---|
| 主镜 | 4–8 次，超过就改词 |
| 过场、交代 | 2–3 次 |
| 群像、多人对话、复杂手部、镜面与水面 | 6–12 次，先拆镜降难度 |
| 低分辨率试抽 | 2–4 次 |

写下用途分配再动手："本镜预算 6 次：3 次同词、2 次换光向、1 次换机位"。主镜只抽 2 次、过场却抽 8 次，是最常见的预算错位。

**五项各打 1–5 分**：

| 项 | 1 分（直接弃） | 5 分（主镜想要的） |
|---|---|---|
| 脸 | 换了人、五官漂移、死眼 | 极端表情下仍是同一个人，眼神有微行为 |
| 光 | 平光、脸被补亮、没有真正的黑、光向反了 | 单一动机光源、明暗比可数、高光只在允许处 |
| 空间 | 越轴、瞬移、家具漂移、纵深塌平 | 机位与轴线全对，地标距离与参考一致 |
| 动作 | 漂浮、穿模、不成形 | 重量转移、接触点、布料延迟都在 |
| 表演 | 挤表情、等提示、死脸 | 连续行为、反应先于台词、一个意外但真实的选择 |

弃与过：任一项 1 分立即弃；脸、光、空间任一低于 3 分弃；主镜总分 ≥ 17 且表演 ≥ 4 才过；过场总分 ≥ 12 且脸 ≥ 3 就过。抽完只打勾排序，不再商量。

**抽 20 条选不出一条，是标准没写，不是数量不够。** 评价一条提示词写得好不好，看"5 次里中几次"，不看"这一次中没中"。

## 二、分诊：先钉到层，再上阶梯

改之前先把症状钉到一层：

| 看到的 | 层 | 先查什么 |
|---|---|---|
| 下一镜换了人、换了脸 | 身份 | 是否只挂了一张身份参考；外貌描写是否和参考图竞争；身份锁写没写 |
| 镜头滑向中景、该压缩的没压缩、脸变形 | 光学 | 一镜是否锁死一个视角；是否写了视角 + 距离 + 结果；有没有写"超广角拍脸" |
| 画面平、脸被补亮、没有真正的黑 | 光 | 曝光优先、允许的高光、明暗比、光向是否写明 |
| 动作飘、道具没重量、像游戏引擎 | 运动与物理 | 接触点、重量转移、在途状态写没写；动作总量是否超时长 |
| 机位一动空间就散、越轴、瞬移、道具变两个 | 空间与尺度 | 每场是否有一份不变的空间地图；轴线、地标距离、物件数量写没写 |
| 脸在演、身体在休息、死眼、群演同步 | 表演 | 有没有目标与战术；反应是否早于话尾；每 1–2 秒有没有可见微事件 |
| 台词、嘴型、音色跨镜漂 | 台词与声音 | 音色块是否逐字一致；不说话的人是否写了嘴唇静止 |
| 上一镜的人或物混进本镜、多出一个人 | 上下文 | 正文里有没有"之前、同上、接上一镜"；参考是否只挂本镜出场的 |
| 越禁越出现 | 负向 | 描述性正文里有没有"不要 X"；改成正面状态 |
| 板上的轮廓光、影棚光进了每个镜头 | 板与镜头的分界 | 板上是否有边缘光或影棚光；板只交身份、结构、本色 |

然后按五档**一次只上一档**：

1. **改词**：描述、单位、视角、锁。最便宜，第一次失败只许动这一档。
2. **改参考或资产**：同一处第二次坏，才允许动资产。只坏过一次就重做板，会把好板重做三遍而问题还在提示词里。
3. **改参数**：换条数、换时长、换视角、唱歌镜临时关生成音频。
4. **改内容**：动作在时长内做不完、复杂动作放在中段，回分镜改：过渡动作改成已到达的状态，一镜两个大动作拆开。
5. **只能绕**：模型先验，见四。

三条纪律：**只补失败的那一段**，不整条重写——会把对的部分一起丢掉，下一版也没法比较。**回读参考素材，不回读上一版提示词**——连续几版都打在错的那一端，通常是描述已经和素材脱钩。**说得出错在哪一层再改**；文本自检通过但结果仍偏，记为生成偏差，不倒推改剧情，也不承诺改几句就一定成。

## 三、同词重抽，还是改

| 类别 | 例子 | 处置 |
|---|---|---|
| 抽得出来 | 构图轻微偏、光比略偏、手位高低、动作快慢、表演的随机细节 | 同词重抽 |
| 抽不出来 | 身份漂移、越轴瞬移、漂浮穿模、镜头性格错、参考构图被继承、冒出文字水印、群像同步 | 改词 / 改参考 |
| 灰区 | 复杂手部、多人对话、镜面水面、拥挤人群 | 先拆镜降难度，再给小预算 |

四条纪律：

1. **一轮只变一个量**：种子、一句措辞、一张参考、换模型，一次只动一样。
2. **前 2–3 次用原词重抽**，先排除随机性，再谈改词。
3. **同词三次不中就停**，改词、改参考或拆镜，然后重新数三次。不许在同一条词上抽到第九次。
4. **命中就归档**，写清它锚住的是什么：脸、光、几何还是构图。

低分辨率里选中不等于成片：记下参数 → 同词升档重跑 → 重新打一次脸分。升档后脸崩、皮肤发蜡，说明这条只在低分辨率成立。

## 四、修不了的：模型先验

连改两版仍同一症状，先在这张表里裁定。命中就换结构，不再加描述。

| 看到的 | 病因 | 怎么办 |
|---|---|---|
| 平光、脸被补亮 | 补光先验 | 半可修：写死逆光曝光、允许脸进深阴影；仍平就改侧逆光构图或夜景 |
| 越禁越出现 | 否定把概念注入画面 | 可修：改正面句，两侧夹住 |
| 15 人以上塌成 3–5 人 | 人群被当成可数个体 | 绕：人群当资产 + 前景配角，写边缘身体不写人数 |
| 写"超广角"一拍脸就变形 | 取最广的刻板印象 | 绕：写度数加距离 |
| 复合运镜被平均 | 一镜两种运镜 | 绕：只留一条主轴 |
| 嘴对空、拒绝唱歌 | 能力缺失 | 绕：先录轨、关生成音频、锁嘴型、后期铺轨 |
| 形容词没有约束力 | 装饰词扩大采样空间 | 可修：换成可检查的事实 |
| 尾条只剩一两秒 | 时长机制 | 绕：重排条数，改成均分 |
| 器材词几乎无效 | 视频模型不认器材 | 绕：视频写结果，器材词只给图片 |

裁定成"绕"的，把绕法写进项目状态文件，下一版直接用。

## 五、止损：看失败同不同形

- **每次坏在同一处（同形）** → 只改那一行词，别动结构。
- **每次坏法都不一样（不同形）** → 简化镜头，不简化句子：拆两半、删一个动作、换角度。
- 同一镜换到十几版还没过，就换镜头，不换句子。到这一步说明它已在模型能力边界外，继续打是沉没成本。
- 过了止损线不再提交原措辞。只删形容词没有用——镜头本身装不下，删词救不了。

> 例：门怎么都撞不开，演员在门口磨蹭后冻住。解法是把"已在破门中"写到这一条开头，接近的过程另起一镜。

## 六、失败先归到一个词

返工时先问：这次失败能不能归到**一个词**？能，就记进项目的触发词台账，按词族清，不按单词清：

| 触发词（词族） | 模型实际做了什么 | 改成什么 |
|---|---|---|
| 柔、柔和、轻轻地 | 柔光、柔焦、软影 | 低、轻、小、微弱 |

只记"眼睛看起来很假"这种现象，下次无法检索，照犯；只记单词不记词族，"轻柔"就会漏掉。

## 七、把判断固化成规则

规则库是伤疤录，不是美学宣言：只有"因为没写它而废过一个镜头"的判断才值得固化。写之前过三问：

1. 跨镜会复现吗？偶发的只记日志。
2. 能绑到具体的块或槽吗？答不出"改哪里"的不写。
3. 只在这部片成立吗？是就写进项目状态文件或画布上的规则节点；跨片都成立，才提议改进本 skill 的方法论。

条目一律三段式：**症状 → 修法 → 放进哪一块**。新坑追加新条目，旧条目不重排不删除。规则写了不等于被遵守：定期拿几条已通过的提示词回查，规则没被执行就补，不把"写进文档"当成"生效"。
