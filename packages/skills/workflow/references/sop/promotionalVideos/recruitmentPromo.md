# 招聘宣传片

让人投简历：降低申请阻力，回答"我为什么要来这儿"。说服力来自可验证的细节，不来自"朝气蓬勃"。

## 一、适用 / 不适用

- 适用：校园招聘片、社会招聘片、雇主品牌片、宣讲会开场片、招聘网站与朋友圈投放片。主片 90–180 秒，另出竖版切片与宣讲会版。
- 不适用：讲公司整体实力 → `companyPromo.md`；讲某个岗位的职责与操作 → `educationalVideos/skillTutorial.md`；年会、活动纪录 → `documentariesAndEvents/`。
- **一句话判据：看完的人知不知道"来了能得到什么、怎么投"？** 只知道"公司很好"，还不是招聘片。

## 二、开工必问

一次一个。

1. 招谁：校招、社招、技术、蓝领，还是管培？——决定他们最担心什么。
2. 他们现在最担心哪一件：成长、项目意义、钱、稳定，还是城市与生活？——决定三条承诺。
3. 有哪些真实员工可以出镜（不同年限、岗位、性别）？——决定人物覆盖面。
4. 用在什么场合（宣讲会开场、双选会循环、线上切片）？——决定时长与版本。

答不上来落保守值：120 秒主片 + 3 条竖版切片 + 无声循环版，员工原话为主，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 主片时长 | 90–180 秒 | 宣讲会开场版可到 3 分钟 |
| 版本矩阵 | 1 条主片 + 2–3 条竖版切片（30–60 秒）+ 1 条无声循环版 | 切片一条只讲一件事：成长、项目或生活 |
| 字幕 | 单行 ≤ 16 字；关键承诺上字幕 | 校招片多在手机上看 |

先定三条承诺，再定镜头。三条承诺写不出来，先去做员工访谈，别开工。

## 四、结构

120 秒主片：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 真话开场 | 0–5 秒 | 0–4.2% | 一个真实动作或一句员工原话（"我第一年做废了三版"） |
| 谁在这里工作 | 5–20 秒 | 4.2–16.7% | 三张脸、三个岗位、三个年限，让人对号入座 |
| 承诺一：成长 | 20–45 秒 | 16.7–37.5% | 一个具体成长路径：谁带的、多久、学会了什么 |
| 承诺二：项目 | 45–70 秒 | 37.5–58.3% | 一个说得清的项目，以及他负责哪一块 |
| 承诺三：生活 | 70–90 秒 | 58.3–75% | 通勤、食堂、宿舍、城市；给可核的细节 |
| 加入路径 | 90–110 秒 | 75–91.7% | 流程几步、多久出结果、在哪投、什么时候截止 |
| 收束 | 110–120 秒 | 91.7–100% | 一句可验证的承诺 + 投递入口 |

切片（30–60 秒）：一条只留一条承诺 + 路径；竖版第一帧就要有人脸和一句真话。

三条硬约束：单条片出镜员工 ≤ 6 人；每个承诺后面跟一个可核细节（数字、地点、制度）；不出现"广阔平台""无限可能"这类无法验证的词。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 出镜员工 | 4–6 | 统一形象 | 真实员工；服装与工牌统一，不要全员西装 |
| 工作场景 | 5–8 | 核心 3 个 | 工位、会议室、实验室、车间、食堂 |
| 生活场景 | 2–3 | 否 | 通勤、宿舍、城市街景；真实优先 |
| 物料 | 按需 | 否 | offer、工牌、培训手册；文字核对清楚 |
| 数据 | 3–5 | 否 | 招聘人数、转正率、平均司龄、晋升周期；有出处 |

不用演员冒充员工，不用生成人脸替代出镜人。员工不愿出镜就拍手、工位、他做的东西。生成只做空镜、转场、城市氛围。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定招聘对象与时长版本 | 规格表 + 版本表 |
| S1 | 3–5 个员工访谈 → 三条承诺 → 脚本 | 承诺表 + 访谈记录 + 脚本 |
| S2 | 盘点可出镜员工与场景 | 资产表 |
| S3 | 需生成的空镜场景做板 | 已采用资产 |
| S4 | 采访提纲 + 空镜提示词；不写员工台词 | 提纲 + 分镜 |
| S5 | 实拍为主线，生成补空镜与城市转场 | 素材库 + 粗剪 |
| S6 | 原声、音乐、字幕 | 混音母版 |
| S7 | 各版本按第八节验收；HR 核对口径 | 主片 + 切片 + 无声版 |

## 八、验收清单

- [ ] 5 秒内出现真实员工与一句真话，没有航拍开场
- [ ] 三条承诺各有一个可核细节
- [ ] 出镜员工是真实员工，姓名岗位核对无误
- [ ] 薪资、转正率、晋升周期有出处
- [ ] 加入路径清楚：几步、多久、在哪投、截止时间
- [ ] 静音看一遍，承诺与路径都在字幕上
- [ ] 竖版单独构图，人脸不被裁
- [ ] 片尾有可扫的投递入口

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 全是航拍、笑脸、跑步 | 按企业片套路拍 | 换成员工原话与工位细节，第一帧就有人 |
| 领导讲话占一半 | 把招聘片当内部汇报 | 领导最多一句 |
| 只讲情怀不讲路径 | 忘了观众要投简历 | 最后 20 秒补"几步、多久、在哪投" |
| 承诺过度 | 没和 HR 对口径 | 改成制度能支持的表述 |
| 片子好看但没人投 | 没有行动入口 | 片尾加二维码、网址、截止日期 |
| 三条竖版切片讲同一件事 | 切片没分工 | 成长、项目、生活各一条 |
| 受访者都说"氛围很好" | 问题问的是感想 | 改问"今年哪一件事让你觉得值得" |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；表里的数字是示意，实际以 HR 书面确认为准。

- 需求："我们是做工业机器人的，今年校招想做个片子，宣讲会开场放。"
- 落值：120 秒主片 + 3 条竖版切片 + 无声循环版；招机械与电气专业应届生；他们最担心"进去只是打杂"。
- 一句话：看完知道"来了三个月就能自己调一条产线，投递截止 10 月 31 日"。

承诺表（从 4 个员工访谈里提炼）：

| 承诺 | 员工原话 | 可核细节 | 出处 |
|---|---|---|---|
| 成长 | "第一个月师傅就把示教器交给我了。" | 新人配带教师傅，三个月独立调线 | 培训制度文件 |
| 项目 | "我第一年调的焊接线，现在在电池厂跑。" | 新人参与的真实项目 | 项目部确认 |
| 生活 | "宿舍到车间骑车十分钟。" | 园区宿舍两人间、通勤班车 | 行政部确认 |

开场 0–5 秒用第二句原话配他站在那条焊接线前；加入路径段（90–110 秒）写清：网申 → 笔试 → 两轮面试，约三周出结果，投递入口与截止日期上字幕。

最容易错的一处：员工不愿出镜就生成几个"员工"。不愿出镜就拍他的手、工位和他调过的那条线。
