# 城市文旅

让人来：给一个非来不可的理由，并把"怎么来、来了做什么"说清。主片 2–4 分钟，另出 3–5 条竖版切片。

## 一、适用 / 不适用

- 适用：城市、区县、景区、文旅局的形象片、季节性推广片、节庆片、线路片。
- 不适用：招商引资、产业园区推介 → `companyPromo.md`（对象是投资人）；单一景区门票、酒店产品 → `productPromo.md`；纯航拍风光合集、无人物无信息的延时 → 观众记不住，先重写脚本。
- **一句话判据：看完的人知不知道"为什么现在去、去了做什么、怎么去"？** 只记得"风景很美"，不是文旅片。

## 二、开工必问

一次一个。

1. 给谁看：周边 3 小时高铁圈、全国、入境，还是本地市民？——决定交通信息与语言。
2. 现在最缺什么：知名度、淡季客流、过夜率，还是二次消费？——决定片子的目标动作。
3. 哪个东西"只有这里有"（一道菜、一门手艺、一个时辰、一句话）？——决定创意主张。
4. 有没有线下承接：活动、优惠、装置、预约、演艺？——没有承接，片子只涨播放不涨客流。

答不上来落保守值：3 分钟主片 + 3 条竖版切片、周边 3 小时高铁圈、目标动作是"来过一夜"，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 主片时长 | 2–4 分钟 | 常见 3 分半左右 |
| 切片 | 3–5 条、30–60 秒 | 一条只讲一个点：一道菜、一个时辰、一条街 |
| 可带走的东西 | 1 个 | 一张优惠券、一枚印章、一句能在评论区复述的话 |
| 字幕 | 地名、店名、价格、时间必须上字幕 | 方言与外语都要标 |

## 四、结构

3 分钟主片：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 具体的人 | 0:00–0:05 | 0–2.8% | 一个具体的人、一句方言、一个动作；不要航拍开场 |
| 为什么现在来 | 0:05–0:30 | 2.8–16.7% | 一个情绪理由（累了、想带孩子看真的），不说"历史悠久" |
| 可体验一：吃 | 0:30–1:00 | 16.7–33.3% | 一道菜，从做到吃，给店名与价格区间 |
| 可体验二：看 | 1:00–1:30 | 33.3–50% | 一个只有这里能看到的场面或手艺，给时间与地点 |
| 可体验三：做 | 1:30–2:00 | 50–66.7% | 一件能上手的事（做、穿、坐、走），给预约方式 |
| 城市性格 | 2:00–2:30 | 66.7–83.3% | 一条街、一个夜晚、一种节奏；让人相信这里值得待两天 |
| 怎么来 | 2:30–3:00 | 83.3–100% | 交通、最佳季节、优惠、可带走的东西；给一个动作 |

切片：一条只留一个可体验点 + 一个动作；竖版 0–2 秒必须出现具体的人、食物或手艺。

三条硬约束：5 秒内出现具体的人；至少 3 个可导航地点（地图搜得到、名字与字幕一致）；必须有 1 个可执行动作（扫码、领券、预约）。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 地标 / 街区 | 6–10 | 核心 4–5 个 | 一个地点一张；声明"本段只出现其中这一部分" |
| 非遗 / 手艺 | 2–4 | 是 | 动作流程要能拍完整，不只拍成品 |
| 店铺 / 摊主 | 3–5 | 否 | 真实店名、真实人物 |
| 食物 | 3–6 | 否 | 从做到吃的完整动作 |
| 交通 / 活动物料 | 按需 | 否 | 高铁站、接驳、印章、优惠券；信息要能核 |

真实素材优先。生成只做氛围、转场、示意，**不用生成画面替代真实景点**——游客到现场会对不上。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 先定客源与目标动作，再定时长 | 规格表 + 目标动作 |
| S1 | 创意主张 + 可带走的东西 → 排点位 → 脚本 | 主张卡 + 脚本 |
| S2 | 盘点点位与开放时间；标出可拍时段 | 点位表 |
| S3 | 需生成的场景做板 | 已采用资产 |
| S4 | 按点位写分镜；转场与氛围写提示词 | 分镜 + 提示词 |
| S5 | 实拍为主线，生成补转场 | 素材库 + 粗剪 |
| S6 | 同期声、环境声、音乐、字幕 | 混音母版 |
| S7 | 主片与切片分别验收；核价格与营业状态 | 主片 + 切片 |

## 八、验收清单

- [ ] 5 秒内出现具体的人、食物或手艺，没有航拍开场
- [ ] 有一个说得清的情绪理由
- [ ] 至少 3 个可导航地点，字幕名字与地图一致
- [ ] 有 1 个可执行动作
- [ ] 价格、营业时间、场次核对准确；方言、店名、地名文字无误
- [ ] 没有用生成画面替代真实景点
- [ ] 有线下承接

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 开场 30 秒航拍 | 按风光片套路 | 换成一个人在做一件事；航拍留到中段当标点 |
| 宣传语堆砌 | 没有具体主张 | 一个理由一个动作，写成一句人话 |
| 只有景没有人 | 怕真人不好拍 | 找摊主、手艺人、游客 |
| 点位已停业 | 没核最新信息 | 逐个核营业状态与交通，标出替代点 |
| 主片 5 分钟 | 什么都想放 | 砍到 3 分钟，删掉的做成切片 |
| 非遗当背景板 | 只拍成品 | 拍完整动作流程与人的手 |
| 切片用了主片没有的新地点 | 切片单独找素材 | 切片从主片的点位里长出来，一条一个点 |
| 价格写成"实惠" | 没去问 | 写价格区间，并注明核对日期 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；地名用"某县"代替。

- 需求："我们县想在 11 月淡季拉一波周边城市的游客。"
- 落值：3 分钟主片 + 4 条竖版切片；客源是周边 3 小时高铁圈；目标动作是"来过一夜"；线下承接：老街米粉店凭券送一碗早餐。
- 一句话：看完知道"累了就来这儿吃一碗早上五点的米粉，高铁下来公交 15 分钟"。

点位表（S2 的产物）：

| 点位 | 地图上搜得到的名字 | 开放时间 | 怎么拍 |
|---|---|---|---|
| 米粉店 | 某县老街 × 记米粉 | 5:00–13:00 | 实拍：凌晨开灶到第一碗出锅 |
| 晒腊肉的巷子 | 某县 × 巷 | 冬至前后 | 实拍 |
| 竹编工坊 | 某县竹编非遗工坊 | 需提前一天预约 | 实拍完整编织流程 |
| 江边夜景 | 某县滨江步道 | 全天 | 实拍；转场用一条生成的江雾空镜 |

0:00–0:05 是米粉店阿婆凌晨揭开锅盖，热汽扑上镜头；2:30–3:00 给高铁站到老街的公交线路和"米粉券"的领取方式。

最容易错的一处：竹编工坊淡季不开门，就用生成画面补。景点和手艺只能实拍，拍不到就换点位。
