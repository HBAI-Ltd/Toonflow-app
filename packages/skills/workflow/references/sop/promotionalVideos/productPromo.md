# 产品宣传片

解决一个具体的购买阻力：不知道、不信、怕麻烦、怕买错。时长 30–90 秒，横竖双版本，常需静音可看。

## 一、适用 / 不适用

- 适用：新品发布、电商详情页主视频、众筹预热、展会演示、门店循环。
- 不适用：讲公司整体实力 → `companyPromo.md`；真人出镜口播 → `ecommerceAds/salesPitch.md`；纯商品展示 → `ecommerceAds/productVideo.md`；没有样机、没有测试资料、也不打算补证据 → 先补证据，别先做片。
- **一句话判据：看完，买方少了一个具体的顾虑吗？** 少的是"我还不了解这家公司"，去 `companyPromo.md`；少的必须是"怕它不行、怕装不上、怕买错"里的一个。

## 二、开工必问

一次一个。第一个问题决定整条片的结构。

1. 目标买方此刻因为什么还不能决定：不知道这个品类、不信性能、怕装不上，还是嫌贵？——决定主主张。
2. 只能留一条主主张，是哪条？——其余信息只能当证据。
3. 样机能不能在真实条件下稳定复现这个结果？——决定主张是"可直接拍"还是"需补证据"。
4. 有没有测试报告、对比数据或实测记录？——没有就降级表述。
5. 要不要同时出静音可看版（如展会循环、详情页静音播放）？——决定版本与字幕密度。

答不上来落保守值：60 秒、横竖双版、一条主主张 + 两条证据、静音可看，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 30 / 60 / 90 秒三档 | 详情页主视频常见 30–60 秒 |
| 版本 | 横竖双版 + 静音可看版 | 竖版重新构图并保留条件字幕 |
| 证据配比 | 一条主主张 + 两条证据 | 证据超过两条，一条都记不住 |
| 字幕 | 单行 ≤ 16 字 | 不遮产品与手；生效条件进画面 |

## 四、结构

60 秒版：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 结果或冲突 | 0–3 秒 | 0–5% | 使用后的状态，或使用前的麻烦；不出现 logo |
| 品类与用途 | 3–10 秒 | 5–16.7% | 这是什么、给谁用、替代什么 |
| 主主张 | 10–20 秒 | 16.7–33.3% | 一个可观察的连续动作，看到起始状态与结果 |
| 证据一 | 20–30 秒 | 33.3–50% | 换一种证据形式（场景、对比、动画、引证） |
| 证据二 | 30–40 秒 | 50–66.7% | 最硬的一条，或换成"怕麻烦"那类阻力 |
| 条件与边界 | 40–52 秒 | 66.7–86.7% | 兼容设备、环境、版本、设置；条件入画 |
| 行动 | 52–60 秒 | 86.7–100% | 怎么买、怎么试、去哪看；回扣最硬的证据 |

30 秒版：结果 0–3、品类 3–8、主主张 8–20（条件并入字幕）、证据一 20–26、行动 26–30 秒。90 秒版：0–4 / 4–13 / 13–28 / 28–43 / 43–58 / 58–80 / 80–90 秒。

三种阻力对应三种开头：不知道品类 → 先给使用场景；不信性能 → 先给结果；怕麻烦 → 先给上手第一步。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 产品本体 | 1 | 是（2×2 板） | 材质、配色、丝印与实际一致 |
| 界面 / 包装 | 按需 | 是 | 屏幕内容、包装文字逐字精确 |
| 使用场景 | 3–5 | 是（母版） | 桌面、车内、户外、厨房；一个场景一张 |
| 手部 / 人物 | 按需 | 否 | 只出现手时不立角色资产；出现脸才建 |
| 对比样品 | 按需 | 否 | 竞品不露 logo、不指名，对比条件一致 |
| 测试素材 | 按需 | 否 | 报告、仪表读数、录屏；只用真实的 |

使用场景和质感镜可以生成；测试结果、读数、认证**绝不生成**。

本类目用不上：故事与剧作、表演与动作的角色主档与群戏。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定购买阻力，再定时长与版本 | 规格表 + 版本表 |
| S1 | 主张状态表 → 脚本 | 主张状态表 + 脚本 |
| S2 | 按状态表盘点样机、配件、场景、测试资料 | 资产表 + 缺口 |
| S3 | 产品板先做；界面与包装文字逐字校对 | 已采用资产 |
| S4 | 主主张与两条证据各一组镜头卡：条件、动作、结果、限制 | 证据镜头卡 + 提示词 |
| S5 | 实拍演示 + 生成场景镜拼接 | 素材库 + 粗剪 |
| S6 | 字幕、旁白、音效 | 混音母版 |
| S7 | 横竖版、静音版分别验收 | 各版本成片 |

## 八、验收清单

- [ ] 3 秒内出现使用后的状态或使用前的麻烦
- [ ] 只有一条主主张；另外两条只是证据
- [ ] 每条主张与证据都有可观察的镜头，不靠旁白断言
- [ ] 条件在画面里，不在片尾小字
- [ ] 所有数字、对比、"领先"表述有出处与范围
- [ ] 静音看一遍，关键结论都在字幕上
- [ ] 竖版重新构图，产品与手不被裁，条件字幕仍在
- [ ] 样机在拍摄条件下能复现，没有靠剪辑省略步骤
- [ ] 没有生成的测试读数；竞品不露 logo
- [ ] 结尾有明确行动

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 12 条卖点塞进 60 秒 | 按资料页顺序写 | 只留一条主主张，其余降为证据或删 |
| 用跳切假装"一秒装好" | 过程拍不出来 | 补真实步骤，或把主张降级为"几步完成" |
| 大字主张 + 小字免责 | 条件没进叙事 | 条件做成画面内字幕或旁白 |
| 生成画面伪造测试读数 | 没有真实素材 | 改用真实录屏或仪表，或改成体验表达 |
| 产品旋转 30 秒 | 没有购买阻力判断 | 先回答"他为什么还不买" |
| 90 秒版比 60 秒更散 | 只拉长时长没加证据 | 按 90 秒占比给主张、证据、条件各加时间 |
| 演示在样板间里，用户不信 | 环境太干净 | 至少一个镜头在真实用户家里或真实使用环境 |
| 条件字幕一闪而过 | 条件放在快切镜上 | 条件字幕跟着停留 ≥ 2 秒的镜头出 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我们出了一款免打孔的浴室置物架，要做详情页视频。"
- 落值：60 秒；电商详情页（竖版、静音可看）；购买阻力是"怕粘不牢掉下来"。
- 一句话：看完少了一个顾虑——"它在光滑瓷砖上真的挂得住"。

主张状态表：

| 信息 | 状态 | 处理 |
|---|---|---|
| 贴合 24 小时后承重 5 公斤 | 需说明条件 | 实测 + 条件字幕"光滑瓷砖，贴合 24 小时后" |
| 三步安装 | 可直接拍 | 撕膜、按压 10 秒、挂上，连续实拍 |
| 撕下不伤墙 | 需补证据 | 补一段撕下后墙面无残胶的实拍；补不到就删 |
| 防锈 | 删除降级 | 没有测试报告，不说 |

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–3 秒 | 结果或冲突 | 一个旧置物架连同瓶瓶罐罐从墙上掉进浴缸 |
| 3–10 秒 | 品类与用途 | 免打孔浴室置物架，租房也能装 |
| 10–20 秒 | 主主张 | 挂上 5 公斤哑铃，静置 24 小时的实拍延时，计时器入画 |
| 20–30 秒 | 证据一 | 三步安装的连续实拍 |
| 30–40 秒 | 证据二 | 一位租房用户家里用了三个月的样子 |
| 40–52 秒 | 条件与边界 | 字幕："只适用于光滑瓷砖、玻璃；墙砖有缝、墙纸不行；贴好 24 小时内别挂重物" |
| 52–60 秒 | 行动 | 下单时备注墙面类型，回扣那 24 小时的计时器 |

最容易错的一处：用生成画面拍"挂满东西的置物架"冒充承重测试。承重只能实测。
