# 公益宣传片

为**一个具体的行为改变**做片子：不酒驾、戴头盔、别信陌生转账、按时体检。

## 一、适用 / 不适用

- 适用：公益短片、公共屏循环片、安全与健康倡导片。
- 不适用：介绍某单位工作成绩 → `governmentPromo.md`；卖货或抬品牌 → `ecommerceAds/brandAds.md`；记录真实人物或事件 → `documentariesAndEvents/personalDocumentary.md`；只在内部播放的企业社会责任片 → 按企业宣传片做，别占公益的名义。
- **一句话判据：看完之后，观众要做的那一个动作是什么？** 说不出，这条片还停在"感慨"。

## 二、开工必问

一次一个，已知的跳过。

1. 想让观众看完**做哪一件事**？——只准一件，越具体越好（"骑车戴头盔"，不是"注意安全"）。
2. 谁最需要被说动：不戴头盔的外卖骑手、图省事的家长，还是嫌麻烦的上班族？——"全体市民"等于没说。
3. 要不要另出无声循环版（如公共屏播放）？——决定做几个版本与字幕密度。
4. 时长定多少：15、30、45、60 秒？——先定最需要的那一版，其余从它剪。

问两次还是"都行"，落保守值：30 秒、一个行为、主版 + 手机竖版 + 公共屏无解说版，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 15 / 30 / 45 / 60 秒，最长不超过 120 秒 | 30 秒最常用 |
| 版本 | 主版 + 手机竖版 + 公共屏无解说版 | 竖版重新构图 |
| 落版 | ≤ 5 秒 | 机构名称、热线或二维码清晰可读 |

## 四、结构

30 秒版：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 一个具体的人做一件具体的事 | 0–3 秒 | 0–10% | 不解释、不打字幕、不起音乐；先让人看见"这是真事" |
| 让人发现不对 | 3–12 秒 | 10–40% | 一个可验证的细节：头盔挂在车把上、屏幕上的转账界面 |
| 代价或反转 | 12–24 秒 | 40–80% | 不喊口号，让后果自己发生 |
| 动作 + 落版 | 24–30 秒 | 80–100% | 一句祈使句（"戴上"）+ 落版（机构名、热线、二维码），落版 ≤ 5 秒 |

15 秒版：细节 0–4、后果 4–9、动作与落版 9–15 秒。60 秒版：在 3–12 秒之后加一段"他本来可以怎么做"，其余按比例伸展。

四条硬约束：一条片只推一个行为；主角是**会被这件事影响的人**，不是宣传者、志愿者、领导；不用悲情音乐代替洞察；数据带出处与年份，没有出处的数字不上屏。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主角（受影响的人） | 1 | 是 | 要演得出"日常状态"和"出事之后"两个状态 |
| 配角 / 见证者 | 0–2 | 否 | 只出现在一个镜头里的不做板 |
| 场景 | 2–4 | 是 | 路口、家里、办事大厅；一张板一个地点 |
| 关键道具 | 1–2 | 是 | 头盔、手机、药盒、检测单——证据靠它落地 |
| 数据与证明 | 按需 | 否 | 事故统计、检测报告、热线号码：实拍或官方文件翻拍 |
| 落版素材 | 1 套 | 否 | 机构 logo、热线、二维码；后期叠加，不进生成 |

演绎部分可以生成；观众会拿去核对的读数、报告、通报、证件、热线、二维码**一律实拍或用官方素材**。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定一个行为 + 一个受众，再定时长与版本 | 一页规格 + 版本矩阵 |
| S1 | 一句主张 → 三个画面 → 选一个 → 脚本 | 主张 + 脚本 |
| S2 | 场景与人物盘点；证据类素材列实拍清单 | 资产表 + 实拍清单 |
| S3 | 主角板与 2–3 个地点板、道具板 | 已采用资产 |
| S4 | 一镜一个信息；同一场景光向一致 | 分镜提示词 |
| S5 | 生成演绎段，叠入实拍证据与落版 | 粗剪 |
| S6 | 音乐进出点、无解说版、两套字幕 | 混音母版 |
| S7 | 按第八节验收 | 各版本成片 |

## 八、验收清单

- [ ] 看完能说出一个具体动作
- [ ] 前 3 秒是一个人做一件事，没有风景、字幕卡、音乐起势
- [ ] 主角是会被这件事影响的人
- [ ] 全片只推一个行为，没有第二个行动号召
- [ ] 所有数字有出处与年份
- [ ] 证据类画面全部实拍或官方素材，无生成读数

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 看完只觉得"挺感人" | 只给了情绪没给动作 | 结尾换成一句祈使句 + 一个可见动作 |
| 30 秒讲了三件事 | 想一次说全 | 只留一个行为，其余拆成另一条片 |
| 主角是志愿者或干部 | 把宣传者当主角 | 换成受影响的人 |
| 画面太干净，像广告 | 素材缺使用痕迹 | 补灰尘、雨渍、旧漆、磨损，换成现场光 |
| 落版堆了六七个 logo | 各方都要露出 | 一个主体 + 一个支持单位 |
| 音乐很满、情绪很假 | 用音乐替代洞察 | 先减音乐，看画面还成不成立 |
| 后果拍得太血腥 | 想要冲击力 | 用物件和声音暗示后果，不拍伤者 |
| 落版热线号码错了 | 抄了旧材料 | 热线向主体单位书面确认后再上屏 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："交警支队要一条劝骑手戴头盔的公益片。"
- 落值：30 秒主版 + 15 秒版 + 公共屏无解说版；受众是外卖骑手。
- 一句主张："头盔挂在车把上，等于没戴。"三个候选画面：头盔在车把上晃 / 头盔扣着却没系带 / 骑手把头盔挂在后视镜上去取餐——选第一个，最常见。

| 时间 | 段落 | 画面与声音 |
|---|---|---|
| 0–3 秒 | 一个人做一件事 | 骑手拎起头盔，随手挂在车把上，拧动电门 |
| 3–12 秒 | 让人发现不对 | 头盔随颠簸在车把上来回晃，他低头看手机导航 |
| 12–24 秒 | 代价 | 一声急刹，画面里只有那个头盔从车把上滚落、在马路上转了两圈停住；不拍人 |
| 24–30 秒 | 动作 + 落版 | 一只手把头盔捡起来扣在头上，咔哒一声；字幕"戴上"；落版：支队名称与热线，4 秒 |

最容易错的一处：为了冲击力拍伤者和血。用一个滚落的头盔和一声刹车就够，后果留给观众自己想。
