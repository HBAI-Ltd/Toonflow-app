# 企业宣传片

让看的人**相信这家公司做得到**：有真实场景、真人、数据与客户可拍。主片 2–5 分钟，另出切片与竖版。

## 一、适用 / 不适用

- 适用：公司形象片、实力片、招商片、展会循环片、官网首屏片、政府或投资人汇报片。
- 不适用：要证明某个产品的具体性能 → `productPromo.md`；要让人投简历 → `recruitmentPromo.md`；要让人来旅游 → `cityTourism.md`；纯活动纪录、年会回顾 → `documentariesAndEvents/`。
- **一句话判据：看完能不能说出"这家公司干成过哪件事"？** 说不出，拍的是自我介绍，不是实力片。

## 二、开工必问

一次一个。这类是交付型任务，给谁看、多长、谁点头三件可以一次问清。

1. 给谁看：客户、政府、投资人、展会路人，还是新员工？——决定先讲结果还是先讲"我们是谁"。
2. 多长：60 秒、3 分钟，还是 5 分钟以上？——决定能放几条证据。
3. 最想让对方记住哪一件事？——只准一件，说不出就先做这个决定。
4. 有哪些真实场景和真人可以拍（车间、实验室、门店、工地、客户）？——决定实拍与补镜的范围。
5. 谁拍板看片：老板、市场部，还是甲方？——决定要不要先出脚本再拍。

答不上来落保守值：3 分钟主片 + 3 条 60 秒切片 + 展会无声版，先出脚本再拍，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 主片时长 | 2–5 分钟，3 分钟常用 | 超过 5 分钟先问用途，通常该走专题片 |
| 版本矩阵 | 1 条主片 + 3–5 条切片（30–90 秒，主推 60 秒）+ 展会无声循环版 | 一版通吃所有场合，必然每处都不合适 |
| 证据 | 3 条能力，每条一个现场或一个人 | |

## 四、结构

3 分钟主片：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 结果先行 | 0:00–0:20 | 0–11.1% | 一个具体结果或一个真实问题；不要大楼航拍、不要 logo 开场 |
| 我们是谁 | 0:20–0:50 | 11.1–27.8% | 一句话定位 + 一个可核的数字（年限、产能、覆盖、客户数） |
| 能力证据 | 0:50–2:10 | 27.8–72.2% | 三条能力，每条约 26 秒，各配一个现场或一个人 |
| 人 | 2:10–2:40 | 72.2–88.9% | 一线员工或客户说一句只有这里才有的话 |
| 收束 | 2:40–3:00 | 88.9–100% | 回到开头那个结果，给一个行动（联系、参观、合作） |

60 秒切片：结果 0–5 秒、我们是谁 5–15 秒、一条能力证据 15–50 秒、行动 50–60 秒。90 秒切片：0–6 / 6–20 / 20–62 / 62–90 秒。

三条硬约束：每个形容词后面跟一个可拍载体；数据带出处与年份；前 20 秒不出现"成立于 ×× 年"这类只有自己关心的信息。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 真实场景 | 6–10 | 核心 3–4 个 | 车间、实验室、门店、仓库、工地；一张板一个地点 |
| 出镜人物 | 4–6 | 统一形象 | 负责人、工程师、一线员工、客户；服装与工牌统一 |
| 产品与设备 | 按需 | 是 | 型号、涂装、界面文字与实际一致 |
| 数据与资质 | 3–5 | 否 | 证书、专利、检测报告、客户名单；要拍到原件 |
| 历史素材 | 按需 | 否 | 老照片、旧影像 |

真实场景优先：能实拍就不生成。生成只做空镜、氛围、示意、转场，不用生成人脸替代员工或客户。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 先定用途与版本矩阵，再定时长 | 一页规格 + 版本表 |
| S1 | 3–5 条能力的证据表 → 脚本；采访提纲 | 证据表 + 脚本 + 采访提纲 |
| S2 | 盘点真实场景与真人，缺的列补拍清单；不虚构场景 | 资产表 + 补拍清单 |
| S3 | 需要生成的空镜场景做板 | 已采用资产 |
| S4 | 空镜、氛围镜写提示词 | 分镜 + 空镜提示词 |
| S5 | 实拍素材为主线拼接；生成补空镜与转场 | 素材库 + 粗剪 |
| S6 | 解说、音乐、音效、字幕 | 混音母版 |
| S7 | 各版本按第八节分别验收 | 主片 + 切片 + 无声版 |

## 八、验收清单

- [ ] 1 条主片（2–5 分钟）+ 3–5 条切片，各版本单独成片
- [ ] 20 秒内说清"这家公司做什么"，没有 logo 开场与大楼航拍
- [ ] 每个形容词后面有可拍载体，删掉形容词画面仍成立
- [ ] 三条能力各有一条证据，证据拍到原件或现场
- [ ] 所有数字有出处与年份，口径全片一致
- [ ] 展会循环版无声也能看懂
- [ ] 竖版切片重新构过图，不是裁一刀
- [ ] 员工与客户没有被生成人脸替代

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 开场 20 秒航拍 + 大楼 + logo | 按"气势"套路写 | 换成结果或问题：一条下线产品、一个交付现场、一句客户的话 |
| 老板讲话占 2 分钟 | 把汇报当宣传 | 老板只留一句判断，其余给一线与客户 |
| 员工像演员 | 给了稿子让他背 | 给三个问题，用自己的话说，留停顿与口音 |
| 数据和实际对不上 | 沿用旧资料 | 每个数字回到最新报表或证书核对 |
| 证据全是图表，没有人 | 怕现场乱、人难约 | 每条证据配一个现场或一个人，图表只作补充 |
| 空镜比证据还多 | 生成方便就多放 | 先排证据镜，空镜只放在段落之间当标点 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；表里的数字是示意。

- 需求："给我们冷链物流公司做个宣传片，展会和官网都要用。"
- 落值：3 分钟主片 + 3 条 60 秒切片 + 展会无声版；给客户看；最想让人记住"生鲜 24 小时到店"。
- 一句话：看完能说出"这家公司能把草莓 24 小时从产地送上货架"。

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0:00–0:20 | 结果先行 | 凌晨 4 点，超市店员打开冷柜门，草莓上还挂着冷凝水 |
| 0:20–0:50 | 我们是谁 | 一句话定位 + "每天 300 家门店"（出处：年度运营报表） |
| 0:50–2:10 | 能力证据 | 三条，见下表 |
| 2:10–2:40 | 人 | 夜班司机："这条线我跑了六年，草莓比我先到。" |
| 2:40–3:00 | 收束 | 回到那个冷柜，给联系方式 |

证据表：

| 说法 | 载体（拍什么） | 来源 | 放在第几秒 |
|---|---|---|---|
| 生鲜 24 小时到店 | 一箱草莓从产地装车到上架的完整过程 | 实拍；时效取运营报表 | 0:50–1:16 |
| 全程温控 | 车厢温度记录仪屏幕特写 + 一段温度曲线 | 实拍 + 报表 | 1:16–1:43 |
| 覆盖 300 家门店 | 调度大屏 + 一位司机一天跑的路线 | 实拍 + 图形 | 1:43–2:10 |

需要生成的只有一条转场空镜：凌晨城市高架上冷链车队的远景，按 Seedance 结构写，不出现公司标识与车牌。

最容易错的一处：把"24 小时到店"用生成画面演出来。这是全片的核心证据，必须实拍。
