# 技能教程

交付的是**一个人照着做能复现**。判据：关掉解说只看画面，能不能跟上？跟不上，说明某一步没有可见结果。教程的敌人是跳步，所以每一步都写成三件套：**做什么（动作）→ 变成什么样（可见结果）→ 怎么知道对了（判断标准）**。

## 一、适用 / 不适用

- 适用：软件操作、手工制作、维修、化妆、烹饪、器材使用、动作要领；有明确起点与终点、能验证"做成了没有"的内容。
- 不适用：解释原理与机制 → `scienceExplainer.md`；有课时、章节、作业的系统课 → `courseVideo.md`；纯展示成品 → `ecommerceAds/productVideo.md`；只记录过程不教人复现 → `documentariesAndEvents/processDocumentary.md`；体育动作教学 → `sportsAndEvents/sportsTutorial.md`。
- **前提：先定义成品**——做完了是什么样、拿什么判断做成了。这一步不清，后面所有步骤都没有验收标准。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **学完能做出什么？** "自己换好一个水龙头，还是调出一杯稳定的手冲？"——成品定义决定步骤边界。
2. **他手上有什么、缺什么？**——决定要不要加准备清单和替代方案。
3. **最难的是哪一步？** "拧不动、对不齐，还是配比算不准？"——难点决定时间分配。
4. **拍手部特写还是全身动作？** "俯拍看手，还是侧机位看全身？"——两种不能混着拍。
5. **有没有安全或失败代价？** "会烫到、会短路、会毁材料吗？"——有就必须给前置警告与错误示范。

"你看着办"就落：一个可验证成品、俯拍手部、5 步、给错误示范、90 秒，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 60–180 秒 | 步骤多就拆集，不靠加速压缩 |
| 单步时长 | 9–18 秒 | 超过 18 秒拆两步；不足 9 秒并进相邻步 |
| 步骤数 | 90 秒版 3–6 步 | 步骤段时长 ÷ 单步时长；超过 6 步拆集 |
| 机位 | 固定为主，一步一机位 | 运镜只用于跟随动作 |
| 字幕 | 每步一行动作指令 + 一行结果验收 | 静音可跟做 |
| 变速 | 只对等待、重复段加速并标倍数 | 关键动作必须原速 |
| 安全提示 | 危险操作（电、火、高处、化学品、刀具）给前置警告，不省略安全步骤 | |

## 四、结构

90 秒基准；步骤段装 3–6 步：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 成品先行 | 0–9 秒 | 0–10% | 先给做完的样子 + 一句"几步能做完" |
| 准备清单 | 9–18 秒 | 10–20% | 工具、材料、替代方案一次铺开 |
| 步骤 1–N | 18–72 秒 | 20–80% | 每步三件套；难点步给两个机位或慢放 |
| 错误示范 | 72–81 秒 | 80–90% | 最常错的那一步错一次给人看，再说怎么救 |
| 验收与延伸 | 81–90 秒 | 90–100% | 怎么判断做成了；"做到这一步可以停"或"下一步做什么" |

三件套例：「沿逆时针拧到底 → 阀体不再渗水 → 用纸巾擦一圈，纸上没有水痕」。

三条硬约束：每一步都有可见结果和判断标准；最难那一步给特写或慢放；危险段落不加速。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 手 / 操作者 | 必须 | 是（可只做手与前臂） | 同一双手、同一袖口，跨镜不许换 |
| 工作台 / 操作面 | 必须 | 是（俯拍视角单独一版） | 台面材质、底色、边界固定 |
| 工具 | 必须 | 关键工具做板 | 型号、颜色、磨损一致 |
| 材料 | 必须 | 前、中、后三个状态各一版 | 教程的价值在"变化"，状态必须可辨 |
| 成品 | 必须 | 是 | 开头与结尾用同一件 |
| 错误示范 | 有错误段就要 | 变体板 | 与正确版同构图，方便对照 |

软件教程以真实录屏为主线，不生成界面；实物教程有实拍就以实拍为主，生成补示意与难拍角度。

## 八、验收清单

- [ ] 前 9 秒给出成品和"几步能做完"
- [ ] 准备清单齐，缺件给了替代方案
- [ ] 每一步都有可见结果和判断标准
- [ ] 步数 3–6、每步 9–18 秒
- [ ] 最难那一步有特写或慢放

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 观众卡在第 3 步 | 作者觉得"显而易见"而跳步 | 补中间动作，一步拆两步；补"怎么知道对了" |
| 手一会出现一会不见 | 初始位置没写死 | 每镜写清手从哪进、初始位置、离开方向 |
| 台面跳动 | 台面板没做，或每镜换底色 | 做台面板，同一集固定台面 |
| 步骤都对，做出来不一样 | 省略了温度、力度、型号这些条件 | 把隐含条件写成字幕数字 |
| 出了事故 | 没给警告，只演对的 | 前置警告 + 错误示范 + 补救 |
| 太长没人看完 | 细节平铺 | 主线 3–6 步一集，进阶单独一集 |
| 工具在镜头里换了一把 | 分几次拍、拿错工具 | 工具板固定型号与颜色，补拍用同一把 |
| 观众买错配件 | 没给型号与尺寸 | 准备清单写明型号、尺寸与怎么核对 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："教大家自己换一个漏水的水龙头阀芯。"
- 落值：成品是"关上后出水口 1 分钟内不滴水"；俯拍看手；4 步；给一个错误示范；90 秒。
- 一句话：关掉声音只看画面，也能跟着换完。

步骤卡（S1 的产物，步骤段 18–72 秒，4 步各约 13 秒）：

| 步 | 做什么 | 变成什么样 | 怎么知道对了 |
|---|---|---|---|
| 1 | 关掉水槽下的进水角阀 | 打开龙头，水流变细后停 | 开到最大也没有水 |
| 2 | 撬开手柄装饰帽，拧下螺丝，取下手柄 | 露出阀芯的铜螺母 | 螺母完整露出，没有被手柄挡住 |
| 3 | 扳手逆时针拧出旧阀芯 | 旧阀芯取出 | 新旧阀芯并排，齿数和长度一致 |
| 4 | 装入新阀芯，顺时针拧紧，装回手柄，打开角阀 | 龙头出水正常 | 关上后 1 分钟内出水口没有水滴 |

0–9 秒先给成品：关上的龙头特写，字幕"1 分钟不滴水，4 步换完"；72–81 秒错误示范：没关角阀就拧螺母，水喷出来，立刻拧回去再关角阀。

最容易错的一处：准备清单只写"买个阀芯"。要写明怎么核对型号：拿旧阀芯数齿数、量长度再买。
