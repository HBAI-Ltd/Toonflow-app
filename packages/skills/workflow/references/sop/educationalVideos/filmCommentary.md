# 影视解说

**用别人的作品讲自己的判断。** 成立的前提是增量：观众看完得到的是你的分析，不是一个更省时间的剧情梗概。判据：把原片画面全部换成剧照和示意，这条解说还成立吗？

## 一、适用 / 不适用

- 适用：电影、剧集、纪录片、综艺的评论、主题分析、人物分析、手法拆解、对照解读；有明确观点、需要论证。
- 不适用：纯剪辑混剪、名场面合集 → `gamingAndAnime/fanEdit.md`；讲一个知识原理 → `scienceExplainer.md`；原创故事 → `shortDrama/`。
- **前提**：必须有独立观点（能写出"我认为这部片子在讲 X"），不把整条做成流水账式的剧情速看。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **你要说的那句判断是什么？** "'这是一部关于体面的失败的电影'，还是'它的剪辑在骗观众'？"——没有判断就只是梗概。
2. **讲全片还是拆一个段落？**——拆一场戏的深度与说服力往往更好。
3. **画面用什么？** "只用剧照、关系图和自制示意画面（A 级），还是穿插原片片段举例（B 级）？"
4. **做多长？** "3 分钟短版，还是 8–10 分钟中长版？"
5. **要不要出镜？**——决定做不做解说人板。

"你看着办"就落：拆一场戏、A 级素材（剧照 + 示意图 + 自制重演）、3 分钟、出镜讲，说明可推翻；判断句问不出来，给两个角度让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 1–10 分钟 | 短版 1–3 分钟、中长版 5–10 分钟，选一个 |
| 分析占比 | ≥ 55% | 分析时长必须超过复述时长 |
| 剧情复述占比 | ≤ 20% | 只留因果节点（谁要什么、被什么挡住、结果如何） |
| 原片画面 | 只用于举例论证 | 不作连续剧情复述，看完仍想看原片 |
| 署名 | 片名、年份、导演或主创 | 开头 3 秒内或结尾 |

## 四、结构

3 分钟基准；长版加分析层，不加剧情层：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 判断钩子 | 0–9 秒 | 0–5% | 一句可争论的判断或一个反问；先给观点 |
| 定位 | 9–18 秒 | 5–10% | 片名、年份、谁拍的，加一句"为什么现在讲它" |
| 剧情骨架 | 18–54 秒 | 10–30% | 只留因果节点，不逐场讲 |
| 分析一 | 54–108 秒 | 30–60% | 论点 + 证据（一场戏、一个镜头、一句台词）+ 你的解释 |
| 分析二 | 108–153 秒 | 60–85% | 第二个角度，与分析一递进不并列 |
| 反方与边界 | 153–171 秒 | 85–95% | 承认另一种看法，说明你为什么不同意 |
| 结论 | 171–180 秒 | 95–100% | 回到开头的判断，给"值得看 / 不值得看"和一个理由 |

比例铁律：剧情骨架 ≤ 36 秒；两段分析合计 ≥ 99 秒。做不到，就砍剧情或改成拆一场戏。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 解说人 | 出镜就要 | 是（角色板） | 真人实拍；数字解说人做原创形象板 |
| 原片素材 | B 级才用 | 否 | 只用于举例论证 |
| 剧照 / 海报 | A 级主力 | 否 | 关键剧照 |
| 示意图 / 关系图 | 必须 | 图形规范 | 用图讲结构，替代大段原片 |
| 重演 / 空镜 | 建议 | 视情况 | 自制的关键场面，是 A 级的核心替代物；不复刻原片的角色、服装、标志画面 |
| 引用文字卡 | 必须 | 图形规范 | 原片台词、影评引文与自己的话样式能区分 |

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定判断句、时长与素材等级（A 级或 B 级） | 规格 + 素材等级 |
| S1 | 论点—证据表 → 解说稿 | 证据表 + 解说稿 |
| S2 | 剧照、原片引用段、示意图、重演需求盘点 | 素材表 |
| S3 | 示意图、关系图、解说人板 | 已采用资产 |
| S4 | 出镜段与重演段提示词；原片只挑能证明那一句的几秒 | 分镜提示词 |
| S5 | 出镜、重演、图形、原片引用拼接 | 粗剪 |
| S6 | 解说、字幕、混音 | 混音版 |
| S7 | 第八节清单 + 替代性自测（问一个没看过原片的人：看完还想看原片吗？） | 成片 |

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 做成了流水账速看 | 连续剪辑 + 剧情复述，没有观点增量 | 砍原片到只为例证；砍剧情到 20% 以下；补分析与重演 |
| 像念百科 | 只有梗概与评价词 | 先写判断句再倒推证据；删掉"很精彩""很震撼" |
| 中段弃看 | 剧情段太长 | 压到因果节点，分析提前 |
| 被指带节奏 | 没有反方段 | 补反方：写清另一种合理解释与你的反驳 |
| A 级方案撑不起来 | 没有重演，示意图太薄 | 补关系图与时间线，加自制关键场面；仍不够就缩成拆一场戏 |
| 重演镜复刻了原片的角色和布景 | 想做得像 | 重演只取动作与情境，角色与布景原创 |
| 结论只有"推荐"两个字 | 没给理由 | 结论段给一个理由，并说给谁看 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；片名用《某片》代替。

- 需求："想讲一部家庭片，我觉得它拍得特别狠，但不是那种吵架戏。"
- 落值：拆全片的一个主题；A 级素材（不引用原片，只用官方剧照、自绘关系图、原创重演）；3 分钟；出镜讲。
- 判断句："这部片最狠的不是吵架，是每次吵完都有人默默去洗碗。"

论点—证据表（S1 的产物）：

| 论点 | 证据 | 素材怎么做 |
|---|---|---|
| 洗碗是这家人唯一的和解方式 | 三场吵架后，都是不同的人去洗碗 | 官方剧照三张 + 自绘"谁在什么时候洗碗"时间线 |
| 最后一次没人洗碗，才是真正的崩塌 | 结尾那场饭后，碗一直摆在桌上 | 原创重演：一张原创厨房里，一叠没洗的碗在灯下放了一夜（生成，不复刻原片角色与布景） |
| 反方：有人认为这是在美化忍耐 | 片中母亲的一句台词 | 引用文字卡，标明出处 |

时长控制：剧情骨架 18–54 秒只讲"一家四口、三次吵架、一次没人洗碗"；分析段从 54 秒到 153 秒。

最容易错的一处：剧情骨架讲成逐场复述，超过 36 秒。只留因果节点，细节放进分析里当证据。
