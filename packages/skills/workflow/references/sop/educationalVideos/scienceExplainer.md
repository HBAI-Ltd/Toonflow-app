# 科普讲解

交付**一条能被人转述的解释链**：现象 → 为什么 → 怎么个为什么 → 什么情况下不成立。判据：观众能不能用一句自己的话，把这条视频的因果讲给第三个人听？讲不出，只是把百科念了一遍。科普回答"为什么会这样"，教程回答"我该怎么操作"。

## 一、适用 / 不适用

- 适用：解释一个现象、原理、机制、误区；辟谣；概念科普；"为什么 X 会 Y"类选题。
- 不适用：教人完成一件具体的事 → `skillTutorial.md`；有课时、章节、考核的系统课 → `courseVideo.md`；讲一部影视作品 → `filmCommentary.md`；商品卖点展示 → `ecommerceAds/productVideo.md`。
- **一句话判据：删掉画面只剩口播，观众还能复述因果吗？** 能，是科普；必须看着操作才能跟上，是教程。
- 前提：要拆掉的那个错误认知必须先说清——观众不知道自己错在哪，解释就没有落点。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **要纠正的是哪个具体误解？** "'骨头汤能补钙'，还是'隔夜水会致癌'？"——一个误解一条视频。
2. **讲给谁？** "完全没基础的人，还是有点常识但记错了的人？"——决定第一句从常识切入还是从反例切入。
3. **有没有能亲眼看见的证据？** "实验、显微、剖面、慢放、对比——哪个能做出来？"——一个都没有，改做访谈。
4. **结论要落到哪一句？**——写不出这句，不进 S1。
5. **做多长？** "60–180 秒短版，还是 5–10 分钟中长版？"——决定拆几环，不决定讲多深。

"你看着办"就落：拆一个误解、讲给零基础、一组对比实验、90 秒，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 短视频时长 | 60–180 秒 | 超 180 秒走中长版或拆条 |
| 中长版时长 | 5–10 分钟 | 超 8 分钟每 3–4 分钟一个小标题 |
| 换画面 | 每 7–10 秒一次 | 换镜、换图表、换实验画面都算 |
| 知识点配比 | 1 个核心 + 2–3 个支撑点 | 每点 ≤ 30 秒 |
| 口播 | 每秒 4–5 字 | 术语首次出现加白话注解 |
| 严谨边界 | 不把相关说成因果；不引用无法溯源的"研究表明"；结论带成立条件 | 素材与数据标来源 |

## 四、结构

90 秒基准；中长版按"一个机制环 45–90 秒"扩环，不增支撑点：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 反常识结论 | 0–9 秒 | 0–10% | 一句与常识相反的结论或一个反常画面；不说"大家好、今天聊聊" |
| 现象锚定 | 9–18 秒 | 10–20% | 一个具体场景，让观众确认"这说的是我" |
| 机制第一环 | 18–45 秒 | 20–50% | 直接原因；一句因果一句话 |
| 机制第二环 | 45–63 秒 | 50–70% | 再追问一层"那又为什么"——这是讲透和念百科的分界 |
| 类比锚点 | 63–72 秒 | 70–80% | 一个日常物对照，并说明它不同构的地方 |
| 边界与反例 | 72–81 秒 | 80–90% | 什么情况下不成立；没有这段，结论就是新的迷信 |
| 可复述结论 | 81–90 秒 | 90–100% | 一句能被转述的话，不重复全片 |

中长版：七段保留，两个机制环各扩成 2–3 环，其余段不扩。

三条硬约束：机制段之间的连接词必须是因果（因为、所以、于是），不能是"另外、还有"；全片至少三次因果落在画面上；有边界段。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 示意图 / 原理图 | 必须（≥ 2 张） | 图形规范 | 同一张图跨镜复用，配色不随场景光变 |
| 讲解者 | 出镜才要 | 建议（角色板） | 同一账号保持同一形象 |
| 实验 / 演示道具 | 有证据段就要 | 关键道具做板 | 必须真能做出可见变化 |
| 数据图表 | 有数据就要 | 图形规范 | 单位、标度、来源写在图上 |
| 字幕卡 | 必须 | 图形规范 | 术语卡、数字卡、结论卡各一套模板 |

图形资产不进生成通道，后期做。生成用于原理动画、微观示意、类比场景；真实实验的结果镜优先实拍，生成的示意镜要能被看出是示意。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 拿到"要拆的误解"和"要落的结论"两句话，定时长版本 | 规格 |
| S1 | 解释链表 → 口播稿 | 解释链表 + 口播稿 |
| S2 | 图形资产、演示道具、讲解者盘点 | 资产表 |
| S3 | 图形资产先做（示意图 ≥ 2、图表、字幕卡模板） | 已采用资产 |
| S4 | 一镜一信息；示意镜与实拍镜交替，同一画面不超过 10 秒 | 分镜提示词 |
| S5 | 演示镜 → 讲解镜 → 拼接 | 粗剪 |
| S6 | 口播、字幕、结论卡 | 混音版 |
| S7 | 第八节清单 + 转述测试（找一个人看完，让他用自己的话讲一遍，记下漏掉的环） | 成片 |

## 八、验收清单

- [ ] 前 3 秒给出反常识结论或反常画面，没有自我介绍
- [ ] 只讲一个误解；支撑点 ≤ 3 个，每点 ≤ 30 秒
- [ ] 机制至少追了两层"为什么"
- [ ] 有一个日常物类比，并说明它不同构的地方
- [ ] 有边界或反例段
- [ ] 转述测试通过
- [ ] 每 7–10 秒换一次画面；机制段的连接词全是因果
- [ ] 数据与研究有可见来源；术语首次出现有白话注解
- [ ] 没有把相关当因果，结论带有成立条件

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 看完说不出讲了啥 | 只有知识点没有因果链 | 重写解释链，每段用"因为…所以…"接 |
| 前 3 秒掉人 | 开头在铺垫背景 | 把结论提到第 0 秒 |
| 中段弃看 | 画面 10 秒没变 | 插图表、剖面、慢放、类比动画 |
| 观众学会一个更错的版本 | 没有边界段 | 补边界：在什么条件下不成立 |
| 类比反而误导 | 类比物与机制不同构 | 换同构的日常物，补一句"它不一样的地方是…" |
| 论证站不住脚 | 空引研究、把相关当因果 | 补来源；"导致"改成"相关"；删掉无出处数字 |
| 示意动画被当成真实显微画面 | 没标示意 | 生成的微观、剖面画面角落标"示意" |
| 第二环只是第一环换个说法 | 没真正追问 | 第二环必须回答"那又为什么"，换一个更深的原因 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；数字按用户提供或实测的数据填，并标出处。

- 需求："想做个视频辟谣'喝骨头汤补钙'。"
- 落值：拆一个误解、讲给零基础、一组对比实验（同一锅汤与一杯牛奶的钙含量对照，用公开测定数据）、90 秒。
- 一句话：观众能转述"汤熬白了不等于钙多，钙锁在骨头里出不来"。

解释链表（S1 的产物）：

| 格 | 内容 |
|---|---|
| 结论 | 一碗熬了三小时的骨头汤，钙远不如一杯牛奶 |
| 现象 | 家里老人炖汤给孩子"补钙"，汤越白越觉得有营养 |
| 第一环 | 因为骨头里的钙是一种不溶于水的晶体，所以熬再久也溶出很少 |
| 第二环 | 那为什么不溶？因为它要在酸性条件下才会分解，汤是中性的 |
| 类比 | 像用热水泡一块石灰石想泡出石灰——但不一样的地方是，骨头里的胶原和脂肪会溶出来 |
| 边界 | 加醋久炖会多溶一点，但仍远低于一杯牛奶；汤里的蛋白和脂肪也不是零 |
| 结论句 | 汤白是脂肪，不是钙 |

0–9 秒画面：一锅奶白的骨头汤旁边放一杯牛奶，字幕"哪个钙多？"；45–63 秒的晶体示意由生成完成，角落标"示意"。

最容易错的一处：写"研究表明骨头汤几乎没钙"却不给来源。每个数字要能指到一份可查的测定数据。
