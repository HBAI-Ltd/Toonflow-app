# 课程视频

交付**一套能被学完的结构**：章 → 节 → 知识点。最小单位是"一节课"。判据：学完这一节，能不能通过这一节的检查、并且接得上下一节。课程的死因是结构塌陷——一节塞三个知识点、长度超过注意力、没有回顾、没有检查点。

## 一、适用 / 不适用

- 适用：有课时编排的系统课、MOOC、企业内训、付费课程、需要作业与测验的知识传递；单节 5–15 分钟。
- 不适用：单条讲一个原理 → `scienceExplainer.md`；单条教一个操作 → `skillTutorial.md`；把已讲完的直播重新切开 → `lectureClips.md`；招生宣传 → `promotionalVideos/`。
- **前提：先有一句"学完能做什么"。** 写不出来，章节一定按教材目录排，学员一定掉队。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **学完能做什么？** "独立做一张资产负债表，还是通过某个考试的第 2 章？"——决定章节顺序与验收方式。
2. **一节多长、一共几节？** "6–8 分钟的微课，还是 12–15 分钟的系统课？"——决定每节装几个知识点。
3. **有没有现成讲义或课件？**——决定 S2 从哪起步。
4. **要不要出镜？** "讲师全程出镜，还是只出声音 + 课件？"——决定资产与后期量级。
5. **怎么检查学会没有？** "随堂测、作业，还是实操录屏？"——没有检查点，只是长视频合集。

"你看着办"就落：8 分钟一节、讲师 + 课件、每节 2–3 个知识点、每 6 分钟一个检查点，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单节时长 | 5–15 分钟（示例 8 分钟） | 超 15 分钟必须拆节 |
| 每周总量 | 1–2 小时 | 超过就分周 |
| 课程周期 | ≤ 15 周 | 超了拆成两门课 |
| 片头 / 片尾 | 各 ≤ 10 秒 | 片头含课程名、讲次、主讲；片尾含制作单位 |
| 检查点 | 间隔 ≤ 6 分钟 | 8 分钟版放在 3:00（提问）与 6:00（小测） |
| 字幕 | 独立字幕文件，一屏一行，横版每行 ≤ 20 字，错字率 ≤ 1% | 不烧进画面 |

## 四、结构

8 分钟一节：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 本节目标 | 0:00–0:24 | 0–5% | 一句话说清"这节学完你能做什么" |
| 上节回顾 | 0:24–0:48 | 5–10% | 一句钩回上节结论；新学员也能听懂 |
| 知识点 1–3 | 0:48–4:48 | 10–60% | 每点 80 秒：是什么 → 为什么 → 例子；点与点之间用"所以我们能…"过渡 |
| 演示 / 例题 | 4:48–6:00 | 60–75% | 用一次完整过程走一遍；"会做"和"听过"的分界 |
| 检查点 | 6:00–6:24 | 75–80% | 一道题或一个提问，给思考时间 |
| 小结 | 6:24–7:36 | 80–95% | 三条以内，逐条对应本节目标，不引入新内容 |
| 下节预告 | 7:36–8:00 | 95–100% | 下节解决什么，为什么需要它 |

片头不占结构表时长，另加在本节目标之前。知识点少于 3 个时，每点仍 80 秒，空出的时间给演示。章级：每章第一节只做"地图"（这章解决什么、分几节），最后一节做串讲 + 章测。

三条硬约束：一节 2–3 个知识点；检查点间隔 ≤ 6 分钟；全课同一套课件模板、讲师形象、术语叫法。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 讲师形象 | 出镜就要 | 是（角色板） | 真人讲师实拍；数字讲师做角色板，全课不换脸 |
| 课件模板 | 必须 | 图形规范 | 标题位、页码、配色、字体、图示语言全部冻结 |
| 图表 / 示意图 | 按知识点 | 图形规范 | 单位、标度、来源写在图上 |
| 片头片尾模板 | 必须 | 图形 + 动效模板 | 一次做好，全课复用 |
| 字幕样式 | 必须 | 规范 | 字号、行宽、位置 |

课件、图示、公式、流程用图形动效做，不进生成通道；生成只负责讲师镜（数字讲师时）与实景、示意画面。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定"学完能做什么"、总节数、单节时长、检查方式，四项缺一不进 S1 | 规格 |
| S1 | 课程地图 → 单节脚本 | 地图 + 第一节脚本 |
| S2 | 讲师、课件、图表、模板盘点 | 资产表 |
| S3 | 课件模板、片头片尾模板冻结；讲师板 | 已采用资产 |
| S4 | 讲师镜与课件镜分开排，一节内机位不超过 2 种 | 分镜 |
| S5 | 第一节完整版 → 验收 → 批量 | 第一节 + 其余节 |
| S6 | 字幕文件、术语统一、响度对齐 | 字幕 + 混音 |
| S7 | 第八节清单 + 连看两节测试（接不接得上、累不累） | 全课 |

## 八、验收清单

- [ ] 全课有一句"学完能做什么"
- [ ] 三级目录完整，无跳号
- [ ] 每节 2–3 个知识点，七段齐全，落点与结构表一致
- [ ] 检查点间隔 ≤ 6 分钟
- [ ] 单节 5–15 分钟，超长已拆节
- [ ] 片头片尾各 ≤ 10 秒；字幕是独立文件，错字率 ≤ 1%
- [ ] 讲师形象、课件模板、配色字体、术语全课一致
- [ ] 图表与引用标清来源

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 学员第 3 节掉队 | 没有回顾段，节与节不接 | 每节补回顾；章首补地图节 |
| 一节塞了三件事 | 按教材目录切 | 拆节；每 6 分钟插检查点 |
| 听懂了但不会做 | 缺演示或例题 | 补一次完整过程，含一个容易错的地方 |
| 每节像不同的课 | 模板与配色没冻结 | 冻结模板与色板，只换内容 |
| 术语一会一个叫法 | 没有术语表 | 建术语表，字幕与口播同步 |
| 录屏里的字小得看不清 | 用原始分辨率录全屏 | 录制前把界面放大到 125–150%，关键操作区域给放大镜头 |
| 例题和知识点用的不是同一份数据 | 临时找素材 | 全节用同一份练习文件，学员可以下载跟做 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："公司内训，给财务新人做 Excel 透视表的课，一共 6 节。"
- 落值：8 分钟一节、讲师出镜 + 录屏课件、每节 2–3 个知识点；检查方式是随堂小测。
- 课程地图：第一章 整理数据（第 1–2 节）/ 第二章 透视表（第 3–5 节）/ 第三章 串讲与章测（第 6 节）。

第 3 节《第一张透视表》：

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0:00–0:24 | 本节目标 | "这节学完，你能 30 秒做出按部门汇总的报销表。" |
| 0:24–0:48 | 上节回顾 | "上节我们把表整理成一行一条记录——今天就用这张表。" |
| 0:48–4:48 | 知识点 1–3 | 插入透视表 / 把字段拖进行和值 / 改汇总方式，各 80 秒；3:00 口头提问："放进'值'和放进'行'有什么区别？" |
| 4:48–6:00 | 演示 / 例题 | 用一份 200 行的报销记录完整走一遍，故意先把金额拖进"行"，再改回来 |
| 6:00–6:24 | 检查点 | "要看每个人每月报销多少，字段该放哪？"停 10 秒 |
| 6:24–7:36 | 小结 | 三条，对应本节目标 |
| 7:36–8:00 | 下节预告 | "原始表更新了，透视表怎么跟着变？" |

最容易错的一处：顺手把条件格式和图表也讲了。那是另一节的知识点，塞进来这节就超了。
