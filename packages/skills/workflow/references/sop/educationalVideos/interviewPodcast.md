# 访谈播客

交付**一段对话里被剪出来的判断链**：他为什么这么想、被什么逼出来的、什么条件下他自己会推翻。判据：没听过原片的人只看这一条，能不能说出嘉宾的一个判断和它的前提？只记住一句狠话，就是切片失败。主体是两个人的关系，信息藏在追问里，不在旁白里。

## 一、适用 / 不适用

- 适用：双人或多人的长对谈、嘉宾访谈、圆桌；从直播或录制里二次剪出的观点切片。
- 不适用：单人讲授 → `scienceExplainer.md` / `courseVideo.md` / `lectureClips.md`；以被访者为素材的人物片 → `documentariesAndEvents/personalDocumentary.md`；连麦卖货 → `ecommerceAds/`；虚构对话 → `shortDrama/`。
- **前提**：主线是剪辑，生成只补空镜与图形——如果用户只要纯剪辑、不需要任何生成，按 `sopRouting.md` 一说明边界。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **给谁听？** "想听这个人怎么想事，还是想听一件具体的事？"——前者剪观点，后者剪情节。
2. **几轨素材？** "分轨录的，还是只有一路混录？"——混录只能整段用，跳剪会破音。
3. **一条长的，还是一串短的？** "20–60 分钟完整版，还是 30–60 秒观点切片？"

"你看着办"就落：分轨双人、45 秒切片、原话保留，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 长版时长 | 20–60 分钟 | 一集装不下，按"问题"拆两集 |
| 切片时长 | 30–60 秒 | 钩子型取 30 秒；干货型 45–60 秒 |
| 切片产出 | 每 6–8 分钟原片 1 条 | 60 分钟原片出 7–10 条；少于 7 条回 S2 重切，不硬凑 |
| 字幕 | 全程硬字幕；切片关键词高亮 | 静音可读 |
| 机位 | 主机位中景 + 反打 + 手部桌面特写 | 只有一台机器时用不超过 1.15 倍的数字变焦做假反打 |
| 剪辑纪律 | 不剪掉限定条件只留结论；不把假设说成事实；切片第一句在原片里必须成立 | |

## 四、结构

长版按"问题"分章，不按时间分章；每章标题是一句能被搜索的问句：

| 段落 | 占比 | 这一段要完成什么 |
|---|---|---|
| 冷开场 | 0–3% | 一句最有信息量的原话或一个反问 |
| 他是谁 | 3–6% | 只给理解下面这段所必需的那一条身份 |
| 第一问 | 6–25% | 把他放回具体处境：当时能选什么、不能选什么 |
| 追问 | 25–55% | 追一层代价、一个反例——访谈和聊天的分界 |
| 翻面 | 55–75% | 他自己推翻自己一次，或承认一件不利的事 |
| 回到当下 | 75–92% | 这段经历改变了他现在哪个做法 |
| 收 | 92–100% | 一句他自己的话，不加主持人总结 |

切片 60 秒：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 钩子 | 0–3 秒 | 0–5% | 结论或反常识原话，直接开口 |
| 身份 | 3–9 秒 | 5–15% | 谁、在什么位置上说；一句字幕解决 |
| 追问 | 9–51 秒 | 15–85% | 一个追问 + 他给出的理由与代价；没有追问就回原片重切 |
| 落点 | 51–60 秒 | 85–100% | 一句可复述的话，或"完整版见主页" |

三条硬约束：切片第一秒必须有人正在说话；字幕只能补身份，不能补因果；长版删掉的内容切片不能复活（两版共用一份"已删清单"）。

## 五、资产清单

| 资产 | 要不要 | 做板 | 说明 |
|---|---|---|---|
| 场地主视图 | 必须 | 是（仅当要生成空镜时） | 谁坐哪、灯从哪来、背景有什么；跨期复用 |
| 出镜人 | 必须 | **不做板** | 真人只走实拍，不生成 |
| 身份条 / 引用卡 | 必须 | 图形规范 | 全片同版式 |
| 关键词卡 | 切片要 | 图形规范 | 一屏不超过 6 字 |
| 空镜与桌面插入 | 转场用 | 否 | 当天拍的优先 |
| 转写稿 | 必须 | — | 逐句时间码按稿选段 |

**不做证明性画面**：聊天记录、证件、病历、判决书用真实素材或不做；生成一张"看起来像真的"截图，是这个类目最严重的失败。

| S5 | [画布与交付](../../methods/canvasAndDelivery.md) 三 | 主线是剪辑：多机位对齐、跳剪、去口癖与长停顿 |

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定交付形态（长版 + 几条切片） | 规格 |
| S1 | 问题清单 + 章节表 + 切片候选 | 章节表 + 候选段（带时间码） |
| S2 | 盘人、场地、旧素材；转写稿切候选段 | 素材表 |
| S3 | 场地主视图、字幕卡模板 | 模板 |
| S4 | 空镜与图形动画提示词（可空） | 补镜清单 |
| S5 | 剪辑长版 → 切片 | 长版 + 切片 |
| S6 | 字幕、响度、关键词 | 混音 + 字幕 |
| S7 | 长版与切片分开验收；附已删清单 | 成片 + 附件 |

## 八、验收清单

- [ ] 长版 20–60 分钟；每章标题是一句问句
- [ ] 冷开场第一句在原片里成立
- [ ] 切片 30–60 秒；60 分钟原片出 7–10 条
- [ ] 每个切片第一秒有人在说话，6 秒内知道在讲什么
- [ ] 每段追问后面有一层代价或一个反例
- [ ] 没有旁白替嘉宾总结
- [ ] 字幕与转写稿逐字核对

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 长版像录音转写 | 按时间剪 | 一章一个问句，删寒暄与重复 |
| 切片点开不知道在讲什么 | 从半句话开始 | 前 3 秒给结论，3–9 秒一句字幕补身份 |
| 意思被剪歪 | 钩子句离开上下文不成立 | 换钩子，或在钩子后立刻补前提 |
| 竖版裁得只剩半张脸 | 直接中心裁 | 上下分屏或焦点跟随，按人物位置重排 |
| 混录素材跳剪破音 | 只有一路音轨 | 不跳剪，用插入镜与字幕卡遮断点 |
| 主持人话比嘉宾多 | 追问变成了发言 | 追问只留一句，其余剪掉 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我们录了一期 60 分钟的对谈，嘉宾是做了 20 年的乡村医生。"
- 落值：分轨双人；长版 45 分钟 + 8 条切片；原话保留。
- 一句话：看完能说出"他三次拒绝进城，代价是一年只见女儿四次"。

章节表（每章一个问句）：

| 章 | 问句标题 | 原片时间码 |
|---|---|---|
| 1 | 一个村医一天要走多少路？ | 00:03:20–00:11:40 |
| 2 | 为什么三次拒绝城里的医院？ | 00:11:40–00:24:10 |
| 3 | 他什么时候想过放弃？ | 00:24:10–00:36:00 |
| 4 | 现在他每天先做哪件事？ | 00:36:00–00:44:30 |

切片 60 秒（取自第 2 章）：0–3 秒"我拒绝过三次进城。"；3–9 秒字幕"乡村医生，从业 20 年"；9–51 秒主持人追问"第三次为什么也拒绝"，他讲出代价："那年村里只剩我一个医生，我女儿在城里上学，一年见四次。"；51–60 秒落点"完整版见主页"。

最容易错的一处：钩子只剪"我拒绝过三次进城"，后面的前提没跟上，听起来像在炫耀。钩子之后立刻补"那年村里只剩我一个医生"。
