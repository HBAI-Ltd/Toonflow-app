# 二创混剪

用别人的画面说自己的话。论点只有一个，片子里必须有"你加的东西"——评论、重构、对位或节奏；只有原片段拼接，不算二创。

## 一、适用 / 不适用

- 适用：拿已有作品（游戏 PV、CG、实况、动画、影视、官方物料）重剪：节奏踩点、主题向与角色向混剪、剧情重构、整活、AMV；竖屏 15–90 秒，横屏 1–3 分钟。
- 不适用：官方物料 → `gamePromo.md`；自己玩的过程 → `gameplayEdit.md`；原创角色为主 → `characterShort.md`；要把一部作品讲清楚 → `educationalVideos/filmCommentary.md`；纯搬运、整段切片 → 不做。
- 主线是剪辑；生成只补转场、示意与个人表达部分。

## 二、开工必问

一次一个，已知的跳过。

1. 这条片的"论点"是什么：一个角色、一段关系，还是一种情绪？——一条只允许一个。
2. 手上有哪些原片或官方物料片段？——决定能切多密。
3. 用哪首曲、速度大概多快？——音乐决定结构与切点。
4. 做多长：竖屏 15–90 秒，还是横屏 1–3 分钟？

两次都"都行"，落保守值：竖屏 60 秒，说明可推翻；论点问不出来，给两个具体方向让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 竖屏 15–90 秒；横屏 1–3 分钟 | 一条只讲一个论点 |
| 单素材段 | 1–3 秒为主，情绪段 4–6 秒，任何一段不超 6 秒 | |
| 引用总量 | ≤ 全片 2/3；关键剧情、结局、反转不整段放完 | 保留悬念让人想看原作 |
| 音乐 | 先定曲，速度决定段落与切点 | |

## 四、结构

60 秒竖屏踩点混剪：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 钩子 | 0–6 秒 | 0–10% | 最狠的一帧 + 一句 3–7 字主题句，先给情绪再给信息 |
| 立规则 | 6–15 秒 | 10–25% | 一句字幕告诉观众"这是关于什么的"，从此不跑题 |
| 堆叠 | 15–42 秒 | 25–70% | 强拍切、弱拍推；素材轮转，情绪一层层加 |
| 爆发 | 42–54 秒 | 70–90% | 副歌或爆点；最长的一段留给情绪 |
| 收束 | 54–60 秒 | 90–100% | 回到开头形成循环，或一句反问 |

横屏按同一占比折算。

三条硬约束：一个片子只有一个论点；音乐决定结构，不反过来；关键剧情、结局、最高光不完整放完——目标是看完"想去看原作"。

## 五、资产清单

| 类型 | 说明 |
|---|---|
| 素材库 | 按来源、角色、情绪命名；每段记出处与时长 |
| 音乐 | 记下速度与段落拍点 |
| 音效 | 重音、转场声 |
| 字幕模板 | 一次 4–7 个词 |

生成的补镜用于转场或示意时，与原片色调和节奏对齐。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定论点与时长 | 规格表 |
| S1 | 曲目 + 论点句 + 素材清单 | 三样 |
| S2 | 素材盘点与分桶 | 素材表 |
| S3 | 不做 | — |
| S4 | 卡点表（含每段时长）；补镜提示词（可空） | 卡点表 |

| S6 | 音乐、音效、字幕 | 成片 |

## 八、验收清单

- [ ] 时长与第三节一致
- [ ] 引用总量 ≤ 全片 2/3；单段 ≤ 6 秒；关键剧情与最高光没有完整放完
- [ ] 论点能用一句话说清，全片没有第二个
- [ ] 切点落在重拍；中段有递进

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 素材堆砌没主题 | 先挑画面再想说什么 | 先写论点，再按论点选素材 |
| 全程一个节奏 | 只会每拍一切 | 中段加密、副歌留长镜、结尾留白 |
| 像官方预告 | 照搬官方语气与包装 | 加个人表达视角，换掉官方字卡 |
| 观众看完不去看原作 | 把高光全放完了 | 剪到"想看"为止 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；游戏是示意。

- 需求："想用某款游戏的剧情动画剪个配角向的混剪。"
- 落值：竖屏 60 秒。
- 论点："这个配角每次出场都在替主角挡刀。"

卡点表：0–6 秒他第一次挡刀，2 秒；6–15 秒字幕"他每次都站在前面"；15–42 秒五次挡刀轮转，每段 1–3 秒；42–54 秒副歌留给他回头看主角的那一眼，4 秒；54–60 秒回到第一次挡刀。

最容易错的一处：爆发段把官方动画最高光那一整段放完。剪到"想去看原作"为止。
