# 实况剪辑

剪的是结果，不是过程。观众只给 1–2 秒，留不留人全看最猛的那一下在不在第 1 帧。素材是**自己玩的过程**——画面里没有"我在玩"的证据，就不是实况。

## 一、适用 / 不适用

- 适用：录屏、直播回放、主机或手机内录，剪成 15 秒到 8 分钟：高光集锦、解说切片、挑战整活、攻略过程、名场面回顾。
- 不适用：官方宣传 → `gamePromo.md`；只讲一个角色 → `characterShort.md`；拿别人的作品重剪 → `fanEdit.md`；讲清机制或操作原理 → `educationalVideos/skillTutorial.md`；官方赛事集锦 → `sportsAndEvents/eventHighlights.md`；纯搬运别人的实况 → 不做。
- 主线是剪辑，生成只补封面与少量转场；用户只要纯剪辑、不需要任何生成时，按 `sopRouting.md` 一说明边界。

## 二、开工必问

一次一个。

1. 要做成哪种形态：竖屏短视频（15–30 秒）、横屏高光（30–60 秒），还是完整实况（3–8 分钟）？——决定时长与开头强度。
2. 这条卖什么：我强、好笑，还是"这游戏真好玩"？——决定选哪几段、字幕写什么。
3. 有没有人声：现场解说、后期配音，还是纯原声？
4. 要不要做成系列：固定片头、字幕模板、结尾钩子？

两次都"都行"，落保守值：竖屏 30 秒、高光向、有字幕，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 竖屏 15–30 秒；横屏高光 30–60 秒；完整实况 3–8 分钟 | 一条只留一件事 |
| 单片段 | 3–5 秒，峰值镜可 6 秒，从高潮前一刻起 | 铺垫整段剪掉 |
| 开头 | 1–2 秒内从**结果**开始 | 不展示走路、读条、开背包 |
| 竖版 | 横屏素材重构图，关键信息（准星、血条、记分板）留在中间六成 | 不靠黑边填充 |
| 字幕 | 一次 4–7 个词，白字黑描边 | 静音时字幕是第二条声轨 |

## 四、结构

30 秒竖屏高光：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 结果 | 0–3 秒 | 0–10% | 最猛的一帧放最前：一枪、一次翻盘、一个大失误 |
| 处境 | 3–6 秒 | 10–20% | 一句字幕交代条件：1 打 4、残血、只剩 30 秒 |
| 过程 | 6–21 秒 | 20–70% | 三个递进动作，每个 5 秒，一个动作一个信息 |
| 峰值 | 21–27 秒 | 70–90% | 慢放 + 原声，音乐让位；不加花字 |
| 回环 | 27–30 秒 | 90–100% | 给结果，尾帧接首帧，让人不知不觉再看一遍 |

横屏高光按同一占比折算。完整实况 5 分钟：开场 0–15 秒（这局看什么）→ 完整回合 15–180 秒（按发生顺序，不跳关键因果）→ 复盘与彩蛋 180–300 秒。

三条硬约束：一个片段只留一个信息；解说别念画面（不说"我打他"，说"他只剩一丝血还敢反打"）；原声是证据，音乐不盖过枪声、命中声与队友喊话。

## 五、资产清单

| 类型 | 数量 | 说明 |
|---|---|---|
| 高光候选片段 | 成片的 2–3 倍 | 每段 3–6 秒；先攒够再挑 |
| 解说人声 | 1 条 | 口播稿先写后录 |
| 配乐与音效 | 1 首 + 6–10 个 | 节拍清晰 |
| 字幕、花字与封面模板 | 1 套 + 3 版封面 | 封面写结果不写人名 |

不做角色板：实况的脸是游戏里的脸。封面要画人物时才做一张角色板。

## 八、验收清单

- [ ] 时长与第三节一致
- [ ] 第 1 帧就是结果或危机
- [ ] 全片只讲一件事
- [ ] 单片段 3–5 秒（峰值 ≤ 6 秒）
- [ ] 原声清楚，没被配乐盖住
- [ ] 字幕一次 4–7 个词，静音也能看懂
- [ ] 竖版关键信息在中间六成
- [ ] 尾帧接得上首帧，或结尾留了让人重看的问题

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 开头在走路或读条 | 按完整对局思维剪 | 把结果提到第 1 帧 |
| 横屏直接加黑边 | 没重构图 | 按竖版重新取景 |
| 全片一个速度 | 只会硬切 | 强拍切、弱拍推、峰值慢放 |
| 高光没有因果 | 只放结果 | 补一句字幕说清条件 |
| 解说在念画面 | 没写口播稿 | 写判断和情绪 |
| 竖版只截了中间，击杀提示在右上角被切 | 关键信息不在中间 | 竖版把击杀提示单独抠出来放进安全区 |
| 队友的骂人语音被保留 | 剪辑时没听全 | 粗剪后完整听一遍，脏话消音或删 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我打了一把 1 打 4 的残局，想剪个短视频。"
- 落值：竖屏 30 秒；卖"我强"；有现场解说。
- 一句话：第 1 帧就是最后那一枪。

结果清单（S1 的产物）：先定结果——最后一枪带走第四个人；再倒推需要：残血的血条、换弹的那一秒、两次反打。

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–3 秒 | 结果 | 最后一枪命中，"团灭"提示弹出 |
| 3–6 秒 | 处境 | 字幕"1 打 4，残血，只剩半个弹夹" |
| 6–21 秒 | 过程 | 三个动作各 5 秒：绕后、换弹、反打 |
| 21–27 秒 | 峰值 | 最后一枪慢放，只留枪声和他的一声"走" |
| 27–30 秒 | 回环 | 回到"团灭"提示，接回第 1 帧 |

最容易错的一处：从跳伞落地开始剪。观众 2 秒内看不到结果就划走了。
