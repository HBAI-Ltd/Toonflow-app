# 角色短片

只回答一个问题：**他是谁。** 不卖版本，也不教玩法；靠一个"只有他会做"的选择让人记住。

## 一、适用 / 不适用

- 适用：角色 PV、角色演示、角色预告、角色短片；60–90 秒为主，长版 3–5 分钟。
- 不适用：卖游戏、卖版本 → `gamePromo.md`；玩的过程 → `gameplayEdit.md`；拿现成作品重剪 → `fanEdit.md`；多角色长故事、每集推进 → `shortDrama/aiComicDrama.md`。
- **一句话判据：全片是不是只回答"他是谁"？** 一旦要回答"这游戏怎么玩"，就不属于本类目。只有设定没有一场戏，先补戏。

## 二、开工必问

一次一个，已知的跳过。第 1 题答不清，后面都白问。

1. 这个角色最想要什么、最怕失去什么？——一条片子只回答这一个问题。
2. 观众现在认识他吗：全新角色、已有粉丝，还是内部人物？——决定要不要花 5 秒交代身份。
3. 有没有既定设定不能动：外观、年龄、关系、能力上限？
4. 有现成立绘、模型、声线吗？——决定做板还是直接引用。

两次都"都行"，落保守值：75 秒、无对白，说明可推翻；角色欲望与怕失去什么问不出来，给两版具体的让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 60–90 秒；长版 3–5 分钟 | |
| 条数 | 时长 ÷ 所选模型单次上限，向上取整 | 情绪镜单独一条 |
| 单镜 | 2–4 秒；情绪镜可 5–6 秒 | 长镜留给表情，短镜留给动作 |
| 对白 | 单句 ≤ 20 字；全片 ≤ 6 句 | 说人物，不解说设定 |

## 四、结构

一个人物五段：**想要 → 受阻 → 加压 → 选择 → 余韵**。60 秒基准：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 亮相 | 0–5 秒 | 0–8.3% | 他在做什么；用一个动作定性格，不报履历、不打字幕卡 |
| 缺口 | 5–18 秒 | 8.3–30% | 他要什么、缺什么；用一件小事露出来，不靠旁白 |
| 加压 | 18–38 秒 | 30–63.3% | 两件小事把他逼到墙角；第二次的代价比第一次贵 |
| 选择 | 38–50 秒 | 63.3–83.3% | 他做了一个"只有他会做"的选择；不给解释 |
| 余韵 | 50–60 秒 | 83.3–100% | 一个动作、一句台词、一个空镜；不总结、不上价值 |

长版把"加压"拆成两轮，五段与占比不变。角色演示另走一套：亮相 0–10% → 战斗展示 10–60% → 一处反差（他强，但也会累、会怕）60–85% → 收在标志动作 85–100%；技能长在情节里，不做技能复读。

三条硬约束：一条片子只回答一个问题；不新增能力、秘密与剧情线索，只补可见细节；结尾不总结、不上价值。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主角 | 1 | 是 | 四视图 + 无表情 / 微笑两张特写 |
| 对手 / 常同框 | ≤ 2 | 是 | 并排看能否分开，先做"谁是谁" |
| 变体 | 按剧情 | 从上一状态改 | 换装、伤势、年龄；不覆盖旧文件 |
| 场景母版 | 2–3 | 是 | 一个地点一张 |
| 识别物 | 1–2 | 视镜头 | 武器、饰品、纹样；观众靠它认人 |
| 声线 | 1 | 否 | 一条音色块，跨片沿用 |
| 标题卡与片尾 | 1 套 | 否 | 后期合成 |

全部画面可由生成完成；主角板必须先过测试。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定用途、时长与设定边界 | 规格表 |
| S1 | 人物功能 + 节拍表 + 台词 | 节拍表 |
| S2 | 只盘会入画的：主角、同框者、场景、识别物、声线 | 资产表 |
| S3 | 主角板先做并测试；变体 | 已采用资产 |
| S4 | 按条数写提示词；情绪镜单独一条 | 逐条提示词 |
| S5 | 先跑脸，再跑动作 | 已采用片段 |
| S6 | 声线、配音、字幕 | 混音版 |
| S7 | 第八节清单；各比例成片 | 成片 |

## 八、验收清单

- [ ] 时长与条数与第三节一致
- [ ] 前 5 秒观众知道"他是谁、在干什么"，没有履历字幕
- [ ] 全片只回答一个问题；没有新增能力、秘密或新角色
- [ ] 主角在不同动作、景别、地点下都认得出（测试记录在）
- [ ] 脸没被磨皮、瘦脸、换年龄；同场两人一眼分得开
- [ ] 选择是他做的，不是巧合、来电、外力
- [ ] 结尾没上价值；最后一个镜头能独立成立
- [ ] 对白 ≤ 6 句、单句 ≤ 20 字

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 看完不知道他是谁 | 用旁白念设定 | 删旁白，补一件"只有他会做"的小事 |
| 人物像纸片 | 只有强，没有代价 | 加一处反差：他也会累、会怕、会算错 |
| 技能展示割裂 | 演示段独立成块 | 技能长进情节 |
| 表情空、像摆拍 | 写的是形容词 | 改写成动作与时间片 |
| 角色板和游戏内模型对不上 | 资产按想象重画 | 已有模型的角色，角色板按模型截图做 |
| 余韵段又加了一句台词总结 | 怕观众没看懂 | 删掉，留一个动作或一个空镜 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；角色是示意。

- 需求："给我们游戏里的守灯人阿沅做个 60 秒角色短片。"
- 落值：原创角色，已有立绘与声线；给玩家看；无对白，只在余韵段一句话。
- 人物功能："负责守灯，却不肯点亮最后一盏。"

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–5 秒 | 亮相 | 他用袖子擦灯罩，擦完又擦一遍 |
| 5–18 秒 | 缺口 | 塔顶最后一盏灯积满灰，他每次路过都绕开 |
| 18–38 秒 | 加压 | 风暴来，下面的灯一盏盏灭；他修好一盏，又灭一盏 |
| 38–50 秒 | 选择 | 他走到最后那盏灯前，点亮它，灯罩上映出一个人的旧照片 |
| 50–60 秒 | 余韵 | 他坐在灯下，说了全片唯一一句："回来吧。" |

表演主档（节选）：

```text
阿沅，三十出头，瘦，肩背微驼——在塔顶的风里站了十年。他一直在等一艘不会回来的船。
习惯：紧张时用拇指反复擦衣角；有人提到海，他先看窗外再回答。
步态：踩着木楼梯数步子走，重心压在脚跟。
但当灯灭时，他会跑——那是全片唯一一次他动得快。
```

最容易错的一处：开头用旁白说"他是最后的守灯人"。删掉，让他擦两遍灯罩，性格就出来了。
