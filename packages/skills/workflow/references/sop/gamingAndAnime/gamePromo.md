# 游戏PV

只干一件事：**让人想玩**。素材是实机还是 CG 决定可信度，卖点只留一个决定记忆点。

## 一、适用 / 不适用

- 适用：概念预告、玩法预告、上市预告、版本更新预告、实机演示片；目的是让人预约、加愿望单、下载、回坑；15–180 秒。
- 不适用：玩的过程与高光 → `gameplayEdit.md`；只讲一个角色 → `characterShort.md`；拿现成作品重剪 → `fanEdit.md`；卖货、留资、投信息流 → `ecommerceAds/`。
- **一句话判据：看完知道"这游戏怎么玩"和"下一步做什么"吗？** 只有氛围、没有动作，先补核心玩法与行动号召。游戏连一段能录的画面都没有，先出概念案并标"非实机"。

## 二、开工必问

一次一个，已知的跳过。

1. 做哪种预告：概念预告、玩法演示、上市预告、版本更新，还是 30 秒短版？——决定比例、时长、节奏。
2. 看完做什么：预约、加愿望单、下载、更新，还是只是记住？——决定最后 5 秒。
3. 素材是实机、CG，还是两者都有？——决定画面分工。
4. 最想突出的那一个核心玩法或卖点是什么？——一条片子只卖一个。

两次都"都行"，落保守值：横版 60 秒上市预告，说明可推翻；卖点问不出来，给两个方向让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 概念 60–120 秒；玩法 60–180 秒；上市 60 秒；版本更新 45 秒；短版 30 秒；短片式 20–45 秒 | 按预告用途选档 |
| 版本 | 横版与竖版各出一条母版 | 竖版重新构图，关键信息进中间六成 |
| 单镜 | 主镜 1–3 秒，高光镜 0.5–1 秒 | 第 1 帧就在动，2 秒内给出一句看得懂的话 |

## 四、结构

60 秒上市预告：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 钩子 | 0–3 秒 | 0–5% | 全片最猛的一帧，配一句 3–7 字的话；不解释，不放 logo |
| 世界与身份 | 3–9 秒 | 5–15% | 这是哪、你是谁、要干什么，一句话说清 |
| 核心循环 | 9–27 秒 | 15–45% | 玩家实际会做什么：打、跑、解、建、抽；一段一个动作 |
| 升级 | 27–45 秒 | 45–75% | 敌人更大、地图更深、代价更高；让"还有更多"看得见 |
| 峰值 | 45–54 秒 | 75–90% | 全片最贵的一镜；音乐落最重的一拍 |
| 收口 | 54–60 秒 | 90–100% | 标题卡 + 日期 + 一个动作指令 |

30 秒投放版：钩子 0–3、核心循环 3–9、峰值 9–24（最贵的一镜连给两下）、收口 24–30 秒。

变体：概念、玩法预告把核心循环拉长、升级压短，没实机就明说"非实机画面"；版本更新从老玩家视角写"新增什么、什么时候、为什么回来"；短片式只保钩子、核心循环、收口。

三条硬约束：一条片子只卖一个卖点；实机与 CG 让观众分得清；最后 5 秒给"下一步做什么"。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主角 / 关键角色 | 1–3 | 补 CG 时做 | 与实机模型同一设计，不另造第二版 |
| 主场景 | 2–4 | 补 CG 时做（母版） | 一段一个地点 |
| 标志武器 / 道具 | 1–2 | 视镜头 | 特写要看清结构时才做 |
| logo 与标题卡 | 1 套 | 否 | 矢量源文件；后期合成，不交给模型画 |
| 音乐、音效、字体 | 1 首 + 6–10 个 + 1–2 款 | 否 | 节拍与打击点清晰 |

实机为主时不做新板；生成只补实机拍不到的 CG 段与氛围镜。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定时长与条数；问清实机还是 CG | 规格表 |
| S1 | 卖点清单 + 节拍表 | 卖点表 + 节拍表 |
| S2 | 只盘会入画的：录屏、角色、场景、logo、字体 | 资产表 |
| S3 | 补 CG 时做角色与场景板 | 已采用资产 |
| S4 | 补 CG 段提示词 | 逐条提示词 |
| S5 | 无声粗剪 → 生成 → 拼接 | 已采用片段 |
| S6 | 音乐、音效、标题卡 | 混音版 |
| S7 | 横竖版与各时长分别验收 | 各版本成片 |

## 八、验收清单

- [ ] 时长与第三节一致
- [ ] 前 2 秒就在动，且有一句看得懂的话；没有 logo 开场、没有黑场
- [ ] 全片只卖一个卖点，观众能一句话复述
- [ ] 实机段与非实机段分得清
- [ ] 最后 5 秒给了明确动作
- [ ] 竖版没切掉准星、血条、字幕

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 看完不知道怎么玩 | 只堆氛围 | 补一段 12–18 秒的"你实际会做什么" |
| CG 被当成实机 | 没做区分 | 加"非实机画面"角标，或把实机段提前 |
| 竖版把血条切了 | 居中裁切 | 按竖版重新构图 |
| 音乐很响但没劲 | 剪辑点没贴拍 | 先定曲打拍点，再摆镜头 |
| 结尾停在氛围上 | 没有行动号召 | 收口固定三件：标题卡、日期、动作指令 |
| 实机录屏里 UI 挡住主体 | 录屏没关调试与多余界面 | 录专用的干净画面版本，或后期遮挡 |
| 上市日期写错 | 用了旧版物料 | 发行方书面确认最终日期 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；游戏是示意。

- 需求："我们的独立游戏《守灯人》要上市了，做个 60 秒预告。"
- 落值：实机为主，开头一段 CG 风暴；看完要"加愿望单"；卖点只留一个："夜里修灯，白天捡漂流物，灯灭了船就回不来"。

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–3 秒 | 钩子 | 一道巨浪砸向灯塔，灯闪了一下没灭；字幕"灯不能灭" |
| 3–9 秒 | 世界与身份 | 你是孤岛上最后一个守灯人 |
| 9–27 秒 | 核心循环 | 实机：夜里爬塔修灯，白天在沙滩捡零件 |
| 27–45 秒 | 升级 | 风暴更大、零件更少、远处出现第一艘船 |
| 45–54 秒 | 峰值 | 实机：灯重新亮起，光扫过海面，船调头靠岸 |
| 54–60 秒 | 收口 | 标题卡 + 上市日期 + "加入愿望单" |

开头 0–3 秒的巨浪是 CG 生成，角落标"非实机画面"；9 秒以后全部实机，并标"实机画面"。

最容易错的一处：开头的 CG 太好看，被当成实机。标清楚，并把实机段尽早放出来。
