# 过程纪录

交付**一件东西从 A 状态变到 B 状态，中间有可见的步骤**：造、修、装、拆、上色、施工、布展、幕后。唯一的标准：观众能在画面里看见"变了"。没有变化的步骤直接合并。它记录过程，不教人复现。

## 一、适用 / 不适用

- 适用：有明确 A、B 两个状态，中间步骤能拍到、每一步变化能在画面上验证的过程；30–90 秒快版或 3–8 分钟完整版。
- 不适用：讲一个人 → `personalDocumentary.md`；只讲卖点 → `ecommerceAds/productVideo.md`；没有可拍过程的纯概念 → `educationalVideos/scienceExplainer.md`；要人照着做 → `educationalVideos/skillTutorial.md`；做菜过程 → `foodAndLifestyle/cookingVideo.md`。
- **前提：A 状态与 B 状态各要一张实物图。** 没有终点图不开工——终点不清，步骤就没有判据。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **起点是什么样，终点是什么样？** 各给一张照片或一句话。
2. **中间有几步？哪一步最容易翻车？**——难点决定时间分配。
3. **能拍到"手"和"工具"吗，还是只能拍到成品？**——只能拍成品，改做商品视频或不拍。
4. **有没有延时条件？** "固定机位、稳定光、能拍够时长，三样齐吗？"
5. **品牌和价格露出到什么程度？** "全遮、露 logo，还是必须念出型号？"

"你看着办"就落：拍 3–8 分钟完整版再剪 60 秒快版、固定机位延时 + 手持特写、品牌全遮、危险步骤加防护与提示卡，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 快版 | 30–90 秒 | 前 3 秒必须是终点；只留 3–5 个关键变化 |
| 完整版 | 3–8 分钟 | 超过 8 分钟按工序拆上下集，不靠加速硬塞 |
| 声音 | 现场声为主（工具、材料、环境），解说克制 | 工具声与材料声分层 |
| 字幕 | 每步一行：做什么 + 耗时 | 耗时是实测值 |
| 安全 | 护具（口罩、护目镜、手套）与危险动作提示卡 | 电、切割、高空、粉尘、化学品各有对应防护；不用生成画面替代真实过程 |

## 四、结构

3 分钟完整版：

| 段落 | 时长 | 占比 | 画面要交代什么 |
|---|---|---|---|
| 结果前置 | 0–9 秒 | 0–5% | 先给终点：成品转一圈或一个关键特写 |
| 起点 | 9–27 秒 | 5–15% | 原材料、空场地、未拆的箱；防护装备穿戴入画 |
| 步骤 | 27–108 秒 | 15–60% | 按步分段，每步一个"变化证据"：切开了、装上了、变平了 |
| 难点 | 108–135 秒 | 60–75% | 最容易翻车的那一步，给足时间，允许失败一次 |
| 对照 | 135–171 秒 | 75–95% | 同机位、同光、同构图下 A 与 B 并置 |
| 收尾 | 171–180 秒 | 95–100% | 一句"所以呢"：现在能干什么，或一共花了多久 |

安全提示的三个位置：起点段防护装备与作业许可入画；第一次出现危险动作前 1.5–3 秒插提示卡；难点段若含危险动作，再上一次角标提示，不遮操作区。

三条硬约束：颗粒度按"能不能看见变化"定，不按工序表定；难点必须留；对照镜头同机位同光同构图。

## 五、资产清单

| 资产 | 要不要 | 做板 | 说明 |
|---|---|---|---|
| 物件本体 | 必须 | 前后状态（变体写法） | 同一件东西的两个状态，不是两件东西 |
| 工作台与空间 | 必须 | 主视图 | 交代固定机位在哪、光从哪来 |
| 工具 | 必须 | 只收反复出现的 | |
| 手部 | 出镜就要 | 同一双手、同一副手套 | 前后不穿帮 |
| 延时素材 | 有条件就要 | — | 固定机位、固定光 |
| 防护装备 | 有危险步骤就要 | 道具板 | 与作业许可一起拍进起点段 |

真实过程一律实拍。生成只补拍不到的角度：微距、剖面、内部结构、原理动画，并标"示意"。

|---|---|---|
| S0 | 要 A、B 两张实物图；事实单落纸 | 规格 + 事实单 |
| S1 | 步骤表 | 步骤表 |
| S2 | 盘物件、工具、手部、延时素材、防护装备 | 素材表 |

## 八、验收清单

- [ ] 前 3 秒看见终点（两版都要）
- [ ] 每一步都有可见变化
- [ ] 前后对照同机位、同光、同构图
- [ ] 手部、工具、服装前后一致
- [ ] 步骤字幕与画面同步，耗时是实测值
- [ ] 难点段保留了失败或返工
- [ ] 防护装备在起点段入画；首次危险动作前有提示卡
- [ ] 没有用生成画面替代真实过程

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 步骤平铺，没有重点 | 按工序表剪 | 找出最容易翻车的一步给足时长，其余压缩 |
| 全程固定机位，像监控 | 只有延时 | 每步补一个手持特写，插入切 |
| 前后对照机位不一致 | 没提前锁机位 | 重拍对照，或改用"同一位置摇过去" |
| 只有环境声，没有工具声 | 没单独收声 | 补录关键声音 |
| 结尾没有"所以呢" | 停在成品转圈 | 加一句用途或总耗时 |
| 加速掩盖了步骤 | 关键步骤也加速 | 关键步骤常速，只压缩等待与重复 |
| 延时段画面忽明忽暗 | 窗外自然光在变 | 延时用固定人工光，拉上窗帘 |
| 成品和起点不像同一件东西 | 换了角度和背景 | 起点、终点同机位、同背景各拍一张 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；耗时是实测示意。

- 需求："我在翻新一把奶奶留下的老藤椅，想拍成视频。"
- 落值：A 状态是藤面破洞、木框脱漆；B 状态是新藤面、上好清漆；3 分钟完整版 + 60 秒快版；固定机位延时 + 手持特写；无品牌露出。
- 一句话：观众每一段都能看见"变了"——藤拆掉了、框变亮了、藤编回去了。

步骤表（S1 的产物）：

| 步 | 这一步变了什么 | 实测耗时 | 镜头 | 危险 |
|---|---|---|---|---|
| 1 拆旧藤 | 破藤面变成光秃的木框 | 40 分钟 | 延时压到 6 秒 + 剪刀特写 | 剪刀 |
| 2 打磨上漆 | 发灰的框变成发亮的木色 | 3 小时 | 打磨一次就剪，上漆给足 | 粉尘：口罩、护目镜；上漆：开窗通风 |
| 3 编藤 | 一根根藤从框边织满整个座面 | 6 小时 | 延时 + 手部特写 | — |
| 4 收口 | 最后一圈压边，藤面绷紧 | 30 分钟 | 难点，给足时间，含一次收松重来 | — |

结构落地：0–9 秒新藤椅转一圈；9–27 秒破椅 + 戴上口罩护目镜入画，字幕"打磨前戴好防护"；27–108 秒步骤 1–3；108–135 秒收口，第一次收松了重来；135–171 秒同机位旧椅与新椅并置；171–180 秒"一共 10 个小时，奶奶坐了 30 年的椅子"。

最容易错的一处：打磨三小时全放。打磨没有可见变化就剪成一次，留给上漆那一下变亮。
