# 年会回顾

一年的事，事后讲给内部人听：尾牙、年度大会、颁奖礼上播，或会后发给全员。它管的是集体记忆——谁被看见、谁被点名、哪件事算数。判据：散场后有人问"那个镜头是谁"，这条就成了。

## 一、适用 / 不适用

- 适用：2–10 分钟的年度回顾、访谈感谢、综合版与个人表彰单条。
- 不适用：开场定调 → `eventOpening.md`；对外品牌片 → `promotionalVideos/companyPromo.md`；当晚发的 30 秒花絮 → 另开一条，别挤进回顾片。
- **一句话判据：片里每个部门都能找到自己人吗？** 找不到，现场就会有人低头玩手机。

## 二、开工必问

一次一个。第 2、3 题决定片长与素材能不能用，问完再谈创意。

1. 给谁看：全员、管理层，还是客户也在场？——决定重点放业务节点还是内部花絮。
2. 播在哪一段：开场前、颁奖中，还是散场前？一共能给几分钟？——决定版本与现场上限。
3. 有没有"必须出现"的人，和"绝对不能出现"的人？
4. 素材在哪：共享盘、各人手机，还是市场部一个人手上？
5. 谁审片、能改几轮？

答不上来落保守值：年度回顾型、制作 3 分钟、现场 2–3 分钟、带音乐与纯人声两版，说明可推翻。

## 三、规格

版本矩阵，制作时长与现场上限分开写；现场版从制作版里裁，不另拍：

| 版本 | 制作时长 | 现场播放上限 | 用途 |
|---|---|---|---|
| 年度回顾型 | 3–4 分钟 | 2–3 分钟 | 开场前或散场前 |
| 访谈感谢型 | 3–6 分钟 | 3–5 分钟 | 颁奖间隙、内部场 |
| 综合版 | 5–10 分钟 | 5–7 分钟 | 现场用 5–7 分钟版；长版会后传播 |
| 个人表彰单条 | 60–90 秒 | 30–90 秒 | 颁奖时逐人放 |

| 项 | 出发值 | 备注 |
|---|---|---|
| 备用音轨 | 另出一版无音乐、纯人声 | |
| 字幕 | 访谈全部烧字幕，另存一份外挂字幕 | |
| 排期 | 提前 6 周定版本与名单，4 周拍完访谈收齐素材，3 周出初版，改不超过 2 轮，提前 2–3 天交场地方 | |

## 四、结构

3 分钟基准；改 4 或 5 分钟按比例放，快剪段固定不超过 20 秒，差额从当晚高光里调：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 年度节点快剪 | 0–20 秒 | 0–11.1% | 项目、签约、发货、团建，一秒一个，先把"这一年"框住 |
| 当晚高光 | 20–108 秒 | 11.1–60% | 颁奖、节目、抽奖，每段不超过 15 秒 |
| 员工原话 | 108–144 秒 | 60–80% | 3–4 人，每人一句"今年最想说的一句话" |
| 合影与明年 | 144–171 秒 | 80–95% | 全员合影 + 一行目标字，不喊口号 |
| 收尾镜头 | 171–180 秒 | 95–100% | 散场、收场、关灯，给一个"结束"的实感 |

四条规则：回顾型超过 4 分钟除了当事人没人看完，想放更多就拆一条专题；现场版按上限压；每个部门至少一张脸；访谈只给"一句"——说 30 秒剪到 8 秒。

## 五、资产清单

| 资产 | 要不要 | 说明 |
|---|---|---|
| 年度素材库 | 必须 | 按季度建共享夹；手机压缩图上大屏必糊 |
| 当晚必拍清单 | 必须 | 签到、进场表情、后台、上台前、颁奖握手、下台被围、抽奖、碰杯、老员工被点名、散场合影 |
| 受访者名单与问题单 | 必须 | 问具体的：今年最有成就感的一件事；哪个瞬间觉得这份工作值得 |
| 年度数字 | 必须 | 营收、出货、人数、年限，每个数字有签字人 |
| 历史照片 | 按需 | 来源与年份逐张记 |
| 字卡与数据动效样式 | 必须 | 全片统一 |

主体是既有素材与实拍。**真人不进生成池**：员工的脸只用真实素材，缺镜头就补拍，不生成"像员工的人"。生成只做字卡动效、数据动效、拍不到的空镜。

## 六、方法论调用

以下文件都在 `references/methods/`。

| 阶段 | 读 | 本类目怎么用 |
|---|---|---|
| S1 | [脚本与口播](../../methods/scriptsAndNarration.md) 一、四、七 | 不写故事，写素材清单 + 时间线：哪个月发生什么、谁在场；访谈给问题不给稿 |
| S2–S3 | [资产设计](../../methods/assetDesign.md) 二 | 不做角色板；盘人物名单表与年度事件表；只做字卡与数据动效的样式板 |
| S4 | [镜头设计](../../methods/shotDesign.md) 七；[提示词写法](../../methods/promptWriting.md) 二 | 补空镜只写场景、视角、光、声音，不写角色与表演——一写就假；字卡字号、位置、出现时机写成常量 |
| S5 | [画布与交付](../../methods/canvasAndDelivery.md) 三、五 | 三机位：主机位全景、侧机位 45 度抓表情、游机走桌 |
| S6 | [声音](../../methods/sound.md) 二、九 | 现场同期声基本不可用：单独录主持人话筒线对时间轴，重要发言补录；环境声、动作声、配乐分开记 |

本类目用不上：故事与剧作、表演与动作、分段与装配的多条拆分。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定版本与两个时长（制作版、现场上限），写进确认单 | 确认单 |
| S1 | 素材清单 + 时间线 + 访谈问题单 | 三张表 |
| S2 | 人物名单表、年度事件表 | 两张表 |
| S3 | 字卡与数据动效样式板 | 样式板 |
| S4 | 空镜与动效提示词（可空） | 补镜清单 |
| S5 | 当晚三机位拍摄 + 素材拼接 | 粗剪 |
| S6 | 话筒线对轴、访谈字幕、带音乐与纯人声两版 | 混音 |
| S7 | 定版前彩排实播；竖版单独取景；文件名带版次 | 交付包 |

## 八、验收清单

- [ ] 每个部门都至少出现一个人
- [ ] 三个"年度必须提到"的事件都在
- [ ] 片长按版本矩阵的现场上限
- [ ] 访谈全部有字幕，方言口音能看懂
- [ ] 所有数字有出处，与公司口径一致
- [ ] 带音乐版与纯人声版各一份
- [ ] 竖版单独取景，不是裁中间
- [ ] 现场彩排实播过，播完能干净退出

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 太长，散场前没人看 | 什么都想放 | 回顾压到 2–3 分钟，想放的另做专题 |
| 只有领导，没有一线 | 素材来源偏 | 按部门补脸 |
| 访谈像念稿 | 问的是感想 | 问一件具体的事；先聊十分钟再开机 |
| 改到最后一刻 | 没限轮次 | 修改控制在 2 轮，定版后只改错字 |
| 漏掉当年的大事 | 靠回忆 | 用年度事件表逐条对 |
| 获奖名单念错名字 | 没核对 | 名单向 HR 拿书面版逐字核 |
| 新员工完全没出现 | 素材只来自老员工手机 | 盘点时按入职年份看一遍，补拍新员工 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："300 人的公司年会，散场前放一段回顾。"
- 落值：年度回顾型，制作 3 分钟、现场上限 3 分钟；给全员看；必须出现：第一个海外订单、新厂区搬迁、年度客户奖；素材在共享盘和各部门手机里。
- 一句话：8 个部门在片里都找得到自己人。

年度事件表（S2 的产物，节选）：

| 月 | 事件 | 谁在场 | 素材在哪 |
|---|---|---|---|
| 3 月 | 第一个海外订单发货 | 仓储部、外贸部 | 共享盘 /03 |
| 6 月 | 新厂区搬迁 | 全员 | 行政部手机 + 共享盘 /06 |
| 11 月 | 拿下年度客户奖 | 销售部 | 市场部 |

部门覆盖表：研发 ✓ / 生产 ✓ / 仓储 ✓ / 外贸 ✓ / 销售 ✓ / 财务 ✗（补拍） / 行政 ✓ / 人事 ✗（补拍）。

结构落地：0–20 秒三个事件各 2 秒加 14 秒其他节点快剪；20–108 秒当晚颁奖、节目、抽奖，每段不超过 15 秒；108–144 秒 4 个人各一句"今年最想说的一句话"；144–171 秒全员合影 + 一行明年目标；171–180 秒散场关灯。

最容易错的一处：财务和人事没素材就算了。漏一个部门，现场就有一桌人低头看手机，开拍前补拍。
