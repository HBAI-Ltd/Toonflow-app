# 活动开场

现场要播的开场片：年会、发布会、论坛、颁奖礼、展会，放在"灯暗下去"到"主持人开口"之间。它是一条**舞台装置**，只在一个晚上、一块屏、一个时间点上生效。判据只有一条：灯暗到主持人开口这段空档，观众有没有抬头看屏。

## 一、适用 / 不适用

- 适用：主片 3–6 分钟，另出 90–120 秒短版，在现场大屏播放。
- 不适用：会后传播 → `annualEventRecap.md`；对外品牌叙事 → `promotionalVideos/companyPromo.md`；线上首发 → `promotionalVideos/productPromo.md`。
- **一句话判据：离开那块屏和那个时间点，这条片还需要成立吗？** 不需要，才是活动开场。

## 二、开工必问

一次一个。第 1 题问错，后面全白做。

1. **那块屏的物理比例与像素是多少？** 要具体数字，不要"高清"。——画幅由屏定，覆盖项目默认画幅。
2. 从灯暗到主持人第一句话，中间有多少秒？——决定片长。
3. 现场谁在放、用什么设备放、有没有彩排？
4. 需不需要带角标版？有没有第二块屏或同步直播？
5. 要不要在片里"念出成绩"（数字、奖项、人名）？出处谁签字？

屏体参数没有保守值，拿不到就不动手；其余答不上来落保守值：主片 4 分钟 + 105 秒短版、四件套 + 无音乐音轨，说明可推翻。

## 三、规格

| 版本 | 角标 | 时长 | 用途 |
|---|---|---|---|
| 长版·带角标 | 有 | 3–6 分钟 | 主屏播出 |
| 长版·去角标 | 无 | 3–6 分钟 | 转播、回放、二次使用 |
| 短版·带角标 | 有 | 90–120 秒 | 流程压缩时的替补 |
| 短版·去角标 | 无 | 90–120 秒 | 会后物料 |
| 无音乐音轨 | — | 同长版 | 现场调音、换曲 |

| 项 | 出发值 | 备注 |
|---|---|---|
| 画幅 | 按屏定：常见 16:9、32:9、6:1 | 读视频文件的实际显示比例核对，不用播放器窗口量 |
| 落版 | 末帧定格 2–3 秒 | |
| 安全区 | 按屏的实际比例单独排 | 不套 16:9 模板 |

## 四、结构

主片 4 分钟基准；换 3 或 6 分钟，落版固定最后 2–3 秒，差额从抬升段扣，其余等比：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 起 | 0–5 秒 | 0–2% | 一记重音 + 一个画面；让人知道"开始了" |
| 定调 | 5–36 秒 | 2–15% | 主题字或符号出现，交代今晚的调子（不是公司简介） |
| 讲事一 | 36–108 秒 | 15–45% | 实拍 + 数字：这一年做成了什么，用人和场景说 |
| 讲事二 | 108–168 秒 | 45–70% | 第二组事实：规模、突破，或一个人的一天 |
| 抬升 | 168–238 秒 | 70–99% | 集体镜头、快剪，音乐推到最响 |
| 落版 | 238–240 秒 | 99–100% | 主题字 + 标识，定格；不加"谢谢观看" |

短版 105 秒，内容取自长版，不重拍：起 0–3、定调 3–10、讲事（一个数字 + 一个人）10–45、抬升 45–102、落版 102–105 秒。

两条规则：实拍段讲事，图形段定调，交替推进——全实拍在超宽屏上显平，全图形会空；切点密度按屏宽定——超宽屏上视线横向游走，切得比 16:9 慢（约 20 秒一切）。

## 五、资产清单

- 屏体参数表：物理尺寸、像素、显示比例、亮度、播放器型号——一张表，甲方签字
- 场地与人物实拍：厂房、门店、工位、一线的人
- 年度数字：每个数字有出处和签字人
- 品牌角标：带与不带两套，位置按屏的比例单独排
- 音乐：主音乐轨 + 一条无音乐音轨
- 生成画面：只做图形段与实拍补不上的氛围镜

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 第一件事要屏体参数与流程表；没有参数不动手 | 屏体参数表 + 规格 |
| S1 | 现场时间轴 | 时间轴 |
| S2 | 实拍素材、年度数字、角标、音乐盘点；播放清单 | 素材表 + 播放清单 |
| S3 | 角标与主题字 | 图形资产 |
| S4 | 图形段与氛围补镜提示词 | 补镜清单 |
| S5 | 按屏比例取景，实拍与图形交替拼接 | 长版 + 短版 |
| S6 | 音乐、音效、按现场扩声校音量 | 混音 + 无音乐音轨 |
| S7 | 五件齐；现场彩排实播一遍；两个介质各存一份 | 交付包 |

彩排不是可选项：播不出来、声音只从笔记本出来、播完主持人话筒没切回来——这三种事故每年都在发生。

## 八、验收清单

- [ ] 文件显示比例与屏体比例一致
- [ ] 关键文字、标识都在安全区内，超宽画面单独排过版
- [ ] 灯全暗时前 3 秒能看清主画面
- [ ] 主片 3–6 分钟、短版 90–120 秒，两版都能独立看懂
- [ ] 落版定格 2–3 秒，没有提前黑屏
- [ ] 五件齐：长、短 × 带、去角标 + 无音乐音轨
- [ ] 超宽画面没有硬拉，补画接缝看不出来
- [ ] 每个数字有出处与签字人
- [ ] 彩排实播过：满屏、音量合适、播完干净退出

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 人和字被拉变形 | 拿 16:9 拉伸铺满 | 按屏的真实比例重排 |
| 文字贴边 | 套了 16:9 安全区 | 按超宽重定安全区，落版单独摆 |
| 开头 30 秒只有 logo 动画 | 标识放错位置 | 前 15 秒内出现一个"事"，标识放落版 |
| 片子比流程长 | 没按流程反推片长 | 删段落，不删落版 |
| 只交一个版本 | 没做版本矩阵 | 四件套一次交齐，加无音乐音轨 |
| 正式开场时声音比彩排小 | 彩排时场内没人 | 满场会吸音，按满场留出音量余量，开场前再听一次 |
| 落版后主持人没接上 | 时间轴没给主持人 | 时间轴写清"结束后几秒主持人开口"，交给主持与导播 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；屏体参数是示意。

- 需求："公司年会开场片，舞台是一块很宽的屏。"
- 落值：屏体比例 6:1（甲方签字的参数表）；从灯暗到主持人开口 4 分钟；现场有导播，提前一天彩排。

屏体参数表（S0 的产物）：

| 项 | 值 |
|---|---|
| 物理尺寸 | 18 米 × 3 米 |
| 像素 | 5760 × 960 |
| 显示比例 | 6:1 |
| 播放器 | 型号按场地方提供，提前一天测试 |

现场时间轴（S1 的产物）：

| 时刻 | 发生什么 |
|---|---|
| T+0 | 灯全暗 |
| T+0.3 秒 | 一记鼓声，画面亮起：一线工人推开厂房大门 |
| T+5 秒 | 主题字出现 |
| T+36 秒 | 讲事一：今年第一条全自动产线投产 |
| T+108 秒 | 讲事二：一位质检员的一天 |
| T+168 秒 | 抬升：全员合影快剪，音乐推到最响 |
| T+238 秒 | 落版：主题字 + 标识，定格 |
| T+240 秒 | 黑场，主持人话筒打开 |

定调段的图形背景由生成完成：先按 21:9 生成，再左右补画到 6:1，标识和主题字后期合成。

最容易错的一处：拿 16:9 素材直接拉宽铺满 6:1。人会被拉扁，必须按 6:1 重新取景或补画。
