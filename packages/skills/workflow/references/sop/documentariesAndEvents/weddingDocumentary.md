# 婚礼纪实

交付**一天里不能再来的那几个瞬间**：现场不可控、时间线由流程决定、没有补拍机会，快剪当天就要在宴席上放。判据：新人父母看完，有没有一处让他们停下来不说话？主体是两家人的关系，最重的镜头往往不在新人身上。

## 一、适用 / 不适用

- 适用：婚礼全天记录、订婚与回门、纪念日短片、当天快剪、给长辈看的完整版、暖场成长相册、恋爱回顾。
- 不适用：婚纱照（不是视频）；企业活动 → `eventOpening.md`；单人故事 → `personalDocumentary.md`；虚构婚礼剧情 → `shortDrama/`。
- **一句话判据：这条片里的每个瞬间都真实发生过吗？** 加入虚构剧情与表演，就不是纪实了。

## 二、开工必问

一次一个。

1. **当天流程几点到几点？** 要一张时间表：化妆、迎亲、仪式、敬酒、送客。
2. **要不要当天快剪？**——要快剪，素材交付时间就得倒排。
3. **几台机器、谁拍？**
4. **要不要另做暖场相册或恋爱回顾？**

"你看着办"就落：双机位、3 分钟快剪 + 15 分钟完整版，说明可推翻。

## 三、规格

| 版本 | 时长 | 什么时候放 | 备注 |
|---|---|---|---|
| 当天快剪 | 3–4 分钟 | 宴席开始前 | 超过 6 分钟台下开始说话、动筷子 |
| 完整版 | 15–30 分钟 | 给家里人 | 按一天顺序，节奏可比快剪慢 |
| 暖场 / 成长相册 | 3–4 分钟 | 宴席前循环 | 旧照片为主，用扫描件 |
| 恋爱回顾 | 3–5 分钟 | 仪式前或二次场 | 需要两人各自的素材 |

| 项 | 出发值 | 备注 |
|---|---|---|
| 声音 | 同期声优先；誓言、长辈说话、笑声不许被音乐盖掉 | |
| 字幕 | 誓言与受访全字幕；方言加注；人名称谓核对 | |

## 四、结构

完整版 20 分钟基准，按"一天"排，不按"好看"排：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 序 | 0–2 分 | 0–10% | 一个物件或一个动作：戒指、信、系领带的手、母亲整理头纱；先声后人 |
| 迎亲 | 2–6 分 | 10–30% | 门里门外两边的反应；给一个具体的人一个具体的表情 |
| 仪式 | 6–13 分 | 30–65% | 入场、交接、誓言、交换、拥吻；誓言不剪碎，留完整一句 |
| 宴席 | 13–17 分 | 65–85% | 敬酒、长辈说话、朋友起哄；挑一个"失控"的瞬间 |
| 尾声 | 17–20 分 | 85–100% | 一个空镜收（椅背、花瓣、灯），加一行事实字幕：日期、地点 |

当天快剪 3 分 30 秒基准，素材按到手顺序剪，最后按表重排：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 先声 | 0–21 秒 | 0–10% | 一句誓言或一句笑声，先出声音 |
| 三个快镜 | 21–84 秒 | 10–40% | 化妆、出门、入场，每个 15–20 秒 |
| 情绪高点 | 84–178 秒 | 40–84.8% | 交接或拥吻，放慢，不加花字 |
| 收尾 | 178–210 秒 | 84.8–100% | 送客、花絮、合影快切；最后 2–3 秒落一行日期地点，定格 |

快剪宁短勿长：宁可少一个环节，也不为凑长度放重复画面。暖场与恋爱回顾沿用完整版占比，只换素材。

## 五、资产清单

| 资产 | 要不要 | 做板 | 说明 |
|---|---|---|---|
| 流程表 | 必须 | — | 时间、地点、负责人电话；拍摄清单挂在每段后面 |
| 称谓与身份表 | 必须 | — | 谁是谁、怎么称呼；错一个字整片失礼 |
| 地点主视图 | 有补拍空镜才要 | 是 | 化妆间、仪式厅、宴会厅 |
| 人物 | 必须 | **不做板** | 真人只实拍，不进生成池 |
| 旧照片与旧视频 | 暖场要 | 否 | 提前两周扫描 |
| 双备份 | 必须 | — | 两份不同设备，格式能被现场播放器识别 |

**不做证明性画面**：结婚证、户口本、戒指内刻字、宾客名单用真实素材或不做。生成只补没拍到的空镜，并标"情景再现"。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定版本与时间倒排表 | 规格表 |
| S1 | 流程表 + 拍摄清单 + 问题清单 | 三张表 |
| S2 | 机位、电池卡、旧素材、音乐；当天按清单点一遍再出门 | 盘点表 |
| S3 | 补空镜需要的地点主视图（可空） | — |
| S4 | 补拍空镜提示词，每条标"情景再现"（可空） | 补镜清单 |
| S5 | 仪式结束即拷卡，边拷边剪快剪；之后剪完整版 | 快剪 + 完整版 |
| S6 | 原声、音乐、方言字幕过一遍母语者 | 混音 |
| S7 | 新人与父母看片；称谓逐项过；现场播放备份包 | 各版本 + 备份包 |

## 八、验收清单

- [ ] 前 30 秒有一个具体的人在做一件具体的事
- [ ] 誓言段至少保留一句完整原话，没被音乐盖掉
- [ ] 有一个镜头拍的是父母
- [ ] 全片有一处让人停下来的静默
- [ ] 时长按版本表
- [ ] 称谓逐条核对无误
- [ ] 现场包：两份备份，提前在播放设备上完整试放

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 像流程录像 | 按环节平均分配时长 | 按情绪重排：仪式与父母段加长，敬酒压缩 |
| 快剪赶不出来 | 素材交付晚于宴席 | 倒排：仪式结束即拷卡，边拷边剪 |
| 音乐盖住誓言 | 全程铺满配乐 | 誓言段拉掉音乐 |
| 片子只有新人 | 机位都对着舞台 | 补父母、伴郎伴娘、宾客的反应镜 |
| 长辈称谓错 | 没做身份表 | 建表让新人过一遍再上字幕 |
| 新娘的脸被 LED 屏映得发红 | 屏幕光打到人身上 | 机位避开 LED 直射，白平衡按人脸定 |
| 誓言被宾客的说话声盖住 | 只用了相机机头录音 | 新人身上别领夹麦，誓言单独收一轨 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："朋友下个月结婚，想要宴席开始前放一段当天的快剪。"
- 落值：双机位；3 分 30 秒快剪 + 15 分钟完整版；仪式 10:30–11:15，宴席 12:00 开始。
- 倒排时间：11:15 仪式结束立刻拷卡 → 11:20–11:50 剪快剪 → 11:55 交给现场播放，已提前一天在宴会厅设备上试放过。

必须拍到的 8 个镜头（S1 的产物）：
1. 母亲给新娘整理头纱的手
2. 新郎父亲在门外等待的背影
3. 交接时新娘父亲松手的那一秒
4. 誓言里完整的一句
5. 交换戒指的两只手
6. 双方父母第一次同框
7. 一个宾客笑出眼泪
8. 送客后空下来的椅子

快剪落地：0–21 秒先出誓言里那一句的声音，再出画面；21–84 秒化妆、出门、入场各 20 秒左右；84–178 秒交接与拥吻，放慢，不加花字；178–210 秒送客、合影快切，最后 3 秒落"2026.12.20 某酒店"并定格。

最容易错的一处：机位都对着舞台，父母的反应一个没拍到。第二机位全程跟着双方父母。
