# 人物纪实

交付**一个真实的人，一件真实发生或正在发生的事**。靠采访、跟随实拍、旧素材撑起来，不靠旁白把人夸一遍。唯一的硬标准：片子里出现的每一件事，都能指到一个人、一个时间、一个地点；指不到，就是情景再现或传闻，必须标注或删掉。

## 一、适用 / 不适用

- 适用：一个真实人物的处境、行动与代价；采访 + 跟随 + 旧素材能拍到、能核实的题材；3–5 分钟社媒版或 8–15 分钟完整版。
- 不适用：虚构人物 → `shortDrama/`；企业形象片 → `promotionalVideos/companyPromo.md`；只记录物件变化 → `processDocumentary.md`；主体是两人对话 → `educationalVideos/interviewPodcast.md`。
- **前提：那件事还能拍到吗？** 能拍到是纪实；拍不到就是口述史加情景再现。两种做法完全不同。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **这个人是谁，你为什么想拍他？** 不要"他很励志"，要一件具体的事。
2. **他现在被什么卡着？** "拿不到、留不住、来不及，是哪一种？"——决定"处境"段拍什么。
3. **那件事还能拍到吗，还是只能靠他说？手上有哪些旧东西（照片、视频、文件）？**——决定纪实还是口述史形态。

"你看着办"就落：5 分钟短版、双机采访 + 跟随，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 社媒版 | 3–5 分钟 | 超出就砍回望与旧素材，不砍处境与代价 |
| 完整版 | 8–15 分钟 | 超出按事件阶段拆上下集 |
| 采访占比 | 出镜采访 ≤ 全片 1/3 | 超过说明画面没跟上，回 S2 补跟拍 |
| 声音 | 同期声优先；旁白只补事实 | 旁白不评价、不替他总结 |
| 字幕 | 原话全字幕；方言加注 | 不改写原意 |
| 情景再现 | 只补拍不到的过去，每处标"情景再现" | 不生成证件、新闻画面、聊天记录；不摆拍关键事实 |

## 四、结构

5 分钟社媒版；完整版按同一比例放大，顺序不变：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 冷开场 | 0–24 秒 | 0–8% | 一个动作或一句原话；先看见他在做事，不介绍身份 |
| 处境 | 24–75 秒 | 8–25% | 他被什么卡住：期限、钱、身体、关系；代价具体到能看见 |
| 行动 | 75–165 秒 | 25–55% | 他去做了什么，怎么试，第一次失败在哪一步 |
| 代价 | 165–240 秒 | 55–80% | 事情没按他想的走；他改了什么，或者没改 |
| 回望 | 240–285 秒 | 80–95% | 他自己怎么理解这段；不替他总结 |
| 落版 | 285–300 秒 | 95–100% | 一句他自己的话 + 事实交代：时间、地点、现在怎么样 |

两条编排规则：采访不承担叙事，只承担"他自己怎么说"——旁白能说清的事实不用采访，画面能看到的变化不用旁白；每段采访后面必须接一个他刚说过的事的画面，接不上就删这段采访。

落版的时间、地点、现状必须与事实表逐字对得上。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 人物本人 | 必须 | **不做角色板** | 真人只走真实素材，不生成 |
| 地点主视图 | 有情景再现才要 | 是 | 家、工作地、常去的路口；同地点跨场复用 |
| 关键物件 | 有情景再现才要 | 是（道具板） | 与事件直接相关的物件 |
| 旧素材 | 按需 | 否 | 逐件记来源与拍摄时间 |
| 第三方 | 出镜就要 | 否 | 不愿出镜用背影、手部或声音 |
| 事实表 | 必须 | — | 事件、时间、地点、数字、称谓、职务、出处，一条一行 |

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定形态（纪实或口述史）与时长版本 | 规格 |
| S1 | 事实表 + 拍摄清单 + 问题清单 | 三张表 |
| S2 | 盘人、地点、旧素材、第三方 | 素材表 |
| S3 | 只做情景再现需要的地点与物件板 | 已采用资产 |
| S4 | 情景再现与空镜提示词，每镜标"此镜为情景再现" | 补镜清单 |
| S5 | 双机采访 + 跟随 + 旧素材为主线，情景再现叠入 | 粗剪 |
| S6 | 原声、字幕、底噪 | 混音版 |
| S7 | 事实复核 | 成片（主版 + 竖版） |

## 八、验收清单

- [ ] 冷开场段内看见具体的人在具体的地方做具体的事
- [ ] 核心事件有时间、地点、代价；落版与事实表逐字对得上
- [ ] 采访出镜 ≤ 全片 1/3，没有一段是"他夸自己"
- [ ] 每处情景再现都有标注
- [ ] 数字与称谓有出处；受访者核过关键事实
- [ ] 方言字幕过了一遍母语者

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 通篇旁白夸人 | 旁白在评价 | 删掉评价，只留他自己说的话和做的事 |
| 采访太多，像口述史 | 画面没跟上 | 每段采访后接画面，接不上就删 |
| 只拍成功，不拍代价 | 怕难看 | 补失败、犹豫、损失 |
| 摆拍关键事实 | 来不及跟拍 | 改成跟随，或明确标"情景再现" |
| 时间线乱 | 按好看排 | 按事实表时间重排 |
| 情景再现里出现了人脸 | 想更有代入感 | 情景再现只拍物件、手、背影，不生成会被当成真人的脸 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："菜市场门口修了 30 年鞋的老师傅，摊位要拆了，想给他拍个片。"
- 落值：纪实形态（现在还能跟拍）；5 分钟社媒版；双机采访 + 跟随。
- 一句话：每件事都能指到人、时间、地点——"2026 年 9 月贴出拆迁通知，他用最后一个月把手上的鞋修完"。

事实表（S1 的产物，节选）：

| 事件 | 时间 | 地点 | 出处 |
|---|---|---|---|
| 摊位拆迁通知贴出 | 2026 年 9 月 | × 菜市场东门 | 通知原件，实拍 |
| 第一次摆摊 | 1996 年 | 同一位置 | 本人口述 + 一张旧照片（家属提供） |
| 最后一双鞋 | 拆迁前一天 | 摊位 | 跟拍 |

问题清单（按"他做过什么"排）：通知贴出来那天，你先做了什么？你去找过谁？最后一双鞋修给了谁？

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–24 秒 | 冷开场 | 他钉好最后一颗鞋钉，把鞋递给一个老顾客，不说话 |
| 24–75 秒 | 处境 | 拆迁通知；他手边还有 40 双没修完的鞋 |
| 75–165 秒 | 行动 | 他挨个打电话让顾客来取；去街道问能不能挪到别处 |
| 165–240 秒 | 代价 | 新位置在地铁口，没人认识他；第一天只来了一个人 |
| 240–285 秒 | 回望 | "修了 30 年，修的都是别人要走的路。" |
| 285–300 秒 | 落版 | 他现在在地铁 B 口，每天早上 7 点出摊 |

1996 年第一次摆摊拍不到，做一条情景再现：清晨街角一张小板凳和一个木鞋箱，没有人，角落标"情景再现"。

最容易错的一处：旁白给他贴"匠人精神"的标签。删掉评价，只留他自己说的话和做的事。
