# 旅行纪录

交付**一段行程里，一个人被改变的那一点**。不是风景集，也不是攻略：行程提供结构，人提供意义。判据：关掉音乐，还看得懂这是一趟什么旅行吗？只剩好看的空镜在动，那是素材拼贴。

## 一、适用 / 不适用

- 适用：一次出行（周末到长途）的个人或小团体纪录；城市漫游、徒步、自驾、探亲；发社媒的 20–60 秒版，与给家里人看的 3–10 分钟长版。
- 不适用：城市与景区宣传 → `promotionalVideos/cityTourism.md`；日常流水账 → `foodAndLifestyle/lifestyleVlog.md`；一件事怎么做 → `processDocumentary.md`；纯空镜混剪；商业带货式旅拍 → `ecommerceAds/`。
- **骨架是地点顺序，落点是人。**

## 二、开工必问

一次一个。

1. **这趟旅行里，你记住了哪一秒？** 要一件具体的事，不要"风景很美"。
2. **有没有一个变化？** "出发前你在烦什么，回来时还想它吗？"——变化是全片的落点。
3. **做多长？** "20–60 秒短版，还是 3–10 分钟长版？"——决定镜头密度与解说。
4. **素材够吗？** 每个地点有没有人、有没有空镜、有没有一个意外。

"你看着办"就落：45 秒竖版、按天排、一句开头一句结尾，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 短版 | 20–60 秒，基准 60 秒 | 20 秒版砍段，不缩时长 |
| 长版 | 3–10 分钟 | 超过 10 分钟按章节分 |
| 地点数 | 20 秒版 2–3 处；60 秒版 3–6 处；长版每天 1–2 处 | 一处只留一个停留镜 |
| 单镜时长 | 1–2 秒；最好的景停 2–3 秒 | 停留镜不超 3 秒 |
| 人的出现频率 | 每 3–4 个镜头出现一次人 | 全是风景是最常见的失败 |
| 声音 | 保留现场声（风、水、脚步、交谈），音乐垫底 | 纯音乐铺满会像广告 |
| 字幕 | 地点标签 + 时间标签；口播全字幕 | 地名路线名不许写错 |

## 四、结构

短版 60 秒：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 标志镜头 + 标题 | 0–3 秒 | 0–5% | 这个地点最容易被认出的一个画面，标题压在上面 |
| 到达 | 3–15 秒 | 5–25% | 怎么来的：车窗、门、第一条街；给观众一个"进入" |
| 地点按序 | 15–39 秒 | 25–65% | 3–6 处，每处广、中、细节各一个 |
| 最好的时刻 | 39–50 秒 | 65–83.3% | 全片最想让人记住的那一个，放慢，不加花字 |
| 最后一夜 / 离开 | 50–58 秒 | 83.3–96.7% | 收行李、回程的路、关灯 |
| 落点 | 58–60 秒 | 96.7–100% | 标题再出现，或一句一行字 |

20 秒版删段：标志镜头 0–2、地点 2–12、最好的时刻 12–17、落点 17–20 秒。长版 6 分钟三幕：为什么去 0–54 秒 → 路上发生了什么 54–306 秒（每处一个"人"的事件，至少一个不顺）→ 回来之后 306–360 秒（回答出发前那件事，回到一个具体的东西）。

四条硬约束：每 3–4 个镜头出现一个人；一个地点只留一组镜头；先快后慢；至少一个"不顺利"（走错路、下雨、错过车）。

## 五、资产清单

| 资产 | 要不要 | 做板 | 说明 |
|---|---|---|---|
| 行程表与素材日志 | 必须 | — | 每条素材记地点、日期、谁在画面里 |
| 地点标签与地图 | 必须 | 图形规范 | 地图只画真实路线 |
| 人物 | 必须（同行者） | **不做板** | 真人只实拍 |
| 音乐 | 必须 | — | 一首，在中段与结尾起 |

**不做假目击**：没拍到的现场（事故、演出、他人生活）不生成，也不做成"当时我看见了"。生成只用于去不了的角度、地图动画、转场、空镜。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定形态（短版还是长版）与时长 | 规格 |
| S1 | 行程表 + 素材日志 + 开头结尾两句 | 三张表 |
| S2 | 按地点归类素材 | 素材表 |
| S3 | 地点标签模板与地图动画 | 图形资产 |
| S4 | 补空镜、地图、转场提示词，注明替代哪一段 | 补镜清单 |
| S5 | 粗排 → 压时长 → 补镜叠入 | 粗剪 |
| S6 | 现场声、音乐、地名字幕 | 混音 |
| S7 | 两种比例分别验收；封面选标志镜头 | 成片 |

## 八、验收清单

- [ ] 关掉音乐仍看得懂这是一趟什么旅行
- [ ] 前 3 秒是当地最容易被认出的镜头
- [ ] 每 3–4 个镜头出现一次人
- [ ] 地点数与时长按版本
- [ ] 至少有一处不顺利
- [ ] 结尾回到一个具体的东西，不是空镜淡出
- [ ] 地名、路线名、日期与实际一致

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 像风景集 | 全是空镜 | 每 3–4 镜补一个人，剪进同行者的反应 |
| 没人看完 | 开头是缓慢空镜或片名 | 标志镜头开场，3 秒内进入 |
| 地点分不清 | 没有地点标签 | 每处第一镜加地名；长版加地图 |
| 音乐像广告 | 纯音乐铺满 | 留现场声 |
| 字幕地名和地图对不上 | 用了民宿老板说的俗称 | 以地图正式名称为准，俗称放括号 |
| 同行的人不想出镜 | 出发前没问 | 出发前问清，不出镜的只拍背影和手 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；地名用"某海边小城"代替。

- 需求："和我妈去海边玩了三天，想剪一条 1 分钟的。"
- 落值：60 秒竖版；按天排；变化是"出发前怕和妈妈吵一路，最后是她叫我起来看日出"；不顺利的一处：第二天下雨没看成日出。
- 一句话：关掉音乐，也看得懂这是一趟"和妈妈和好"的旅行。

素材日志（S1 的产物，节选）：

| 素材 | 地点 | 日期 | 画面里有谁 | 标签 |
|---|---|---|---|---|
| 012 | 小城火车站出口 | 第 1 天 | 妈妈背影 | 到达 |
| 047 | 渔港码头 | 第 2 天 | 没有人 | 空镜、下雨 |
| 063 | 民宿房间 | 第 2 天 | 妈妈看窗外的雨 | 有人、不顺 |
| 091 | 东边礁石 | 第 3 天 5:20 | 妈妈指着天边 | 最好的时刻 |

结构落地：0–3 秒礁石上的日出 + 标题；3–15 秒火车站出口、第一条街；15–39 秒渔港、海鲜市场、雨中的民宿，每处广、中、细节各一个；39–50 秒妈妈叫醒她、两人走到礁石，放慢；50–58 秒收行李、回程车窗；58–60 秒字幕"她早就醒了，在等我"。

最容易错的一处：只剪了海景和日出。每 3–4 个镜头要有一次妈妈，这条片讲的是她。
