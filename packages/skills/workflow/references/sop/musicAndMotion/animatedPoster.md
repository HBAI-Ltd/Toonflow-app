# 动态海报包装

**把一张海报动起来**：3–5 秒，一个动作，一个循环点。它只有一帧的信息量，加一点点运动。判据：暂停任意一帧都像一张能直接发出去的海报；播完一遍，说得出主标题、时间、下一步。

## 一、适用 / 不适用

- 适用：活动预告、新品上线、开票与开播提醒、朋友圈与开屏单条动图、信息流首帧动效、一张主视觉的多比例派生。
- 不适用：长期品牌片头 → `titleSequence.md`；需要叙事 → `trailer.md`；素材踩点 → `beatSyncedMontage.md`。
- **底线：没有一张立得住的主视觉，就别做动态**——动的只会是废话。

## 二、开工必问

一次一个。

1. **最终停在哪一帧？主视觉是哪一张？**——定格帧就是封面，先定它。
2. 要哪几种比例（竖版、方版、横版）？——各自重排，不直接裁切。
3. 文案定稿了吗？主标题、时间、地点、下一步四样齐吗？
4. 要不要声音？——默认同时出无声版与有声版。

"你看着办"就落：5 秒、竖版、一个动作、无声版与有声版各一条，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 3–5 秒（基准 5 秒） | 超过 10 秒注意力明显下降 |
| 比例 | 竖、方、横三套，各自重排 | |
| 安全区 | 关键信息避开上下各 15% | 避免边缘信息被压住 |
| 声音 | 音效 ≤ 3 秒；循环无尾音；另出无声版 | |
| 真实性 | 产品图用真实去背图（颜色、logo、参数与实物一致）；时间地点与文案一字不差 | |

## 四、结构

5 秒基准：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 触发 | 0–0.75 秒 | 0–15% | 一个动作或一次曝光，把视线拉住 |
| 信息建立 | 0.75–3 秒 | 15–60% | 主视觉展开，标题与关键信息落位 |
| 定格 | 3–4.25 秒 | 60–85% | 完全清晰的一帧，停住至少 0.5 秒 |
| 循环收 | 4.25–5 秒 | 85–100% | 回到首帧状态，接得上循环，不闪 |

3 秒版同比例缩，定格仍不少于 0.5 秒。

四条硬约束：只做一个动作（缩放、位移、旋转同时上像模板）；动效从中心或主体起；循环点无跳帧；定格帧就是封面首帧——首帧是黑屏等于白做。

## 五、资产清单

| 资产 | 要不要 | 说明 |
|---|---|---|
| 文案层级表 | 必须 | 主标题、副标题、时间、地点、下一步，五级以内 |
| 字体 | 必须 | 一套字族 |
| 色板 | 必须 | 主色、底色、强调色三个值 |
| logo | 有就要 | 矢量 + 单色版 |
| 产品图 | 电商要 | 真实去背图；颜色以实物为准 |
| 安全区模板 | 必须 | 每种比例一张 |
| 音效 | 可选 | 单独音频 |

**标题、时间、价格、二维码一律后期上版**，不进生成。生成只做背景纹理与光效（纸纹、金属拉丝、光斑），一条一个元素，不生成"成品海报"。

## 八、验收清单

- [ ] 暂停任意一帧都像一张能发的海报
- [ ] 3–5 秒内说完主标题、时间、下一步
- [ ] 只做了一个动作
- [ ] 循环首尾接得上，无跳帧、无闪白
- [ ] 各比例重排未缩放；关键信息在安全区内
- [ ] 产品图、价格、时间、地点与实物和定稿一致

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 像 PPT 动画 | 元素多、动作多 | 删到一个动作，其余静态 |
| 循环时闪一下 | 首尾状态不一致 | 首帧状态做尾帧，或加 2 帧过渡 |
| 封面是黑屏 | 定格帧没放首帧 | 首帧就是定格帧 |
| 字被界面盖住 | 没按安全区排 | 用模板重排 |
| 文案过期 | 没锁文案版本 | 交付前对一遍最终文案 |
| 静帧单独看不成立 | 先做动效后做版式 | 先把定格帧做成一张能发的海报，再加动作 |
| 时间写成"本周六" | 文案没写具体日期 | 写具体日期与时间 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："书店办读书会，要一张能动的海报发朋友圈。"
- 落值：5 秒循环；竖版 + 方版；无声版与有声版（一声翻书声）；文案已定。

信息层级表（S1 的产物）：

| 级 | 内容 |
|---|---|
| 主标题 | 夜读会 · 第 12 期 |
| 副标题 | 一起读完一本短篇 |
| 时间 | 12 月 14 日 19:30 |
| 地点 | 某书店二楼 |
| 下一步 | 扫码报名 |

动作脚本：只有一个动作——画面中央一盏台灯从暗到亮。0–0.75 秒灯丝亮起；0.75–3 秒光铺开，标题与时间落位；3–4.25 秒定格；4.25–5 秒灯光回到首帧的亮度，接上循环。

背景纸纹由生成完成，标题、时间、地点、二维码全部后期上版。

最容易错的一处：台灯亮的同时让文字也从四周飞进来。只做一个动作，文字跟着光出现就够了。
