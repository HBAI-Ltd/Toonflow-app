# 预告片

判据两条：**看完能复述"要发生什么事"，但说不出"结果是什么"。** 说了结果是剧透片，说不出要发生什么是氛围片。本类目只有一个动作：控制信息——给什么、藏什么、误导什么，先定死，再剪。

## 一、适用 / 不适用

- 适用：正片、剧集、短剧、活动、课程、游戏的上线预告；先导片、正式预告、社媒短版。长版 90–150 秒，短版 15–60 秒。
- 不适用：正片本身 → `shortDrama/`、`promotionalVideos/`；幕后花絮 → `documentariesAndEvents/processDocumentary.md`；纯素材踩点 → `beatSyncedMontage.md`；赛事前瞻 → `sportsAndEvents/eventPreview.md`；游戏宣传片 → `gamingAndAnime/gamePromo.md`。
- **三幕是所有版本的骨架**，短版也照三幕压：冷开场给氛围不给事件，升级把问题越问越具体，静默后落片名与日期。

## 二、开工必问

一次一个。第 2 题比第 1 题重要——预告片卖的是问题，不是答案。

1. 观众看完必须知道哪三件事？——写成三句。
2. **哪一件事绝对不能给**：结局、凶手、反转，还是那个人是谁？
3. 正片素材量够不够剪到 90 秒？——正片是本项目生成的，就从已采用片段里挑。
4. 片名和上线日期定了吗？

答不上来落保守值：120 秒长版 + 30 秒短版、只给三件事、结局与反转一律不给，说明可推翻。

## 三、规格

| 项 | 长版（正式预告） | 短版（先导 / 短视频） |
|---|---|---|
| 时长 | 90–150 秒 | 15–60 秒 |
| 旁白 | 3–6 句短陈述句，落在镜头之间 | 0–2 句，能不用就不用 |
| 标题卡 | 出现 1 次，前面留一拍静默 | 出现 1 次 |
| 文字卡 | 3–4 个词，停留 < 1 秒 | 3–4 个词，停留 < 0.5 秒 |

## 四、结构

长版 120 秒基准：

| 段落 | 幕 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|---|
| 冷开场 | 一 | 0–36 秒 | 0–30% | 宽景、慢切，交代世界与主角；给氛围不给事件 |
| 升级 | 二 | 36–90 秒 | 30–75% | 冲突清楚，剪切加快；信息一层层加，问题越问越具体 |
| 静默 | 三 | 90–102 秒 | 75–85% | 停一拍：音乐断、画面定 |
| 标题卡 | 三 | 102–108 秒 | 85–90% | 最响的一击上落片名，字要停得住 |
| 收尾 | 三 | 108–120 秒 | 90–100% | 一行日期或一个收尾镜头，然后黑 |

短版 30 秒：冷开场 0–6、升级 6–18、静默 18–21、标题卡 21–24、收尾 24–30 秒。60 秒版秒数 × 2；15 秒版删静默，按 0–3 / 3–9 / 9–11 / 11–15 秒排。

三条硬约束：每一幕用一句话写意图，写在分镜表最上面；节奏跟着音乐走——先定音乐，把三幕转折钉在音乐的起势与爆发上；静默那一拍必须留。

## 五、资产清单

| 资产 | 要不要 | 合格标准 |
|---|---|---|
| 正片素材 | 必须 | 分两堆："可以给的"与"绝对不能给的"，物理分开两个文件夹 |
| 片名标准字 | 必须 | 矢量，带安全区；后期做，不交给模型画 |
| 上线信息 | 必须 | 日期与片名按定稿写法 |
| 旁白 | 有就用 | 3–6 句，提前写好 |
| 音乐 | 必须 | 先选，标出起势、爆发、静默段的时间点 |
| 角色资产 | 补镜时才要 | 沿用正片的角色板，不另做 |

镜头多数来自正片；生成只补"正片里没有的那一个"，并沿用正片的画风文字与资产。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 信息红线表 + 三幕意图 | 规格 + 红线表 |
| S1 | 先定音乐，再排镜头；每个切点标落在哪一拍 | 音乐结构表 + 镜头表 |
| S2 | 正片素材分两堆物理隔离 | 素材表 |
| S3 | 片名标准字、音乐结构表到位 | 图形与音乐 |
| S4 | 补镜提示词（可空） | 补镜清单 |
| S5 | 按曲剪三幕 | 粗剪 |
| S6 | 旁白、音效、标题卡 | 混音版 |
| S7 | 长版 + 竖版 + 短版；片名与日期逐字校 | 三条成片 |

## 八、验收清单

- [ ] 长版 90–150 秒，短版 15–60 秒
- [ ] 三幕齐全，每幕有一句意图
- [ ] 结局、真凶、反转一个都没给
- [ ] 旁白不超过 6 句，没有一句在解释画面
- [ ] 标题卡落在最响处，前面有一拍静默，停留 ≥ 1 秒
- [ ] 主要角色跨镜头是同一个人
- [ ] 竖版是重剪的，不是裁的
- [ ] 片名与日期逐字校对

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 把结局剪进去了 | 素材没隔离 | 建"不能给的"文件夹，剪辑时看不到 |
| 剪完配不上音乐 | 先剪画面后配乐 | 先定曲，把三幕钉在起势与爆发上 |
| 越剪越长 | 重复镜头太多 | 砍第一幕与升级段的重复镜头 |
| 只有氛围，说不出要发生什么 | 升级段没有具体冲突 | 升级段给三个指向一个人或一个决定的冲突 |
| 预告里的台词正片里没有 | 为预告另写了台词 | 预告只用正片里有的台词，补镜不配新台词 |
| 竖版标题卡被裁 | 横版标题直接缩 | 竖版单独排标题卡 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我们那部 AI 漫剧第一季做完了，要一条上线预告。"
- 落值：正片是本项目已采用的片段；120 秒长版 + 30 秒短版；上线日期已定。
- 信息红线表（S0 的产物）：

| 给 | 藏 | 误导 |
|---|---|---|
| 她能听见物件的最后一句话 | 代价是忘记记忆（只给一个她叫不出熟人名字的镜头） | 让人以为掌柜是反派 |
| 当铺要被抵给钱庄 | 钱庄少东家也有一把同样的铜锁 | — |

三幕意图：第一幕"让人看见这家当铺和她的手"；第二幕"每次用能力，她都丢掉一点东西"；第三幕"她还要不要用？"

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–36 秒 | 冷开场 | 当铺全景、她摸铜锁、那句"别开门" |
| 36–90 秒 | 升级 | 揭穿假货、地契、她认错人，剪切越来越快 |
| 90–102 秒 | 静默 | 音乐断，她看着自己的手 |
| 102–108 秒 | 标题卡 | 最响的一击落片名 |
| 108–120 秒 | 收尾 | 上线日期 + 平台，然后黑 |

最容易错的一处：把少东家拿出铜锁那一镜剪进升级段——那是第一季的反转，属于"绝对不能给"。
