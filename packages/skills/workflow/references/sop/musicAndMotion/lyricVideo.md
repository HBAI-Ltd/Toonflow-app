# 歌词版MV

画面主体是**文字本身**：没有演员、没有场景，字号、字重、出现方式就是景别和运镜。判据：随便暂停一帧，字看得清、词对得上、没有越界。

## 一、适用 / 不适用

- 适用：歌曲官方歌词版；发片前的副歌切片（15–30 秒）；竖版歌词卡；同一支歌的多比例派生。
- 不适用：有演员表演与叙事 → `musicVideo.md`；需要口型对位 → `musicVideo.md`；素材踩点 → `beatSyncedMontage.md`；品牌片头 → `titleSequence.md`。
- **底线：整段主歌一次铺满屏，不叫设计。** 字是主角，动是标点。

## 二、开工必问

一次一个。

1. 出整首还是一条副歌切片？——决定时长与排版工作量。
2. 要几种比例？——各自重排，不是缩放。
3. 要不要双语字幕？
4. 副歌最想砸出来的那两三个关键词是什么？——决定强调档位。

"你看着办"就落：一条 27 秒副歌切片、竖版、单语、整首另排，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 副歌切片 | 15–30 秒；100 BPM 下约 27 秒 | 一条只做一段副歌 |
| 整首 | 跟随歌曲，通常 3–5 分钟 | |
| 字高 | 单词模式占画面高 18–28%（竖版）、22–32%（横版）；行模式 6–8% / 7–9% | 同一片内不换档 |
| 行宽 | 竖版 ≤ 24 字；横版 ≤ 20 字 | |
| 入场提前量 | 硬切字 1–2 帧；滑入、缩放 3–5 帧 | 晚于演唱出现是业余感头号来源 |
| 对比度 | 文字与背景 ≥ 4.5:1；压素材时 ≥ 7:1 | 不够就加 20–30% 黑底或投影 |
| 安全区 | 竖版文字落在横向 8–88%、纵向 15–75%；横版边距 5%；方版 6% | 避免边缘文字被压住 |
| 歌词与版式 | 歌词一字不改；标点、大小写、重复段完整保留 | |

## 四、结构

副歌切片 27 秒基准（100 BPM、11 小节）：

| 段落 | 时长 | 占比 | 文字要做什么 |
|---|---|---|---|
| 歌名按住 | 0–2.4 秒 | 0–9% | 歌名与演唱者，小字，停住 |
| 主歌逐句 | 2.4–12 秒 | 9–44.4% | 一句一行，逐句出现；字号稳定 |
| 副歌逐词 | 12–21.6 秒 | 44.4–80% | 关键词放大到 1.6–2 倍，允许换色、反白、砸下 |
| 尾句停住 | 21.6–27 秒 | 80–100% | 最后一行停满 1.5 秒，在最后一拍收 |

整首按歌曲段落：前奏（歌名小字停住）→ 主歌（逐句）→ 副歌（关键词放大）→ 间奏（留白或只留一个词）→ 副歌二（比第一次更强）→ 尾奏（最后一行至少停 1.5 秒）。

三条硬约束：先对词，再设计（逐词时间码核准了才排版）；一屏一到两行；强调只有三档——0.5 倍（低语）、1 倍（正常）、1.6–2 倍（副歌重音）。

## 五、资产清单

| 资产 | 要不要 | 说明 |
|---|---|---|
| 歌词原文 | 必须 | 一字不改；标点、大小写、重复段都保留 |
| 逐词时间码表 | 必须 | 词、入点、出点、强调级别；按波形核 |
| 字体 | 必须 | 跨比例用同一字族 |
| 色板 | 必须 | 底色、字色、强调色三个值，不加第四个 |
| 背景素材 | 要就统一 | 纹样、粒子、空镜；同一素材不许两套调色 |
| 封面首帧 | 必须 | 首帧就是封面 |

**字不进模型**：歌名、歌词、角标一律后期上版。生成只做背景质感（颗粒、纸纹、光斑、空镜），一条一个元素，循环段单独做。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定时长、比例与单双语 | 规格 |
| S1 | 歌词时间码表 + 段落表 + 强调分级 | 三张表 |
| S2 | 字体、色板、背景素材、封面盘点 | 素材表 |

| S7 | 各比例分别验收；出封面 | 交付包 |

## 八、验收清单

- [ ] 任意暂停一帧，字看得清、词对得上、没越安全区
- [ ] 切片 15–30 秒，整首 3–5 分钟
- [ ] 对比度达标，不够已加底衬
- [ ] 每个文字入场不晚于演唱起音
- [ ] 一屏不超过两行，行宽合适
- [ ] 歌词一字未改
- [ ] 各比例各自重排，没有缩放

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 字比声音慢半拍 | 时间码没校准 | 按波形逐词校，入场提前 1–5 帧 |
| 一行读不完 | 整句上屏 | 拆两行，断在标点后、连词前 |
| 快歌满屏单词 | 语速每秒超 3 词还用单词模式 | 改整行卡拉 OK，行内高亮当前词 |
| 副歌不炸 | 全片同一字号与动效 | 关键词放大，加一次反色或砸下 |
| 细字压纹样看不清 | 字太细、背景太花 | 换粗字体，加黑底 |
| 竖版字贴边被压 | 按横版安全区排 | 竖版重排 |
| 双语字幕挤成四行 | 中英各两行 | 中文一行、英文一行，超宽就拆屏 |
| 背景素材比字还抢眼 | 生成的背景太花 | 背景只留一层质感，压暗 20–30% |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；歌词是示意。

- 需求："我的新歌要发了，先做一条副歌的歌词版。"
- 落值：27 秒副歌切片；竖版；单语。

逐词时间码表（S1 的产物，副歌段节选）：

| 词 | 入点 | 出点 | 强调 |
|---|---|---|---|
| 我 | 12.00 | 12.40 | 1 倍 |
| 不 | 12.40 | 12.75 | 1 倍 |
| 回 | 12.75 | 13.60 | 1.8 倍，反白 |
| 头 | 13.60 | 14.20 | 1.8 倍，反白 |
| 了 | 14.20 | 14.90 | 0.5 倍 |

结构落地：0–2.4 秒歌名与演唱者小字停住；2.4–12 秒主歌一句一行；12–21.6 秒副歌逐词，"回头"两字放大砸下；21.6–27 秒最后一行停满 1.5 秒。每个词比演唱起音提前 2 帧出现。

背景素材：一层旧纸纹理加缓慢飘动的光斑，生成一条 5 秒循环，压暗 25%。

最容易错的一处：时间码用自动转写直接上。自动转写常晚半拍，要按波形逐词校。
