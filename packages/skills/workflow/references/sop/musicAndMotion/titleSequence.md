# 片头包装

判据只有一条：**第二支片子拿去直接套，不用改一个像素。** 交付的是可复用资产：片头、logo 演绎、尾标、转场、角标。一次做好，后面每条片子都省一遍。

## 一、适用 / 不适用

- 适用：品牌、栏目、账号、剧集的固定开场与收尾。
- 不适用：一次性活动开场 → `documentariesAndEvents/eventOpening.md`；预告 → `trailer.md`；整片画风（在流程第二步定）；动态海报 → `animatedPoster.md`。
- **一句话判据：换一支片子还能直接用吗？** 不能，就是在做作品，不是做资产。

## 二、开工必问

一次一个。

1. **有品牌规范吗？** logo 矢量、字体、色值、安全边距。——没有就先做一页"最小规范"（logo 最小尺寸、安全边距、主色三个值）。
2. 用在哪几处：片头、片尾、转场、角标，还是都要？
3. 要不要声音标识？多长？
4. 要几种比例？有没有超宽？
5. 谁能用、怎么用：要不要一份使用说明？

答不上来落保守值：片头 4 秒、尾标三档、横竖方三种比例、声音标识 ≤ 3 秒，说明可推翻。

## 三、规格

| 件 | 时长 | 用在哪 | 怎么做 |
|---|---|---|---|
| 片头 | 4 秒 | 常规栏目、账号开场 | 材质底可生成，logo 矢量合成 |
| 片头·形象片 | 8 秒 | 品牌形象片、发布会 | 上限 8 秒，再长观众就跳 |
| 尾标·短版 | 1.5 秒 | 30 秒以内的社媒物料 | 短于生成下限，只用动效与矢量合成 |
| 尾标·标准版 | 3 秒 | 超过 30 秒的视频 | 同上 |
| 尾标·电影感版 | 5 秒 | 形象片、叙事内容、纪录片 | 材质可生成，logo 矢量合成 |

| 项 | 出发值 | 备注 |
|---|---|---|
| 比例 | 横、竖、方三套各自重排 | 不裁边 |
| 安全区 | 四边留 ≥ 5%，避开底部信息栏 | |
| 声音标识 | ≤ 3 秒，单独一条音频 | 不与其他声音混 |

## 四、结构

片头：

| 段落 | 占比 | 4 秒 | 8 秒 | 这一段要完成什么 |
|---|---|---|---|---|
| 触发 | 0–10% | 0–0.4 秒 | 0–0.8 秒 | 一个动作或一个声音抓注意力，不是先出 logo |
| 建立 | 10–60% | 0.4–2.4 秒 | 0.8–4.8 秒 | 图形从中心展开，带出品牌色与字体 |
| 定格 | 60–85% | 2.4–3.4 秒 | 4.8–6.8 秒 | logo 完整出现，停住，让人看清 |
| 收 | 85–100% | 3.4–4 秒 | 6.8–8 秒 | 留出与正片叠化的尾巴，不硬切黑 |

尾标：出现 0–20%（logo 从品牌色或主视觉里浮现）→ 定格 20–80%（完全清晰，停够时间）→ 叠化 80–100%（与正片叠化，不留硬边）；1.5 / 3 / 5 秒三档按同一占比。

四条硬约束：动画从中心起；声音标识与画面同帧；品牌专属转场一条片子里用一次，不反复叠；三档尾标一次做齐。

## 五、资产清单

| 资产 | 要不要 | 合格标准 |
|---|---|---|
| 品牌规范 | 必须 | logo 矢量（含单色版）、主辅色值、字体、最小尺寸与安全边距 |
| 声音标识 | 必须 | ≤ 3 秒，单独音频 |
| 模板工程 | 必须 | 可改字、可换色，交给客户也能改 |
| 尺寸输出清单 | 必须 | 每个比例的文件名、时长、格式 |
| 使用说明 | 必须 | 谁能用、怎么用、不能怎么改（拉伸、改色、加阴影） |

片头基本不靠生成，靠动效。生成只做材质底（金属、纸、玻璃）与背景氛围，**不带任何文字或标识**——模型画的 logo 必错，最终 logo 一律矢量合成。

## 八、验收清单

- [ ] 片头 4 秒（形象片 8 秒），不超过 8 秒
- [ ] 尾标三档都在
- [ ] 三种比例单独排过版，logo 与字没被切
- [ ] logo 没被拉伸、改色、加阴影，四边安全距 ≥ 5%
- [ ] 声音标识与画面同帧
- [ ] 透明底版叠在任何底色上都不脏边
- [ ] 生成的材质片不带文字与标识；短尾标没有走生成
- [ ] 附使用说明

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| logo 被拉伸变形 | 没锁比例 | 锁比例，按安全区缩放 |
| 动画抢过品牌本身 | 动作太多 | 减到 1–2 个动作，让 logo 停够时间 |
| 只有一种比例 | 图省事 | 三种比例一次做齐 |
| 声音比画面晚 | 没对帧 | 先定声音，再定画面收尾 |
| 每支片子都要重做 | 没做模板 | 做成模板工程加使用说明 |
| 角标和正片字幕打架 | 角标位置没避开字幕区 | 角标放在右上角，避开底部字幕与平台界面区 |
| 换了一首配乐后声音标识被盖住 | 声音标识和配乐混在一条轨里 | 声音标识单独一轨，正片配乐在片头结束后再进 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我们做美食账号，想要一个每期都能用的片头。"
- 落值：品牌规范：主色橙、辅色深灰；片头 4 秒 + 尾标三档；声音标识是 2.5 秒的下锅"滋啦"声；横、竖、方三种比例。

逐帧表（S1 的产物，4 秒 = 120 帧，按 30 帧每秒）：

| 帧 | 段落 | 发生什么 |
|---|---|---|
| 0–12 | 触发 | 声音标识第 0 帧起，画面中心一点火苗亮起 |
| 12–72 | 建立 | 火苗从中心展开成一个橙色圆，栏目名逐字落位 |
| 72–102 | 定格 | logo 完整停住 |
| 102–120 | 收 | 圆缩小到右上角变成角标，与正片叠化 |

生成只做一条材质底：铸铁锅面的纹理特写，暖光从左上方来，画面里没有任何文字和标识；logo、栏目名、角标都是矢量合成。

最容易错的一处：让模型直接生成"带 logo 的片头"。字和 logo 一定会画错，只让模型出材质。
