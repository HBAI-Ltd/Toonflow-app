# 歌曲MV

一首完整的歌配一套画面。判据：**关掉画面只听歌，它还是完整的歌；关掉声音只看画面，它还是一支片子。** 只有一边成立，是配图或配乐。

## 一、适用 / 不适用

- 适用：3–5 分钟全曲 MV；表演线与叙事线并行，或只取一条；另出 30 秒副歌切片。
- 不适用：30–90 秒踩点快剪 → `beatSyncedMontage.md`；歌词字幕与文字排版为主 → `lyricVideo.md`；舞台实录 → 走现场多机位剪辑。
- **一句话判据：画面是不是跟着主歌、副歌、间奏的段落结构走？**

## 二、开工必问

一次一个。

1. 歌手出不出镜？有没有必须保持的固定形象？——决定是否做歌手板。
2. 讲一个故事，还是以表演和氛围为主？两条线比例多少？
3. 有几个场景、几套造型？
4. 全片贯穿的唯一视觉符号是什么？

答不上来落保守值：全曲长版 + 30 秒副歌切片、一个视觉符号；讲故事还是以表演为主，给两版让他挑，说明可推翻。

## 三、规格

| 项 | 长版（全曲） | 短版（副歌切片） |
|---|---|---|
| 时长 | 跟随歌曲，通常 3–5 分钟 | 30 秒 |
| 单镜时长 | 表演镜 8–15 秒，叙事镜 4–8 秒 | 4–8 秒 |
| 口型镜 | 一句一镜，按歌词分句切 | 只取副歌最强一句 |
| 歌词字幕 | 后期加，位置全片固定 | 同左 |
| 条数 | 按所选模型单次上限切；切点落在乐句上 | 同左 |

## 四、结构

长版跟歌走，六段对六个歌段；240 秒基准，按歌曲实际长度同比换算：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 前奏 | 0–12 秒 | 0–5% | 建立世界，埋一个视觉符号（只给一个） |
| 主歌一 | 12–60 秒 | 5–25% | 人物与处境，叙事开始推进 |
| 副歌一 | 60–108 秒 | 25–45% | 情绪爆点，全片第一个记忆画面 |
| 主歌二 / 间奏 | 108–156 秒 | 45–65% | 转折、留白或换场景；信息加一层 |
| 副歌二 | 156–204 秒 | 65–85% | 比第一次更强：景别、光、动作、规模至少升一个 |
| 尾奏 | 204–240 秒 | 85–100% | 回到开头的符号，收 |

短版 30 秒四段：前奏 0–3（一个符号或一个字幕）、主歌 3–9（交代人和地方）、副歌 9–24（最强一句，重复两次，画面升级一次）、尾奏 24–30 秒（定格在符号上，不淡出）。

三条硬约束：副歌至少一次画面升级；同一个符号出现至少两次（一次是装饰，两次才是结构）；表演线与叙事线的比例先定死，写进分镜表第一行。

## 五、资产清单

| 资产 | 要不要 | 做板 | 合格标准 |
|---|---|---|---|
| 歌手 | 出镜就要 | 是 | 一套服装一块板；妆容单独写一句 |
| 场景 | 必须 | 是 | 3–5 处，与情绪段落对应，不按"好看"堆 |
| 符号道具 | 必须 | 是 | 唯一一件，贯穿全片，跨场同形同色 |
| 乐队 / 舞者 | 按需 | 是 | 同框的人一眼分得开 |
| 歌词文本 | 必须 | 否 | 原文，不翻译、不改写、不改标点 |

歌手脸一漂，整支片就散；符号每场长得不一样，结构就没了。歌词、歌名、字幕一律后期上，不进生成。

本类目用不上：脚本与口播。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定表演与叙事比例、时长与版本 | 规格表 |
| S1 | 歌段表：时间码、情绪、表演 / 叙事归属、符号出现点 | 歌段表 |
| S2 | 歌手造型、符号道具优先，场景其次 | 资产表 + 服装表 |
| S3 | 歌手板 + 符号板 + 场景板 | 已采用资产 |
| S4 | 一镜一句词的提示词；口型镜与叙事镜分开 | 分镜提示词 |
| S5 | 表演线先做（口型要对），叙事线补齐；同一造型集中做完 | 已采用片段 |
| S6 | 按歌对位、歌词字幕 | 成片 |
| S7 | 长版 + 副歌切片 + 竖版验收 | 交付包 |

## 八、验收清单

- [ ] 长版六个画面段与六个歌段对得上，每段第一个切点落在该歌段第一拍上
- [ ] 短版 30 秒四段，副歌占 15 秒
- [ ] 第二次副歌比第一次有明显升级
- [ ] 视觉符号至少出现两次，首尾呼应
- [ ] 有演唱的镜头口型对得上，没有人声的镜头嘴是闭的
- [ ] 一套衣服只出现在一个段落
- [ ] 歌词字幕一字未改，位置全片固定

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 画面和歌没关系，只是好看 | 没按歌段排 | 主歌给事，副歌给情绪，间奏给转折 |
| 副歌没爆点 | 两次副歌一样 | 景别、光、动作规模至少升一个 |
| 换装混乱 | 没有服装表 | 按段落定服装表 |
| 口型对不上 | 一镜塞了多句 | 按歌词分句，一句一镜；唱歌镜先录轨 |
| 竖版直接裁横版 | 没重新取景 | 竖版重新构图 |
| 符号道具每场长得不一样 | 每场重新描述 | 符号做一张板，每条只引用，不重写外观 |
| 生成的现场声和歌打架 | 成片没处理生成音频 | 成片以母带为主轨，生成的现场声只在间奏或留白处保留 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我自己写了首歌《末班车》，自己唱的，想做个 MV，我不出镜。"
- 落值：歌手不出镜，主角是一个原创角色；叙事七成、氛围三成；4 分钟全曲 + 30 秒副歌切片；视觉符号是"一张折过的车票"。
- 一句话：关掉声音，看得出是一个人终于下了车；关掉画面，歌还是完整的。

歌段表（S1 的产物）：

| 歌段 | 时间 | 情绪 | 归属 | 画面 |
|---|---|---|---|---|
| 前奏 | 0–12 秒 | 冷 | 氛围 | 雨夜公交站，一张折过的车票卡在广告牌缝里（符号第一次） |
| 主歌一 | 12–60 秒 | 压着 | 叙事 | 她每晚坐末班车，车票在手里折了又折 |
| 副歌一 | 60–108 秒 | 爆 | 叙事 | 车停在她该下的那站，她没下 |
| 主歌二 | 108–156 秒 | 转 | 叙事 | 终点站，司机熄火，车厢只剩她 |
| 副歌二 | 156–204 秒 | 更爆 | 叙事 | 天亮，她走下车，同一个车站——景别从近景升到大全景，光从夜到日 |
| 尾奏 | 204–240 秒 | 收 | 氛围 | 她把那张车票夹进书里（符号第二次） |

主角不唱，全片没有口型镜：每条提示词写"无台词，嘴唇全程闭合"；成片音轨用母带，歌词字幕后期上。

最容易错的一处：第二次副歌和第一次一样是车厢近景。副歌二至少升一样：景别、光、场景规模。
