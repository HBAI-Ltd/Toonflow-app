# 带货口播

卖的不是参数，是**"我信这个人"**：我为什么用它、我踩过什么坑、你现在该不该买。人是主角，产品是证据。判据：把产品换成同类竞品，这条脚本还成立吗？成立，写的是人；不成立，写的是参数，回 `productVideo.md`。

## 一、适用 / 不适用

- 适用：达人、店主、素人对镜头口播带货；短视频挂车、私域推荐；一个主讲人 + 1–3 件产品。
- 不适用：无真人的纯产品展示 → `productVideo.md`；以 3 秒拦截为唯一目标的投流素材 → `feedAds.md`；品牌定调 → `brandAds.md`；不带货的知识输出 → `educationalVideos/scienceExplainer.md`；从直播回放里剪 → `livestreamClips.md`。
- **前提：主讲人是真人还是数字人，先定死。** 数字人要在前 3 秒让人看出这是账号的固定形象，不能像某位真人，也不能声称"亲测""我用了三年"。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **谁在说？** "你本人出镜，还是账号的固定主播或数字人？"——决定做不做人物板，也决定"亲测"能不能说。
2. **说给谁听？** "经常加班到凌晨的运营，还是娃刚上幼儿园、手头紧的宝妈？"——身份越具体，前 5 秒越抓人。
3. **只推一件，还是几件里挑一件重点讲？**——超过 3 件必须拆条，一条只卖一个决定。
4. **有什么能当场验证的东西？** "温度计、秒表、称、检测报告——哪个能拍进画面？"——没有可验证证据，只能靠喊。
5. **落地动作是什么？** "小黄车、评论区暗号，还是直播间几点？"——只能有一个。

"你看着办"就落：本人出镜、单一身份标签、一件主推、一个可验证证据、一个购物车指令，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 30–90 秒，常见 30–60 秒 | 低于 20 秒讲不完 |
| 单条产品数 | 1 件（最多 3 件，须同一决策） | 多品拆条 |
| 台词密度 | 每秒 4–5 字 | 超过 6 字每秒，听不清也看不过来 |
| 字幕 | 全程硬字幕，一屏一行 | 静音可读 |

## 四、结构

60 秒基准，前 8 秒决定生死：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 认知冲突 | 0–3 秒 | 0–5% | 一句反常识的话或一个反常画面，破掉"广告"预期；不说"大家好、今天推荐" |
| 身份锚定 | 3–8 秒 | 5–13.3% | 点名一个人群标签（职业 + 状态 + 痛点细节），让目标人认领自己 |
| 痛点三连 | 8–25 秒 | 13.3–41.7% | "你有没有…→ 结果导致…→ 现在终于…"，用场景不用参数 |
| 可验证证据 | 25–52 秒 | 41.7–86.7% | 一个能当场看见的测试（读数、计时、称重、对比）；小而真胜过大而空 |
| 零思考指令 | 52–60 秒 | 86.7–100% | 一个动作 + 一个可见利益，路径唯一 |

30 秒版：0–2 / 2–5 / 5–12 / 12–26 / 26–30 秒。

变体策略：痛点、证据、指令三段不动，只换前两段做 3–5 个开头测人群。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 主讲人 | 必须 | 是（角色板） | 真人出镜时实拍；数字人做原创形象板，跨条复用 |
| 主讲人服装变体 | 换季、换人设才要 | 每变体一板 | 从上一状态改 |
| 产品 | 必须 | 是（2×2 道具板） | 证据镜头要看清结构 |
| 验证工具 | 有证据段就要 | 否 | **证据镜头必须实拍，读数不得由生成产出** |
| 生活场景 | 至少 1 个 | 建议 | 家、工位、车内；真实环境光 |

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定主讲人身份、时长与证据方式 | 规格 + 约束 |
| S1 | 逐字稿 → 时间码 → 开头变体 | 逐字稿 + 开头矩阵 |
| S2 | 主讲人、产品、验证工具、场景盘点 | 资产表 |
| S3 | 人物板 + 产品板 | 已采用资产 |
| S4 | 一句一镜，口型镜与产品镜分开 | 分镜提示词 |
| S5 | 前 8 秒先跑通再批量；证据镜实拍叠入 | 粗剪 |
| S6 | 配音、字幕、混音 | 混音版 |
| S7 | 按第八节验收；静音只看字幕测一遍 | 主版 + 开头变体 |

## 八、验收清单

- [ ] 前 3 秒没有"大家好、今天给大家推荐"
- [ ] 3–8 秒里有一个具体到职业和状态的人群标签
- [ ] 痛点段是场景，不是参数罗列
- [ ] 有一个能当场看见读数的证据镜头，且是实拍
- [ ] 结尾只有一个动作指令
- [ ] 全程同一张脸、同一件衣服、同一间屋
- [ ] 台词与口型对得上
- [ ] 静音看字幕能看懂在卖什么、卖给谁
- [ ] 字幕无错字（人名、品牌名、规格数字重点核）

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 前 3 秒就掉人 | 开头在自我介绍或报产品名 | 换成反常识断言或反常画面；把"我"换成"你" |
| 像念稿不像说话 | 逐字稿是书面语、句子太长 | 拆短句，加口语连接词，念一遍删拗口处 |
| 有流量没转化 | 证据太虚，或指令太绕 | 换可验证证据；指令压到一个动作 + 一个可见利益 |
| 一条塞三件货 | 想一次讲完 | 拆条，每条一个决策 |
| 读数镜被快切切没了 | 节奏太快 | 读数镜停留 ≥ 2 秒，字幕同步打出数字 |
| 口播只喊空话"最健康""零涂层最安全" | 没给可见证据 | 换成能当场验证、而且真的当场验证过的事实，比如把测试过程完整拍进画面 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我是店主，自己出镜卖一口不粘炒锅。"
- 落值：店主本人出镜（可以说亲测）；60 秒；一件主推；证据是"钢丝球擦 100 下后煎蛋不粘"；落地动作是购物车。
- 一句话：把锅换成别家的，这条脚本就不成立——因为证据是她当场擦的那 100 下。

逐字稿（节选，一句一镜）：

| 时间 | 镜号 | 台词 | 画面 |
|---|---|---|---|
| 0–3 秒 | 1 | "我拿钢丝球擦了这口锅一百下。" | 她举着钢丝球，锅在灶上 |
| 3–8 秒 | 2 | "一个人租房、下班只想十分钟搞定晚饭的，听我说完。" | 中景，她看镜头 |
| 8–25 秒 | 3–5 | "煎个蛋粘一锅底——洗锅洗到不想做饭——后来我换了这口。" | 三镜：粘锅的旧锅、水池里的碗、她把新锅放上灶 |
| 25–52 秒 | 6–9 | "擦完一百下，不放油，打个蛋……你看，自己滑出来了。" | 计数字幕从 1 跳到 100；蛋滑出锅的特写停留 2 秒 |
| 52–60 秒 | 10 | "左下角小黄车，今天下单送一把木铲。" | 她指向画面左下角 |

最容易错的一处：为了显得自然把擦锅的过程剪成三秒快切。观众要看见擦了很多下，计数字幕和停留时间都不能省。
