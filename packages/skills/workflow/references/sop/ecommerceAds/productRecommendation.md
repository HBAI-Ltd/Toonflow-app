# 种草视频

让人**收藏、去搜、进店看看**，不是当场成交。产品是"我最近在用的一件东西"，人是"一个真实用过的人"。素材常常很薄——几张商品图、一段自拍、一个使用场景也能做，一条只讲一个变化。

## 一、适用 / 不适用

- 适用：护肤、家居、穿搭、收纳、办公小物、工具清洁类的分享内容。
- 不适用：主讲人对镜头逐条说服、要当场转化 → `salesPitch.md`；无人讲解的纯产品展示 → `productVideo.md`；投放素材 → `feedAds.md`；品牌定调 → `brandAds.md`；开箱过程为主 → `foodAndLifestyle/productUnboxing.md`。
- **一句话判据：像"朋友在说他自己用过"，还是像"详情页在念"？** 像详情页，回 S1 重写，不靠加转场救。

**两种方向**：分享感（先说自己遇到的问题，适合护肤、家居、穿搭、收纳）；卖点感（先给明确结果，适合工具、清洁、功能型商品）。种草绝大多数走分享感。

## 二、开工必问

一次一个；某一项连答两次"都行"，按保守值办：20 秒、分享感、一条只讲一个变化，说明可推翻。

1. 这条讲的是**问题**、**变化**，还是**使用感**？——三选一；三个都要，就是三条视频。
2. 谁用过之后会觉得"这就是我"？——人群越具体，第一屏越抓人。
3. 有没有一个**能当场看见的变化**（不是形容词）？——没有就只能做展示，不能做种草。
4. 看完希望他做什么：收藏、搜某个词，还是进店？——只能有一个。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 15–25 秒 | 超过 30 秒要有更硬的信息 |
| 素材下限 | 6–8 张图就能做一条 | 主图 1 + 细节 2 + 场景 1–2 + 前后对比 1 + 收尾 1 |
| 节奏 | 重点画面留 2–3 秒 | 每秒都换图显得急，反而不真实 |
| 台词 | 每秒 4–5 字；20 秒版 80–100 字 | 一句一件事，留停顿 |
| 第一屏 | 单独设计 | 不是从片子里截的 |

先写脚本再选图：先把图堆进时间线再想文案，最后图很多但没有主线。顺序是**脚本 → 选 6–8 张图 → 排节奏**。

## 四、结构

20 秒基准：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 第一屏：问题或结果 | 0–2 秒 | 0–10% | 一眼看懂"这是在说我的麻烦"；不先放产品正面图 |
| 使用场景 | 2–8 秒 | 10–40% | 具体到时间、地点、身份（"晚上十点还在改方案的时候"） |
| 一个真实变化 | 8–16 秒 | 40–80% | 可验证的细节：收纳前后的桌面、续航到第几天、洗完有没有变形 |
| 判断句 | 16–20 秒 | 80–100% | "适合谁 / 不适合谁" + 一个轻动作 |

15 秒版砍段不缩镜：0–2 / 2–6 / 6–12 / 12–15 秒，四段仍在。

三段式口播骨架：**问题**（我为什么会注意到它）→ **使用感**（它帮我解决了什么）→ **判断**（适不适合哪类人）。

三条硬约束：一条只讲一个变化；说"不适合谁"比说"适合谁"更可信；少用夸张判断，多写具体感受。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 产品图 | 6–8 张 | 否（用真实图） | 包装上的字必须是真字 |
| 出镜人（手、半身、口播） | 0–1 | 建议 | 跨条复用同一张脸；只出手也统一指甲、袖口、肤色 |
| 生活场景 | 1–2 | 建议 | 书桌、厨房台面、通勤包；真实的乱度，不做样板间 |
| 对比素材 | 1 组 | 否 | 前后对比真实拍摄，**不生成** |
| 佐证素材 | 按需 | 否 | 成分表、检测报告、订单截图：实拍 |

生成的只能是氛围与场景，不能是证据；不生成带读数的画面（温度、重量、时长、百分比）。

| 阶段 | 本类目做什么 | 产出 |

| S0 | 定方向与时长 | 一页规格 |
| S1 | 三段式口播 + 逐句时间码 | 脚本 |

## 八、验收清单

- [ ] 第一屏就能看懂"这是在说我的麻烦"
- [ ] 一条主线，只讲一个能看见的变化
- [ ] 时长 15–25 秒；20 秒版台词 80–100 字；重点画面留 2–3 秒
- [ ] 说了"不适合谁"；台词是口语短句
- [ ] 商品与包装文字与真实一致
- [ ] 对比、读数、检测报告全部实拍

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 一眼就像广告，被划走 | 第一屏堆卖点、句子太完整 | 第一屏换成问题或结果；长句拆短 |
| 有播放没收藏 | 结尾没有能拿走的东西 | 补一句判断 + 一个搜索词 |
| 图堆到 8 张没有主线 | 先选图后写文案 | 回 S1 先写脚本，再按脚本选图 |
| 像在读详情页 | 文案照抄卖点 | 删掉"显著提升"这类词 |
| 产品颜色被改 | 为了好看调了本色 | 本色不动，只调环境光 |
| 判断句是"适合所有人" | 不敢劝退 | 必须写出一类不适合的人 |
| 前后对比用了商家图 | 自己没拍"之前" | 动手前先拍"之前"，对比只用自己拍的 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我买了个桌面理线盒，挺好用，想做条种草。"
- 落值：20 秒；分享感；讲一个变化：桌下乱线收干净了；看完希望他收藏。
- 一句话：像朋友在说"我那团线终于不拽我电脑了"。

三段式口播（约 90 字）：

| 时间 | 段落 | 口播 | 画面 |
|---|---|---|---|
| 0–2 秒 | 第一屏 | "我桌子底下这团线，上周把我电脑拽断电了。" | 桌脚下缠成一团的插线板和充电线 |
| 2–8 秒 | 使用场景 | "晚上十点改方案，脚一勾，插头就掉。" | 一只脚勾到电线，插头弹出 |
| 8–16 秒 | 一个变化 | "后来塞进这个盒子，插线板放里面，线从两头出来，桌下就剩一根。" | 同机位前后对比，自己拍的 |
| 16–20 秒 | 判断 | "插头多的可以试试，就一两个插头的不用买。" | 盒子全貌，手把它推回桌角 |

最容易错的一处：第一屏放产品正面图。第一屏是那团线——观众先认出自己的麻烦，才会看下去。
