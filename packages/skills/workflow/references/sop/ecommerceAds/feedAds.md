# 信息流广告

只有一个目标：**在手指划走之前让他停住，并且停住之后不觉得被骗。** 它是一条被投出去的测试单元，所以写法是模块化的：开头做 3–5 个变体去测，主体与行动号召不动。判据：这条素材能不能一天内裂变出 5 个开头版本？

## 一、适用 / 不适用

- 适用：以点击、下单、留资为目标的短视频转化素材；需要批量测款、快速迭代的多开头版本。
- 不适用：自然流量内容 → `salesPitch.md`；商详页常驻视频 → `productVideo.md`；不考核转化的品牌曝光 → `brandAds.md`。
- **前提：承接页（落地页、商详、直播间）与素材必须是同一件事。** 素材承诺 A、落地页卖 B，是最常见的浪费预算方式。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **考核什么动作？** "带货看下单，还是留资看表单？"——决定结尾是"下单"还是"点咨询"。
2. **这条打谁？** "刚被甲醛检测坑过的新业主，还是想给娃换学习桌的家长？"——一个素材只打一个人群。
3. **能给出什么即时利益？** "价格直降、赠品、免费测、暗号立减——哪个是真的？"——没有利益就写证据，不要编。
4. **有什么一秒看懂的视觉冲突？** "脏和净、前和后、慢和快——能拍到哪一组？"——前 0.5 秒靠它，不靠文案。
5. **一次出几版开头？**——默认要多版，问的是 3 版还是 5 版。

"你看着办"就落：带货看下单、单一人群、真实降价或赠品、一组前后对比、出 3 版开头，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 常用 15–30 秒；快转化 10–30 秒；单一爆点 4–10 秒 | 按卖点与对比复杂度选档 |
| 开头变体 | 3–5 个 | 每个开头换切入类型，不只换措辞 |
| 首帧 | 必须有主体、有对比、可读 | 首帧就是封面 |
| 字幕 | 全程硬字幕，关键词高亮；第 1 秒就要有字 | 静音场景占比高 |

## 四、结构

20 秒基准；其他时长按同一结构重排，不等比拉伸：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 动作爆点 | 0–0.5 秒 | 0–2.5% | 必须有位移或变化（砸入、快推、猛然抬头、液体飞溅）；静止起幅等于没开头 |
| 大字提问 | 0.5–1.5 秒 | 2.5–7.5% | 屏幕中央一行大字抛出核心疑问，关键词换色 |
| 痛点 + 解法 | 1.5–3 秒 | 7.5–15% | 一句点痛，一句引出"这个东西"；必须和卖点闭环 |
| 卖点展开 | 3–8 秒 | 15–40% | 只讲 1–2 个卖点，每个给一个可见证据 |
| 信任 / 对比 | 8–15 秒 | 40–75% | 前后对比、实测读数、场景复用；解决"是不是智商税" |
| 价格 / 促销 | 15–17.5 秒 | 75–87.5% | 具体数字 + 时限 + 条件，一句说完 |
| 行动号召 | 17.5–20 秒 | 87.5–100% | 一个动作 + 一个可见利益，画面同时有指向元素 |

**模块化**：前三段是可替换的开头模块，后四段是固定主体。一条主体 + 5 个开头 = 5 条素材。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 产品 | 必须 | 是（2×2 道具板） | 前后对比是同一件东西的两个状态，状态另立变体 |
| 使用前后状态 | 有对比段就要 | 各一版 | 必须可辨，且不能造假 |
| 出镜人 | 有口播段就要 | 建议 | 质感靠运镜与光，不靠换脸 |
| 场景 | 至少 1 个 | 建议 | 真实光，避免影棚感 |
| 证据道具 | 有实测段就要 | 否 | 读数镜头实拍，不生成 |
| 促销贴纸 / 角标 | 有促销段就要 | 图形资产 | 尺寸、位置、颜色固定，多版本复用；后期叠加 |

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 问考核指标、要来承接页；按第三节定时长与开头版本数 | 开工单（时长、开头版本数、字幕字号占比） |
| S1 | 开头矩阵 + 主体脚本 | 开头矩阵 + 脚本 |
| S2 | 产品与前后状态、出镜人、场景按开头需要盘点 | 资产表 |
| S3 | 产品板必做，其余按需 | 已采用资产 |
| S4 | 前 3 秒 0.5 秒粒度；主体一镜一信息 | 分镜提示词 |
| S5 | 开头 4 秒版横比 → 补主体 → 拼出各版 | 各版本粗剪 |
| S6 | 字幕、关键词换色、配音 | 混音版 |
| S7 | 静音测试 + 一臂距离小屏测试 + 第八节清单 | 各开头版本成片 |

## 八、验收清单

- [ ] 0–0.5 秒有位移或变化
- [ ] 1.5 秒前屏幕上有可读的大字
- [ ] 前 3 秒的承诺和产品真实卖点闭环
- [ ] 全片只有 1–2 个卖点
- [ ] 有一个能看见读数的实拍证据镜头
- [ ] 价格优惠是真数字 + 真时限 + 真条件
- [ ] 结尾只有一个动作，且与承接页一致
- [ ] 静音能看懂；手机拿远一臂，字还认得出
- [ ] 关键信息不压画面底部与右侧边缘

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 留存高、转化低 | 开头与卖点脱节，观众觉得被骗 | 第三段必须承接第二段，3 秒内说清"这个东西"是什么 |
| 前 3 秒就掉 | 开头是 logo、空镜、自我介绍 | 换动作爆点起幅 |
| 5 个版本都跑不动 | 5 个开头其实是同一个意思 | 换切入类型，不换措辞 |
| 素材一天就衰退 | 单版本硬投 | 按周补 3–5 个新开头，主体不动 |
| 承接页跳出高 | 素材与落地页不是一件事 | 素材与落地页同稿同图 |
| 对比镜两只鞋不是同一双 | 图省事 | 同一双鞋左右脚对比，同机位、同光 |
| 价格段观众不信 | 原价、时限写得虚 | 写"活动价 + 截止时间 + 条件"，有实据才写 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："鞋子清洁泡沫，要投信息流，看下单。"
- 落值：带货看下单；20 秒主体；即时利益是"活动价 + 今晚 24 点截止"（真实）；视觉冲突是"一只脏鞋擦过、一只没擦"；出 3 版开头。
- 一句话：前 3 秒承诺"小白鞋发黄 30 秒能救"，后面的对比镜必须兑现它。

开头矩阵（主体 3–20 秒三版共用）：

| 版本 | 人群 | 冲突 | 第一帧 | 大字提问 |
|---|---|---|---|---|
| A | 学生 | 体育课前发现鞋发黄 | 泡沫"啪"地喷满一只脏鞋 | "小白鞋发黄，30 秒能救吗？" |
| B | 通勤族 | 周一早上鞋被踩脏 | 一只鞋擦过地铁台阶的泥水 | "早上 7 点鞋脏了怎么办？" |
| C | 家长 | 孩子的鞋一天一脏 | 小孩一脚踩进泥坑 | "孩子的鞋还要天天刷？" |

主体：3–8 秒免水洗、擦一下；8–15 秒同一双鞋左右脚对比（同机位）；15–17.5 秒"活动价 × 元，今晚 24 点截止"；17.5–20 秒"点下方链接"并出现箭头贴纸。

最容易错的一处：三个开头只换了措辞没换人群和第一帧，测出来没有差别。
