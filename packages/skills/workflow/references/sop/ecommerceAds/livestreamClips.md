# 直播切片

从**直播回放**里剪出能独立发布的短视频：一条只切一个完整段落（问题 → 反应 → 解法），拿自然流量、带动搜索、给直播间或商品页导流。主线是剪辑，生成只补空镜。

## 一、适用 / 不适用

- 适用：手上是带货直播回放，要切出能独立看的短视频。
- 不适用：自己出镜按脚本重讲 → `salesPitch.md`；商品细节展示 → `productVideo.md`；投流素材 → `feedAds.md`；讲课类直播回放 → `educationalVideos/lectureClips.md`。
- **一句话判据：剪完的这条，去掉主播名字还成不成立？** 成立，观众会收藏、会去搜；不成立，只是剪了一段"高能"。
- 本 skill 的边界：如果用户只要纯剪辑、完全不需要生成任何画面或包装，按 `sopRouting.md` 一说明边界，只做剪辑方案与字幕。

## 二、开工必问

按顺序，一次一个。

1. 这条切片给谁看：正在挑这类东西的人，还是路过刷到的人？——决定开头切在"问题句"还是"结论句"。
2. 原片里哪一段是完整的"问题 → 反应 → 解法"？——给时间码，不给"大约半小时那里"。
3. 看完希望他搜什么词？——标题与评论区关键词指向这个词，不是主播名字。
4. 挂不挂车、挂哪个？——挂车内容必须和切片讲的一致。

答不上来落保守值：45 秒、只切一段、不加解说，说明可推翻。

## 三、规格

| 类型 | 开头 | 中段 | 收尾 | 典型时长 |
|---|---|---|---|---|
| 问题型 | 问题句 | 判断与纠正 | 可执行结论 | 35–60 秒 |
| 对比型 | 两个选项并置 | 各给一个使用结果 | 一句"选哪个" | 40–60 秒 |
| 避坑型 | 常见错误做法 | 为什么错、代价 | 正确做法 | 20–45 秒 |

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 15–60 秒 | 信息必须闭环；超过 60 秒要靠完整案例 |
| 竖版 | 原片多为横屏，切竖版要重新构图 | 人脸与商品同时在框内 |
| 开头 | 从问题句中间切入，0–1.5 秒进正题 | 不剪"家人们""欢迎来到直播间" |
| 字幕 | 全程硬字幕，逐字对齐原声 | 去口水词可以，改语义不行 |

一条 45 秒切片，通常要从 20–40 分钟原片里删掉 95% 以上。判断标准只有一条：这段话离开直播场景还站得住吗？

## 四、结构

问题型 45 秒基准；对比型、避坑型换段名，占比不变：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 问题句直接进 | 0–1.5 秒 | 0–3.3% | 原话最锋利的那半句；不要开场白、封面卡 |
| 痛点具体化 | 1.5–8 秒 | 3.3–17.8% | 主播点出具体场景与代价，不是泛泛而谈 |
| 真实判断 / 纠正 | 8–25 秒 | 17.8–55.6% | 这一段是价值：他为什么这么判断、纠正了什么常见说法 |
| 可复用结论 | 25–40 秒 | 55.6–88.9% | 一句能拿走的话或一个可执行动作（"看水洗标上这一行"） |
| 收尾 + 搜索承接 | 40–45 秒 | 88.9–100% | 一句收束；标题与关键词指向用户会去搜的词 |

五条硬约束：一条只留一个闭环；不改原意；保留真实语气与停顿；不加伪造字幕，不改数字、价格、规格；收尾做一个"可带走的东西"，不做高能反转。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 直播回放原片 | 1 场或数段 | 否 | 保留原始文件与时间码 |
| 主播形象 | 沿用 | 否 | 不生成、不换脸、不换声 |
| 商品实物 | 按需 | 否 | 与链接一致；实物细节实拍 |
| 佐证素材 | 按需 | 否 | 检测报告、成分表、水洗标、价格签：实拍，不生成读数 |
| 字卡 / 花字 | 1 套 | 否 | 后期叠加；只用原话里的词 |

**本类目基本不做生成**：只在需要补一个空镜、一个示意底、一个转场时用；生成内容不得替换主播面部、商品实物与任何读数。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定切片类型与时长 | 一页规格 |
| S1 | 选段：5–8 个候选闭环，选 1 个 | 候选段清单（带时间码） |
| S2 | 盘点原片、商品链接、佐证素材 | 素材表 |
| S3 | 不做资产图；只做字卡模板与封面 | 字卡模板 + 封面 |
| S4 | 需要补空镜时写 1–2 条，否则跳过 | 补镜清单（可空） |
| S5 | 剪辑、竖版重构图、补镜叠入 | 剪好的母版 |
| S6 | 字幕逐字对齐、混音 | 字幕 + 混音 |
| S7 | 按第八节验收；把切片放回原段落核对原意 | 成片 |

## 八、验收清单

- [ ] 类型写明，段名与类型一致，时长 15–60 秒
- [ ] 0–1.5 秒直接进问题句
- [ ] 一条只有一个完整闭环
- [ ] 字幕逐字对齐原声；语义、数字、价格、规格未改；放回原段落意思不变
- [ ] 商品实物、检测报告、价格签全部实拍，无生成读数
- [ ] 挂车内容与切片一致
- [ ] 标题与关键词指向用户会去搜的词
- [ ] 生成只用于空镜、示意、转场，未替换主播面部

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 前 1.5 秒是"家人们" | 按直播开场剪 | 从问题句中间切入，封面卡与关注引导全删 |
| 有停留没收藏、像广告 | 只剪"最响的 30 秒"，或剪得太顺、字幕重写 | 补完整闭环；留一次停顿；字幕回到原话 |
| 意思被剪歪 | 把前后限定条件剪掉了 | 补一句限定条件，放回原段落自检 |
| 流量一次性 | 没有搜索承接 | 标题与关键词换成用户会搜的词 |
| 切片里的商品和挂车链接不是同一款 | 换了颜色或规格 | 一条切片对一个规格，换链接就重剪 |
| 去口水词把限定条件也删了 | 只看字数 | 删词后把切片放回原段落听一遍，意思不变才算 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我自己的直播间卖羊毛衫，2 小时回放想剪几条。"
- 落值：给正在挑羊毛衫的人看；问题型 45 秒；看完希望他搜"羊毛衫怎么洗"；挂当场讲的那款。
- 一句话：去掉主播名字，这条仍然是一条有用的"羊毛衫为什么会缩水"。

候选段清单（S1 的产物）：

| 候选 | 原片时间码 | 闭环 | 类型 | 选不选 |
|---|---|---|---|---|
| 1 | 00:42:10–00:43:05 | 为什么洗了会缩 → 是水温和甩干 → "看水洗标上画着手和盆的那个图标" | 问题型 | 选 |
| 2 | 01:05:30–01:06:40 | 60 支和 80 支怎么选 → 各给一个穿着结果 → "通勤选 60 支" | 对比型 | 备选，另剪一条 |
| 3 | 01:30:00–01:30:20 | "家人们三二一上链接" | 没有闭环 | 不选 |

候选 1 剪成：0–1.5 秒从"你这件为什么一洗就缩"中间切入；8–25 秒保留她拿起水洗标指给镜头看的那一下和一次口误；40–45 秒落在"看这个图标"；标题写"羊毛衫怎么洗不缩水"。

最容易错的一处：把她后面那句"我说的是这一款"剪掉，切片就成了断章取义。
