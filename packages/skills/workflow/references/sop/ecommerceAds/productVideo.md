# 商品视频

回答一个问题：**这东西长什么样、多大、什么材质、怎么用。** 不负责让人记住品牌，也不靠一个真人说服人买。判据很硬：看完能说出"多大、什么材质、和别家差在哪"。

## 一、适用 / 不适用

- 适用：平台商品主图视频、详情页视频、推荐流商品卡视频；展示外观、结构、材质、尺寸、配件、使用方式；一个 SKU，或主体不变的同款变体（换色、换尺码）。
- 不适用：靠真人对镜头建立信任 → `salesPitch.md`；以 3 秒拦截和转化为唯一目标的投流素材 → `feedAds.md`；品牌定调 → `brandAds.md`；纯操作演示、商品只是道具 → `educationalVideos/skillTutorial.md`。
- **一句话判据：静音看完，能不能说出"是什么、多大、什么材质"？**

## 二、开工必问

一次一个，每个给两个具体选项，已知的不问。

1. **观众看完要能说出哪三件事？** "比如容量 1.2L、内胆 316 不锈钢、能进洗碗机。"——决定段落配比；超过 5 条要砍。
2. **有实物可拍，还是只有图和参数？**——决定实拍还是生成，也决定参数敢不敢上屏。
3. **要做多长：15 秒短版、30 秒标准版，还是 60 秒详版？**——决定每个卖点给几镜。
4. **要不要一套素材出多尺寸（竖版、方版、横版）？**——决定构图留边。

"你看着办"就落：15–30 秒、三条卖点、有实物、出两种比例，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 15–90 秒，主体 15–45 秒 | 按卖点复杂程度选档 |
| 数量 | 单商品通常最多 5 条 | 前几条展示位最重要 |
| 卖点 | 3 条 | 一个卖点 1–2 镜 |
| 画质纪律 | 首帧不是全屏纯色；不闪屏；无大面积纯色边框；不拉伸变形；不完全无声 | |

## 四、结构

30 秒基准：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 定场全貌 | 0–2 秒 | 0–6.7% | 一眼看清是什么、多大；最像"实物在眼前"的角度 |
| 三个卖点 | 2–11 秒 | 6.7–36.7% | 每个卖点一组镜：全景给位置、特写给证据；按用户在乎程度排 |
| 尺寸规格 | 11–15.5 秒 | 36.7–51.7% | 给可比参照（手掌、A4 纸、常见同类物） |
| 材质细节 | 15.5–20 秒 | 51.7–66.7% | 表面处理、接缝、纹理、厚薄；近到能看清工艺 |
| 使用场景 | 20–26 秒 | 66.7–86.7% | 在真实环境里怎么被用；真实场景光 |
| 收口 | 26–30 秒 | 86.7–100% | 回全貌或定版图；补一句规格或包装内含，不喊口号 |

15 秒档先保定场与收口的绝对时长，其余等比压缩。

三条硬约束：每 2–3 秒换一次信息，停顿超过 4 秒观众判定"没新东西"；尺寸必须有参照物；产品颜色是本色，不是被场景光染过的颜色。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 产品 | 必须 | 是（2×2 道具板） | 决定全片"是不是同一个东西" |
| 产品变体 | 换色换尺码才要 | 每变体一板 | 新状态新名字 |
| 使用场景 | 有场景段就要 | 建议 | 一个场景一张 |
| 手模 | 握持、上身效果才要 | 只做手 | |
| 参照物 | 有尺寸段就要 | 否 | 用真实常见物，不造假比例 |
| 包装内含 | 有开箱段就要 | 建议 | 与实物清单逐项对齐 |

有实物时，材质与细节镜优先实拍；生成镜的产品外观必须引用同一张产品板。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 按第三节锁定时长、比例与数量；三条卖点必答 | 规格单 |
| S1 | 卖点表 + 镜头对应表 | 卖点镜头表 |
| S2 | 产品、变体、场景、参照物盘点 | 资产表 |
| S3 | 产品板先做先验收 | 已采用资产 |
| S4 | 一卖点一组镜，每组 1–2 镜 | 分镜提示词 |
| S5 | 材质测试镜 → 批量；实拍与生成拼接 | 粗剪 |
| S6 | 字幕、底噪、响度统一 | 混音版 |
| S7 | 按第八节验收，各比例分别导出 | 各版本成片 |

## 八、验收清单

- [ ] 三条卖点都能在画面里指出来，且与实物、参数一致
- [ ] 尺寸段有可比参照物，比例没被镜头拉歪
- [ ] 产品颜色与实物一致
- [ ] 首帧不是全屏纯色，全片无闪屏
- [ ] 比例与约定一致
- [ ] 静音看一遍仍能看懂"是什么、多大、什么材质"
- [ ] 包装内含与实物清单逐项对得上

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 像渲染图不像实物 | 写了"高级质感""影棚光"，没写材质响应 | 逐材质写表面处理与物理；加有理由的使用痕迹 |
| 尺寸说不清 | 没参照物，或参照物被放大 | 参照物同框、写死相对距离；必要时字幕标数字 |
| 几个镜头像不同产品 | 没做产品板，或每镜重写外观 | 做板；每镜只引参考，删掉外观长描写 |
| 卖点堆成参数表 | 按参数表顺序排 | 按在乎程度重排；参数进字幕不进旁白 |
| 首帧被拒 | 纯色起幅或 logo 首帧 | 首帧换成产品全貌，定版图放结尾 |
| 产品镜打了一圈轮廓光 | 按"高级感"拍 | 写真实场景光，轮廓光只在场景有依据时用 |
| 生成镜里产品比实物大一圈 | 没有参照物，或参照物没写距离 | 参照物与产品同框，写死相对距离与尺寸 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："给我们 500ml 保温杯做个商品卡视频。"
- 落值：30 秒、三条卖点、有实物；出竖版与方版。
- 一句话：静音看完能说出"单手开盖、6 小时后还有 60°C、杯身不留指纹"。

卖点镜头表（S1 的产物）：

| 卖点 | 证据镜头 | 参照物 | 时间 |
|---|---|---|---|
| 单手一键开盖 | 拇指按下，盖子弹开到 90° | 握杯的手 | 2–5 秒 |
| 6 小时后还有 60°C | 温度计插进杯口，读数停留 2 秒（实拍） | 墙上的钟显示 6 小时后 | 5–8 秒 |
| 杯身不留指纹 | 手握后松开，磨砂杯身无指印特写 | 旁边一只亮面杯留下指印 | 8–11 秒 |

其余段：11–15.5 秒放进通勤包侧袋、手掌并排给尺寸；15.5–20 秒杯口螺纹与磨砂纹理特写；20–26 秒早高峰地铁上单手开盖喝水；26–30 秒回全貌 + "500ml，附杯刷"。

使用场景那条可以生成，杯子外观引用产品板，地铁车厢写真实顶灯与窗外光；温度计读数那条必须实拍。

最容易错的一处：6 小时保温的读数用生成画面糊过去。读数只能实拍，拍不到就不说这条卖点。
