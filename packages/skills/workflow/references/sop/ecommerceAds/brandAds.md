# 品牌广告

卖的是一句能被复述的话和一个能被认出的画面。**不要求观众立刻买，要求他记住。** 判据：关掉声音、遮住产品，观众还能不能说出这是谁家的片子？能，记到位了；不能，只是拍得好看。

## 一、适用 / 不适用

- 适用：品牌形象片、TVC 与投放版本（15 / 30 / 60 秒）、新品上市定调片、周年或年度主题片、需要统一视觉语言的系列广告。
- 不适用：考核单次转化的投放素材 → `feedAds.md`；讲参数与用法 → `productVideo.md`；真人对镜头说服购买 → `salesPitch.md`；企业介绍与招商 → `promotionalVideos/companyPromo.md`。
- **前提：品牌方有没有 VI**（logo 用法、标准色、指定字体、slogan 规范）。有就按 VI；没有就先定一套并让品牌方确认。VI 决定记忆点能不能累积。

## 二、开工必问

一次一个，每个给两个具体选项。

1. **要让人记住哪一句话？** "'贵一点，用五年'，还是'每天都想开的那辆车'？"——一句，超过一句就是没有。
2. **要让人记住哪一个画面？** "一个人、一个动作，还是一个场景？"——品牌片靠一个可被复述的画面活着。
3. **做多长？** "15 秒短版、30 秒标准版，还是 60 秒长版？"——一稿多长是最常见的失败。
4. **有没有必须出现的元素？** "logo、slogan、产品、地址、二维码——哪些是硬性？"——决定定版留几秒。
5. **和上一支片子什么关系？** "同一系列的下一支，还是全新开始？"——系列片必须沿用同一段画风文字。

"你看着办"就落：30 秒主片 + 15 秒短版、一句话记忆点、一个画面母题、结尾 3 秒定版，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 主片时长 | 30 秒 / 60 秒 | 60 秒用于线上主片与发布会 |
| 短版 | 15 秒 | 从 30 秒重写，不是压缩 |
| 派生比例 | 主版 + 竖版 + 方版 | 派生版重排构图，不做中心裁切 |
| 定版 | 最后 2–3 秒，画面静止 | 少于 2 秒，logo 与 slogan 读不完 |
| 品名出现 | 30 秒内 ≥ 3 次 | 口播、字幕、画面各算一次 |
| 利益点 | 1 个（最多 2 个） | |

## 四、结构

30 秒基准：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 记忆钩子 | 0–3 秒 | 0–10% | 一个反常画面或一个声音动机，立刻建立"这支片子不一样"；不出现 logo |
| 品牌世界 | 3–10 秒 | 10–33.3% | 这支片子的时空、质感、人的状态；让观众想待在里面 |
| 利益点戏剧化 | 10–20 秒 | 33.3–66.7% | 唯一那个利益点，用一次事件演出来，不用旁白解释 |
| 产品主镜 | 20–25 秒 | 66.7–83.3% | 产品单独出现，形态、质感、使用状态一次看清 |
| 品名 + slogan | 25–28 秒 | 83.3–93.3% | 口播念品名，字幕上 slogan，两者不抢同一秒 |
| 定版 | 28–30 秒 | 93.3–100% | logo 落位 + 必要的地址、二维码；画面静止 |

15 秒版：钩子 0–2、利益点 2–7、产品 7–10、品名 10–13、定版 13–15 秒，删掉品牌世界。60 秒版：0–5 / 5–20 / 20–40 / 40–48 / 48–56 / 56–60 秒，只扩前两段内容，不新增段落。

系列片规则：钩子的构图逻辑、品名的字体与落位、定版时长三处逐帧对齐上一支；换的是内容，不是语法。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 品牌资产 | 必须 | 图形规范文件，不是生成图 | logo 正负形、标准色、字体、slogan 排版；定版不用位图 |
| 产品主镜 | 必须 | 是（2×2 道具板） | 与实物一致；颜色错就是品牌事故 |
| 品牌世界场景 | 必须 | 是（地点板） | 系列片沿用同一板 |
| 常驻角色 / 吉祥物 | 系列片才要 | 是（角色板） | 跨片复用 |
| 道具与陈设 | 视剧本 | 关键道具做板 | 与品牌调性冲突的一律换掉 |
| 声音标识 | 有就要 | 否 | 3 秒内可辨 |

品牌世界与戏剧化段落可以生成；logo、定版文字后期做，不进生成。

画风在流程第二步已冻结；品牌片尤其不能换画风文字——换画风等于换品牌。要和竞品拉开，就在定画风时至少让三个维度取非行业默认值。

本类目用不上：故事与剧作的连载分集与漫剧部分。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 收 VI 与上一支片子；定时长档与版本 | 规格 + VI 清单 |
| S1 | 一句话 + 画面母题 + 30 秒节拍表；再重写 15 秒版 | 节拍表（30 / 15） |
| S2 | 品牌资产、产品、场景、角色盘点 | 资产表 |
| S3 | 品牌资产落规范文件；产品板与地点板 | 已采用资产 |
| S4 | 先写 30 秒版，再重写 15 秒版 | 分镜提示词 |
| S5 | 钩子与产品主镜测试 → 补全 | 粗剪 |
| S6 | [声音](../../methods/sound.md)标识、口播、音乐、定版 | 混音母版 |
| S7 | 第八节清单 + 关[声音](../../methods/sound.md)测试 + 截 6 帧当海报测试 | 各时长、各比例成片 |

## 八、验收清单

- [ ] 一句话记忆点能被剧组以外的人复述
- [ ] 有一个可被指认的画面母题，全片至少出现 2 次
- [ ] 全片只有 1 个利益点
- [ ] 30 秒版品名出现 ≥ 3 次，且不挤在同一秒
- [ ] 定版 ≥ 2 秒且静止，logo 与 slogan 读得完
- [ ] 关掉声音仍能认出品牌；截 6 张静帧至少 3 张能单独当海报
- [ ] 品牌色比例与 VI 一致；产品颜色与实物一致
- [ ] 系列片在钩子语法、字体落位、定版时长上对齐上一支

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 好看但记不住 | 只有氛围，没有记忆点 | 先定一句话和一个画面母题，删掉不服务这两样的镜头 |
| 像竞品拍的 | 风格取了行业平均值 | 重定画风时让至少三个维度取非默认值 |
| 30 秒讲了三件事 | 品牌方要放的太多 | 砍到一个利益点，其余挪到详情页与公关稿 |
| 关声音认不出 | 全靠旁白报品牌 | 加视觉识别元素（色块、构图、产品形态），品名上字幕 |
| 15 秒版像快进的 30 秒 | 用变速压缩 | 重写 15 秒版，删掉品牌世界段 |
| 系列片越拍越散 | 每支重新定风格 | 冻结同一段画风文字，只换内容 |
| 画面母题只出现一次 | 没设计复现 | 母题在钩子和产品主镜各出现一次 |
| 品牌色铺满全片 | 把"品牌色为主"当成每镜都用 | 品牌色只给强调色那一成，落在一两处 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："国产登山鞋品牌，想要一支能让人记住的品牌片。"
- 落值：30 秒主片 + 15 秒投放版；一句话记忆点"路走多了，鞋会记得"；画面母题是"鞋底的纹路印在不同的地面上"；结尾 2 秒定版。
- 一句话：关掉声音，看到那枚鞋底印就认得出是这个牌子。

节拍表（按事件写）：

| 时间 | 段落 | 事件 |
|---|---|---|
| 0–3 秒 | 记忆钩子 | 低角度，一只沾泥的鞋底从镜头前踩下，泥印留在画面中央（母题第一次） |
| 3–10 秒 | 品牌世界 | 清晨山脊，一个中年人坐在石头上系鞋带，身后是同样旧的背包 |
| 10–20 秒 | 利益点戏剧化 | 同一双鞋走过雪地、石阶、陪孩子第一次登顶——鞋底印一次比一次浅，还是那双 |
| 20–25 秒 | 产品主镜 | 新鞋放在旧鞋旁边，鞋底朝上，纹路一模一样（母题第二次） |
| 25–28 秒 | 品名 + slogan | 口播品名；字幕"路走多了，鞋会记得" |
| 28–30 秒 | 定版 | logo 静止 |

风格块里本条的色比：六成岩灰、三成苔绿、一成品牌橙——橙色只落在鞋带上。

15 秒版重写：钩子 0–2、利益点 2–7（只留登顶那一幕）、产品主镜 7–10、品名 10–13、定版 13–15 秒。

最容易错的一处：把 slogan 写成"能穿十年"这种可被追问的性能承诺。品牌片的话要能被记住，不要能被投诉。
