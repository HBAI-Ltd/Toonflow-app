# 好物开箱

开箱给的是一个判断，不是一个包裹。两种目的二选一：**决策型要判断，解压型要声音与节奏**。两边都占就是四不像。

## 一、适用 / 不适用

- 适用：单品开箱、同款对比、包装内含与配件、第一印象与上手。决策型 45–90 秒，解压型 15–45 秒。
- 不适用：一道菜怎么做 → `cookingVideo.md`；一家店值不值得去 → `venueVisit.md`；只讲外观与规格、不给判断 → `ecommerceAds/productVideo.md`；种草分享 → `ecommerceAds/productRecommendation.md`。
- **一句话判据**：决策型必须有可验证的判断与一条劝退；解压型不要求判断与参数，只核声音、节奏与收口。

## 二、开工必问

一次一个。

1. **决策型还是解压型？**——决定结构与验收，定了不再改。
2. 一句话结论是什么，能验证吗？"89 块，我把家里另外两个扔了"。
3. 给谁用、什么场景？——观众要在描述里认出自己。
4. 三个可感知的细节是什么、什么人别买？——接缝有没有毛刺、支架是不是金属；参数不算细节。

决策型还是解压型问不出来，各说一句会拍成什么样让他挑；其余答不上来落保守值：60 秒、至少一条劝退，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 决策型 45–90 秒（45–60 秒最稳）；解压型 15–45 秒 | |
| 声音 | 现场声（撕、扣、按、放）+ 口播 | 解压型靠声音吃饭 |
| 字幕 | 价格、型号、尺寸、结论关键词 | 参数进字幕不进旁白 |
| 真实性 | 测试读数必须实拍，仪器屏幕入画；不伪造读数与对比，不二次封箱摆拍"第一次打开" | |

## 四、结构

决策型 60 秒（45 与 90 秒按同一占比）：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 结论前置 | 0–3 秒 | 0–5% | 先给判断或最强画面，不从拆快递开始 |
| 身份与场景 | 3–9 秒 | 5–15% | 什么品类、多少钱、给谁用 |
| 拆 + 评 | 9–39 秒 | 15–65% | 每拆出一样，立刻给一句评价；用可感知细节 |
| 判断 + 劝退 | 39–57 秒 | 65–95% | 适合谁、不适合谁；给一个替代或升级方向 |
| 收口 | 57–60 秒 | 95–100% | 回全貌或补一句规格；带货版才加行动指令 |

解压型 30 秒（15 与 45 秒按同一占比）：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 拆封第一下 | 0–3 秒 | 0–10% | 声音优先，第一下就要清楚 |
| 逐个拆 | 3–21 秒 | 10–70% | 边拆边给一句；不判断值不值，不上参数 |
| 摆齐 | 21–27 秒 | 70–90% | 一件件摆齐，给全貌与质感 |
| 收口 | 27–30 秒 | 90–100% | 一句感受；不总结、不劝买 |

三条硬约束：决策型别从拆开始，边拆边评（"说明书是中文的，上一代全英文"才是信息）；劝退具体到场景；解压型不叠加判断。

## 五、资产清单

| 资产 | 要不要 | 必须做板 | 说明 |
|---|---|---|---|
| 产品本体 | 必须 | 补拍时做（2×2） | 决定全片是不是同一个东西 |
| 包装与内含 | 必须 | 否 | 与实物清单逐项对齐 |
| 手 | 必须 | 固定 | 同一双手、同一副指甲 |
| 参照物 | 有尺寸段就要 | 否 | 手掌、A4 纸；不造假比例 |
| 使用场景 | 决策型有场景段就要 | 补拍时做 | 真实桌面或厨房 |
| 价格与型号 | 决策型必须 | — | 出现在画面或字幕 |

**真实拆封一律实拍**；生成只补内部结构、剖面、示意，并引用同一张产品板。

## 八、验收清单

决策型：
- [ ] 时长 45–90 秒；结论一句话，画面能验证
- [ ] 价格在片中出现，型号版本没说错；三个细节可感知
- [ ] 至少一条具体劝退
- [ ] 尺寸段有参照物；产品颜色与实物一致

解压型：
- [ ] 时长 15–45 秒；拆封声清楚
- [ ] 第一下在 3 秒内；逐个拆，不跳件、不补件
- [ ] 收口一句感受，不上参数

共同：
- [ ] 数字有出处；读数镜全部实拍；不用别人素材冒充开箱

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 三十秒还在拆胶带 | 从拆开始 | 结论前置，拆的过程压到 3 秒内 |
| 全是夸 | 不敢说不足 | 补一条具体劝退场景 |
| 数据可疑 | 读数没有出处 | 删掉，或换成可核的参数并注明来源 |
| 解压型没声音 | 拆封声轻、配乐盖住 | 单独补录，配乐压到垫底 |
| 劝退写成"见仁见智" | 不敢具体 | 写清一个具体场景："想当主灯的别买" |
| 开箱时间和实际使用时长对不上 | 说"用了一个月"其实刚拆 | 写真实时长："拆开第一天"或"用了 21 天" |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："买了个 89 块的台灯，想做个开箱，告诉大家值不值。"
- 落值：决策型 60 秒；用了 21 天。
- 一句话结论："89 块，我把家里另外两个台灯都收起来了。"

结论 + 三个细节 + 一条劝退（S1 的产物）：

| 项 | 内容 | 画面怎么证明 |
|---|---|---|
| 细节 1 | 灯臂是金属的，掰到哪停到哪 | 掰到三个角度各停 1 秒 |
| 细节 2 | 底座有配重，碰一下不倒 | 用手指推灯臂，底座不动 |
| 细节 3 | 调光旋钮有段落感 | 旋钮特写 + 咔哒声 |
| 劝退 | 想当房间主灯的别买，它只照得亮一张桌子 | 关掉顶灯，只开它，房间其余地方是暗的 |

结构落地：0–3 秒结论 + 灯亮起；3–9 秒"89 块，书桌台灯，给晚上要加班的人"；9–39 秒边拆边评三个细节；39–57 秒判断与劝退；57–60 秒灯的全貌 + "高 45 厘米"。

最容易错的一处：说"护眼"。没有检测与资质就不说功效，只说你看得见的东西。
