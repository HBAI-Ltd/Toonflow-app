# 生活Vlog

不拍"一天"，拍**这一天里的一处变化**。观众不是为了看你吃了什么，是为了在你身上认出自己那点事。判据：看完能说出一句"他今天怎么了"，不是"他今天干了这些事"。

## 一、适用 / 不适用

- 适用：一天或一段时间的生活记录，一个人或一家人的日常，且有一处明确转折（心情、关系、决定、认知）；竖版 60–180 秒，长版 3–8 分钟。
- 不适用：交付明确信息 → `educationalVideos/skillTutorial.md`；卖一件东西 → `productUnboxing.md`；目的地是主体 → `documentariesAndEvents/travelDocumentary.md`；摆拍剧情 → `shortDrama/`。
- **一句话判据：有没有一个"本来没计划、发生了、改变了他"的事件？** 没有，就只是记录素材，先别剪。

## 二、开工必问

一次一个。第 3、4 题是删素材的依据，不是可选项。

1. 这段时间里，哪一件事让你情绪变了？——这就是转折。找不到就不拍。
2. 这件事能不能拍到你本人？——只能拍环境，就做氛围短片，别叫 Vlog。
3. 做 60–180 秒竖版快剪，还是 3–8 分钟长版？——决定要不要第二个转折。

答不上来落保守值：竖版 60 秒、只讲一个转折，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 竖版快剪 | 60–180 秒 | |
| 长版 | 3–8 分钟 | 要有第二个转折才撑得住 |
| 声音 | 同期声优先：走路、开门、水声、说话；口播少而具体 | |
| 字幕 | 时间、地点、花销这类硬信息上屏；情绪不靠字幕解释 | |

## 四、结构

60 秒竖版；90 秒、3 分钟、8 分钟按同一占比，长版把事件段拆多一轮：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 一个正在发生的动作 | 0–3 秒 | 0–5% | 不打招呼、不自我介绍：系鞋带、关灯、把药盒放进口袋 |
| 今天要干什么 | 3–9 秒 | 5–15% | 一个当天能完成的具体目标：交材料、清阳台、见一个人 |
| 两三个事件 | 9–42 秒 | 15–70% | 至少一件事偏离计划；顺到底就是流水账 |
| 转折 | 42–54 秒 | 70–90% | 情绪或决定在这里变；给一个能看见的动作，不给抒情 |
| 落点 | 54–60 秒 | 90–100% | 一句"所以我……"，只收一件事，不总结人生 |

四条硬约束：一条只回答一个问题；流水账的病因是没取舍——拍 80 段用 12 段；允许不完美（没洗的碗、走错的路）；**可以补空镜，不能补事件**。

## 五、资产清单

| 资产 | 要不要 | 说明 |
|---|---|---|
| 本人 | 必须 | 实拍；同一发型、同一副眼镜 |
| 住处或常去地点 | 必须 | 玄关、厨房、阳台、通勤路线；观众靠它认地方 |
| 日常道具 | 有戏才要 | 只收反复出现的：杯子、包、钥匙 |
| 空镜清单 | 必须 | 8–12 个：窗、鞋、水壶、路灯、手部动作 |
| 音乐 | 必须 | 两段够用：日常段轻、转折段留白 |

真实事件一律实拍；生成只补空镜与转场，补的镜头单独记一份。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 先定"这一处在哪一分钟变"，再定时长 | 规格表 |
| S1 | 目标 + 事件表 + 落点句 | 事件表 |
| S2 | 本人、地点、空镜盘点；路人不进盘点 | 资产表 |
| S3 | 不做剧情场景图 | — |
| S4 | 空镜与转场提示词（可空） | 补镜清单 |
| S5 | 粗剪事件顺序 → 补空镜 | 粗剪 |
| S6 | 同期声、硬信息字幕、配乐 | 混音版 |
| S7 | 第八节清单 | 成片 |

## 八、验收清单

- [ ] 时长与第三节一致
- [ ] 能一句话说出"他今天怎么了"
- [ ] 有一个明确转折，且转折是动作不是旁白
- [ ] 前 3 秒是一个正在发生的动作
- [ ] 同期声在，没被配乐盖住
- [ ] 时间、地点、花销与画面一致
- [ ] 补的空镜有记录

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 流水账 | 没取舍 | 先定转折，再按"推进 / 不推进"删段 |
| 全程旁白解释情绪 | 拍不到情绪 | 换成动作：把手机扣在桌上、反复看门口 |
| 假 | 补拍了"应该发生的样子" | 只补空镜，不补事件 |
| 前 3 秒劝退 | 从起床、打招呼开始 | 从已经在做的那件事切入 |
| 像广告 | 中途开始推产品 | 要推就走 `productUnboxing.md` |
| 转折段配了一大段抒情旁白 | 不放心观众看不懂 | 删旁白，留一个动作和环境声 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："周末搬家，想拍条 Vlog。"
- 落值：竖版 60 秒；出镜的只有自己，搬家师傅拍背影。
- 一句话：看完知道"她今天差点没舍得走"。

事件表（S1 的产物）：

| 项 | 内容 |
|---|---|
| 目标 | 一天搬完，晚上睡在新房子里 |
| 事件 1 | 搬家师傅迟到两个小时（偏离计划） |
| 事件 2 | 拆衣柜时翻出一盒三年前的电影票根 |
| 事件 3 | 楼下奶奶送来一袋橘子 |
| 转折 | 最后一趟回去关灯，她在空房间的地板上坐了很久 |
| 落点 | "所以我把钥匙交了，橘子带走了。" |

结构落地：0–3 秒她把最后一个纸箱封上胶带；3–9 秒字幕"今天要搬完"；9–42 秒三个事件；42–54 秒空房间、关灯前她坐下，只有楼道里的声音；54–60 秒新房子里，橘子摆在窗台上。

最容易错的一处：转折段配音乐和"告别青春"的旁白。只留她坐在地板上和楼道的声音，观众自己会懂。
