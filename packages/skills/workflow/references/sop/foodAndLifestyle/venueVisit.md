# 探店

替观众做一个决定：**这家店值不值得来、什么时候来、点什么、别点什么。** 先给判断，再给证据。判据：看完能说出人均多少、值不值得来、什么时候别来——缺一件就是空镜合集。

## 一、适用 / 不适用

- 适用：到店实拍，餐饮、咖啡馆、面包店、小吃摊、新店首探与复访对比；45–90 秒。
- 不适用：一道菜怎么做 → `cookingVideo.md`；厨具好不好用 → `productUnboxing.md`；城市与目的地为主体 → `promotionalVideos/cityTourism.md`；门店官方形象片 → `promotionalVideos/companyPromo.md`。
- **一句话判据：有没有一个"只有到店才能拍到"的判断依据？** 分量、上菜速度、等位、真实价格。没有到店证据就是素材拼接。

## 二、开工必问

一次一个。

1. 一句话结论是什么？"人均 40，分量吓人"——第一句就要它。
2. 人均、地址、营业时间、要不要等位？——四个数必须给。
3. 最值得拍的 2–3 个点，分别对应什么画面？——想不出画面，这个点就不成立。
4. 一个真实缺点是什么？——说不出缺点，先别拍。

答不上来落保守值：60 秒、必须有一个真实缺点，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 时长 | 45–90 秒，60 秒基准 | |
| 声音 | 现场声（环境、出锅、上菜）+ 口播 | 纯配乐空镜完播最差 |
| 字幕 | 人均、地址、营业时间、招牌菜名；价目给全 | |
| 真实性 | 菜品、分量、环境、价格与到店一致：不换盘、不补摆、不用别桌的菜 | |

## 四、结构

60 秒基准；45 与 90 秒按同一占比：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 结论钩子 | 0–3 秒 | 0–5% | 直接抛判断或反差；不说"大家好""今天带大家来" |
| 身份与场景 | 3–9 秒 | 5–15% | 品类 + 人均 + 场合；门头与环境 1–2 镜带过 |
| 核心亮点 | 9–36 秒 | 15–60% | 2–3 个点，每点配一个可拍画面 |
| 劝退 | 36–48 秒 | 60–80% | 一个真实缺点，说清"什么人别来" |
| 行动 | 48–60 秒 | 80–100% | 几点去、点什么、怎么停车；不喊"快来打卡" |

三条硬约束：前 8 秒不出现门头空镜和自我介绍；每个亮点配一个画面（"鱼是现捞的，端上来锅还在响"才是信息）；缺点要影响某类人。

## 五、资产清单

| 资产 | 要不要 | 说明 |
|---|---|---|
| 门店外观 | 必须 | 门头、招牌、入口；不用别的时段冒充 |
| 店内空间 | 必须 | 座位、吧台、动线；观众要判断"坐得下吗、吵不吵" |
| 菜品 | 必须 | 上桌即拍 |
| 价目表 | 必须 | 人均与招牌价的依据 |
| 出镜人 | 必须 | 同一人、同一套衣服，跨集不换 |
| 信息卡 | 必须 | 人均、地址、营业时间卡 |

**实拍就是证据**：门店、菜品、环境一律实拍，不生成。生成只做封面、信息卡底图与示意转场。

| 阶段 | 本类目做什么 | 产出 |

| S0 | 定一句话结论与时长 | 规格 |

## 八、验收清单

- [ ] 时长 45–90 秒
- [ ] 前 3 秒是判断或反差
- [ ] 人均、地址、营业时间、招牌菜名上屏，与菜单核对过
- [ ] 2–3 个亮点各有一个画面
- [ ] 有一个具体缺点，说清什么人别来
- [ ] 菜品、分量、环境、价格与到店一致

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 前 8 秒就划走 | 门头空镜 + 自我介绍 | 第一句换成判断，门头压到 1 秒以内 |
| 像软文 | 只夸不贬 | 补一个真实缺点和什么人别来 |
| 亮点记不住 | 说了四个以上 | 砍到 2–3 个 |
| 分量对不上 | 用了别桌的菜 | 上桌即拍，对不上就重拍 |
| 信息错 | 人均、时间是估的 | 核对后再上屏 |
| 人均算的是双人套餐 | 没说清口径 | 人均按一个人一顿正常点单算，并写清口径 |
| 店里太暗拍得发黑 | 没补光又不敢提高感光 | 带一盏小补光灯，靠窗座位拍菜 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写；店名和地址用"某"代替。

- 需求："我常去的一家社区面馆，想做个探店。"
- 落值：60 秒；人均 22 元、某路 × 号、6:00–14:00、中午排队约 30 分钟。
- 结论句："人均 22，一碗牛肉面能吃到撑，但中午 12 点别去。"

| 时间 | 段落 | 放什么 |
|---|---|---|
| 0–3 秒 | 结论钩子 | 一碗面端上桌，牛肉盖满碗面；口播结论句 |
| 3–9 秒 | 身份与场景 | 社区面馆、人均 22、适合一个人吃早午饭；门头 1 秒 |
| 9–36 秒 | 核心亮点 | 后厨现切牛肉；汤锅里的骨头；加面免费，第二份端上来 |
| 36–48 秒 | 劝退 | 12 点门口排队的人，店里只有风扇："怕热、赶时间的别中午来" |
| 48–60 秒 | 行动 | "11 点前到，点大碗牛肉面，加面跟老板说一声" |

拍摄前问过老板和店员，排队的顾客拍背影。

最容易错的一处：只拍了牛肉面好看，没给"什么时候别来"。那个缺点才让人相信你说的人均和分量。
