# 运动教学

这是纠错题，不是演示题：观众来确认"我做的那个是不是错的"，核心交付是**正确与错误的同机位对照**。判据：找个没做过的人照做一遍，他能说出卡在第几步、卡在哪个关节；说不出，就是那一步没交代条件。

## 一、适用 / 不适用

- 适用：一个动作、一组训练、一次纠错、器械使用、热身与放松、跑姿与发力；单动作 120 秒、一组动作 180 秒。
- 不适用：赛事高光 → `eventHighlights.md`；讲原理机制 → `educationalVideos/scienceExplainer.md`；带课时的系统课 → `educationalVideos/courseVideo.md`；医疗康复处方、用药与诊断 → 不属本 skill，指向专业人员。
- **安全写在最前面，不写在最后一行**：

| 安全项 | 必须写成 | 出现位置 |
|---|---|---|
| 禁忌人群 | 具体到人：孕期、术后 6 个月内、膝关节急性疼痛期、未控制的高血压 | 片头安全段，字幕 + 口播 |
| 停止信号 | 出现刺痛、眩晕、关节弹响伴痛、麻木就停 | 片头安全段 |
| 疼痛处置 | 停练、冰敷 15 分钟、48 小时不缓解就医 | 结尾一屏，停留 ≥ 3 秒 |
| 医疗边界 | 不诊断、不荐药、不给康复处方、不承诺疗效 | 全片 |

## 二、开工必问

一次一个。

1. 教哪个动作，学完怎么算做到了？——答不出判断标准，先别开工。
2. 谁学：零基础、有基础、青少年、中老年？——决定强度、幅度与禁忌。
3. 有没有伤病、手术史、孕期、心血管问题？——有就只做保守版，开头挂"先问医生"。
4. 场地器材有什么，缺什么能替代？

"你看着办"就落：单动作 120 秒、3 个分解、1 个错误示范、正侧双机位、开头安全卡、只做自重不加负荷，说明可推翻。

## 三、规格

| 项 | 短版（单动作） | 长版（一组动作） |
|---|---|---|
| 时长 | 120 秒 | 180 秒 |
| 机位 | 正面 + 侧面固定；纠错镜与正确镜同机位、同景别、同距离 | 同左 |
| 单镜 | 一步一镜，镜内"进入 → 执行 → 停在结果" | 同左 |
| 变速 | 只对等待与重复段加速并标倍数；关键动作原速 | 同左 |
| 安全段 | 0–6 秒 | 0–9 秒 |

## 四、结构

| 段落 | 短版 | 长版 | 占比 | 这一段要完成什么 |
|---|---|---|---|---|
| 安全与准备 | 0–6 秒 | 0–9 秒 | 0–5% | 禁忌人群、停止信号、场地器材 |
| 标准动作先行 | 6–18 秒 | 9–27 秒 | 5–15% | 先看做完什么样，一句"几步能学会" |
| 分解 | 18–66 秒 | 27–99 秒 | 15–55% | 短版 3 步、每步 16 秒；长版 4 个动作、每个 18 秒 |
| 完整串联 | 66–84 秒 | 99–126 秒 | 55–70% | 连起来原速做一遍，不切碎 |
| 错误对照 | 84–108 秒 | 126–162 秒 | 70–90% | 短版 1 个错、长版 2 个；错一次给人看，再说怎么改 |
| 自测与进阶 | 108–120 秒 | 162–180 秒 | 90–100% | 怎么知道做对了；加负荷的顺序 |

每步三件套：做什么 → 变成什么样 → 怎么知道对了。例：「髋向后坐，膝盖对准第二脚趾 → 大腿接近与地面平行 → 从侧面看，膝盖朝着第二脚趾的方向、脚跟不离地、腰不塌」。

两条说明：只教一次健身里的一段（准备、基本、放松）时，开头说清教哪段；加负荷顺序是先加每天时长、再加每周天数、最后加强度。

## 五、资产清单

| 资产 | 要不要 | 说明 |
|---|---|---|
| 示范者 | 必须 | 真人实拍；同一个人、同一套衣服、同一双鞋 |
| 场地 | 必须 | 地面材质、颜色、边界固定 |
| 器械 | 关键器械必须 | 型号、重量、颜色一致 |
| 安全卡 | 必须 | 后期模板：禁忌人群、停止信号、疼痛处置 |

**示范动作一律真人实拍，不用生成替代**——生成的动作"看起来对、其实是错的"，会教人受伤。生成只补空镜与示意（如肌肉发力示意，标"示意"）。

## 八、验收清单

- [ ] 时长与六段占比按表
- [ ] 安全四项齐，整段落在片头安全段内；疼痛处置在结尾停留 ≥ 3 秒
- [ ] 每一步都有可见结果和判断标准
- [ ] 错误示范数量够，且给了改法
- [ ] 纠错镜与正确镜同机位、同景别、同距离
- [ ] 全身可见，关节不被裁切
- [ ] 关键动作原速，变速段标了倍数
- [ ] 没有用生成替代示范动作
- [ ] 跟做测试通过

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 照着做，做出来不一样 | 省略了角度、节奏、呼吸、起始位置 | 把隐含条件写成字幕数字 |
| 只演对的 | 觉得错误示范不体面 | 补错误版，与正确版同机位 |
| 动作看起来对其实错 | 用生成替代了示范 | 换真人实拍 |
| 安全提示一闪而过 | 当片头 | 整段压进安全段，字幕与口播同时出 |
| 竖版裁掉了脚 | 按横屏构图再裁 | 竖版重新取景，全身入画 |
| 示范者动作太标准，新手做不到 | 只拍了专业版 | 补一个降低难度的版本（扶墙、减小幅度） |
| 计数和口令对不上画面节奏 | 后期配口令 | 口令按示范实际节奏录，或现场同期录 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："教零基础的人做徒手深蹲，别把膝盖做伤。"
- 落值：单动作 120 秒；零基础成年人；自重不加负荷；正面 + 侧面双机位。
- 判断标准："膝盖始终朝着第二脚趾的方向，脚跟不离地，背是一条直线，蹲到大腿接近与地面平行。"（膝盖略超过脚尖本身不算错，内扣和脚跟抬起才是）

安全段（0–6 秒）字幕：膝关节急性疼痛期、术后 6 个月内、孕期不做；出现刺痛、关节弹响伴痛就停。

步骤卡（分解 18–66 秒，3 步各 16 秒）：

| 步 | 做什么 | 变成什么样 | 怎么知道对了 |
|---|---|---|---|
| 1 | 双脚与肩同宽，脚尖略向外 | 两脚尖朝外约 15° | 低头看，膝盖和第二脚趾同一个方向 |
| 2 | 髋向后坐，像要坐椅子 | 臀部后移，上身前倾 | 侧面看，背是一条直线 |
| 3 | 蹲到大腿接近水平，脚跟发力站起 | 回到站立 | 全程脚跟没离地 |

错误对照（84–108 秒）：膝盖内扣——同机位先做错一次，再做对一次，字幕"膝盖跟着脚尖走"。

最容易错的一处：安全提示放在片尾。禁忌人群和停止信号必须在前 6 秒，字幕和口播同时出。
