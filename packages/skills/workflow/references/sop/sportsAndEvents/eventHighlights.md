# 赛事集锦

只做**已发生的事的排序**。判据：静音播前 3 秒，看不看得出谁赢了？看不出就重排结果条；看得出但回合之间说不出因果，就重剪回合组。

## 一、适用 / 不适用

- 适用：单场高光、轮次与赛季回顾、球员个人集锦、赛事周报；竖屏切片 60–90 秒，横屏全场集锦 3–8 分钟。
- 不适用：完整回放与战术长片；赛前造势 → `eventPreview.md`；球迷情绪 → `fanSupport.md`；动作拆解 → `sportsTutorial.md`。
- 主线是剪辑；只要剪辑、不需要任何生成时，按 `sopRouting.md` 一说明边界。

## 二、开工必问

一次一个。

1. 结果是什么：比分、逆转、个人纪录？写成一句话。——决定前 3 秒放什么。
2. 给谁看：本队球迷、中立观众、没看比赛的人？——三种人的"结果"定义不一样。
3. 手上有几路机位、有没有现场声或解说音轨？——决定剪辑与混音方式。
4. 做一条，还是"主片 + 切片组"？——决定时长档位。

答不上来落保守值：竖屏 60 秒短版、给中立观众看，说明可推翻。

## 三、规格

| 项 | 短版（竖屏切片） | 长版（横屏全场） |
|---|---|---|
| 时长 | 60–90 秒 | 3–8 分钟 |
| 结果出现 | 前 3 秒 | 前 15 秒 |
| 回合数 | 3–6 个，每个 8–12 秒 | 9–24 个，每个 8–12 秒 |
| 剪切节奏 | 回合内 2–3 秒切一次，得分镜 8–10 秒 | 同左 |

## 四、结构

短版 60 秒、长版 5 分钟两个基准：

| 段落 | 短版 | 长版 | 占比 | 这一段要完成什么 |
|---|---|---|---|---|
| 结果条 | 0–3 秒 | 0–15 秒 | 0–5% | 比分、胜负或最炸一球，一句字卡说清谁赢了 |
| 反向交代 | 3–9 秒 | 15–45 秒 | 5–15% | 为什么值得看：赛前预期、排名落差、恩怨 |
| 回合组 | 9–45 秒 | 45–225 秒 | 15–75% | 短版 4 回合、长版 15 回合，按因果排 |
| 决胜 | 45–54 秒 | 225–270 秒 | 75–90% | 决定胜负的那一下，给一个完整回合，不切碎 |
| 定格收尾 | 54–60 秒 | 270–300 秒 | 90–100% | 结果、关键数据、下一场 |

短版拉到 90 秒时，结果条、反向交代、决胜、收尾的秒数不变，多出来的全给回合组。高光段少于 3 个不做集锦，改做单条切片；多于 24 个拆"主片 + 切片组"。回合之间要有因果：这一球为什么发生、改变了什么——堆进球是素材流，不是集锦。

## 五、资产清单

| 资产 | 要不要 | 合格标准 |
|---|---|---|
| 结果清单 | 必须 | 时间码、比分、球员、事件类型，行行对准——同时决定剪辑顺序与字幕 |
| 机位优先表 | 多机位必须 | 得分用主机位，反应切观众与替补席 |
| 解说音轨 | 有就用 | 与现场声分层 |
| 比分条与数据条模板 | 必须 | 字号、位置、安全区固定 |
| 封面首帧 | 必须 | 用结果镜头 |

**不生成比赛画面、队徽、球衣、球员脸**；慢镜用素材自身变速，不用生成补帧造瞬间。生成只补转场、空镜、数据条底。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 结果一句话与时长版本先定 | 规格 |
| S1 | 结果清单 + 回合顺序 | 结果清单 |
| S2 | 多机位素材、解说音轨、比分数据 | 素材表 |
| S3 | 比分条、数据条、封面首帧 | 图形资产 |
| S4 | 补镜提示词（可空） | 补镜清单 |
| S5 | 剪回合 → 补镜 | 粗剪 |
| S6 | 现场声、解说、音乐、字幕 | 混音版 |
| S7 | 按第八节清单验收 | 短版 + 长版 |

## 八、验收清单

- [ ] 时长与回合数按第三节
- [ ] 前 3 秒给出比分或最炸一球（长版 15 秒内）
- [ ] 每个回合说清了"改变了什么"
- [ ] 决胜那一下给足 8 秒以上
- [ ] 比分、时间、球员名与号码逐字核对
- [ ] 没有生成的比赛画面、队徽、球衣、球员脸
- [ ] 整画面冲击（闪白、震屏）≤ 3 处
- [ ] 竖屏与横屏各自成立，不是裁边

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 只堆进球，看完不知道谁赢了 | 结果没前置 | 开头加结果条；回合按因果重排 |
| 中立观众看不懂背景 | 默认观众看过比赛 | 反向交代段补一句字卡 |
| 竖版主角跑出画面 | 硬裁中央 | 跟随主体横转竖 |
| 音乐盖住解说 | 音乐铺满 | 解说段压低音乐 |
| 比分条和实际比分对不上 | 剪辑时没对结果清单 | 每个回合的比分条从结果清单取，不凭记忆 |
| 中立观众不知道谁是谁 | 球员只有号码 | 关键球员第一次出现时上一次名字条 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我们城市业余足球联赛决赛，我拍了两台机，想发个集锦。"
- 落值：两台机位实拍素材；竖屏 60 秒。
- 结果一句话："蓝队第 88 分钟 1 比 2 逆转夺冠。"

结果清单（S1 的产物）：

| 时间码 | 比分 | 球员 | 事件 | 改变了什么 |
|---|---|---|---|---|
| 23' | 1:0 | 红 9 | 进球 | 红队领先 |
| 61' | 1:1 | 蓝 7 | 进球 | 扳平，蓝队开始压上 |
| 79' | 1:1 | 蓝门将 | 扑点 | 守住平局 |
| 88' | 1:2 | 蓝 10 | 进球 | 逆转 |

结构落地：0–3 秒 88 分钟那一脚 + 比分条"1:2"；3–9 秒字卡"上半场落后，蓝队去年在决赛输过"；9–45 秒前三个回合按因果排；45–54 秒 88 分钟完整回合，不切碎；54–60 秒捧杯 + "下赛季见"。

最容易错的一处：开头放赛前合影。结果条必须先出，静音也看得出谁赢了。
