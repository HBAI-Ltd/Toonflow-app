# AI漫剧

用视频模型生成**连续画面**的连载漫剧：人物真的在动、有表演，跨镜是同一张脸。骨架是一条能反复逼人物做选择的规则。

## 一、适用 / 不适用

- 适用：二次元、国漫、日漫这类非写实画风，用视频模型连续生成画面；单集 60–120 秒、60 集以上的连载；也做预告与切片。故事里有一条反复逼人物做选择的规则（世界规则、身份错位、职业机制、关系机制）。
- 不适用：写实的真人或 AI 仿真人短剧 → `portraitDrama.md`（单集 5 分钟以上 → `landscapeDrama.md`）；真人实拍或真人换脸 → 不按本文件；静帧加推拉、局部动效 → `motionComic.md`；单条品牌片、宣传片 → `promotionalVideos/`。
- **一句话判据：画风是不是非写实的二次元、国漫、日漫？** 是，按本文件；写实的真人或仿真人，回 `portraitDrama.md`。
- 故事再自查一句：把那条规则删掉，故事还剩几成？删掉就散，骨架才立住；删得掉，先补一条能反复逼人物做选择的规则，不换类目。

## 二、开工必问

一次一个。

1. 画风走哪条：日漫、国漫，还是三渲二？——决定资产路线（画风本身在流程第二步用一段文字锁定；要写实仿真人，换 `portraitDrama.md`）。
2. 单集多长、多少集？——决定条数与制作量。
3. 故事里的那条核心规则是什么、用一次要付什么代价？——决定首集立不立得住。
4. 配音怎么出：模型原生音频，还是外部 TTS 或真人？——决定口型镜的写法。

答不上来落保守值：90 秒、先做 12 集试水、原生音频（画风在流程第二步定，不在这里落），说明可推翻；核心规则问不出来，给两条不同机制让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单集时长 | 60–120 秒 | AI 短剧单集已基本固定在 1–2 分钟 |
| 集数 | 60–100 集 | 首季先做 12–20 集试水，再决定是否铺满 |
| 条数 | 单集时长 ÷ 所选模型单次上限，向上取整 | 条数决定跨条漂移的次数，不只是预算 |

## 四、结构

90 秒单集：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 规则露头 | 0–3 秒 | 0–3.3% | 一个异常：规则第一次起作用，不解释名词 |
| 处境与代价 | 3–15 秒 | 3.3–16.7% | 主角为什么不能按普通方式活；不用规则要付什么 |
| 赢第一小局 | 15–45 秒 | 16.7–50% | 规则一手给机会、一手添麻烦；主角用它拿到一样东西 |
| 规则反咬 | 45–70 秒 | 50–77.8% | 代价落地：赢了这一局，失去另一样 |
| 对手还手 | 70–90 秒 | 77.8–100% | 对手合理反制，留一个必须回答的问题 |

60 秒版：0–2 / 2–10 / 10–30 / 30–47 / 47–60 秒；120 秒版：0–4 / 4–20 / 20–60 / 60–93 / 93–120 秒。

规则曲线：1–3 集新奇（给机会）→ 4–10 集验证（可重复）→ 11–20 集误判（以为是好处）→ 21–40 集代价（开始要债）→ 40 集后边界（被改写或付出终极代价）。同一条规则第二次回来，要让人重新理解第一次。

三条硬约束：每集至少一处规则的新变化（新用法、新代价、新边界），靠画面被看见，不靠字幕解释名词；每镜 4–8 秒且镜内有动作起止，不是"图片呼吸"；打斗与特效必须有物理反应。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主角 | 1 | 是 | 四视图 + 无表情 / 微笑两张特写 |
| 对手 | 1 | 是 | 与主角并排看轮廓、配色、体量 |
| 常驻配角 | 2–3 | 是 | 漫剧观众靠色块认人，配色不能撞 |
| 场景母版 | 4–6 | 是 | 一个地点一张 |
| 规则道具 | 2–4 | 是 | 徽记、器皿、界面、凭证；规则要靠它被看见 |
| 服装 / 伤势变体 | 按集 | 否 | 从上一状态改，新状态独立命名 |

全部画面由生成完成；一张脸只留一个身份来源。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定单集时长、集数与条数 | 规格表 |
| S1 | 规则卡 → 12 集集纲 → 首集剧本 | 规则卡 + 集纲 + 首集剧本 |
| S2 | 角色、场景、规则道具盘点 | 资产表 |
| S3 | 四张核心板先做并测试 | 已采用资产 |
| S4 | 先出整集分镜（逐镜秒数，每镜 4–8 秒），核总长，再归条写逐条提示词；对白镜单独成条，不先定条数再平均切；归条后回资产表，把单集人物的“待分条后定”按实际条数改掉 | 整集分镜 + 每集提示词 |
| S5 | 第 1 集整集跑通再批量 | 已采用片段 |
| S6 | 配音、音效、字幕 | 混音版 |
| S7 | 按第八节验收 | 成片 + 资产列表、剧集列表、提示词与片段 |

## 八、验收清单

- [ ] 单集 60–120 秒；条数与第三节一致；每条 3–5 镜、每镜 4–8 秒
- [ ] 主角在不同动作、景别、地点下都认得出是同一人（测试记录在）
- [ ] 每集至少一处规则新变化，靠画面被看见
- [ ] 打斗与特效有物理反应，不是慢动作糊过去
- [ ] 对白镜口型对得上
- [ ] 跨集连续：服装、伤势、道具状态、规则代价至少三项对上

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 图片微微呼吸冒充漫剧 | 用动态漫做法做漫剧 | 镜内要有动作起止与结果，或转 `motionComic.md` |
| 设定靠字幕 | 规则没做成可见事件 | 让规则让人进不去、藏不住、站错边、失去资源 |
| 每集重复同一爽点 | 规则没有升级 | 按规则曲线换阶段 |
| 30 秒塞 12 个镜头 | 按剪辑思维写提示词 | 砍到 3–5 镜，切点写绝对秒数 |
| 声音与画不同步 | 先出画后配音 | 先定配音时长，再按语音节拍写动作时间轴 |
| 爆款预期过高 | 供给大、爆款率低 | 先做 12–20 集试水，用数据决定是否铺满 |
| 规则的代价只说不演 | 代价没有画面 | 让代价落到一个可见行为：她叫不出熟人的名字、认错人 |
| 同一角色两集之间发色变了 | 变体从母版重造 | 从上一集的已采用状态改 |
| 打斗像在放慢动作 | 没写接触与反作用 | 写接触五段与打击感，全程实时，只在冲击瞬间放慢 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："想做个国风漫剧，女主有个特殊能力，但用了要付代价。"
- 落值：国漫、90 秒、先做 12 集试水、原生音频；单次上限按 15 秒算 → 一集 6 条。
- 规则卡：摸到一件物件，能听见它上一个主人最后说的一句话；代价是每听一次，忘掉自己的一段记忆；边界留到 40 集以后再揭。

| 时间 | 段落 | 画面与声音 |
|---|---|---|
| 0–3 秒 | 规则露头 | 当铺学徒小禾摸到一把铜锁，耳边响起一个女人的声音"别开门"，她的手指僵住 |
| 3–15 秒 | 处境与代价 | 掌柜要她三天内估出一批来路不明的古董，不然当铺抵给钱庄；不用能力看不出真假，用一次就忘一段——她已经想不起母亲的脸 |
| 15–45 秒 | 赢第一小局 | 她摸出一件假货，当众揭穿钱庄的人，拿回当铺地契 |
| 45–70 秒 | 规则反咬 | 她忘了掌柜长什么样，把地契交给了冒充掌柜的钱庄打手 |
| 70–90 秒 | 对手还手 | 钱庄少东家拿着地契走进来，手里也有一把一样的铜锁——他是不是也听得见？ |

规则露头镜的动作时间轴与物理（节选）：

```text
【动作时间轴】镜头 1 —（0.0–4.0 秒）机位与构图锁定，特写小禾的右手与铜锁。0.5 秒 她的指尖碰到锁面；1.0 秒 画外一个女人低声说："别开门。"；1.6 秒 她的手指停住，指节发白；2.8 秒 她把手缓缓收回半寸，铜锁仍在原位。4.0 秒硬切。
【物理】铜锁表面有一层薄绿锈，指尖压过的地方留下一道亮痕；锁身沉，她收手时锁没有晃动。
【台词】画外女声（1.0–1.6 秒）："别开门。"画面里没有人说话，小禾嘴唇闭合。
```

最容易错的一处：用字幕解释"读物术"之类的名词。让观众看见她摸锁、听见声音、手停住，比任何字幕都清楚。
