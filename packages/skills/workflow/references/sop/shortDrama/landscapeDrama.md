# 横屏短剧

单集 5–20 分钟、集内有完整起承转合的横屏连续剧。和竖屏短剧的区别不在画幅，在一集是不是一个完整的故事单元。

## 一、适用 / 不适用

- 适用：横屏、单集 5–20 分钟、成系列（12–24 集中剧，或 30–80 集横屏短剧）；一集有自己的起承转合，不是 90 秒钩子的拼接。
- 不适用：单集 60–90 秒的钩子连续剧 → `portraitDrama.md`；二次元、国漫、日漫这类非写实画风、单集 60–120 秒 → `aiComicDrama.md`；非写实画风但单集 5 分钟以上，集结构按本文件，资产与画面口径按 `aiComicDrama.md`；企业、城市、产品形象片 → `promotionalVideos/`。
- **一句话判据：换到电视上连看两集，第二集还需不需要倒回去看？** 需要，是竖屏钩子剧的加长版，回 `portraitDrama.md`；不需要，才是集内完整的横屏短剧。

## 二、开工必问

一次一个，已知的跳过。

1. 一集多长：5–10 分钟，还是 10–20 分钟？——决定结构与成本。
2. 什么类型：悬疑、年代、古装、现实？——决定叙事节奏与资产路线。
3. 整季准备做多少集，先做前三集样集还是铺整季？——决定体量与排期。
4. 配音怎么出：模型原生音频，还是外部配音？——决定对白与混音方式。

答不上来落保守值：10 分钟、12 集、先做前三集、原生音频；类型问不出来就给两个具体题材让他挑，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单集时长 | 5–20 分钟，5–10 分钟最稳 | 常见单集 ≤ 20 分钟 |
| 集数 | 12–24 集，或 30–80 集 | 首季常见 12 集起 |
| 单集场次 | ≤ 6 场，单场说话人 ≤ 5 位 | |
| 条数 | 单集时长 ÷ 所选模型单次上限，向上取整 | 10 分钟按 30 秒上限约 20 条、按 15 秒上限约 40 条；按场拆条，不按镜拆条 |

## 四、结构

10 分钟单集：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 冷开场 | 0:00–0:40 | 0–6.7% | 先给一件已经发生的事的后果，人物在收拾残局；不解释前情 |
| 建置 | 0:40–2:30 | 6.7–25% | 谁要什么、谁挡着、他准备怎么拿；本集目标落地 |
| 第一次转折 | 2:30–4:30 | 25–45% | 办法失效或被对手反用；目标被迫改变 |
| 对抗升级 | 4:30–7:30 | 45–75% | 对手反制、代价加码；关系翻一次面 |
| 集末 | 7:30–10:00 | 75–100% | 小结算落地（得到或失去一样东西）+ 一个必须回答的问题 |

5 分钟版：冷开场 0:00–0:20，建置 0:20–1:10，一次转折 1:10–3:20，集末 3:20–5:00。20 分钟版：冷开场 0:00–1:00，建置 1:00–5:00，第一次转折 5:00–9:00，对抗升级 9:00–17:00（两段各 4 分钟），集末 17:00–20:00。

整季：1–3 集建置世界与主问题，每集一个独立小案；4–9 集对抗与翻面，每 2–3 集变一次关系或筹码；10–12 集收束主问题，留续订钩，但不新开一群新势力。

三条硬约束：单集 ≤ 6 场、单场说话人 ≤ 5 位；冷开场 40 秒内必须出现人；集末问题由本集的选择产生，不靠"下集预告"。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主要角色 | 5–8 | 是 | 双主角 + 关键对手必做；并排看轮廓与明度 |
| 群像 / 配角 | 按场次 | 分级 | 小群体给稳定标识；大群体只定允许出现的外观范围 |
| 场景 | 8–12（母版 + 子区域） | 核心 4–5 个 | 一条街、一栋楼先做母版，子区域从母版取 |
| 关键道具 | 5–8 | 视剧情 | 证据、凶器、信件、工牌；靠它传信息或翻局 |
| 年代 / 伤势变体 | 按集 | 否 | 换装、持续伤势、时间跳跃才建 |

载具与动物按道具规则做，给结构板，不给"氛围图"。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 先定 5–10 还是 10–20 分钟，再定集数与条数 | 规格表 |
| S1 | 整季三幕 → 前 3 集完整剧本 | 集纲 + 前三集剧本 |
| S2 | 角色、场景母版、关键道具盘点 | 资产表 + 场景关系图 |
| S3 | 核心 4–5 个场景和主要角色先做板并测试 | 已采用资产 |
| S4 | 按场拆条，长镜头单独标注 | 分场提示词 |
| S5 | 第 1 集整集跑通再批量 | 已采用片段 |
| S6 | 对白、音效、配乐、字幕 | 混音母版 |
| S7 | 按第八节逐集验收 | 成片 |

## 八、验收清单

- [ ] 单集 5–20 分钟；集数 12–24 或 30–80
- [ ] 条数与第三节一致；每条 3–5 镜
- [ ] 冷开场 40 秒内出现人，而且是一个后果，不是一段交代
- [ ] 单集有独立小结算：得到或失去一样具体的东西
- [ ] 单集 ≤ 6 场、单场说话人 ≤ 5 位，每场都有场景目标，没有纯过场
- [ ] 同框 5 人以上时，至少 3 人靠轮廓、服装、站位能分开
- [ ] 集末问题由本集的选择产生；下一集开头回应上一集的问题

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 节奏像加长版竖屏，信息过密 | 用 90 秒思维写 10 分钟 | 每场留一个反应或余波的节拍，允许人物停一下 |
| 单集 18 分钟，内容只有 6 分钟 | 用空镜和走路凑时长 | 砍到 8–9 分钟，或补一场真正的对抗 |
| 集末靠"下集预告" | 本集没有结算 | 把结算提前到 90% 处，最后 10% 只留问题 |
| 20 分钟版第 12 分钟塌 | 中段缺一次转折 | 中点补"办法失效"，集末结算推迟到 90% |
| 场景越拍越不像同一个地方 | 母版没定，每次重做 | 先做场景母版，子区域只取一部分 |
| 每场都在开会说话 | 冲突只靠对白 | 给每场一个可争夺的物件或位置：诱饵包裹、钥匙、座位 |
| 第 2 集开头又从头交代一遍 | 怕新观众看不懂 | 只重复一次起态，前情用一个物件带过 |
| 群戏站位每条乱跳 | 站位没写成常量 | 每场写一次空间地图与轴线，本场每条逐字粘贴 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："做一个老小区的悬疑剧，退休老刑警查案那种。"
- 落值：10 分钟、12 集、悬疑；单次上限按 15 秒算 → 一集约 40 条，按场拆。
- 一句话：第 1 集的小结算是"他拿回了怀表"，集末问题是"谁知道他亡妻的名字？"

| 时间 | 段落 | 这一集放什么 |
|---|---|---|
| 0:00–0:40 | 冷开场 | 凌晨，退休刑警老顾蹲在楼道里，把一地被拆开的快递盒翻过来看面单——这已经是第七次 |
| 0:40–2:30 | 建置 | 他要在周五业委会开会前找出拆快递的人，否则物业要装收费快递柜，楼里老人的代收点就没了；物业经理拦着；他的办法：在三楼放一个装着旧怀表的诱饵包裹 |
| 2:30–4:30 | 第一次转折 | 包裹没被拆，第二天却出现在他家门口，面单上写着他亡妻的名字——办法被反用 |
| 4:30–7:30 | 对抗升级 | 物业经理在业委会上说他老糊涂；独居的女邻居小林承认快递是她拆的，她在找一封寄错的信——两人关系翻面 |
| 7:30–10:00 | 集末 | 他拿回怀表（得到一样东西），怀表背面多了一行刻字；谁知道他亡妻的名字？ |

场次表（≤ 6 场）：1-1 夜·内 楼道 / 1-2 日·内 物业办公室 / 1-3 夜·内 三楼楼道 / 1-4 日·外 老顾家门口 / 1-5 日·内 业委会活动室 / 1-6 夜·内 小林家。

1-5 的空间常量（本场每条逐字粘贴）：

```text
业委会活动室：长桌东西向摆在房间中央，门在画面右侧墙上，两扇窗在左侧墙。老顾始终坐在长桌靠窗一侧，物业经理坐在靠门一侧，两人隔桌相距 1.5 米。相机始终在长桌南侧。日光从左侧窗户照进来，影子朝画面右方。
```

最容易错的一处：冷开场写成"老顾平常的一天"。冷开场要的是一件已经发生的事的后果。
