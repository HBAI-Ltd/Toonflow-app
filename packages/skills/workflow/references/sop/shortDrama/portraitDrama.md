# 竖屏短剧

一集 60–90 秒、一连几十集的竖屏连续剧，靠集集有钩让人想看下一集。判据只有一条：每一集结尾都留下一个人物自己闯出来、必须回答的问题。

## 一、适用 / 不适用

- 适用：竖屏、单集 60–90 秒、成系列（40–80 集）的真人或 AI 仿真人短剧；手上是小说、剧本或一个"爽点设定"，要拆成一集接一集的连续剧。
- 不适用：单集 5 分钟以上的横屏连续剧 → `landscapeDrama.md`；二次元、国漫、日漫这类非写实画风 → `aiComicDrama.md`（看画风，不看是不是 AI 生成）；静帧加位移 → `motionComic.md`；只有一条、目的是让人知道或买 → `promotionalVideos/`、`ecommerceAds/`。
- **一句话判据：相邻两集能不能对调？** 能对调，你写的是单元剧，去 `episodicSitcom.md`；不能对调，才按本文件做连续钩。

## 二、开工必问

一次一个，答完再问下一个，已知的跳过。

1. 一集多长、总共多少集？——决定条数与制作量。
2. 主角现在什么处境、最怕失去什么？——决定开场钩子立不立得住。
3. 对手拿什么压着他、第一集结束想让人爽还是悬着？——决定首集冲突走向。
4. 配音怎么出：模型原生音频，还是外部 TTS 或真人？——决定口型镜的写法。

问两次还是"都行"，落保守值：90 秒、60 集、原生音频，说明可推翻；主角处境与冲突方向问不出来，给两版具体的让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单集时长 | 60–90 秒 | 90 秒是常用档 |
| 集数 | 40–80 集 | 前 3 集定留存；先做前 3 集再决定铺满 |
| 单集场次 | ≤ 3 场、出场 ≤ 3 人 | 观众不用记第四个人 |
| 条数 | 单集时长 ÷ 所选模型单次上限，向上取整 | 算法见方法论 [分段与装配](../../methods/segmentationAndAssembly.md) 二；先定条数再写剧本 |

## 四、结构

90 秒单集：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 开门 | 0–3 秒 | 0–3.3% | 一句台词或一个动作把人物推进冲突；不交代背景、不打字幕卡 |
| 三连钩 | 3–12 秒 | 3.3–13.3% | 三次信息递进：身份翻一次、动机翻一次、关系翻一次 |
| 升级 | 12–45 秒 | 13.3–50% | 对手加码；主角第一次用错办法，付出可见代价 |
| 峰值 | 45–75 秒 | 50–83.3% | 被逼到边缘，做出一个会改局面的选择 |
| 切断 | 75–90 秒 | 83.3–100% | 在冲击点切，不在余韵点切；留一个必须回答的问题 |

60 秒版按同一占比：0–2 / 2–8 / 8–30 / 30–50 / 50–60 秒，段落任务不变。

系列层：第 1 集前 30 秒交代处境、规则、代价；每 5–10 集一次中结算（赢一局或失去一样东西）；最后一集回答主问题，不新开谜。集尾钩型轮换：身份逆转、绝境、隐藏身份、倒计时、揭露。

三条硬约束：单集出场 ≤ 3 人；每 15 秒至少一次信息变化（身份、动机、关系、筹码）；集末问题由人物自己闯出来，不靠来电、昏迷、巧合。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主角 | 1 | 是 | 四视图 + 无表情特写 + 微笑特写 |
| 对手 | 1 | 是 | 与主角并排看轮廓、体量、明度能否分开 |
| 常驻配角 | ≤ 2 | 否，有旧图就复用 | 只在对白里出现的不做 |
| 主场景 | 3–5 | 是（母版） | 家、公司或店、街、医院或餐厅；不同时段记状态，不重做 |
| 关键道具 | 2–3 | 视剧情 | 证据、信物、手机；靠它传信息或触发事件才做 |
| 服装与伤势变体 | 按集 | 否 | 从上一状态改，新状态独立命名 |

全部画面由生成完成；事实类画面（证件、通报、检测读数）出现时按真实样式做，不编造可被当真的信息。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定单集时长、集数；按第三节算条数 | 一页规格表 |
| S1 | 先写分集表，再写前 3 集剧本；不按章号切 | 分集表 + 前 3 集剧本 |
| S2 | 只列会复用的；单集新出场的人不进素材库，跨两条以上出镜的做一张单集参考图 | 资产表（含状态与出处） |
| S3 | 主角、对手、主场景三张板先做，测试通过再开工 | 已采用资产 |
| S4 | 一集按条数切，集末镜单独一条 | 每集提示词 |
| S5 | 第 1 集全流程跑通再批量；跨条按方法论重写光向、服装、伤势 | 已采用片段 |
| S6 | 配音、音效、字幕 | 混音版 |
| S7 | 按第八节逐集验收 | 成片 |

## 八、验收清单

- [ ] 单集 60–90 秒；条数与第三节算法一致
- [ ] 前 3 秒有冲突或一句强台词，没有风景、没有字幕卡
- [ ] 每 15 秒至少一次信息变化
- [ ] 单集 ≤ 3 场、出场 ≤ 3 人
- [ ] 集末切在冲击点，问题由人物自己闯出来
- [ ] 单句台词 ≤ 38 字，配音有换气空间
- [ ] 每条 3–5 镜、每镜 4–8 秒，切点写绝对秒数
- [ ] 字幕不遮脸、不压底部与右侧边缘
- [ ] 跨集连续：服装、伤势、道具状态、光向至少三项核对过

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 前 3 秒是城市空镜 | 按宣传片思维开场 | 换成人物正在做的动作，第一句台词就是冲突 |
| 90 秒里塞了 3 分钟信息 | 把一集写成一场完整戏 | 砍到一件事：一个目标、一个阻力、一次反转 |
| 反转靠巧合或来电 | 没提前埋筹码 | 补对手的筹码和主角的办法（故事与剧作 三） |
| 每集钩子长得一样 | 只用一种钩型 | 五种钩型轮换 |
| 竖屏里全是大远景 | 沿用横屏景别 | 改中近景，用前后景关系代替横向信息 |
| 集末"满意收尾" | 切晚了 | 在冲击点切断，宁可少 5 秒 |
| 人物超过 3 个记不住 | 群像没分级 | 合并功能相同的角色，或把一人降成"只被提到" |
| 开门那句 3 秒说不完 | 台词太长 | 开门台词压到 12 字以内，动作先于台词 |
| 第 8 集前后大量流失 | 一直加压不结算 | 每 5–10 集让主角赢一局或失去一样东西 |
| 主角一直被欺负没有反击 | 只写压制不写办法 | 每集给主角一个有限资源下的办法，哪怕这次失败 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："想做个复仇爽剧，女主被赶出家门，后来回来打脸。"
- 落值：90 秒、60 集；所选模型单次上限按 15 秒算 → 一集 6 条，集末镜单独一条。
- 一句话：第 1 集的集尾问题是"遗嘱上那个签名是谁签的？"

| 时间 | 段落 | 画面与声音 |
|---|---|---|
| 0–3 秒 | 开门 | 灵堂门口，继母把女主的行李箱踢出门槛："这个家没你的位置。" |
| 3–12 秒 | 三连钩 | 身份翻：她亮出律所工牌，她是这桩遗产案的代理律师；动机翻：她不是来闹，是来查父亲的死因；关系翻：继母身边站着的是她前未婚夫 |
| 12–45 秒 | 升级 | 继母当众宣读遗嘱，全部财产归继子；她当场质疑笔迹（第一次用错办法），被众人推出灵堂，手腕被门框划破 |
| 45–75 秒 | 峰值 | 她回到灵堂，在父亲遗像前拿出一支旧录音笔——公开，还是私下拿去要挟继母？她按下播放键 |
| 75–90 秒 | 切断 | 录音里父亲说"遗嘱我还没签"，切在继母脸色变的那一下 |

第 1 条提示词的开头（Seedance，节选）：

```text
【场景背景】傍晚灵堂门口，继母把女主的行李箱踢出门槛。这一条要交付：她被赶出门，却亮出律所工牌。
【拍摄模式】3 镜。0.0 秒开始，4.0 秒、9.5 秒处硬切，总长 15 秒。
【开场状态】镜头 1：女主站在门槛外，画面右三分之一，左手握着行李箱拉杆；继母站在门槛内，画面左三分之一，右脚已贴着箱子侧面。所有主体已就位，之后不再有人入画。
【动作时间轴】镜头 1 —（0.0–4.0 秒）机位与构图锁定。0.5 秒 继母右脚一蹬，箱子滑出门槛；0.8 秒 继母："这个家没你的位置。"；2.6 秒 箱子撞上女主小腿停住，她低头看了一眼，没有后退。4.0 秒硬切，切在她抬眼的那一帧。
```

最容易错的一处：开头写成灵堂全景或葬礼铺垫。第一秒就要是踢箱子这个动作。
