# 动态漫

用**静帧 + 确定性的图层运动**做的漫画视频：分格推进、推拉摇移、局部动效（眨眼、发丝、口型）、配音与字幕。成本在"画"和"排"，不在"生成"。

## 一、适用 / 不适用

- 适用：已有漫画、条漫、IP 插画要视频化；或预算周期不足以做连续生成。单集 60–90 秒、成系列的竖屏连载。
- 不适用：需要连续表演、大运动、打斗长镜头 → `aiComicDrama.md`；真人实拍 → 不按本文件；单条品牌、产品、城市片 → `promotionalVideos/`。
- **一句话判据：画面里有没有"从 A 动到 B"的连续过程？** 只有缩放、位移、图层视差，按本文件；有角色完成一整段连续动作，去 `aiComicDrama.md`。

## 二、开工必问

一次一个。

1. 画面素材从哪来：手上已有漫画或插画，还是要新画？——决定工作量与一致性基线。
2. 单集多长、多少集？——决定分格密度与产能。
3. 动效做到哪一级：微动（呼吸、发丝）、中动（推拉 + 局部），还是接近动画？——决定成本与失败率。
4. 配音怎么出：TTS、真人，还是先无声看节奏？——决定口型与停顿。

答不上来落保守值：新画、60 秒、中动、TTS，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单集时长 | 60–90 秒 | 60 秒是底线 |
| 分格 | 一格 3–5 秒；60 秒 12–20 格、90 秒 18–30 格 | 格数 = 单集时长 ÷ 格长；任何一格超过 6 秒，必须靠运镜或对白撑住 |
| 台词 | 单集 ≤ 12 句，一句一格 | |

## 四、结构

60 秒单集：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 定帧钩 | 0–2 秒 | 0–3.3% | 一张信息量最大的画：人物在冲突现场，不是风景 |
| 三格推进 | 2–10 秒 | 3.3–16.7% | 三格三句台词，每格换一次信息（谁、要什么、被什么挡着） |
| 对话与动效 | 10–40 秒 | 16.7–66.7% | 每 3–5 秒一次画面变化（换格、推拉、局部动），台词推进冲突 |
| 反转定格 | 40–52 秒 | 66.7–86.7% | 一格大画，把前面的理解翻一次 |
| 集末 | 52–60 秒 | 86.7–100% | 一句台词或一个动作留下必须回答的问题 |

90 秒版按同一占比：0–3 / 3–15 / 15–60 / 60–78 / 78–90 秒。

系列层：第 1 集 10 秒内让人看懂"这是什么规则、什么关系"；每 5 集一次小结算；最后一集回答主问题。

三条硬约束：每 3–5 秒必须有一次画面变化；单集台词 ≤ 12 句，一句一格；集末停在一句没说完的话或一个动作上。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主角设定 | 1 套 | 是 | 三视图 + 6–9 张表情（喜、怒、悲、惊、尬、冷、笑、哭） |
| 配角设定 | 2–3 | 是 | 靠发色、轮廓、服装色块区分 |
| 场景 | 3–5 | 是（分层） | 每张拆前景、中景、背景三层，供视差与推拉；固定一个 3/4 视角 |
| 道具 | 2–4 | 视剧情 | 证据、信物、手机界面；要能单独动 |
| 动效素材 | 按格 | 否 | 眨眼、口型、发丝、雨雪、光斑，各 2–3 帧循环 |

**分层是硬要求**：不拆层只能整张推拉，做不出视差，观众会觉得是 PPT。生成只用在资产图和少数局部动效镜（雨、烟、光）；画面运动靠合成参数，不靠视频生成。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定动效等级与单集格数 | 规格表 + 格数表 |
| S1 | 分格脚本 | 分格表（格号、时长、台词、动效） |
| S2 | 先盘已有素材，能复用不新画；表情不够先补 | 资产表 + 缺口清单 |
| S3 | 主角三视图、表情、3–5 张分层场景 | 已采用资产 |
| S4 | 每格动效参数；少数局部动效镜写提示词 | 动效参数表 |
| S5 | 按参数合成；局部动效镜生成后叠入 | 合成片 |
| S6 | 配音、对口型、字幕、音效 | 混音版 |
| S7 | 按第八节验收 | 成片 |

## 八、验收清单

- [ ] 单集 60–90 秒；60 秒 12–20 格、90 秒 18–30 格
- [ ] 每格 3–5 秒，无一格超过 6 秒；每 3–5 秒有一次画面变化
- [ ] 单集台词 ≤ 12 句，一句一格；单句 ≤ 38 字
- [ ] 前景、中景、背景层次正确，推拉时不错位、不切边
- [ ] 角色跨格一致：发色、瞳色、服装、疤痣位置
- [ ] 对白优先，配乐压在对白下面；口型和停顿与配音对得上
- [ ] 字幕不遮脸、不压底部与右侧边缘

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 像 PPT，一张图停 10 秒 | 格数太少、没做动效 | 补到规格格数，每格给推拉或局部动 |
| 动效太大，像幻灯片切换 | 位移、缩放过量 | 单格位移 ≤ 画面 8%、缩放 1.0→1.15 以内，用缓动不用线性 |
| 图层切边、错位 | 分层时没对齐 | 用同一构图导出三层，边缘各留 5% 余量 |
| 配音比画面快 | 先做画面后配音 | 先定配音时长，再排格 |
| 表情不够用，全靠台词 | 表情没做够 | 先补 6–9 张表情，再分格 |
| 背景透视和角色对不上 | 场景不是同一视角 | 场景固定一个 3/4 视角，角色按这个视角摆 |
| 90 秒版后半段拖 | 格数照 60 秒版抄 | 按 18–30 格重排，多出的格给反转与集末 |
| 雨雪特效遮住脸 | 粒子层压在角色层之上 | 粒子放到角色层之后，或避开脸部区域 |
| 同一角色每格大小忽大忽小 | 没定角色在画面里的尺度 | 每种景别定一个角色高度占比，全集沿用 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："我有一部自己画的条漫，想做成竖屏动态漫。"
- 落值：已有条漫、60 秒、中动、TTS；60 秒按一格 3–5 秒排 15 格。
- 一句话：第 1 集结束时的问题是"门后那个人为什么认得这只猫？"

分格表（节选）：

| 格号 | 时间 | 台词 | 画面任务 | 动效参数 |
|---|---|---|---|---|
| 01 | 0–2 秒 | — | 定帧钩：雨夜，外卖员抱着一只湿透的猫站在陌生人家门口 | 缩放 1.00→1.06，缓出，雨丝层循环 |
| 02 | 2–5 秒 | "这是你家的猫吗？" | 门开一条缝 | 门板层横移 3%，缓入缓出 |
| 03 | 5–8 秒 | "它叫豆豆。" | 门缝里露出半张脸 | 角色层上移 2%，眨眼 2 帧 |
| 04 | 8–10 秒 | "可它三年前就丢了。" | 猫的眼睛特写 | 缩放 1.10→1.15，瞳孔层轻微放大 |
| …… | | | | |
| 11 | 40–52 秒 | "那天送它走的人，是你。" | 反转定格：一格大画，墙上贴着外卖员三年前的照片 | 视差：前景门框 4%，背景墙 1% |
| 15 | 57–60 秒 | "你……" | 集末：外卖员后退半步，雨伞掉在地上 | 雨伞层下落 6%，停住不循环 |

最容易错的一处：反转那一格塞两句台词。一句一格，第二句挪到下一格。
