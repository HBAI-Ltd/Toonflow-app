# 单元情景剧

每集一个独立故事，观众随便挑一集都能进来。撑住一整季的是**固定人物 + 固定空间 + 固定规则**，不是一条主线。

## 一、适用 / 不适用

- 适用：情景喜剧、家庭单元剧、职场单元剧、志怪民俗单元剧（一事一单元）。一季 10–20 个单元，一个单元 1–3 集；目的是让人笑着（或疼一下）看完，下一集还愿意来。
- 不适用：有主线贯穿、必须按顺序看 → `portraitDrama.md` / `landscapeDrama.md`；有分支要观众选 → `interactiveDrama.md`；静帧加位移 → `motionComic.md`；一集只讲一个知识点 → `educationalVideos/scienceExplainer.md`。
- **一句话判据：把任意一集抽掉，整季还成立吗？** 成立才是单元剧；不成立就是连续剧。

## 二、开工必问

一次一个，已知的跳过。

1. 固定下来的是什么：**一个空间**（家、办公室、小店）、**一组人**，还是**一条规则**（每集来一件邪物、一个客人、一桩投诉）？——这是整季的"单元引擎"，定不下来别写第二集。
2. 一集多长、一季几个单元？——决定每个单元能装几场、要备多少道具。
3. 这一集结束，**什么变了一格**：关系、位置，还是信息？——只把事办完、什么都不变的单元，观众记不住。
4. 观众在哪一下笑出来（或疼一下）？——说不出来就还没有戏，只有情节。

问两次还是"都行"，落保守值：单集 4 分钟、一季 12 个单元，说明可推翻；单元引擎与情绪落点问不出来，给两版具体的让他挑。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单集时长 | 3–5 分钟，主推 4 分钟 | 全季一套时长 |
| 单元 / 集数 | 一季 10–20 个单元，一个单元 1–3 集 | 一个单元讲完一件事，不留跨集主线 |
| 单集场次 | ≤ 3 场，同一固定空间 | 场次一多，固定空间的红利就没了 |
| 固定场景 | 一季 1–2 个主场景母版 | 换地点＝换一季，不是换一集 |
| 条数 | 单集时长 ÷ 所选模型单次上限，向上取整 | 条数决定排期，不决定结构 |

## 四、结构

一集 4 分钟：

| 段落 | 时长 | 占比 | 这一段要完成什么 |
|---|---|---|---|
| 冷开场 | 0:00–0:20 | 0–8.3% | 直接进一件反常的事；不上集回顾、不解释人物关系、不打剧名卡 |
| 单元问题成立 | 0:20–0:50 | 8.3–20.8% | 谁想要什么、谁不让、为什么偏偏今天；不用记前情也跟得上 |
| 试错两轮 | 0:50–2:40 | 20.8–66.7% | 两个办法各失败一次；每次失败改掉一样东西（筹码、信息、位置） |
| 结算 | 2:40–3:40 | 66.7–91.7% | 有人付了代价、关系变了一格；笑点和痛点都落在动作上 |
| 回稳态留钩 | 3:40–4:00 | 91.7–100% | 空间复原到开场状态，留一件"这一集才知道的事" |

3 分钟版：0:00–0:15 / 0:15–0:45 / 试错一轮 0:45–1:55 / 1:55–2:45 / 2:45–3:00。5 分钟版：0:00–0:25 / 0:25–1:00 / 1:00–3:30 / 3:30–4:40 / 4:40–5:00。

**系列层靠三样**：固定搭配（一组人怎么凑在一起，这是观众回来的理由）；运行规则（每单元按同一逻辑启动，能写在一张卡片上，如"邪物出现 → 欲望冲突 → 因果闭环"）；内容土壤（一类能持续长出新故事的题材资源，土壤不够，第 6 集就开始重复）。

三条硬约束：单集 ≤ 3 场；一季固定场景 1–2 个；笑点、痛点落在可见动作或物件上，不靠台词解释"这很好笑"。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 核心人物 | 3–4 | 是 | 四视图 + 无表情 / 微笑两张特写 |
| 常驻配角 | ≤ 3 | 否，有旧图复用 | 每单元只出现一次的不做板 |
| 固定空间 | 1–2 | 是（空间母版） | 子区域靠母版取，不另起一张 |
| 单元道具 | 每集 1 件 | 是 | 这一集的笑点、痛点靠它落地 |
| 临时人物 | 每集 ≤ 2 | 否 | 只服务这一集，不进资产表 |
| 服装变体 | 每单元可换 | 从上一状态改 | 轮廓、体量、识别物不变 |

钱花在反复出现的三样上（人、空间、规则道具），不花在每集新景。事实类画面（证件、通报、检测读数）出现时不编造可被当真的信息。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 先定单元引擎，再定单集时长与单元数 | 规格 + 引擎卡片 |
| S1 | 5 个单元的一句话 → 首单元剧本；不写跨集主线 | 单元表 + 首单元剧本 |
| S2 | 只立反复出现的三样；临时人物与单元道具各归各集 | 资产表（含复用范围） |
| S3 | 空间母版与核心人物先做 | 已采用资产 |
| S4 | 每集从空间母版起手，只换道具与临时人物；末镜单独一条 | 每集提示词 |
| S5 | 跑满一个单元再批量 | 已采用片段 |
| S6 | 环境声、静默拍、字幕 | 混音母版 + 字幕 |
| S7 | 按第八节验收，乱序抽集连看 | 成片 |

## 八、验收清单

- [ ] 单集 3–5 分钟；一季 10–20 个单元
- [ ] 乱序抽 3 集连看，每集都能独立看懂
- [ ] 开场 20 秒内进入反常事件，没有风景、没有字幕卡
- [ ] 单集 ≤ 3 场，场场在固定空间；同一扇窗、同一张桌、同一盏灯至少有一个在画
- [ ] 单元结束时至少变了一格（关系、位置、信息）
- [ ] 笑点、痛点落在可见动作或物件上，遮住台词仍成立

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 看到第 4 集像连续剧的下半段 | 把跨集主线当成留存手段 | 每集重写冷开场，前情只留一件物或一句话 |
| 每集都靠同一个笑点 | 单元引擎只有一个梗 | 换规则不换人物：加一条"这一集才生效的规矩" |
| 固定空间拍成了好几个房间 | 空间地图没做成常量 | 回到空间母版，锁死出入口、主活动区、稳定地标 |
| 结尾强行升华 | 怕观众没看懂 | 换成一件具体的事：谁把东西放下了、谁先走了 |
| 4 分钟塞了 10 分钟信息 | 把完整故事压成一集 | 砍到一个目标、一个阻力、一次结算 |
| 一季越拍越像模板 | 内容土壤不够 | 回 S1 补题材土壤，缺土壤就缩季数 |
| 第 2 集就要观众记人名 | 配角功能重叠 | 每人只留一个可见标签，超过 3 个就合并 |
| 固定人物每集一个样子 | 只靠口头禅区分 | 同一个人用同一套办法处理每集的事，有时成、有时砸 |
| 临时人物抢了主角的戏 | 单元问题落在客人身上 | 客人带来问题，解决问题的必须是固定人物 |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："想做个暖一点的单元剧，每集一个小故事，在一个修车铺里。"
- 落值：4 分钟一集、一季 12 个单元；单元引擎：固定空间（小区门口的修车铺）+ 固定的人（老板老周、学徒阿杰、隔壁奶茶店店主）+ 规则（每集来一辆"有故事的车"）。
- 一句话：这一集变了一格的是"修车铺和奶茶店的关系松了一点"。

| 时间 | 段落 | 画面与声音 |
|---|---|---|
| 0:00–0:20 | 冷开场 | 一个穿西装的男人把一辆旧轿车推进铺子，后备箱一路弹开、合上、又弹开 |
| 0:20–0:50 | 单元问题成立 | 他要在下午三点前修好后备箱锁——婚礼要用这辆车去接新娘，车是他父亲留下的；老周说这锁的零件早停产了 |
| 0:50–2:40 | 试错两轮 | 阿杰网上买到"同款"锁，装上发现钥匙对不上，只剩一小时；老周想拆奶茶店冰柜的锁芯改装，店主不肯，两家第一次翻脸 |
| 2:40–3:40 | 结算 | 老周用一根鞋带把后备箱系死，打了个蝴蝶结；新郎看着结笑了，他父亲当年也这么系过 |
| 3:40–4:00 | 回稳态留钩 | 铺子恢复原样，半截鞋带挂在工具墙上；奶茶店店主隔着门问能不能借把钳子 |

空间常量（全季每条逐字粘贴）：

```text
修车铺：卷帘门朝南，开在画面右侧；门内 3 米是举升机；左墙整面是工具墙，挂满扳手和一卷旧鞋带；后墙一扇小窗正对奶茶店的后门。午后阳光从卷帘门斜照进来，影子朝画面左后方。
```

最容易错的一处：笑点写成台词抖机灵。这一集的笑点和痛点都在那根鞋带上，遮住台词也成立。
