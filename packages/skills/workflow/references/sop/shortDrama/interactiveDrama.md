# 互动剧

观众在播放中做选择、选完立刻看到不同后果的剧：主干 + 选择节点 + 若干结局。分支必须承重，不是把一条线剪成几段。

## 一、适用 / 不适用

- 适用：互动剧（剧情自然发展、交互弱）与互动影游（选择驱动、交互强、可带解谜）。
- 不适用：只有一条线 → 按体量走 `portraitDrama.md` / `landscapeDrama.md`；只是弹幕吐槽、评论区投票、不改剧情 → 单元剧或竖屏短剧，别套互动壳；操作、关卡、数值成长是主体的小游戏 → 超出本 skill，先划边界。
- **一句话判据：把"选择"删掉，故事还完整吗？** 完整，互动是装饰；不完整，分支才承重。

**先定一件事**：做互动剧还是互动影游。两者的节点密度、制作量都不一样，中途改就是重做。

## 二、开工必问

一次一个，已知的跳过。

1. 观众什么时候做选择：**一个**关键抉择，还是每 1–2 分钟一次？——决定互动剧还是互动影游，也决定成本。
2. 主干多长、每个结局多长？——由此算出单条路径、分支总时长、结局数，缺一个就估不出钱。
3. 这个选择的**代价**是什么：失去谁、失去什么、暴露什么？——没有代价，观众选哪个都无所谓。
4. 分支要"换一条路"还是"换一个结果"？——换路要重做整套素材，换结果只多做一段。

问两次还是"都行"：做互动剧还是互动影游，各说一句会是什么样让他挑；其余落保守值：主干占比 ≥ 70%、3 个结局、单条路径 ≥ 30 分钟，说明可推翻。

## 三、规格

| 项 | 出发值 | 备注 |
|---|---|---|
| 单条路径时长 | ≥ 30 分钟 | 走完一个结局的时长 |
| 分支总时长 | 所有分支段相加 ≥ 60 分钟 | 与单条路径是两个数，别混算 |
| 主干占比 | ≥ 70% | 共用段 ÷ 单条路径时长；分叉越晚，这个数越高 |
| 节点时长 | 10–30 秒 | 讲清一个动作或一句关键台词 |
| 单次选择 | 2–3 个选项 | 超过 3 个，观众开始瞎点 |
| 结局数 | 3–6 个 | 所有结局回答同一个问题 |

**先算钱再写剧本**：物理总长 = 主干 + 各分支独有段之和。例：主干 30 分钟 + 3 个结局各 10 分钟独有段 = 物理总长 60 分钟；单条路径 40 分钟；主干占比 30 ÷ 40 = 75%。一条分支多 30 秒，整部多出的是 30 秒乘以分支数。

## 四、结构

30 分钟主干：

| 段落 | 时间轴 | 占主干 | 这一段要完成什么 |
|---|---|---|---|
| 冷开场 | 0:00–1:00 | 0–3.3% | 一个"马上要出事"的具体处境，让人知道自己在替谁做决定 |
| 处境成立 | 1:00–3:00 | 3.3–10% | 谁想要什么、谁拦着、代价是什么；答不完，后面全是瞎选 |
| 主干推进 | 3:00–26:00 | 10–86.7% | 事件与信息并行；每 60–90 秒一个"这件事还没完"的钩；每 3–5 分钟一个选择节点 |
| 收束 | 26:00–30:00 | 86.7–100% | 汇合到主问题；留一句"如果当初选另一个"的回味，再进结局 |

分叉层（不计入主干占比）：

| 段落 | 时长 | 这一段要完成什么 |
|---|---|---|
| 选择节点 | 每 3–5 分钟一次（互动影游 1–2 分钟） | 节点前 3 秒把代价摆出来；选项文案只写动作，不剧透结果 |
| 分叉段 | 每个分叉点 30 秒–3 分钟 | 每条只改一个变量：一个人、一件物、一句台词、一个空间角落 |
| 结局 | 每条 30–60 秒 | 回答同一个问题；每个结局都能独立看懂 |

省钱的分叉策略：选择放中段（放开头观众对人物没感觉，放结尾看不到后果）；结局只在最后分叉；节点长度按"讲得清、留得住"定，不平均分配。

三条硬约束：不能有死路；不能有假分支（选 A 和选 B 不能看到同一段）；每个节点都能独立看懂。

## 五、资产清单

| 类型 | 数量 | 必须做板 | 说明 |
|---|---|---|---|
| 主干人物 | 2–4 | 是 | 含"常态 + 关键变体" |
| 分支专属人物 | 每条 0–1 | 否 | 只在那条分支出现，不做板 |
| 主干空间 | 1–3 | 是（母版） | 分支共用母版，只换角落与陈设状态 |
| 分支空间变体 | 按分支数 | 从母版改 | 只改一处（门开、灯灭、桌子挪了） |
| 关键道具 | 2–3 | 是 | 分支的变量多半落在道具上：信在谁手里、杯子碎没碎 |
| 选择界面素材 | 1 套 | 否 | 选项卡、倒计时、返回、重看；后期做，不进生成 |

资产表多一栏"分支"：哪个资产被哪几条分支引用，一眼看出复用率。

## 七、制作流程

| 阶段 | 本类目做什么 | 产出 |
|---|---|---|
| S0 | 定互动剧还是互动影游、单条路径、分支总时长、结局数；算制作量 | 规格 + 成本估算 |
| S1 | 节点树：主干节点、选择点、分支、汇合点、结局，逐条编号；再写剧本 | 节点树 + 分支结构表 + 剧本 |
| S2 | 按分支列复用表；先算哪条分支最贵 | 资产表（含分支引用） |
| S3 | 主干人物与主干空间先做 | 已采用资产 |
| S4 | 主干镜写全；分支镜只写"改哪一处 + 保留哪些项" | 分支编号的提示词（S01-A…） |
| S5 | 主干 → 最贵分支 → 其余 | 已采用片段 + 拼接线表 |
| S6 | 选择反馈音、分支音效、字幕 | 混音母版 + 分支音效表 |
| S7 | 按第八节逐节点验收 | 成片 + 分支结构表 |

## 八、验收清单

- [ ] 把"选择"删掉后故事不成立
- [ ] 单条路径 ≥ 30 分钟，主干占比 ≥ 70%；分支总时长 ≥ 60 分钟
- [ ] 结局 3–6 个，回答同一个问题；每个节点 10–30 秒
- [ ] 每个选择节点前 3 秒能看到代价，选项 2–3 个且不剧透结果
- [ ] 没有死路，没有假分支
- [ ] 分支段与主干段同一张脸、同一件衣、同一间屋、同一光向
- [ ] 每个节点能独立看懂

## 九、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 观众选完没感觉 | 选择放在结尾，看不到后果 | 前移到中段，选完立刻播不同的下一段 |
| 分支越做越像两个故事 | 分叉太早，共用段太少 | 把分叉往后挪 |
| 选 A 选 B 看到同一段 | 假分支 | 至少改一样可见的东西 |
| 补做的分支一眼看得出 | 光向和空间没抄主干 | 分支镜先抄主干镜的空间与光，再改变量 |
| 成本失控 | 只算总时长没算分支独有段 | 按"主干 + 分支数 × 独有段"估，先做最便宜的结构 |
| 三个结局只是换了句台词 | 结局没换代价 | 每个结局换一个"失去的东西"，用画面交代 |
| 节点短到看不懂 | 按平均时长切节点 | 每个节点给 10–30 秒，先保证一句台词或一个动作讲完 |
| 汇合点接不上 | 两条分支结束时人物位置、持物不同 | 汇合前写死同一个起态，两条分支都落到它 |
| 选项文案剧透了结果 | 写成"报警后真相大白" | 选项只写动作："打 110" / "先翻监控" |

## 十、示例

示例只演示用法，不是模板，项目内容按实际写。

- 需求："想做个互动剧，让观众帮女主决定要不要报警。"
- 落值：互动剧（交互弱）；主干 30 分钟，3 个结局各 10 分钟独有段 → 物理总长 60 分钟，单条路径 40 分钟，主干占比 30 ÷ 40 = 75%。
- 一句话：三个结局都回答同一个问题——"她最后还住不住在这里？"

节点树（节选）：

```text
S01 主干 0:00–4:00  她下班回到合租屋，发现门锁被撬，自己的抽屉被翻过
N1  选择节点 4:00（20 秒）  代价先摆出来：报警就要交出房东违规合租的证据，自己也可能被赶走
    A "打 110"      → S02-A 独有段 2 分钟：民警上门，房东当场翻脸
    B "先翻监控"    → S02-B 独有段 2 分钟：她在楼道监控里看见室友的男朋友
    A、B 都落到同一个起态：她坐在楼道台阶上，手机屏幕亮着，室友从楼下上来 → 汇合 M1
M1  主干 4:20–8:30 ……
N2  选择节点 8:30 ……（之后每 3–5 分钟一个节点）
E1 / E2 / E3  结局各 10 分钟，都回答"她还住不住在这里"
```

最容易错的一处：两条分支结束时她一个在家、一个在派出所，汇合点接不上。分叉前先定好汇合时的起态。
