# 资产图提示词结构

角色板、场景图、道具板的提示词模板与槽位。只管模板与槽位，不管哪些东西该做成资产。

## 一、通用约定

| 项 | 规则 |
|---|---|
| 首槽 | 句首固定放 `{画风文字}`（`AGENTS.md` 里 `## 画风` 原样全文），再接资产类型与主体；一个文件放几张，每张都从画风全文起，不写“同上” |
| 占位符 | `{…}` 必填；标"有真实参考才填写"的行，没有参考就整行删掉 |
| 参考 | `{{ref N}}`，只写真实存在的参考 |
| 生成参数 | 模型、比例、分辨率在平台设置；参考模式按实际能力选 |
| 文字与标注 | 除剧情需要保留的实际文字或图案外，不写说明字、水印、尺寸标注 |
| 画面里的号码 | 电话、车牌、门牌、楼号、单号照剧情写，写法和资产表、剧本一致 |
| 单集人物 | 只为跨两条以上片段出镜的单集人物出图，命名带集号（如“客户-第1集”），不入素材库 |
| 篇幅 | 一个资产一个目标，中文约 150–300 字 |

## 二、版式（新建时的默认）

| 资产 | 版式 |
|---|---|
| 角色 | 一张横排参考板：头部特写、正面全身、右侧 90° 全身、背面全身 |
| 场景 | 一张空间主视图：前、中、后景，宽的 3/4 视角 |
| 道具 | 一张 2×2 参考板：左上正面、右上右侧 90°、左下背面、右下局部细节 |

用户已确认的版式、够用的旧图优先沿用。多视图始终是同一个主体，各视角的结构、材质、尺寸关系、状态一致。

## 三、角色参考板

```text
{画风文字}角色参考板，同一角色为{名称、身份或物种、年龄或生长阶段}。
外观锚点：{轮廓、体型、头部特征、表皮或毛发、配色、服装及必要识别物}。
同一画面横向排列：头部特写、正面完整全身、右侧90°完整全身、背面完整全身。
各视角身份与状态一致，全身尺度一致，完整保留{适用身体结构}，不裁切、不重叠。
{自然静态姿态}，中性表情，双手空着，{符合画风的简洁背景与均匀柔和的光照或平涂方式}，没有边缘光。
{有真实参考才填写：使用 {{ref N}} 的某身份与状态，仅改变哪些已确认内容，保留哪些部分。}
保留已确认服装、徽记等必要文字或图案；无剧情场景、额外角色、手持道具、动作过程、无关说明字、水印或尺寸标注。
```

| 序 | 槽 | 内容 |
|---|---|---|
| 1 | 画风 + 身份 | 画风文字；名称、身份或物种、年龄或生长阶段 |
| 2 | 外观锚点 | 轮廓、体型、头部特征、表皮或毛发、配色、服装、必要识别物 |
| 3 | 版式 | 四视图横向排列 |
| 4 | 一致性 | 身份与状态一致、全身尺度一致、完整保留身体结构、不裁切不重叠 |
| 5 | 姿态与背景 | 自然静态姿态、中性表情、双手空着、背景与光照，无边缘光 |
| 6 | 参考（条件） | `{{ref N}}` 来源、改变的项、保留的项 |
| 7 | 保留与排除 | 保留服饰徽记；排除剧情场景、额外角色、手持道具、说明字、水印 |

版式约束：特写保留完整头部到锁骨附近；三个全身视角保留头顶、身体、四肢、脚，不裁头、不截身、不切脚；视图互不遮挡。需要无表情 + 微笑两张特写时，另出一张，写明"同一副牙齿与下颌"。

## 四、场景主视图

```text
{画风文字}场景主视图：{场景名、室内外、地理或建筑类型、时段与天气}。
前景{进入空间的元素}；中景{主要活动区与固定物件}；后景{边界及远处结构}。
空间关系：{出入口、通道、稳定地标及必要的相对位置}，保留{剧情所需活动空间}。
材质与视觉：{材质、配色、真实表面痕迹，及符合画风的光照或平涂方式}，一个主光源、一个投影方向。
单画面主视图，宽的 3/4 视角，{观察高度和方向}，结构清楚；无人物、人影、故事动物、剧情动作或标注。
{有真实参考才填写：使用 {{ref N}} 保持哪些布局和材质，仅改变哪个时段、状态或视角。}
```

| 序 | 槽 | 内容 |
|---|---|---|
| 1 | 画风 + 场景 | 画风文字；场景名、室内外、建筑类型、时段与天气 |
| 2 | 前中后景 | 前景进入元素；中景活动区与固定物件；后景边界与远处结构 |
| 3 | 空间关系 | 出入口、通道、稳定地标、相对位置、活动空间 |
| 4 | 材质与视觉 | 材质、配色、表面痕迹、光照或平涂方式；一条光逻辑 |
| 5 | 视图 | 3/4 视角、观察高度和方向；排除人物、人影、故事动物、剧情动作、标注 |
| 6 | 参考（条件） | `{{ref N}}` 保持的布局与材质；改变的时段、状态或视角 |

一张图一个地点；地点过宽时写明"本图只出现其中这一部分"。需要环视板时按用户已确认的布局。

## 五、道具资产

```text
{画风文字}道具资产，唯一物件为{名称、形制、用途、材质、配色、尺寸关系与状态}。
关键结构：{功能部件、装饰、影响剧情识别的细节}。
展示方式：{默认2×2：左上正面、右上右侧90°、左下背面、右下局部细节；用户另有已确认版式时替换本项}。
各视角同一结构和状态，完整展示、不裁切，{中性背景与柔和均匀的光照，或符合画风的平涂}。
{有真实参考才填写：使用 {{ref N}} 保持哪些结构，仅改变哪个已确认状态。}
无人物、手部、额外物件和剧情背景；{需要保留的实际文字：精确文案 + 字体字重颜色，或写明"表面空白、无品牌"}，无无关标注或水印。
```

| 序 | 槽 | 内容 |
|---|---|---|
| 1 | 画风 + 物件 | 画风文字；名称、形制、用途、材质、配色、尺寸关系、状态 |
| 2 | 关键结构 | 功能部件、装饰、影响识别的细节 |
| 3 | 展示方式 | 默认 2×2；用户确认版式时替换 |
| 4 | 一致性 | 同一结构状态、完整、不裁切、背景与光照 |
| 5 | 参考（条件） | `{{ref N}}` 保持的结构；改变的状态 |
| 6 | 排除与文字 | 无人物、手部、额外物件、剧情背景；文字给精确文案或写空白 |

局部特写只放大真实存在的结构；道具独立摆放，不带人物、手臂或握持姿态。

## 六、变体与修图

**变体**沿用对应资产的模板：以最近一次状态的实际图为 `{{ref N}}`；未变项写进保留项，此前仍有效的伤势与损坏也写进保留项；改变的部位、服装、物件或状态写进改动项。缺基础图时标明"待补参考"，不假装图生图。

**修图**（只改一处）用四行：

```text
目标：{一句话}。
只改：{这一处，描述精确}。
严格保持：脸与身份、头发、痣与饰品位置、姿态、构图、服装道具、背景、光向、调色、颗粒。
只改{再写一遍这一处}，其余完全相同。
```

要改两处以上，或动构图、身份、景别，就回到对应模板重建整板。

## 七、不进正文

| 内容 | 处理 |
|---|---|
| 模型、比例、分辨率 | 平台设置 |
| 表演、运镜、对白 | 归视频提示词，不进资产图 |
| 设计推导、出处 | 留在资产表 |
