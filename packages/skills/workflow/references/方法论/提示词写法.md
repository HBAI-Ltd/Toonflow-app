# 提示词写法

S4 写任何生成提示词（视频、资产图）都适用的句子层规则。块怎么排、标签怎么写，按所用模型的格式规则，不在本文。

## 一、两种料：可执行动词与可度量事实

句子里只放两种料。形容词和嵌套从句会被模型平均掉。

- **动词**用看得见的：站、面向、看、握、走、举起、触碰、倾身、呼吸、滴落、倒下、滑、按、转、打开、关闭、进入、靠。
- **位置与量**用能检查的单位：1 米以内、画面左三分之一、前景 / 中景 / 背景、髋部高度、眼睛高度、0:03、一步、两个人、三个可见的人。
- **一句一个动作**；一句三个动作，出来各做一半。
- **心理落成可见行为**："她不看他，下颌咬紧"，不写"她很生气"。
- **同一信息只出现一次**；两个事实互相抵消（人物既背对门又面向门），模型只能二选一。
- 不加"电影感、氛围感、高级感、大片质感"——只会让画面更糊。要质感就写具体的光、材质、颗粒。

**薄句按五项补**：具体名词、可量测、微事件、材质行为、声光时序；每块至少命中三项。只加修饰词，句子变长、信息没变。

## 二、常量：钉一次，逐字粘

常量＝两条以上提示词里必须一字不差的文字：画风文字、外观描述、空间地图、照明合同、音色、常用锁句。写法上：

- **同一条提示词里每个常量只出现一次**；跨镜、跨条复用时，副本与母本一字不差。
- 不写同义变体："完全符合参考""高度还原""和参考一致"混用，模型每次按新措辞重新采样，第二镜就换脸。
- 画风文字只进资产图提示词，从 `AGENTS.md` 原样复制，不重写、不凭记忆；视频提示词不贴画风，风格由已经固定的参考图带进来，完全没有参考图的那一条才贴。
- 常量是功能，不是咒语：锁身份可以用固定锁句，也可以靠每张参考的职责句（"只提供这张脸，不提供机位"）。哪种都行，功能不能空。

## 三、上下文隔离：每条都是密封文件

模型没有上文。提示词里出现一个指向上文的词，它就把那一镜的人、物、地点一起带进来。

- 正文不出现：**之前、再次、和刚才一样、继续、接上一镜、同上、如前所述**。要接续，就把需要的状态完整写一遍。
- 参考只挂本镜出场的；每个被引用的参考都要在本镜出场；同一个参考在清单里只出现一次（重复会让生成直接拒绝启动）。
- 场号、集数、剧本头、修改意见留在工作文档，不进正文；批注混进正文，模型会把编辑意见画出来。
- 每条都完整写开场状态：第 0 秒所有人在哪、朝哪、手上有什么。

## 四、写正面状态

**描述性正文不写否定式主句。** 否定句不告诉模型该做什么，点名的概念还会被检索出来——"不要配乐"会去找配乐，"不要 CG 感"会把 CG 送进去。写"应该看到什么"：

| 别写 | 改成 |
|---|---|
| 不要配乐 | 只有画内声：风、呼吸、鞋底踩碎石。 |
| 不要平光 | 单一硬光从左侧斜切；阴影边缘锐利，暗部不补光。 |
| 镜头不要动 | 机位停在原地，画面只带一点手持的细微晃动。 |
| 不要字幕 | 画面填满画幅，只有图像内容。 |
| 不要慢动作 | 实时速度，动作该多快就多快。 |
| 不要多手指 | 画面里只有两只手，都属于同一个人，从同一只袖口伸出。 |
| 不要变焦 | 景别收紧只靠机位物理前进。 |
| 不要 CG 感 | 实拍质感：真实材质、真实磨损。 |
| 不要光斑 | 每个光源都小而收在自己的范围内。 |
| 不要剪辑 | 一个连续镜头，实时速度。 |
| 不要眼泪 | 眼表干涩，眼白哑光。 |
| 不要现代物件 | 每件物件都在九十年代中期以前：素面木器、黄铜、旧涂料。 |

可数的项用正面声明写死数量："画面里只有两个人""只有一扇门"。

## 五、负向：三形态，按车道分

先改写成正面句；改不掉的才进负向。三种形态，**同一条片只用一种**：

| 形态 | 什么时候用 | 写法 |
|---|---|---|
| 无块（默认） | 绝大多数镜头 | 全部写成正面句与数量声明 |
| 局部锁 | 已有正面句，只补一个已知失败 | 负向句紧跟它的正面句，如"机位固定。不摇、不推、不变焦。" |
| 命名负向块 | 同一症状在三镜以上重复，或风险可以列清（数量、部位、光源、文字） | 单独成块、放在全篇最后、短语用"·"分隔、只列本片真实出过的问题 |

- **开块的必要条件是"同一症状在三镜以上重复"**。只在一镜出现的问题改正面句；一上来贴几十项通用禁令，模型只看最后一屏。
- **按车道分**：视频正文尽量不写负向；资产图、修图可以点名禁（"不改脸、不磨皮"）。同一个项目两套政策是正常的。
- 照明的固定失败（平光、美颜补光、棚灯主光、塑料高光）只进约束位置，不进描述性光照正文。
- 模型没有独立的负向参数时（如 MiniMax H3），否定写成散文放在描述末尾。

## 六、易误触发的词

这些词在模型里有自己的偏向，写之前先换掉：

| 别写 | 模型会做什么 | 改成 |
|---|---|---|
| 柔、柔和、轻轻地（任何块，包括声音） | 柔光、柔焦、软影 | 低、轻、小、微弱 |
| 发光、光晕、星芒、光线拉丝 | 加辉光与光斑 | 边缘光、高光点、锐利边缘 |
| 光束、耶稣光、丁达尔效应 | 体积光柱 | 硬侧光穿过飘尘 |
| 眼泪、泪光、眼眶湿 | 满脸泪水或亮晶晶的眼 | 眼表干涩，眼白哑光（真要哭，写泪的位置与数量） |
| 瞄准、准星、视线（和眼睛同句） | 眼睛上长出光学镜 | 沿枪管上沿指向 |
| 剧烈摇晃、大角度倾斜、死死盯住 | 失控的抖动或夸张表演 | 给数值："画面永久倾斜 6°，保持到最后一帧" |
| 插画、动漫、游戏 CG、3D、厚涂（写实片里） | 推向插画质感 | 实拍照片、真实材质、真实磨损 |
| 影楼、柔光箱、轮廓光（写实片里） | 把棚拍器材和边缘光画进去 | 中性灰背景，柔和的定向光 |
| 淡入淡出、叠化、渐隐、转场特效 | 加转场 | 硬切 |
| 颜色名（黑白片里） | 染色 | 中性黑、漂白高光 |
| 一句中文夹一整句英文 | 语言混乱 | 只保留模型要求的固定英文语法，其余单语 |

## 七、篇幅

篇幅看信息项够不够，不看字数凑没凑满：

- 图片提示词短：一个资产一个目标，中文约 150–300 字。写得越长越会稀释指令。
- 视频提示词长：空间、光、表演、声音都要写进去。中文多镜 30 秒一条，常见在 3000–5000 字；单镜一条常见在 2000–3000 字。明显少于这个量，通常是某一块被写成了一行。
- 方法上不设上限，但平台有提示词字数上限时以平台为准，开工前先核；超了先删可选的细节，不删开场状态、动作和光。不注水：照着英文提示词的字数去写中文，只会把形容词灌进去，信息项仍缺。
- 模型有硬性字数上限的（如 MiniMax H3），以模型的字数上限为准。
- 动作时间轴每镜写一整段（中文常见 200–400 字）：段首锁机位与构图，段内 2–5 个可见微事件，切点单独一行。别按时间片逐条拆句，会写成"动作对、机位飘、光不变"的流水账。

质量收尾只留一行，且不替代相机、光与物理的描写："画面清晰锐利，色彩自然，画面稳定。"

## 八、交稿前扫一遍

- [ ] 资产图提示词的画风文字是从 `AGENTS.md` 原样复制的；视频提示词没有贴画风（完全没有参考图的除外）
- [ ] 每个常量只出现一次，与母本一字不差
- [ ] 没有上下文词（之前、再次、接上一镜、同上）
- [ ] 描述性正文没有否定式主句；负向只用一种形态
- [ ] 没有第六节的误触发词
- [ ] 每个参考都在本镜出场，且只出现一次
- [ ] 切点写绝对秒数，没有"然后、接着"
- [ ] 数字、位置、距离都能在成片里被检查
