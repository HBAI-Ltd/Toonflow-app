# 镜头设计

S4 每一镜的画面决定：这一镜让观众看懂什么、用什么景别和焦段、构图先写什么、要不要动、人在空间里怎么站。和模型无关。

## 一、先给这一镜一个观看任务

镜头的第一个决定不是景别或运镜，而是**观众这一刻必须看懂什么**：先于还是晚于人物知道、该靠近还是保持观察距离。写出这一句，再去找承担它的动作、脸、物件或空间关系。

每镜要能归到三种变化之一：剧情发生了新事件；人物改变理解或策略；观众获得新信息。没有增加信息的镜头必须说清在等什么——等一个结果落地、等一次迟疑出现；说不出就是白拍。

从画面构想倒着来也可以，但要回查六步：观看对象 → 必须同时看见的内容 → 景别与机位 → 构图 → 要不要动 → 从哪个可见状态结束。写满景别与运镜却说不出观众该看懂什么，等于没决定。

## 二、按信息范围选景别

景别是信息范围的开关，依据是本镜要容纳的任务，不是情绪强度。

| 景别 | 优先解决 | 使用时核对 |
|---|---|---|
| 大远景 | 地理、规模、人与环境的比例 | 小人物仍可定位；不同时要求读表情或文字 |
| 远景 | 行动路线、处境、接近或离开 | 环境信息真的影响本段 |
| 全景 | 完整身体动作、站位、空间限制 | 手脚、目标、动作结果都在画内 |
| 中景 | 对话、双人关系、身体与物件互动 | 要看的手与道具没被裁掉 |
| 近景 | 反应、视线、呼吸、言语变化 | 空间已建立，不用近景掩盖人物换位 |
| 特写 | 脸、手或关键物件的决定性细节 | 明确部位与要读出的信息，留够辨认时间 |
| 大特写 | 极少信息的集中观看，或有意隐藏整体 | 局部不承担全场空间说明 |

两个动作必须同时证明因果时，不要为"情绪强烈"切成孤立特写——把"谁把东西交给谁"的手裁出画面，就是选错了。也不强制所有场景先远后近。

竖屏片子默认中近景与特写，用前后景关系代替横向铺陈，慎用大远景。

## 三、构图：先写一份不带术语的草案

先写：哪些人和物必须同时出现，各在哪个锚点，观众要从它们之间看懂什么。然后改三遍：

1. **检验相互关系**：要看两人争同一物件，就不能把关键的手裁掉；一人挡住另一人的去路，前后层次与通道必须可辨。用间距、朝向、大小、遮挡说明关系。
2. **模拟观众视线**：缩小画面时哪个对象最突出，下一眼能否找到动作目标，线索会不会过早暴露。
3. **让动作在画框里走一遍**：空处容不容得下下一步路线，移动后主体会不会出画，停下时关系是否已经改变。

三遍走完才选居中、对称、三分或别的布局。位置本身没有固定寓意：画面左侧不天然代表过去，倾斜不天然代表悬疑。为凑构图让人物无故搬家，或把重要东西摆成一排指望观众依次读，都是把构图当摆拍。

## 四、运动：先判断要不要动

固定镜头能完整呈现这次变化时，固定就是正确答案。要动，必须说清三件事：运动新增了什么信息、怎样改变观看关系、开始与结束画面。

**一镜一个运动主轴**（只从 X 到 Y）。确需组合要写清先后阶段与转折依据，不同时要求互斥的推拉与摇移。运动质感（手持、稳定跟随）写"轻微自然晃动""平稳侧向跟随"就够，不堆设备名。

十种运动各自最容易写错的地方：

- **摇（水平 / 上 / 下）**：观察位置不平移，不能借摇镜穿过遮挡。
- **横移**：观察位置真的改变，和原地摇不是一回事。
- **推近 / 拉远**：说明起止景别与新露出的内容，不只写"情绪慢推"。
- **跟随 / 在人物前方后退**：跟谁、从哪一侧、走到哪里；路径不能穿墙。
- **升降**：说明高度变化与可见结果；不为每场加宏大航拍。
- **环绕**：需要已建立的空间支撑；结束时银幕方向不能丢。
- **变焦**：观察位置不变；不能当机位移动，也不能借此看到被挡住的物件。
- **移动并反向变焦**：主体大小稳定、背景关系明显变化；只在确需时用。
- **快摇**：模糊过程不能吞掉必须看清的动作或线索。
- **轴向旋转**：不是环绕，也不是固定倾斜构图。

镜内推拉、变焦在不同模型里能力不同：Seedance 正文里改成硬切加机位前后移，或拆成两次生成；MiniMax H3 可直接用词表里的运镜词。

## 五、空间地图先于分镜

**顺序不能反：先有平面图，才有走位；先有走位，才有分镜。** 地图是镜间契约：每场写一次，本场每一镜逐字粘贴；改写一次，等于给模型换了一张地图。

**地图九项**：机位、朝向、前景、中景、背景、地标位置、人物位置、移动路径、光向。缺一项不算写完。地图的字数靠点名堆，不靠形容词——每件家具、每段距离、每条影子方向都是可检查的事实。

**真实落位先于画面左右**：先从地标建立人物、道具、光源、路线的实际关系，再定本镜从哪看，最后才换算成画面左右、前后。反打或移动后重新核对视线、进入方向与遮挡：画面位置可以因观看方向改变，真实落位不能无故重排。区分人物自身的左手与画面左侧；物件换手要有动作，伤处和服装不能随反打镜像。

## 六、方位、轴线、距离

- **机位用世界锚点 + 人物自身的侧来写**："在吧台远离入口的那一端""从他的右前方"。不写"左下角"——模型分不清人物的左和观众的左，会镜像。
- **轴线一句话定死**：机位始终在哪一侧、甲永远画面左、乙永远画面右、绝不越轴。需要越轴时，用可见移动或重新建立空间让观众理解。
- **躯干和视线分两条写**："躯干朝窗；眼睛锁在她身上；台词落完，头才转"。合成一句，模型会把两件事缠成一件。
- **距离写约束，不写分布**："1 米以内""背靠墙"能被检查；"附近""旁边"不能。

人与人的距离按四区取值，**距离一变＝节拍一变**：

| 区 | 距离 | 用在 |
|---|---|---|
| 亲密 | < 0.5 米 | 爱或暴力 |
| 个人 | 0.5–1.2 米 | 信任 |
| 社交 | 1.2–3.5 米 | 公事、戒备 |
| 公共 | > 3.5 米 | 疏离、等级 |

**一人七事实**：屏幕位置、世界位置、与地标或他人的距离、躯干朝向、视线方向、移动方向、所在层（前 / 中 / 后景）。缺一项，模型就补一个默认值。群像、口播、产品特写这类没人走位的镜，写到位置、朝向、视线三项就够。

## 七、焦段：先选用途，再写结果

焦段六档是用途菜单，不是可以随意取中间值的刻度。先定用途，再选档；落进提示词写**看得见的结果**，不写镜头型号或光圈参数（视频模型对器材词几乎不响应）。

| 档（对角视角） | 用途 | 机位距离 | 可写的结果 |
|---|---|---|---|
| 约 107° | 大尺度地理、沉浸 | 0.5–0.8 米 | 极大景深、全程清晰；前景物体巨大逼近；直线保持笔直、无鱼眼 |
| 约 84° | 环境里的动作、贴身人物 | 1–1.5 米 | 相机贴近，环境始终围着主体可见；画面边缘直线笔直 |
| 约 47° | 纪实、中性 | 3–5 米 | 自然人眼透视；景别差异只靠机位远近 |
| 约 29° | 中景肖像 | 4–6 米 | 浅景深，主体锐利，背景化开 |
| 约 18° | 情绪特写、窥视 | 6–8 米 | 只剩一层薄焦平面，其余化进浓重虚化；背景被压缩 |
| 约 8° | 远观、偷看 | 20–25 米 | 纵深被压扁；虚化的前景遮挡占画面下方三到四成，把主体框在远处 |

- **内容决定视角**：细节塞进超广角、人群塞进长焦，不是不够好看，是整镜立不住。
- **一镜一个内容类型**：一镜里同时要人脸、地理、微距，镜头必然漂；拆成插入镜。
- **47° 是"无风格"，不是默认**：全片默认 47°，出来就是全片没有镜头性格。只在确实要中性纪实感时用。
- **8° 必带前景遮挡**；不写遮挡，只得到一个模糊的长镜头，不是远观。
- **广角必配相机距离**；不写距离，相机不会走近，空间不扩张。
- 一稿只用一种角度口径（统一写对角视角），或者删掉度数只留结果。

自相矛盾或空洞的镜头词一律改成"视角 + 距离 + 结果"：`广角特写`（脸被拉弯）、`长焦全景`（模型二选一）、`超广角拍脸`、`一颗镜头从全景推到特写`（镜内变焦）、裸写"大全景""建立镜头"（画面变空、人被推远）。只写"不要广角"不算指令，必须同时给出想要的视角。

## 八、尺度

尺度只有一个来源时，模型会自己发明一个，而且每镜不一样。**尺度三件套同写**：真实尺寸、占画面比例、对照物。

- 身高两端夹住："不比他高一厘米；拿不准时宁可画矮一点"。
- 非人尺度四件套：绝对尺寸（"三十米高"）、部件类比（"张开的手掌有一辆家用车宽"）、相对剪影（"每帧至少是旁边那人的五倍高"）、取景测试（"画框装不下他的头和脚"）。只写"巨大"没有用。
- 室内用厘米加身体部位："栏杆 110 厘米，对 185 厘米的人，上沿落在腰带稍上"。
- **同框超过 15 人**换写法：人群做成一个资产，加前景几个配角，写"画面边缘都是身体"，不写人数——写"上百人"会生成五个人。
- 动作里的道具逐帧写数量；多余元素点名排除并写精确数量（"只有两条铁轨，没有站台和雨棚"）。

## 九、常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 镜头自己滑回中景 | 视角没锁 | 一镜一视角，只在硬切时换 |
| 脸被拉弯变形 | 写了"超广角 / 极广角"去拍脸 | 按用途选档，写度数加距离 |
| 画面变空，人被推远 | 裸写"大全景""建立镜头" | 视角、距离、结果三样齐写 |
| 运镜被平均，不成立 | 一镜复合运镜 | 只留一条主轴 |
| 机位一动空间就散 | 单张正面参考撑不起体积 | 补另一侧机位的角度；地点板用 3/4 视角 |
| 人物瞬移、换位、越轴 | 每场没有一份不变的空间地图 | 同一份地图，本场每镜原样粘 |
| 反打后沙发跑到同一边、门消失 | 反打没重写机位关系 | 重写该镜观察关系，不搬整个场景 |
| 只写"他在左边"，前后景乱跳 | 七事实缺项 | 补齐位置、朝向、视线、所在层 |
| 同一物件各镜大小不同 | 尺度只有一个来源 | 尺度三件套 |
| 人群塌成三五个人 | 人群被当成可数个体 | 人群当资产，写边缘身体不写人数 |
