# 表演与动作

S4 画面里有人时读：怎么把表演和动作写成镜头里可执行的指令。表演不是情绪展示，是"想要什么、什么挡着、他为此做了什么"，摄影机只是把这件事拍下来。

台词内容、声音身份、机位不在本文。人与人的距离按四区取值：亲密 < 0.5 米（爱或暴力）、个人 0.5–1.2 米（信任）、社交 1.2–3.5 米（公事、戒备）、公共 > 3.5 米（疏离、等级）；距离一变＝节拍一变。

**什么时候必须过这一层**：画面里有脸、有手、有一个人站着（哪怕只是一双手）。只有纯空镜、纯环境、无人插入镜、产品特写可以跳过。

## 一、五根支柱

每场戏、每个角色，五根支柱缺一根表演就垮：

| 支柱 | 一句话 | 要能回答 |
|---|---|---|
| 目标 | 打给某个对手的及物动词 | 我要他做什么 |
| 障碍与赌注 | 外部对手、时间，或内部的骄傲 | 拿不到会失去什么，而且这让他害怕 |
| 战术 | 逼 / 哄 / 羞辱 / 求 / 挑衅 / 交易 / 威胁 / 拖 | 失败时换哪一招 |
| 节拍 | 用一种方式要一件事的那一段 | 2–4 个，每次变化在身体上看得见 |
| 潜台词 | 真目标与嘴上台词之差 | 他说的和他想要的差在哪 |

目标必须及物："让他把钱放回桌上"可演，"他很内疚"不可演。赌注决定镜头松紧：越让角色害怕，镜头越敢往脸上推。

## 二、战术与节拍

一个战术演到底是死戏。活人在战术失败时会换招——从逼改成哄，从哄改成交易——换招那一下就是节拍。节拍在四处结束，每次结束都落成一次停顿、姿态变化、语速变化或视线移动：

| 结束于 | 下一拍变成什么 |
|---|---|
| 目标达成 | 换新目标，或收进下一场 |
| 战术失败 | 换战术动词（最常见） |
| 新信息到达 | 目标不变，筹码或风险变了 |
| 权力偏移 | 谁占上风变了，身体与距离先变 |

十秒内行为毫无变化＝演平了；每两秒乱变一次＝没有因果。

## 三、潜台词

潜台词不靠演，靠"说着假台词、追着真目标"自己漏出来。从五个标记里任选两个搭进戏：不是问题的"问题"；把同一件事问两遍；话题突然切换；不合时宜的玩笑（挡住脆弱）；短得过分的回答（"行。""当然。"）。

填栏测试："台词说的是＿＿，他其实想的是＿＿"，两栏必须不同。

## 四、倾听

表演质量在台词之间。四条全写：

| 标记 | 可直接用的写法 |
|---|---|
| 反应早于话尾 | 他话还没说完，她的脸已经先答了。 |
| 先有念头再有词 | 回答之前有一段看得见的停顿——他在决定说什么。 |
| 评估的时刻 | 消息落下后她停住两秒：目光失焦，喉咙动了一下，然后才开口。 |
| 来自对手的传染 | 他吼，她反而把声音压得更低。 |

反应落在**对方开口之后、话尾之前**；等台词说完才反应，出来就是一张死脸。不说话的人要写"嘴唇静止，只有呼吸与眨眼"。

## 五、身体与眼睛

**身体先于心理**，四件事写对，心理不用写：

| 参数 | 高 / 快 | 低 / 慢 |
|---|---|---|
| 重心 | 胸、下巴前送——自信、攻击 | 肩垮——疲惫、恐惧、臣服 |
| 节奏 | 快而碎——紧张、兴奋 | 慢而省——掌控、威胁（最危险的人动得最少） |
| 开合 | 开肩、摊开手掌 | 交叉手臂、低头 |
| 呼吸 | 高而快——恐慌 | 低而缓——控制；憋住的呼吸＝憋住的情绪 |

**每人一件手上事**，说话时手不停；最重的那个字落在他**停下**手上事的那一刻。手的每一句都要有接触对象："手指摩挲杯沿"合格，"手在动"不合格。一镜里手的主动作最多一个、次要动作最多一个；戒指、伤口这类固定物在镜末确认一次。

**地位是做出来的**：高地位＝头稳、动作慢、凝视长、答前有停顿、占空间、动别人的东西；低地位＝忙乱、摸脸摸头发、话碎、赔笑、用眼睛请示。最好看的是地位的断裂：老板显出一秒恐惧，下属突然不笑了。

**眼睛写得越具体越不假**，死眼是生成表演的头号破绽：

1. 微扫视，对准他注意的人或物，不冻结在一个点上
2. 眨眼频率随状态变：压力下急促连眨，掌控中缓慢平静
3. 眼神光读起来是湿的、活的
4. 受控的静止是被选择的：眨眼稀少、缓慢、有意，视线仍带意图移动
5. 眼睛比头早半拍到达目标
6. 换拍时眨眼频率、凝视稳定度、眼神温度一起变

视线写三段路径：起点 → 途经 → 落点（画外左、画外右、某人、镜头）。看镜头与看画外一镜里二选一。

**镜头越紧，动作越少**：大特写只剩眼睛和念头。

## 六、把情绪写成可表演的指令

模型渲染不了抽象词。"她很悲伤"等于把表演交给模型猜；要写成**哪个部位、什么顺序、到什么程度**：

- 每个情绪词都能指到一个部位（眼睑、嘴角、下颌、喉结、肩线、呼吸、手指）；指不到就不合格。
- 每个抽象词至少换成两个物理项，其中至少一次写到眼睛或眼睑。
- 表情要有时间结构：**起始状态 → 触发点 → 第二状态 → 收尾姿态**。触发点必须是画面里的事件（举杯、对视、台词落点），不能是"她想到了什么"。

> 表情：平静、眼睑半垂；她把酒杯举到唇边却没有喝，右嘴角先于左嘴角慢慢扬起一点克制的笑；随后目光越过镜头，笑容淡去，停在静止的等待姿态。

动作写"类型 + 幅度 + 速度"：小是克制，大是爆发；慢给观众读细节的时间，快是能量或惊慌。移动写清**方向、移动中面朝哪、停下后面朝哪**，再补一句锁身（"身体不转向，脸与胸口全程朝向对方"）——只写"后退一步"，会被读成先转身再后退。移动和运镜不要同时激烈。

非说话的角色也要至少一句身体指令，否则会变成雕像。

**写实短剧与非写实漫剧的表演分寸不同**：竖屏写实短剧画幅窄、节奏密，靠眼神微变化加贴身强戏剧动作（攥紧纸张、把文件拍上桌面、撤步避开触碰、抬起的手停在半空）外化交锋，少排绕场踱步等吃画幅的碎步；非写实漫剧减少生活化琐碎小动作，把篇幅集中给"起势—爆发—定住"的关键姿态剪影与放大一档的反应对比，画风允许时可在喜剧缓冲拍做夸张表情反应，但正剧对峙仍要守住重心、距离与视线因果，也不改动画风锁定的头身比例。

## 七、角色主档

反复出现的角色写一份**表演主档**：150–220 字，一段，写一次，之后每场改写进当下。外形归资产板，音色另写一条固定的音色块，都不进主档。

八条写法：只写可观察行为（不写"他很紧张"，写颤抖的下唇、沉重的吞咽）；每个习惯带扳机（`习惯 + 何时 / 为何`——没有扳机的习惯是装饰）；步态有名字并拆开重心、步幅、躯干、头；至少一个"但当……时"的转折；恰好一个软化对象；不写服装、相机、颜色；体格承载经历。

```text
［名字］，［年龄、体格、姿态——身体就是他经历的记录］。［一句话的内在动力，解释他为什么这样动］。
声音怎么破：［情绪上来时声音怎么变］。
习惯：［标志性小动作 + 扳机］；［压力下的小动作 + 扳机］；［掩饰：他做什么来藏住感受］；［脸上的面具，以及它在什么条件下裂开］。
步态：［有名字的走法：重心、节奏、落脚］。
但当［情绪扳机］时，［姿态、步态、脸怎么变］。
［可选：唯一能让他的脸真正软下来的人或物］。
```

**每场改写，不照贴**：主档回答"他是谁"，照贴的结果是角色永远同一个姿态。五个转换：步态用不上就转移能量（坐进沙发的踱步者，变成不安的微晃、撕纸）；习惯保留扳机只换外壳；眼睛重新对准本场目标；节拍做成可见事件；声音一个字不动。只写在场角色；写成一个流畅段落。

## 八、群戏

同步的群戏一眼就假——真人以波的形式反应：

- **反应错开**：一个人先懂，第二个半拍后懂，第三个没懂。
- **每个事件之后，给看见它的那张脸**——反应比动作值钱。
- **威胁出现时全部停下**：喧闹到静止的对比就是标点。
- **移动＝动机**：贴近（升级）/ 转过身（轻蔑或藏脸）/ 别人坐着自己站着（夺取支配）/ 冲突中坐下（反直觉的权力）/ 停在门口（决定的临界点）。
- **退化会累积**：被磨耗的角色把磨损扛在身上（更灰、更重、反应更慢），不在场与场之间重置。

## 九、怎么判"演得假"

看片时先给症状编号，不许写"感觉假"；查表取修法；一次只修一种。

| 症状 | 原因 | 修法 |
|---|---|---|
| 脸直接"做"情绪 | 把情绪当表演目标 | 把脸从任务里拿开，写目标，给手上一件事 |
| 第一秒就在演结局 | 角色被写成知道结局 | 只写他此刻知道的 |
| 对方说话时一张空脸 | 反应没有提前 | 反应落在对方开口之后、话尾之前 |
| 全场一个颜色 | 单一战术 | 标节拍，每拍换一个战术动词 |
| 说"大"就张开手 | 手势在图解台词 | 手势先于想法、与台词相反，或者没有 |
| 无铺垫的眼泪、暴怒 | 情绪没有代价与阶梯 | 从克制到破防搭梯子 |
| 混混有舞者体态 | 体态没从经历推出 | 先定重心、节奏、磨损 |
| 街头角色说书面语 | 语言没有身份的杂质 | 打断、吞尾音、重复 |
| 眯眼、慢转头、威胁停顿 | 威胁被演成仪式 | 威胁日常化，暴力没有前奏 |
| 所有人同时同幅反应 | 群演被当成一个开关 | 反应成波，强度各异 |
| 静默里什么都没发生 | 静默里没装事件 | 填评估或手上事，填不上就剪 |
| 强事件后立刻恢复 | 状态被当成开关 | 状态有惯性，余波带进下一拍 |
| 表演在向观众眨眼 | 演员不相信情境 | 完全相信；喜剧当正剧演 |
| 大特写上满脸小动作 | 用大动作填小画幅 | 越紧越少动 |
| 凝视、不眨眼、眼神发干 | 眼睛没有微行为 | 按五节写眼睛六条 |
| 写"没人动"得到冻帧 | 没有可拍的微事件 | 每 1–2 秒一个可见微事件 |

发布看两档：**≤ 2 分重写，主镜瞄准 ≥ 4 分**。

| 分 | 状态 | 判据 |
|---|---|---|
| 0 | 人体模型 | 台词念了，行为没有 |
| 1 | 朗诵者 | 被指示出来的情绪，在图解的身体 |
| 2 | 勤奋者 | 目标能猜出来，但只有一个战术、反应迟、停顿是空的 |
| 3 | 匠人 | 目标与节拍成立、会听对手；缺潜台词、缺意外的选择 |
| 4 | 活人 | 连续行为、对比的战术、与台词分离的潜台词、反应先于台词、至少一个意外但真实的选择 |
| 5 | 磁铁 | 4 全都有，并且同时演两件真话（道歉又在辩护） |

## 十、运动机制

模型不知道质量，除非把质量翻译成运动。每个位移说得出**施力者、受力者、反作用**；至少一个接触点写到几何级（手在哪、脚踩哪、物体靠哪）；布料与头发永远比身体晚半拍，然后回落。

**机制链不缺环**：

- 走：脚跟触地 → 重量转移 → 髋部移动 → 前掌蹬地 → 身体沉降
- 跑：真实触地、抬膝、反向摆臂、躯干前倾、步幅变化
- 持重物：手臂承重、手腕随质量转、加速与减速、轨迹连续
- 液体：附着、滴落、积聚、染色，抛物线，留下湿痕
- 粒子：顺风，前中后三层

**接触五段**（打斗、碰撞、搬运按顺序写）：

| 段 | 必写 |
|---|---|
| 接触前 | 重心转移、发力肢蓄力（没有蓄力，命中像贴图） |
| 接触点 | 手在哪、脚踩哪、物体靠哪 |
| 形变 | 攻击手臂先压缩再伸展；物件受压弯下、松手回弹、余震一次 |
| 反作用 | 受力者躯干折叠后退约 40 厘米；落地弯膝、重量沉进地面 |
| 余波 | 尘土碎屑、布料头发晚半拍回落；压痕留在原地，带到下一镜 |

**写状态，不写过渡。** 判据：这段运动能不能用"某一拍"复述？能，写机制链；只是"从 A 到 B 的过程"，写已到达的状态。想要拔枪，写"已经是拔枪中段：枪已离开腰带，枪口正在抬起"，否则得到手在腰上摸索、枪没出来。

**时间块切动作**：一个时间块只做一个动作（"边后退边前进"不合格）；整镜动作总量不超过可用时长；变速必须声明（"全程实时"或"只在冲击瞬间放慢到四成"）。

## 十一、物理：逐材质写行为

物理块是一串**逐材质的行为句**，不是一句"重力真实、质感厚重"。湿与干分开写；三类接触各一条；写机制句不写观感句（"湿帽衫粘着身体往下坠"能执行，"重力真实"只能被猜）；后果留到下一镜。

| 材质 / 接触 | 写法 |
|---|---|
| 湿布料 | 粘着皮肤、拖、坠着走；褶皱积在关节处 |
| 干布料 | 翻动、鼓起、回落；衣角比身体慢半拍 |
| 湿头发 | 一缕缕慢慢剥离，发梢拖在水面上 |
| 干头发 | 随动、回弹、落定 |
| 水 | 挂在表面、聚成股、滴落；砸进水面立起水冠、散出水环；留下湿痕慢慢变暗 |
| 金属 | 受压弯下、松手回弹、余震一次 |
| 木 | 受压微微形变，榫卯一声轻响，人起身后回弹 |
| 鞋底—地面 | 鞋底咬住地面压出印子，砂石往两侧散 |
| 手—物 | 手掌压进物件，指节发白 |
| 身体—家具 | 家具被压出形变、往受力方向偏；压痕留在原地 |

两段可以直接加的料：

- **打击感**（只用于动作、打斗）：接触那一刻 1–2 帧白闪、3 帧顿帧、短暂震屏；攻击手臂先压缩再伸展；受力者躯干折叠后退；尘土碎屑、细拖尾。
- **空气分层**（只用于大外景、建立镜头）：空气约占画面一半；分三层明度——高层薄云最暗、中层雾带居中、地平线亮带最亮；水面倒影重复这三层。

动物步态与人群个体行为没有可靠写法，按因果、重量、接触三件套近似，不编四足步态。
