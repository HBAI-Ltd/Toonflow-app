# 光与色

资产与镜头共用的光色方法：颜色分几层、光从哪来、怎么写进提示词、跨镜怎么不跳。

项目 `AGENTS.md` 里冻结的画风文字管"这部片长什么样"；本文管"这一镜的光和色在画风之内怎么落"，不改画风。

## 一、三层分开：本色、受光、调色

| 层 | 决定什么 | 写在哪 |
|---|---|---|
| 资产本色与表面 | 衣服、毛发、墙体、道具的固有颜色、纹理、粗糙或透光 | 资产锚点与保持项 |
| 环境光与材质响应 | 光从哪来、照到哪、明暗关系；同一表面怎么反射或透光 | 场景状态、镜头的空间与光照 |
| 最终色彩处理 | 白平衡、综合色偏、明暗与饱和关系、对比、质感 | 资产图里的画风文字（经参考图带进视频）+ 镜头的风格块 |

**先定本色，再读当下的时段与真实光源，最后才决定综合色彩。** 白衬衣在暖灯下可以显暖，但资产仍是白；不能把夜景参考里的蓝写成衣物本色。后期冷暖处理不能凭空造出窗户或改变开灯事件；真实灯光变化也不必把所有衣物、肤色都染成同一种颜色。

一条镜头里三层合成一套相容的描述，不交两份互相竞争的灯光与调色指令。

## 二、先写观看任务，再挑手段

"电影感""压抑""温暖"只是方向，要改写成观看任务："先看见她攥紧信封，再意识到门后还有人"。剧情事实（时间、天气、开灯事件、人物识别色、空间结构）不能被风格词改写。

先决定光色和剧情情绪是什么关系：顺着情绪托底、用日常明亮画面反衬暗涌（比如全家在暖亮厨房吃饭，桌下有人把退学通知塞进包里）、保持克制中立，还是切入角色主观感受。**不按情绪贴滤镜**——不因为争吵就打红光，不因为难过就染蓝，更不在同一场戏里随每句台词换一次色调。然后按画面问题挑手段：

- **必要信息看不清** → 先处理明暗：手、脸、物件是否和背景混在同一明度；调局部对比、暗部密度或高光过渡，不是一律提高全画面对比。阴影带色偏时把"暗度"和"色偏"拆开写（如"保留柜底暗度，减弱压在黄铜上的冷绿偏色"）；黑位抬太高会冲淡轮廓，亮部压太死会吞掉灯具本身的发光感。
- **看得清却看错重点** → 处理颜色竞争：找到抢注意力的色块，收背景饱和，或让少量已有颜色与主色拉开，也可以靠构图解决。主辅色管的是画面占比与对照，不是临时给角色换衣服颜色；只调一个区域要写出范围，别把肤色和识别色一起抽走。
- **单镜正常、跨镜变色** → 找共同参照：用同一材质在相近光下的表现，区分真实光源变化与白平衡漂移。冷暖先定中性灰/白物体在画里显什么色，再谈综合色偏，不把灯具色温直接当成整片白平衡。

每个选择用一句能核验的话收束："暗处工具边界可辨，柜面暖亮区保留，背景红色包装降低存在感"。需要加中间调厚度、颗粒或柔化时，先确认不会盖住动作、画面文字与材质差异。

## 三、用光六步

1. **找依据**：已有的窗、门、灯、火、发光物与开关状态；画外光源可合理推断时标为提案
2. **定观看重点**：这一刻要辨识的是脸、手、动作轮廓、出口还是物件——不是永远脸最亮
3. **组织明暗**：主要亮区、必要暗部、背景层次；无关细节可以退后
4. **选软硬**：要明确投影或强形体分割用硬边，要柔和过渡用软边
5. **查空间一致**：方向用窗侧、门外、桌灯附近这类实际锚点；换机位不把光源挪到另一面
6. **查行动范围**：人物从明处走进暗处，受光随位置变；开门、遮挡、关灯有先后与终态。关灯后还要看清某个动作（如把钥匙塞进抽屉），先查空间里有没有门缝光、窗外路灯等已有依据，或把动作调到关灯前；不在生成提示词里凭空加一扇窗或一轮月亮救场

主光负责塑形，环境或反弹光保留暗部信息；是否加分离光由可读性决定，不默认三点布光。深色人物不一定需要轮廓光，可用背景明度、姿态、留白区分。低照度不等于一律压黑，低反差也不等于全画面一样亮；光线软硬看投影边缘的过渡，不拿冷暖或明暗代替，也不把"柔光"当成欢快场面的必然配方。

## 四、照明合同：落进提示词的八项

用光六步是想法；写进视频提示词的光照块时，写满这八项：

| 项 | 写法示例 |
|---|---|
| 主光源 | 窗外阴天天光 / 桌上一盏钨丝台灯 |
| 方向 | 从画面右后方来，仰角约 8°，影子朝左前方 |
| 相机在光哪一侧 | 相机在暗侧（侧逆光）/ 相机在亮侧（顺光） |
| 主体明暗面 | 脸的左半在光里，右半沉进阴影 |
| 背景亮度 | 背景比主体亮一档 / 背景压暗到只剩轮廓 |
| 曝光优先 | 按窗外曝光，允许脸进深阴影 / 按脸曝光 |
| 允许的高光 | 逐条列：湿路缘、钢管边缘、一次眼神光 |
| 明暗比 | 亮面与暗面约 2:1（柔和）或 4:1（强烈） |

- **色温写数字**：主光 3400K、阴影侧天光 6800K、钠灯约 2000K（按实际光源改）。双色温同场（如室内暖灯加窗外冷天光）写清各自照哪一侧、在哪里交界过渡。
- **明暗写比值**：只写"高对比"等于没写。
- **把八项写够厚度**：视频提示词里的光照块通常要写满一整段（只写一句"黄昏、逆光、很暖"，出来只是平光加一层橙色滤镜）。
- **要防的光照失效**（平光、美颜补光、棚灯主光、塑料感高光）不算八项，不进描述性光照正文：先在光照块里用正面状态锁死（"脸留在深阴影里，只靠轮廓光与地面反弹显出细节；所有光都来自画内可见光源；高光只落在真实湿面与金属边"），确需负面限制时放进约束位置，且绝不自相矛盾（一边要剪影，一边在锁定里写"全员脸部清晰可见"）。
- **一场一条光向**，反打也一样：判定就是反打镜里光源是否还在同一空间侧。反打换了观察方向，光相对于房间地标不变，但相对于相机和画面左右要跟着换算（正打时窗光从画面左来照亮他左脸，反打看对面人时，同一扇窗在画面右、照亮对面人的右脸），不能机械把"左脸受光"复制到反打镜。
- **静态资产图与动态视频分车道**：图片资产可按需用机身、镜头或胶片名锚定质感；视频模型对器材词几乎不响应，光照与质感一律写成画面上看得见的明暗、色温、衰减与高光结果。颗粒、质感只写一行，叠三行会和模型自带的质感打架。

**模型有很强的补光先验**：不写曝光优先，脸一定会被补亮。要逆光就写死：

> 主体始终在相机与更亮的背景之间，相机在主体的阴影侧。按背景曝光，脸保持在深阴影里，只靠轮廓光、湿润高光和眼中一点高光交代细节。撑住画面的是剪影与轮廓。

上一版跑出来还是平光、脸被补亮，下一版在曝光优先里直接加一句硬锁：**"全镜按逆光与背景亮区曝光，不为脸补光；允许脸沉入压实的深阴影，靠剪影与轮廓线撑住画面。"**

要自然低照度：

> 只有自然光：［时段 / 光源］，暗而冷，深阴影，真实衰减，明暗对比强，整体低调略欠曝。每个光源都小而收在自己的范围里，光只落在场景上。

## 五、色比与色板

- 色板写成**占比 + 真实色名**："六成暖赭、三成深炭、一成锈红"；不写"氛围感配色"。占比从已确认的画风、场景母版或参考图里提取，不每镜临时编一套新比例去和资产本色打架。
- 常用 60:30:10：主色 / 次色 / 强调色。强调色只给观众该看的那一处。
- 跨板、跨镜统一调色时，写一句关系而不是一串形容词："低饱和、冷灰主导，［暖色元素］是唯一的暖对比，暗部压实，克制的自然调色，柔和的低反差"。这句属于画风范围的，应已写进画风文字；镜头里只补本镜的占比。
- 用户还没定下光色倾向时，可在四类基础关系里挑两三个方向让他比对：**克制自然层次**（收敛色偏，靠构图与动作抓重点）、**柔和亮部与中间调**（压住刺眼高光与硬反差，但保住轮廓不泛白）、**有限冷暖分离**（靠已有光源色差把主体从背景摘出来，不把所有夜景都刷成青橙套路）、**少量亮区配浓密暗部**（靠强轮廓与遮蔽顺序讲故事，但不能吞掉必看动作）。选定一种主关系后再加少量质感，不同时叠满褪色、重颗粒、强辉光与高锐化。
- 要防"一个词把调性推成漫画"：两端同时夹住，写明两端各是什么（"写实到能看见毛孔，但不到冷峻纪录片的灰"）。

## 六、按媒介换控制对象

| 媒介 | 优先控制 | 常见误用 |
|---|---|---|
| 二维平涂 / 赛璐璐 | 角色主色、线稿、阴影色块形状与边界、主体与背景的明度层级 | 加真实皮肤散射、复杂反射、随机渐变，做成立体塑料 |
| 二维水彩 / 绘画 | 色块融合、边缘软硬、纸面或笔触一致、关键轮廓清晰 | 把硬黑线和硬边阴影当成所有二维的必要项 |
| 三维（风格化或写实） | 体积、光源关系、反弹色、粗糙度与高光、必要透光 | 所有材质同一光泽；无依据加雾、景深、轮廓光 |
| 写实影像 | 曝光关系、可信光源、肤色差异、服装识别、亮部过渡 | 磨平皮肤、统一肤色、用重滤镜掩盖照明矛盾 |

二维先看缩小后色块还分不分得开；线稿可黑、可彩或弱化，阴影色块面积与边缘要跨镜稳定，气氛光染色时仍要保住角色主色可认。非写实漫剧遇高燃能力爆发、暗黑气场或强情绪冲击时，优先拉大明暗色块面积对比、加深硬边投影或切高反差单色背景，加一道锐利的亮色轮廓边或局部发光锚点，不套写实三维的柔光散射，也不让发光糊掉五官与线稿。三维先看材质差异：哑光布与金属不该同一高光，透明物不是把不透明物调浅，透光只给皮肤、蜡、薄叶这类材质。雾、景深、辉光只在有依据且不遮信息时用。写实方向要保住不同人物各自的肤色差异，不把同场所有人的脸刷成同一种粉橙色。

## 七、场内稳定、场间有依据地变化

先固定共同基底：媒介质感、综合色彩关系、明暗范围、资产保护；再按日夜内外做必要适配。同地点、同时间状态继承同一基底，子区域和反打不另起风格。

跨场统一的是关系与处理方式，不是所有场同一亮度。确需变化时写"触发 → 起态 → 可见过程 → 终态 → 影响范围"，区分真实光源事件与主观化表达。同一空间被拆成多条连续片段时，下一条的起态必须继承上一条结尾已生效的受光状态（如第一条角色走进红色应急灯下，第二条开场就要保留红光投射与阴影位置，不能重置回走廊入口的中性光，也不能把门板本色改写成红门；若中途灯灭，写清熄灭时点与剩余微光来源）。

相邻片段用**已采用的真实结果**核对亮度、冷暖、阴影与光源状态，不只比计划写的参数。实拍或既有画面配生成补镜时，补镜直接抄既有画面的主光方向、色温、暗部密度与颗粒，不另起炉灶。

## 八、出问题先定位层次

- 本色被改错 → 回资产设计
- 方向不对 → 查空间与受光
- 综合色偏不对 → 调风格块

不要一发现问题就三层全部重做。

| 症状 | 原因 | 修法 |
|---|---|---|
| 平光、脸被补亮 | 补光先验，曝光优先没写 | 写死曝光优先，允许脸进深阴影；仍平就改侧逆光构图 |
| 没有真正的黑 | 曝光优先与背景亮度缺席 | 写满照明合同八项 |
| 全身油亮、高光铺满 | 高光没有被列举 | 只允许列出的那几处高光 |
| 光向跨镜变化，正反打像两个片场 | 光没被当成连续物理事实，或反打没换算画面左右 | 一场一条空间光向；反打时按地标换算光在画面哪一侧与照亮哪半边脸 |
| 明暗差别随机 | "高对比"只是形容词 | 写比值（如 2:1、4:1） |
| 阴影方向打架，或雨夜用了正午色温、火光发冷白 | 光源方向与色温没绑定具体物理源 | 写清单一主光源的侧向、仰角、影子落向与具体色温 K 值 |
| 人和背景粘在一起，没有纵深 | 主体与背景明度相当、色相接近 | 拉开背景与主体的亮度层级（亮景压暗人作剪影，或暗景提亮受光面） |
| 调色与参考图两张皮，每镜主色乱跳 | 60:30:10 比例是脱离参考硬编的 | 从已采用参考板与画风里提取主辅色占比，跨镜沿用 |
| 颗粒重到像噪点 | 质感叠写 | 只留一行 |
| 两个豪华内景像同一个景 | 只靠"豪华"区分 | 用工艺与年代区分：做旧对抛光 |
| 每个镜头都被拖回现代 | 年代只是设定，不是规则 | 年代写成规则，进画风与每块板 |

## 九、数值什么时候能写

数值要带作用对象、单位、参照基准；"对比度 70"没有定义，跨软件不能复用。色值要说明它是阴影色偏、资产本色还是光色。光源色温、相机白平衡、画面最终冷暖是三个概念，不能互推。二维平涂没有真实灯光模型时，直接写"偏冷 / 偏暖"，不为每个色块编色温。

提示词里的参数是目标描述，不能据此宣称输出已经达标；验收看实际画面。
