# 偏好

这份文件给**建议值与字段说明**，不是已经生效的偏好；具体项目的习惯由用户逐项确认后，才写进项目目录的 `AGENTS.md`。通用规则在 `SKILL.md` 和 `references/sop/`。

## 存在哪

这份文件是**建议值与字段说明**。具体项目的偏好写在**项目目录的 `AGENTS.md`**（和画布同级），不写回本文件。

AGENTS.md 里固定四节：画风、模型、画幅、生产偏好。

```markdown
# AGENTS

## 画风
（定稿后的画风文字，用中文，原样粘贴；不放确认图）

## 模型
- 图片：（待确认）
- 视频：（待确认）

## 画幅
- 主画幅：（待确认）
- 比例：（待确认）
- 变体：（待确认）

## 生产偏好
- 画布组织：（待确认）
- 素材库：（待确认）
- 命名：（待确认）
- 审片：（待确认）
- 视频音频：生成音频默认打开（模型支持时同遍生成）
```

保留用户原来写在 AGENTS.md 里的其他内容，只改这几节。**你自己不新增别的节**：项目说明、剧情、类目、一次性决定（比如“这次先不生成”）写进项目目录的工作稿或状态文件，不写进 AGENTS.md。

## 模型与提示词规则

建议模型（先问用户，确认后才写）：

| 项 | 建议 |
|---|---|
| 图片模型 | ToonFlow 供应商最新「全能图片」，分辨率取最低档 |
| 视频模型 | ToonFlow 供应商最新 Seedance，分辨率取最低档 |

最低档是起点：成片需要更高画质时再升，不默认升。

## 画幅与形态

画幅是项目工程偏好，不写在 SOP 里。开工前定：

| 项 | 记什么 |
|---|---|
| 横竖 | 竖屏、横屏，还是两个都要 |
| 主比例 | 9:16、16:9、6:7、1:1，项目只定一个主比例 |
| 变体 | 要不要另出切片/投放比例 |
| 分辨率档 | 建议最低档，需要再升 |

常见形态（出发值，不是规定）：竖屏 9:16、6:7，横屏 16:9，方版 1:1。选哪个由项目偏好定。

**提示词格式跟着所选模型走。** 视频用 Seedance 就读 `references/methods/formatRules/seedance.md`，用 MiniMax H3 就读 `references/methods/formatRules/minimaxH3.md`；资产图读 `references/methods/formatRules/assets.md`。一条片只用一套视频格式，不并排执行两种。换了别的模型、没有对应文件时，参照最接近的一份写，并告诉用户这个模型没有现成的格式规则，生成前先试 1 条。

## 怎么用

- 开工前读项目 AGENTS.md；没有就建一份**待确认**模板，不预填默认值。
- **不许静默默认。** 模型、画幅、资产与画布三件逐项问，一次一个；用户已经说清的，复述一遍请他确认就算问过；确认一项写一项，没确认的写“待确认”。只有他说“你看着办”，才落建议值，并说明选了什么、可推翻；这句话只管正在问的这一项，下一项照常问。
- 缺的、拿不准的，一次问一个，不一次抛五个。
- 优先级：用户当场明确说的 > 这份偏好 > 方法论默认。
- 用户换了做法：先按新的做，做完把这条改掉，记日期。
- 不把项目内容、剧情、一次性决定写进来。这里只记会重复用的习惯。

## 一、资产与画布

**默认：全部放一个画布。** 资产、画风节点、每一集（或每一条）的镜头卡和视频节点都在同一个画布里，按区域分开。问画布组织时先提这个；用户说“都行”“你看着办”，就落这个。

| 做法 | 怎么放 | 什么时候用 |
|---|---|---|
| 全部一个画布（默认） | 资产区、画风节点、各集区域同在一个画布 | 大多数项目；单条视频、系列片也一样 |
| 资产一个画布 + 每集一个画布 | 资产集中在一个画布，每集单独一个画布，集画布引用资产 | 只在用户选了它时用，比如集数多、他想分开管 |

素材库：资产先入素材库，存一份；画布里保留引用，不复制多份。

## 二、画布布局

- 画风文本节点在最上方，资产区在它下面；每集一块区域，按集号从左到右排，区域里镜头卡在左、视频节点在右。拆成多个画布时，集画布里同样镜头卡在左、视频节点在右。
- 连线：镜头卡按顺序连到视频节点；画风节点单独放，不连线。
- 内容多了按区域分开、缩放着看，不自己拆画布；用户说要拆，才拆。
- 什么时候上画布：画风定稿就建画风文本节点；剧本、资产表定稿就建对应文本节点；每条提示词定稿就建一张镜头卡文本节点。画布写不进（工具报错、没有画布工具）才只写工作稿，并在回复里说一句；“还没到那一步”“先存文字”不算写不进。能用了再搬上去。

## 三、命名

- 画布：默认一个，用项目名；区域叫 `资产`、`第N集`。用户选了拆分时，画布才叫 `项目名-资产`、`项目名-第N集`。
- 节点：角色用角色名，场景用场景名，镜头卡用镜号。
- 资产：`角色-状态-版本`；新状态给新名，不覆盖旧文件。
- 版本：v1、v2；不写 final、最新、改好的。

## 四、素材库与引用

- 资产过十次测试再入库；没过的不进库。
- 画布里用引用，不复制节点；同一资产只维护一份。
- 提示词里用库里的编号或名称，和库保持一致。
- 库里资产改版，按影响范围重做对应分集，不全片重跑。

## 五、提示词与生成

- 画风：以 `AGENTS.md` 的 `## 画风` 为唯一来源，原样取，不重写、不凭记忆。画布上的画风文本节点是它的原样副本；两处不一致时以 `AGENTS.md` 为准，并把节点同步过来。资产图提示词开头原样贴这段；视频提示词不贴画风，画面风格由已经固定的参考图带进来；只有一条视频完全没有参考图时，才在开头贴画风文字。
- 资产：按引用取，不重新描述长相。
- 生成模型：按「模型与提示词规则」；TTS 音色、音乐来源：待定，定了再写。
- **视频生成音频：默认打开**（模型支持时同遍生成声音）。提示词里照常写底噪、带秒声事件与「音乐不写」，不要因为默认打开就省略声音块。只有唱歌镜临时关掉，且属失败处置不是默认：先录轨再锁嘴——做法见 `references/methods/sound.md` 一。

## 六、审片与交付

- 建议先样片、后成片；客户要求直接成片时按客户。
- 审片人、最多改几轮：待定。
- 回填到哪个节点、导出到哪、归档在哪：待定。

## 七、建议偏好：短剧漫剧（确认后生效）

下面只是建议，不是已生效；逐条问过、用户点头，再写进 AGENTS.md：

1. 全部放一个画布：画风节点在上，资产区按角色、场景、道具分区，每集一块区域。
2. 资产做完先入素材库，画布里留引用。
3. 每集区域只放：本集镜头卡、视频节点。
4. 集与集之间不复制资产节点，只引用；避免同一角色出现两版。
5. 用户想把资产和各集分开管，才改成“资产一个画布 + 每集一个画布”。

## 八、待确认

拿不准就先问，不擅自替用户定：

- 素材库是否允许同一资产被多集同时引用
- 每集区域用集号还是标题命名
- TTS 音色、音乐来源
- 审片轮次上限、交付归档位置

## 九、记录格式

AGENTS.md 里用短句列，不写长表。变更时在条目后补日期：

```markdown
## 模型
- 图片：ToonFlow 最新全能图片，最低分辨率
- 视频：ToonFlow 最新 Seedance，最低分辨率

## 画幅
- 主画幅：竖屏 / 横屏
- 比例：9:16 / 16:9 / 6:7 / 1:1（项目定一个主比例）
- 变体：要不要另出切片比例

## 生产偏好
- 画布组织：全部一个画布，资产区按角色/场景/道具分，每集一块区域（2026-11-26 确认）
- 视频生成音频：默认打开（2026-11-26 确认）
```

## 十、不写进来

- 具体剧情、台词、客户名
- 一次性决定（这次先做 30 秒）
- 尚未确认的猜测
- 通用规则（那些在 SKILL 与 SOP）
