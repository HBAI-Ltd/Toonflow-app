# 分镜、声音与视频提示词

在本次完整剧本已确认、需要拆分生成片段时读取。先按[资产规则](assets.md)盘点完整制作范围；文字规划可先记录缺图，实际执行所需参考齐备后再生成。
**场次承载连续戏，片段是一次视频生成，镜头是片段内的观看单位。** 一个片段可含多个镜头，共用一份提示词、一个视频节点和一次生成，不按分镜表每行建节点。

## 从剧情拆分片段

开始镜头设计或修订时读取[镜头方法](methods/shotDesign.md)，先明确观众需要看懂什么，再选景别、构图和运动。需要把情绪、对白意图、物件互动或打斗写成可见过程时读取[表演与动作](methods/performanceAndAction.md)；需要新定或修订光色时读取[色彩与用光](methods/colorAndLight.md)。以下片段表与正式提示词承接这些结论，不只填技法名称。

1. 完整读取本次约定范围，保留场号、事件因果、人物出入场、原语言对白、OS/VO及用户要求的音乐、字幕与音效。
2. 按信息揭示、动作收束、情绪转折和说话关系确定片段候选，不按每个动词或每句台词拆段；紧密的拿取、交接、落座等动作链尽量在同段完成。
3. 在片段内安排镜头，观看对象或叙事视角变化时再切镜；固定镜头有效，一镜选一个主运镜并说明观看目标、方向及结束构图。
4. 按真实音频、试读或符合表演的语速估算对白，再计入必要反应、辨识时间与动作；可同时发生的部分不重复累加。
5. 文字规划先列剧情估时；已有可用配置时据实核对能力，没有则标记未核实，不为纯文字任务新建生成节点。准备执行时读取目标节点实际 `node:getConfig` 的模式、可用时长、规格和参考容量，以其支持的组合安排生成时长，不套固定上下限或固定镜头数。
6. 容量不足时沿语义或动作收束处重分，不吞对白、删事件、加速表演或填空镜凑时长。用户目标与完整剧情冲突时，说明取舍并确认改编范围。
7. 回查全片覆盖与重复：每个必要事件、台词、状态变化均有位置。已有清晰规划可直接复用，不为格式重新拆分。

规划表可以使用估算秒数；实际总时长写入生成节点配置，文字本身不能设置模型参数。正式提示词通常用动作先后、停顿和声音进入/结束表达节奏，仅在目标模型或用户需要时增加时间格式。

文字规划可以覆盖尚未生成的全部片段，按剧本列各段预期起止状态，标明它们是计划。进入连续片段的后段生成前，再用前段已采用结果核对和修订；缺少实际视频不阻止写规划，计划也不能冒充实际交界状态。

## 每个片段独立成立

- 模型只收到本次提示词与实际参考，不能假设它记得聊天或前一片段。把前段结束状态改写为本段具体起态，不写“同前”“沿用上一段”代替事实。
- 区分场景位置与画面位置：先用门侧、窗边、桌后等真实地标确定人物关系，再写当前机位、观看方向和画面左右。换机位不搬人物或光源。
- 人物在画外仍保持在场，转场、出入场和重新出现应有剧情依据；数量、身体侧别、朝向、视线及银幕运动方向连续。
- 参考图锁定身份、形制与稳定材质，本段写姿态、持物手、开合、损伤等相关状态。物件按“初始位置与持有人 → 动作 → 结束位置与持有人”描述。
- 已完成的拿取、拆开、到达、揭示不重演；持续声音、人物已知信息和观众已知信息分别核对。真正换场按新场景建立状态。
- 跨段重点核对前段末镜与下段首镜。可用有意义的景别或观看对象变化减少跳切，不为转场凭空添动作、空镜或旁白。

## 表演、动作与风格

- 表演写“剧情刺激 → 可见反应或策略调整 → 稳定落点”，用视线、呼吸、停顿、重心及既有物件互动表现情绪；只写镜头确实看得见的细节。
- 主角和配角的行为沿用已有性格、关系与当前目标；群众按其身份、在场原因和事件反应，不要求逐人小传或所有人同步反应。
- 有打斗时写清起势、距离、动作路径、对手反应、局势变化与收束状态，保持角色能力、持物、场地及剧本结果。普通推挤、追赶不升级成武打。
- 无打斗就省略套招内容，不另造“无动作”文档。复杂动作可单独整理设计，再合入本段镜头描述；不强制设独立审批环节。
- 风格沿用已确认素材与用户方向，必要时说明色调、对比、材质和光影变化。技法服务叙事，不以固定六项参数、摄影术语数量或固定情绪配色作为完成门槛。

## 声音与对白

- 原对白保留说话人，跨镜延续时标明已说和待说内容，避免重复播读；听者反应镜头不让听者代说或跟随口型。
- OS/VO 保留原文、发声身份和声音类型，不要求画内人物张嘴，不用表情替换已要求的内心或画外声音。
- 当前模型支持原生音频时，使用已确认的文字声线描述并跨段保持；没有真实音频时不写“匹配样本”，不把外部样本作为生成前置。
- 有真实音频参考时注明对应角色和用途，借用音色不等于复读样本内容，也不等于已开启声音输出；类型、顺序和能力核对见[画布执行](canvasExecution.md)。
- 无原生音频且本段需要声音时，说明可交付的画面范围及必要配音、配乐或合成备用方案，按用户授权执行，不声称静音视频已包含完整声音。
- 音乐、字幕、音效、画内文字按本段剧本与用户要求处理；画内信件文字不自动变旁白，物理音效对应具体动作和声源，不统一禁止音乐或字幕。

## 一份正式提示词的三个部分

先连接本段实际采用的参考，再核对编号与类型。只引入本段所需素材，给同一对象稳定的局部标识；参考顺序、混合媒体和能力限制统一遵循[画布执行](canvasExecution.md)。
三部分合成同一份正文写入视频节点，不分别提交生成。补全并删除解释性占位符；`{{ref N}}` 仅对应真实已接入参考，不把文件路径或素材名当作引用。

纯声音角色直接定义发声身份与声线，不造视觉参考编号。已明确选择且实际支持无参考生成时，用文本定义主体、空间和起始状态，删除未接入媒体的引用句式，不能留下假 `{{ref N}}`。

```text
一、参考与主体定义
将 {{ref N}} 中的{角色名、采用状态}定义为<主体1>，保持{参考可核对的两三项外观锚点}。
{本段发声时：<主体1>的声线为已确认的音色、音区、语速及口音描述。}
将 {{ref N}} 中的{场景名、采用状态}定义为<场景1>，保持{空间地标、通道与必要陈设}。
将 {{ref N}} 中的{道具名、采用状态}定义为<道具1>，保持{形制、材质及必要细节}。
{按实际主体与参考增删定义；有真实声音参考才补其编号、发声人和用途。}
本段起态：{主体相对地标的位置、朝向、视线、已完成动作；物件持有人与状态；持续声音}。
空间与光线：{当前机位及观察方向、画面内外位置、需要保持的实际光源关系}。

二、片段内镜头
镜头{原镜号}：{景别、一个主运镜、观看目标及必要焦点}。{以局部标识写可见动作、反应、位置与持物变化}。
{说话人及对白原文；OS/VO明确声音类型；听者反应与动作音效按发生顺序写明。}
镜头{下一原镜号}：{保持已到达状态，写下一步行动、切镜后的空间关系与完整声音内容，不重演上一动作}。
{保留本片段全部镜头，在明确可承接的状态收束。}

三、风格与约束
{用户已确认视觉方向，与真实资产的身份、空间、材质和光影相容。}
{本段人物与物件数量、持续状态、合理接触和空间关系；剧本确实要求的变化。}
{对白、OS/VO、音乐、字幕、音效及环境变化的实际要求；只写本段需要的约束。}
```

资产板中的多个视角是同一身份或同一物件，不能被生成成多人、多件或分屏画面。默认把可用资产直接用于实际支持的参考模式，不先逐镜生成分镜图。
若用户需要首帧、首尾帧或其他模式，先核对真实支持与输入槽位，再准备对应素材；静态图只承载该瞬间，不把完整动作链画进一帧。

## 检查、验收与局部调优

- 交付前检查：三部分齐全且自足，所有内部镜头在同一正文，引用与状态正确，剧情与声音完整，容量可执行，邻段可接且动作不重复。
- 调整提示词、参数与实际节点时保持一致，不用后改的文稿冒充旧视频当时的生成依据；生成执行与结果回读见[画布执行](canvasExecution.md)。
- 验收依实际可查看的视频检查事件、身份、人数、对白及口型、空间、接触动作、持物状态、声音和输出规格；工具已启动、文件存在都不等于验收通过。
- 不能完整看视频或听声音时明确核验边界，依据用户反馈处理，不虚构审片结论；计划终态不能充当实际生成终态。
- 根据已采用片段的真实结束状态调整相邻片段；失败结果不能自动改写剧情或资产设定。只修受影响片段，复用无关已通过内容。
- 按实际授权安排后续生成与重试，不强制每个镜头重问。采用记录、待办和最终交付遵循[状态与交付](stateAndDelivery.md)。
