# 风格确定

**风格不是词，是一组轴上的取值。** 风格确定要做的事只有一件：把用户给的东西，翻译成一个点，写成一段固定文字，冻结。

下面所有规则都是从这句话推出来的，不是逐条补的。

## 一、模型：风格是一个轴空间

任何画面，都在这十四个轴上有一个位置：

媒介与工艺 / 年代感 / 造型与线条 / 写实度 / 色板 / 光影 / 材质与纹理 / 形体比例 / 空间与构图 / 信息密度 / 镜头语言 / 调性 / 完成度 / 边界

**边界**这一轴管“最容易跑偏到哪一侧”，但要写成正面：说清这一侧应该是什么样，不写“不要 X”。这段文字会原样贴在每张资产图提示词最前面，“不要三维”“不鲜艳”会把三维、鲜艳带进参考图，再跟着参考图进每一条视频。

**镜头语言**这一轴只写全片的视角与景别习惯（平视为主、近景多、机位与人眼齐平），不写镜内运动：推、拉、摇、移每条在提示词里定，还要服从所选模型的规则。

**一部具体的片子，是这个空间里的一个点。** 一个风格词，是空间里的一大块区域。一句"要高级感"，是一个方向不明的区域。

用户给的任何东西——词、作品名、图、形容词、一句"就那种感觉"——**都只是指针，不是取值。**

于是任务就定死了：**照着指针，把区域收窄成一个点，再把那个点写成文字。**

这一步不需要为"用户给的是图"或"用户给的是导演名"分别写规则。指针的精度不同，读法相同。

## 二、三条不变量

**单值律。** 每个轴只能落一个值。落两个，就是没落定。约数也是两个值：“七八头身”要落成“7 头身”。

**可观察律。** 每个值都要能被画面验证——说得出长什么样。说不出，就是还没落。“电影的分寸”“看着舒服”“国漫感”都说不出长什么样，要换成光从哪来、色板几个色、脸怎么画。

**去指针律。** 定稿的文字，把原来那个指针拿掉，还得成立。拿掉就散，说明写的是指针，不是取值。

三条不变量管着后面的一切。真遇到没见过的输入，拿这三条去套，比翻清单快。

## 三、转译四步

**一、读数。** 顺着指针，把十四个轴能读出来的读出来。指针越具体，读得出的越多：图比作品名读得多，作品名比词读得多，形容词几乎读不出。

**二、补空。** 读不出来的轴，要么按专业判断补一个最保守可执行的值，要么问（问的判据见下一节）。

**三、收敛。** 把活着的指针、读出来的值、补上的值合成一个点。合成完要回读一遍：这十四个值放在一起，能不能同时成立。

**四、去指针。** 把词、作品名、图、导演名从文字里全删掉，再读一遍。还成立，算转译完成。

读数是照抄，补空是判断，收敛是合成，去指针是验收。四步缺一，出来的一定是平均值或者大杂烩。

## 四、问什么

**只问一类问题：读不出来、而且答错会变成另一部片子的轴。**

判断标准只有一条：**这个轴答错，是"另一种片子"，还是"另一种细节"？**

- 是另一种片子 → 问
- 只是细节差别 → 自己定

所以"给谁看"要问——给孩子的和给客户的，是两种片子。"色板第 3 个色是赭石还是砖红"不用问——那是细节。

这条判据不依赖轴的名字。以后轴加了、换了，判据不用改。

**写实还是非写实，几乎总会变成另一部片子。** 用户没说，就在这根轴上给两版（一版写实、一版非写实），不在画风之前替他猜。

问的节奏和例外（默认一次一个、三种情况可以一次列三件、同一条问两次就落值）见 `references/responseStyle.md`。

**同一轴问两次还是"随便"：只是细节的轴，落一个最保守可行的值，说明理由，告诉他可以推翻；会变成另一部片子的轴，写两段不同的文字版本，各用一句话说看起来像什么，让他挑一段，挑完再出那 1 张确认图。** 不追第三次：追问到第三次，不是问信息，是在为难他。

## 五、两种失败，两种药

风格做砸，只有两种：

**抖。** 同一段文字跑几次，结果不一样。这是稳定性失败。

**错。** 跑几次都一样，但不像用户要的。这是保真度失败。

两种都要查，只查一种必然漏。

**抖的病因也只有两种：**

- 某个轴还空着 → **补值**
- 某个轴上落了两个值 → **删掉一个**

怎么分？**看变的幅度。** 细节在变（色相偏一点、颗粒多少）是缺项；范式在变（这张写实那张卡通）是冲突。

冲突的处方是减法。补，只会让两个值更硬，抖得更厉害。

## 六、冲突与融合是同一件事

因为风格是轴空间，所以：

**冲突** = 同一个轴上落了两个值。默认处置是选一个；选不出来，再走下面的分治三条。

**融合** = 不同轴分别取值，再定主轴和比例。不是把两个风格"拼起来"，是**给每个轴分配来源**。

两者都不需要专门的方法论，它们是"轴空间"这个模型的直接推论。

**融合必须写清比例。** 同一组轴，霓虹占一半和霓虹只出现在招牌上，是两个片子。比例写成可观察的句子，不写权重符号。

**逐轴分配要落盘。** 哪个轴取自哪个来源，写进同一个文件，跟风格文字一起版本化。不落盘，下一镜就得靠记忆，而记忆会漂。

**不可调和就走分治。** 三条路，从便宜到贵：

- 切分：按时间（A 段 / B 段）或按元素（人物 / 环境）各自成段
- 分层：主风格一段，指定镜号另贴例外段，例外段绝不混进主段
- 两版：差异太大，出两版让用户挑，不硬拼成第三物

## 七、写出来是什么样

"迪士尼"翻完，大概是这样一段。每一项都落在值上，没有指针，也没有否定句（调性、年代感、写实度、信息密度这四项这里没写，实际交付时要按片补上）：

**一律中文。** 定稿文字只用中文写：不夹英文术语、英文提示词、模型名、平台名。作品名在转译时已经删掉；画面要求一律用中文说清。

```
经典二维手绘动画，赛璐璐上色。闭合的黑色描边，粗细均匀，转角圆润，线条连续。
单主光从左后上方 45 度来；阴影柔和的渐变，最暗处停在中灰，边缘带暖色轮廓光。
色板：暖琥珀与奶油色作底（约占画面 70%），青绿色作点缀，控制在 5% 以内；肤色浅而均匀。
角色：眼睛约占脸的三分之一，每只虹膜两个高光，鼻子小而圆，四肢线条平顺简化，
表情幅度约为真人的两倍；动物拟人、直立、手为人的手。身体 6.5 头身。
背景用柔和的水彩画法，两个景深层次（前景清晰、远景朦胧），舞台式的平面调度。
镜头：平视、正面，机位与人眼齐平，中景和近景为主。
完成度：干净，线条单一清晰，色块平整，边缘整齐。
边界：始终是平面的二维绘制；皮肤是平涂色块；色彩饱和而明亮；脸部五官简化、卡通比例；
笔触平滑；明暗反差温和，暗部透亮。
```

整段里没有"迪士尼"三个字，也没有"经典""高级"这种词——去指针律过了。原来想写的“不要三维、不要低饱和”都改成了“始终是平面的二维绘制”“色彩饱和而明亮”。

这段只对应手绘这一条路。要三维，整段换掉，不是改几个词。

## 八、验证

**稳定性（可选）。** 同一段文字跑两三次，看是不是同一个点；不稳就回去改文字，不是多抽几次碰运气。

**一张图确认。** 定稿后只出 1 张给他看。不满意就改文字，再重出这一张，直到他说可以；不一次出多张让他挑，也不换参考图。

**怎么出。** 同一段文字、同一个主体，出 1 张。改一轮只改文字，不改图。

**他看完这一张。** 认可，冻结；指出哪里不像，**改文字重出这一张，不换图**；说不上来，让他指一处不对，再改一句。

**可以跳过。** 他说不用看、赶时间、或者信你，就按文字版往下做，说清楚"后面看到图觉得不对随时说"，在 AGENTS.md 的 `## 生产偏好` 或项目工作稿里标一句"画风：用户未看图确认"；不写进 `## 画风`，那一节会原样贴进每条提示词。

**判定前先排干扰。** 场景复杂度和随机性先统一，再判断是不是提示词的问题。

## 九、冻结

定稿之后，这段文字是全片常量。每次出资产图都原样贴在最前面，一个字不改；视频提示词不贴，风格由已经固定的参考图带进来。

同义改写会让约束漂移，不值得拿一整片赌。

**"同一段"管的是别改，管不了这段本身是不是单值。**
一段里两个答案，贴同一段照样抖，而且是整镜级别地抖。单值靠单值律保证，不靠冻结。

两种语言只执行一份。并排贴出去，等于每一镜都在改写。

## 十、落盘：写进项目目录的 AGENTS.md

定稿之后，画风文字固定写进**项目目录的 AGENTS.md**（和画布同级），不散落在提示词或分镜卡里。

- 在 AGENTS.md 里开一节 `## 画风`，正文只放这段定稿文字；不写故事、台词、分镜、资产、解释，也不写确认日期、用户原话、“文字确认”这类备注。
- 画风只存文字：确认用的图不写进 AGENTS.md、不挂画布、不作参考图、不入素材库。
- 一个项目一处。已有 `## 画风` 就替换这一节，不重复开节。
- 落盘的就是他看过、认可的那段，一字不改。落盘前想改一句，先把改后的全文给他看，他点头再写。写完读回 `## 画风`，和他认可的那段逐字比对，一个字不同就重写。
- 完全不生成画面的片子，这一节写字卡、字幕与包装的样式（字体、字号、颜色、位置），不出确认图。
- 实拍为主、生成只补空镜的片子，这段文字照已有实拍素材写（光线、色调、颗粒、镜头质感），确认时拿生成的那一张和一张实拍截图并排对照。
- 保留 AGENTS.md 里其他内容（模型、画幅、生产偏好，和用户自己写的内容），只改画风这一节。
- 它是全片唯一来源：每张资产图提示词都从这一节原样复制，不另存、不重写。视频提示词不贴画风，画面风格由已经固定的参考图带进来；只有一条视频完全没有参考图时，才在开头贴画风文字。
- 改风格只改这一节，再按影响范围重做；不要到几十条提示词里逐条改词。
- 落盘前核六件事：是不是定稿版；有没有残留指针（作品名、导演名、参考图、“国漫感”这类词）；有没有混进分镜或台词；有没有否定句（以“不、无、别、避免、不要”起头的，改成正面）；有没有两可值或说不出样子的词（“七八头身”“电影感”）；有没有点名本片的地点、道具、角色（“卷帘门”“电动车”“猫毛”）——画风写的是怎么画，不写画什么，材质写成“金属有锈和划痕”这类通用说法；天气（雨、雪）、地点类型（街景、临街小店）、具体物件（纸箱、手机屏、灯箱）也算“画什么”，写进场景与提示词，不进画风。

## 十一、不做的事

- 不把指针原样写进提示词（词、作品名、导演名、平台名、文件名）
- 不让一个轴落两个值
- 不在画风文字里写否定句（它会原样贴进每张资产图提示词）
- 不在画风里写镜内运动（推拉摇移在每条提示词里定）
- 不用补值的方式修冲突
- 不用图替代那段文字（图是取证和验收，不是载体）
- 不用"同一段"代替"单值"
- 不并排执行两种语言
- 不靠多抽几次碰运气
- 不把画风分散写进每张分镜卡（画布上只存一份，出资产图时从画风节点复制）
- 不写英文风格词或英文提示词（要中文能说清）；模型要求的固定英文语法（如 MiniMax H3 的键名、标签、词表）不算风格词，照模型要求写
- 不承诺 100% 一致
