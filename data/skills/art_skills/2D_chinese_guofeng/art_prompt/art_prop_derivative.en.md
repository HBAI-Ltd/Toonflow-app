# Prop Derived State Generation · Constraint Manual

---

## 1. Derivation principles

1. **The form is anchored** — the prop's core form/silhouette stays recognisable in every state
2. **The state is readable** — the difference between states must be obvious at a glance, so the audience tells them apart immediately
3. **Serving the narrative** — every state variant serves a specific plot beat
4. **Gradual degradation** — damage/ageing states must follow sound physical logic
5. **Prop alone, shown independently** — only the prop itself may appear in frame. Any person, hand or limb is strictly forbidden; the prop must not be held/worn/gripped, and must be presented independently as a still-life display

---

## 2. State types

### 2.1 Use states

| State | Description | Suitable props | Prompt |
|---|---|---|---|
| Brand new | Intact and undamaged, sheen like new | All props | brand new、intact and undamaged、sheen like new |
| Everyday use | Slight wear, natural patina | Weapon/object/jewellery | traces of everyday use、natural patina |
| Old | Clear sense of age, dull color | Object/token/scroll | old and mottled、a sense of age、dull color |

### 2.2 Damage states

| State | Description | Suitable props | Prompt |
|---|---|---|---|
| Slight damage | Small cracks/small chips/light wear | Porcelain/jade pendant/weapon | fine cracks、slight chipping |
| Broken | Clear cracks/fracture/shattering | Porcelain/jewellery/weapon | clear cracks、shattered、fractured |
| Fragment | Only part/shards remain | Porcelain/jade pendant/token | fragment、shards、only half left |

### 2.3 Special states

| State | Description | Suitable props | Prompt |
|---|---|---|---|
| Bloodstained | Blood adhering to it | Weapon/token/scroll | mottled bloodstains、bloodstained、anime rendering |
| Soaked/wet | Water marks, wet reflection | Scroll/token/paper | soaked、wet paper、ink bleeding |
| Burnt/charred | Charred black edges, burn marks | Scroll/token/wooden item | charred black edges、burn marks、carbonised |
| Glowing/activated | Inner energy, light radiating out | Token/ritual implement/jade | faintly glowing、light held within、cel-shaded light effect |
| Wrapped/sealed away | Wrapped in cloth/a box | Token/jewellery/secret object | wrapped in brocade cloth、sealed in a wooden box、ancient-style packaging |

### 2.4 Environment-adapted states (new)

| State | Description | Suitable props | Prompt |
|---|---|---|---|
| Snow-covered | Covered in settled snow | Weapon/object/token | covered in snowflakes、settled snow、a wintry feel |
| Rain-wet | Wet with rainwater | Paper/cloth/wooden item | wet with rainwater、water marks、a damp feel |
| Wind-eroded | Worn by wind and sand | Outdoor object/weapon | traces of wind and sand、wear、a sense of age |
| Rusted | Metal oxidised | Weapon/metal jewellery | covered in rust、oxidised、a sense of passing years |

## 4. Rules for material state change

| Material | Brand new → everyday | Everyday → old | How damage shows |
|---|---|---|---|
| Metal | Bright sheen → slight patina | Patina → rust spots | Chips/rolled edge/fracture |
| Jade | Translucent and mellow → slight wear | Wear → fine surface cracks | Cracks/shattering/chipped corner |
| Wood | Fresh wood grain → natural patina | Patina → dull color | Splitting/fracture/worm holes |
| Porcelain | Glaze sheen → fine scratches | Scratches → dulled glaze | Cracks/shattering/chips |
| Cloth/paper | Brand new and flat → slight creasing | Creasing → yellowed and brittle | Tearing/charring/ink bleeding |

## 6. Constraint rules

### Mandatory

| No. | Rule |
|---|---|
| R1 | The prop's core form/silhouette stays recognisable in every state |
| R2 | State changes must follow physical logic |
| R3 | Must use a four-panel grid (2×2) layout: front + side + back + close-up |
| R4 | Must specify "solid moon white background", even soft light, no hard shadow |
| R5 | Must contain the keywords "Guofeng anime + cel-shaded flat coloring" |

### Forbidden

| No. | Forbidden |
|---|---|
| X1 | The prop becoming unrecognisable after the state change |
| X2 | Damage that breaks physical logic (jade rusting and the like) |
| X3 | Excessively gory/horrific depiction of damage |
| X4 | Any human figure appearing, including full body, half body or part (hand, fingers, arm and other limbs) |
| X5 | The prop being held, gripped, worn or in use |
| X6 | Elements implying a person's presence (traces of being held, a wearer's viewpoint, a using posture) |
