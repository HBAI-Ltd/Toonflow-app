# Video Prompt · Visual Style Constraints

When generating a video prompt, you must inject the following visual style tags:

| Mode | Style tag |
|------|----------|
| **Universal multi-reference mode (English)** | `2D flat design, geometric shapes, solid color blocks, minimal shadows, clean lines, modern aesthetic` |
| **Universal first/last-frame mode (English)** | `2D flat design, geometric shapes, solid color blocks, minimal shadows, clean lines, modern aesthetic, shallow depth of field` |
| **Seedance 2.0 (English)** | `2D flat design style, geometric shapes, solid color blocks, no shadows, clean lines, modern minimalist` |
