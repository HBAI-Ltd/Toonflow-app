# 导演企划手册 · 治愈系都市女性生活与关系

## 一、企划命题

每集从一个可在一天内完成的具体愿望出发，例如“下班后好好吃顿饭”“第一次一个人看日出”“带爸妈买件新衣服”。故事不依赖重大冲突，而是观察人物如何通过一串小动作把普通一天过完整。

企划必须先写清四句话：

1. **今天想完成什么**：具体、可见、可在 68—89 秒内讲清。
2. **途中遇到什么小阻力**：疲惫、时间紧、路远、犹豫、选择多或舍不得离开。
3. **谁通过什么动作参与**：递物、并肩、一起做饭、等待、目送、报平安。
4. **最后停在哪里**：到达、回家、休息、陪伴或一个未说破的小满足。

## 二、固定规格

| 项目 | 企划约束 |
|---|---|
| 母版 | 原生 3:4 竖幅 |
| 总时长 | 68—89 秒，默认约 80 秒 |
| 节拍数 | 20—27 个，建议 22—25 个 |
| 单节拍 | 通常 3—4 秒，必要时 2—5 秒 |
| 开场 | 前 3—6 秒明确动机、时间或异常 |
| 中段 | 时间戳行动链，小满足与小阻力交替 |
| 高点 | 不是吵架或哭戏，而是抵达、交接、共同完成或被理解 |
| 收束 | 到家、坐下、关灯、报平安、看电视、门口目送等生活动作 |

## 三、总叙事公式

`快速动机 → 时间戳行动链 → 小满足/小阻力 → 关系或意志抬升 → 到达/回家/休息/陪伴`

### 推荐时间分配（约 80 秒）

| 段落 | 时间 | 职责 |
|---|---:|---|
| 钩子与动机 | 0—7 秒 | 时间、地点、今天要做什么 |
| 准备与出发 | 7—20 秒 | 人物状态、装备/食材/妆容、动线 |
| 行动链展开 | 20—52 秒 | 具体动作、小满足、小阻力与关系信息 |
| 情绪抬升 | 52—68 秒 | 抵达、共同完成、互相照料或记忆触发 |
| 余韵收束 | 68—80 秒 | 回家、休息、报平安、目送或共享安静 |

时长可按成片在 68—89 秒内伸缩，但不得把同一动作重复拆分来凑时长。

## 四、六类故事模型

### 4.1 独居自愈

**命题**：独处不是缺失，而是主动照料自己的时间。

推荐行动链：

`下班动机 → 回家/买菜 → 换鞋放包 → 洗手备菜 → 烹饪 → 盛盘 → 独自用餐 → 洗漱/护肤 → 阅读/整理 → 关灯`

企划重点：

- 开场用时间戳、工位疲惫或回家动作建立一天结束。
- 做饭占 3—5 个节拍，必须包含完整状态变化而非食物蒙太奇。
- 小满足可以是热汤、洗净头发、床边书、整齐的房间。
- 结尾可停在台灯熄灭、杯子放下或窗外夜色。
- 不增加等待恋人、失恋回忆或男性来电。

### 4.2 通勤工作

**命题**：把忙碌晨间整理成可掌控的小秩序。

推荐行动链：

`闹钟/时间 → 洗漱 → 化妆 → 穿搭 → 早餐/出门 → 电梯/通勤 → 到工位 → 工作片段 → 午后/下班`

商业合作可选：

- 只有项目明确需要时才设置产品段落。
- 产品融入真实动作：取用、涂抹、观察、收纳，不做悬浮硬广。
- 建议不超过全片约 26 秒或约三分之一。
- 产品镜头之后必须回到人物的通勤或工作生活。
- 未确认品牌与文案时用无字中性包装，禁止伪造 Logo 和功效。

### 4.3 独自挑战

**命题**：一个人也可以有准备地完成一次小冒险。

推荐行动链：

`决定 → 检查装备 → 出发 → 夜路/山路 → 第一次疲惫 → 喝水调整 → 继续 → 黎明将近 → 抵达 → 日出 → 下山/回归`

企划重点：

- 开场快速说明目标和时间，不用长篇励志旁白。
- 阻力来自坡度、夜色、疲惫与不确定，不用事故或险情制造戏剧。
- 安全装备始终在场，人物不靠男性救援完成。
- 情绪高点是视野打开和呼吸放缓，不是英雄大喊。

### 4.4 女性友谊

**命题**：成年人的友谊由见面、共享与分别后的惦记构成。

推荐行动链：

`约见/到达 → 并肩进入 → 用餐 → 互拍/看照片 → 逛街 → 护理或按摩 → 送别 → 到家 → 报平安 → 各自夜晚`

企划重点：

- 用双人共同行动代替长正反打。
- 允许玩笑、互相照顾和轻拥抱，但避免情侣化符号。
- “分别后仍惦记”是重要尾部节拍：安全到家消息、各自洗漱或休息。
- 不增加争风吃醋、男性话题主线、恋爱或暧昧。

### 4.5 外婆与旧时光

**命题**：熟悉的动作与旧空间提醒人们，相处的时间值得被认真使用。

推荐行动链：

`返乡动机 → 进入老街 → 门口相见 → 放下东西 → 一起择菜/做饭 → 共餐 → 看旧物/菜园/小店 → 床边或门口短谈 → 离开/目送`

企划重点：

- 老街不是复古景点，要有持续生活。
- 情感来自外婆慢一点的动作、小幸主动接手、旧物仍在原处。
- 可出现“时间有限”的克制文案，但不得推导死亡、疾病、遗嘱、住院或葬礼。
- 离别保持日常：装食物、提醒路上慢点、门口看一会儿。

### 4.6 父母与双向照料

**命题**：成年后，父母继续带来食物，女儿也开始主动照顾他们。

推荐行动链：

`突然到访 → 搬行李 → 打开家乡食物 → 一起做面/做饭 → 共餐 → 出门购物 → 女儿挑衣/买单 → 回家休息 → 一起看电视`

企划重点：

- 父母的爱通过行李、食物、帮手动作出现，不用说教。
- 女儿的回馈必须有可见行动，例如付款、递衣、安排座位或准备茶水。
- 三人同框优先围桌、并肩走和沙发共享空间。
- 禁止催婚冲突、家庭伦理争吵和父亲霸总化。

## 五、节拍设计

每个节拍只承担一个主功能：

- **信息节拍**：时间、地点、目标、关系。
- **动作节拍**：移动、准备、制作、交接。
- **感觉节拍**：热、香、风、疲惫、触感、安静。
- **关系节拍**：等人、递物、并肩、目送、报平安。
- **过渡节拍**：跨时间、跨地点或状态变化。

推荐每 3—5 个动作节拍插入一个感觉或关系节拍，避免全片像操作说明；感觉节拍也必须有可见物理依据。

## 六、文案体系

### 6.1 四层文案

1. **口语行动**：“到家先把鞋换了”“今晚想吃点热的。”
2. **轻松玩笑**：“嘴上说随便，最后还是点了一桌。”
3. **感官舒适**：“锅一开，厨房就暖起来了。”
4. **克制时间感**：“以前总觉得来日方长，现在更想把这一顿饭吃慢一点。”

### 6.2 写作规则

- 时间戳在上，日记短句在下。
- 简体中文、粗白字黑描边，保持一眼可读。
- 每句优先 8—16 个汉字，避免连续长段。
- 说动作时不过度抒情，说情绪时落回具体物件或动作。
- 家庭结尾可左对齐两行，但不直接总结人生。
- 时间戳必须单调递增，跨日需明确标注，禁止时间戳倒退。

### 6.3 禁止文案

- “女人最终还是需要一个归宿”之类性别说教。
- 把闺蜜写成恋爱替代品，把父母写成催婚工具。
- “可能这是最后一次见面”等无依据死亡暗示。
- 空洞鸡汤、连续金句、宏大成功学和产品功效承诺。

## 七、影像组织

基础循环：

`建立镜头 → 动作镜头 → 细节镜头`

- 建立镜头交代人物在哪、谁与谁同场、主要动线。
- 动作镜头完成一个能看懂的行为。
- 细节镜头落到手、食物、装备、衣物、旧物或消息。
- 关系段落用双人/三人同框与共同行动优先，正反打只补充必要反应。
- 每段使用 1 个短空镜交代时间或空间即可，不用景物蒙太奇代替人物行动。

## 八、声音企划

### 配乐

- 独居：轻钢琴、木吉他、柔和 lo-fi 纹理。
- 通勤：轻快但不急促的节拍与柔和键盘。
- 夜爬：低密度脉冲、呼吸感铺底，日出时开放和声。
- 友情：轻松木吉他、软鼓刷或明亮键盘。
- 家庭：钢琴、木吉他或低密度弦乐，保持克制。

### 环境与动作声

- 公寓：钥匙、鞋、切菜、沸水、餐具、翻书、开关灯。
- 工作：电梯、脚步、键盘、纸张、杯子。
- 山路：呼吸、鞋踩石阶、衣料、风、树叶、登山杖。
- 友情：餐厅低语、相机快门、购物袋、车门、安全带。
- 旧宅：树叶、电线轻响、切菜、面粉、旧门轴、小店环境。
- 父母：行李轮、塑料/布袋、和面、擀面、电视低声。

完整成片使用连续立体声，建议综合响度约 `-16 LUFS`，真峰值不高于 `-1 dBTP`。旁白、字幕语义、配乐和动作声不要同时争抢。

## 九、企划自检

- 目标能否在第一段被看懂。
- 是否有 20—27 个可执行节拍，总时长是否在 68—89 秒。
- 是否至少有一个小阻力、一个小满足和一个具体收束动作。
- 关系是否通过共同行动而不是解释性对话建立。
- 是否保持独处的主体性、友情的非恋爱性和家庭的克制。
- 商业内容若存在，是否不超过约三分之一且不篡改故事。
- 是否明确 3:4 母版，未把 9:16 黑边当作风格。
- 是否排除死亡、疾病、霸总、暧昧、样板间和水印等误读。
