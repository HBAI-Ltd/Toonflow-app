# 治愈系都市女性生活半写实二维动画风格说明

本手册用于制作 **3:4 竖幅、约 80 秒** 的治愈系都市女性生活与关系动画 Vlog。它来自六支参考成片的共同规律：独居下班、自我照料、工作日晨间、独自夜爬、女性友谊、探望外婆和父母来访。手册同时包含完整的视觉规范与导演规范，可直接供 Toonflow 的角色、道具、场景、分镜和视频提示词流程调用。

这套风格的核心不是“精致生活展示”，而是：

> 把普通一天里真实可执行的小动作，拍成有时间感、关系感和余温的私人日记。

## 一、内容定位

- **题材**：当代中国都市女性生活、女性友谊、独处、自我照料、轻职场、旅行挑战与三代家庭关系。
- **一级视觉**：半写实二维数字插画动画。
- **二级视觉**：柔和韩系网漫气质、克制赛璐璐明暗、轻电影光影与生活化环境质感。
- **叙事形式**：时间戳日记式 Vlog；用连续行动而非长对白推进。
- **情绪基调**：清爽、温柔、独立、轻幽默、有一点时间流逝的感伤，但不苦情。
- **受众感受**：先看懂“她今天做了什么”，再感到“有人与她彼此惦记”，最后落在安静而具体的满足。

## 二、固定成片规格

| 项目 | 默认要求 |
|---|---|
| 母版画幅 | 3:4 竖幅 |
| 参考时长 | 68—89 秒，典型值约 80 秒 |
| 叙事节拍 | 20—27 个节拍，单节拍通常 3—4 秒 |
| 结构 | 快速动机 → 时间戳行动链 → 小满足/小阻力 → 情绪抬升 → 到达、回家、休息或陪伴收束 |
| 镜头组织 | 建立镜头 → 动作镜头 → 细节镜头，循环推进 |
| 字幕 | 简体中文，时间在上、日记短句在下，粗白字黑描边 |
| 声音 | 轻配乐、动作声、环境声和必要的轻口播；不依赖宏大旁白解释 |

平台若要求 9:16，只允许把 3:4 母版放入平台安全画布或做经过审查的延展；**9:16 黑边不是视觉风格**，不得把黑边生成进画面。

## 三、六类故事模型

1. **独居自愈**：下班回家、买菜、做饭、洗漱、阅读、整理房间、独处夜晚。
2. **通勤工作**：起床、洗漱、化妆、穿搭、通勤、办公；商业合作只作为可选段落，不吞没人物生活。
3. **独自挑战**：准备、出发、遇到疲惫或不确定、继续前进、抵达高点、回归安静。
4. **女性友谊**：见面、吃饭、拍照、逛街、按摩、送别、报平安；亲密来自默契和照料，不来自恋爱编码。
5. **外婆与旧时光**：返乡、穿过老街、共同做饭、旧物细节、院落和小店、离开前的克制停顿。
6. **父母与双向照料**：突然到访、行李中的食物、一起做饭购物、女儿主动买单或安排休息、共同看电视。

## 四、固定人物系统

- **小幸**：女主角的工作代号；当代中国年轻都市女性，身形修长，栗棕色长卷发，暖白肤色，棕色眼睛，柔和秀气五官，精致但不凌厉的妆容。
- **短发闺蜜**：深色短发、清爽利落、与小幸明显不同的脸型和配色。
- **母亲**：中年女性，短卷发，成熟圆润的面部与体态，常用藏蓝或低饱和深色。
- **父亲**：中年男性，成熟结实，灰色、炭色或藏蓝简洁衣着。
- **外婆**：老年女性，灰白短发、轻微含胸，缎面上衣、黑裤与软底鞋，动作慢但不虚弱化。

姓名可按项目替换；角色的年龄层、脸部结构、发型色、体型和身高关系不得跨镜头漂移。不得把所有女性生成成同一种年轻网红脸。

## 五、固定空间系统

- **现代公寓**：卧室、浴室、厨房、餐桌、衣柜和客厅；整洁但有使用痕迹，不是无人物痕迹的样板间。
- **职场与商业空间**：办公室、电梯、商场、餐厅、护理空间、超市、停车场与车内。
- **自然旅行**：公路、山路、石阶、林间、山顶、夜色、日出与远景。
- **老街旧宅**：大树、电线、石板路、低层旧楼、红木家具、绿色旧厨房、菜园、小店和旧院墙。

## 六、色彩与光线

基础色为奶油白、象牙、浅米、暖木和可可黑，建议锚点：

- 奶油白 `#F0E2CE`
- 浅杏米 `#F4E0C4`
- 暖木棕 `#DAA87D`
- 可可黑 `#1E1611`
- 深夜藏蓝 `#27354D`

故事点缀色随内容变化：都市红、夜爬荧光黄绿与日出橙粉、旧宅青绿与红木、闺蜜篇卡其与灰粉、父母篇藏蓝灰与蔬菜绿。白天明净带绿，城市室内为奶油暖光，家庭旧宅略低色温，夜景以深蓝和有来源的局部光为主，团聚或抵达可使用克制金色轮廓光。

## 七、关系表达

关系戏优先拍 **共同行动**：

- 一起切菜、包饺子、下面、摆碗；
- 并肩走路、同坐一辆车、一起挑衣服；
- 给对方拍照、按摩、递水、整理衣领；
- 开车送回、发消息报平安、一起看电视；
- 床边说话、门口目送、把食物塞进行李。

不依赖大量正反打和解释性台词。亲密由动作的先后、距离变化、物件交接与自然停顿产生。

## 八、视觉与生成禁令

- 禁止把友情或亲情改写成恋爱、霸总、暧昧、三角关系。
- 禁止把外婆或父母线夸张成死亡、疾病、贫困奇观或催泪苦情。
- 禁止同脸、年龄漂移、身高漂移、发色漂移和无依据的换装。
- 禁止手指错误、额外肢体、道具穿模、食物变形、衣物互穿。
- 禁止生成错误招牌、品牌 Logo、产品文字、字幕、水印和 UI。
- 禁止画内出现 `@小确幸` 或任何自动生成水印。
- 禁止把 9:16 黑边、播放器边框或平台裁切误判为构图元素。
- 禁止过度溶解导致重影、双重身体、鬼影和时间空间混乱。
- 禁止把每个家都做成纯白精装修样板间。
- 禁止过度磨皮、真人照片感、纯平涂卡通、3D 塑料感与高饱和糖果色。

## 九、手册组成

- `prefix.md`：全部生成任务共用的视觉基因和硬约束。
- `art_prompt/`：角色、衍生角色、道具、场景、衍生场景、分镜视频视觉提示词。
- `driector_skills/`：导演企划、镜头执行与分镜表规范。
- `images/cover.png`：Toonflow 列表中的无字风格封面。

执行时应先锁定故事模型、人物表、空间表和时间轴，再生成资产与分镜。任何专项剧情要求可以增加内容，但不得覆盖本手册的身份连续性、关系边界、3:4 母版和视觉禁令。
