# 道具衍生手册 · 状态链与组合资产

## 一、衍生目标

同一道具的衍生图必须展示故事所需的状态变化，而不是随机换色或重新设计。每组建议生成 3—5 个关键状态，供分镜和视频模型锁定连续性。

## 二、五类衍生方式

1. **开合变化**：行李箱关闭 → 打开 → 取出部分物品 → 重新收好。
2. **消耗变化**：完整食材 → 切配 → 烹饪 → 盛盘 → 吃后剩余。
3. **使用变化**：干毛巾 → 使用中 → 潮湿挂起；书本合上 → 翻开 → 加书签。
4. **环境变化**：登山装备干燥 → 夜露/轻汗 → 山顶风吹后的褶皱。
5. **归属变化**：衣物在货架 → 小幸递给母亲 → 母亲试穿 → 放入购物袋。

## 三、推荐状态组

### 独居晚餐组

- A：台面上的完整食材与空锅。
- B：砧板上的切配食材、刀放在安全位置。
- C：锅中烹饪，蒸汽方向与抽风/窗向一致。
- D：餐桌盛盘，餐具数量与用餐人数一致。
- E：餐后剩余与收拾状态。

### 晨间化妆组

- A：刷具与产品整齐放置，瓶盖关闭。
- B：发夹固定碎发，镜子朝向小幸。
- C：单一工具接触正确面部区域。
- D：工具归位、瓶盖恢复，妆容只做合理增量。

### 夜爬装备组

- A：出发前背包、手电、头灯、水瓶、能量食品齐全。
- B：夜路中头灯点亮，背包与水瓶位置不变。
- C：休息时取出水瓶，瓶盖与剩余水量连续。
- D：山顶仍保留装备，衣物有轻风与轻汗状态。

### 闺蜜聚会组

- A：桌上双人餐具与未动食物。
- B：共同用餐后的合理减少。
- C：手机/相机用于拍照，镜头方向正确。
- D：购物袋数量与已购买内容对应。
- E：分别后手机显示抽象消息气泡，具体文字由后期完成。

### 外婆厨房组

- A：旧木桌、蔬菜、围裙与器具。
- B：两人择菜或和面，共同行动清楚。
- C：热食盛出，蒸汽与光线真实。
- D：吃后碗盘与打包食物，旧物位置保持。

### 父母来访组

- A：关闭的行李箱与保温袋。
- B：行李打开，食物和蔬菜按层次摆放。
- C：部分食材被取到厨房，箱内数量减少。
- D：购物后新增无 Logo 购物袋。
- E：客厅休息时行李已收纳，不在镜头中随机消失。

## 四、组合资产规则

- 组合图只展示同一行动链中的物品，不做“全片道具大拼盘”。
- 桌面物品有前后遮挡但轮廓可读，关键手持物不得被完全遮住。
- 食材、生熟区域和刀具位置符合安全常识。
- 两人用品通过颜色、位置和归属区分，不能复制粘贴成完全相同。
- 旧宅组合允许更多使用痕迹，现代公寓组合保持整洁但非样板间。

## 五、衍生提示词模板

```text
参考基础道具图，生成同一道具的连续状态组。
道具与归属：{名称，归属角色}。
固定不变：尺寸比例、主色、材质、结构、把手方向、磨损位置。
状态顺序：
1. {初始状态与位置}
2. {使用动作与中间状态}
3. {结束状态、剩余量与新位置}
动作逻辑：{角色用哪只手、如何接触、内容物如何变化}。
画面：半写实二维数字插画，柔和网漫质感，真实材质，低对比奶油背景。
禁止：重新设计、随机换色、镜像翻转、道具穿模、无来源蒸汽、液体违背重力、错误文字、Logo、水印、UI。
```

## 六、质量自检

- 每个状态是否能按时间顺序排列且没有回退。
- 数量、内容物、开合方向、污渍和剩余量是否连续。
- 道具是否与角色手型、身体尺寸和空间比例匹配。
- 画内文字是否被避开或留给后期，是否无品牌与水印。
- 是否出现手指错误、道具穿模或无物理依据的漂浮。
