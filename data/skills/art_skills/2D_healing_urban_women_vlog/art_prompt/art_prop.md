# 道具资产手册 · 生活动作的情感载体

## 一、道具原则

本风格中的道具不是静物陈列，而是动作和关系的载体。每个关键道具必须回答：

- 谁在使用或保管；
- 在什么场景、什么时间出现；
- 使用前、使用中、使用后是什么状态；
- 是否发生交接、消耗、开启、加热、沾湿或收纳；
- 它承担行动、舒适、记忆还是关系功能。

道具采用半写实二维数字插画，保留真实比例、材质、重量和使用痕迹。禁止错误品牌、乱码文字、Logo、水印与无用途装饰堆叠。

## 二、道具连续性等级

| 等级 | 定义 | 示例 |
|---|---|---|
| P0 固定识别 | 跨集可复用，外形与主色稳定 | 小幸通勤包、旅行背包、常用马克杯 |
| P1 单集关键 | 推动本集行动，状态必须逐镜连续 | 食材、行李箱、购物袋、相机、登山杖 |
| P2 环境支持 | 构成生活空间，不抢主体 | 台灯、床品、餐具、纸巾、旧家具 |
| P3 氛围点缀 | 只用于色彩和时间，不可无节制增加 | 花束、绿植、香氛、窗边小灯 |

## 三、独居自愈道具组

### 通勤与回家

- 简洁中型通勤包：灰褐、深咖或黑色，无品牌大 Logo。
- 钥匙与门禁卡：尺寸真实，拿取方向和门锁动作合理。
- 手机：现代但不展示错误界面或乱码，必要时使用背面或虚焦屏幕。
- 鞋与拖鞋：玄关位置固定，换鞋前后状态连续。

### 做饭与用餐

- 砧板、厨刀、锅、锅铲、餐盘、碗、筷子、玻璃杯。
- 蔬菜、面食、肉类或汤品按剧情选择，数量不过量。
- 食材存在完整 → 切配 → 烹饪 → 盛盘 → 吃后剩余的状态链。
- 蒸汽只来自热锅、热水和热食；冷食不得无来源冒气。
- 刀刃接触砧板，筷子夹住食物，手指避开热面与刃口。

### 洗漱与休息

- 毛巾、牙刷、护肤瓶、发圈、睡衣、书、马克杯、床头灯。
- 护肤瓶不出现真实品牌文字，泵头与瓶盖状态前后连续。
- 书页、杯中液体和台灯开关必须有可见状态变化。

## 四、通勤工作道具组

- 化妆镜、粉扑、刷具、口红或唇釉、发夹。
- 笔记本电脑、键盘、鼠标、文件夹、便签与水杯。
- 电梯按钮、工位椅、通勤包和手机。
- 商业合作需要产品时，只生成经项目确认的外形和文字；未确认品牌时使用无字中性容器。
- 化妆动作必须明确工具接触区域，不能刷具悬空或镜中手势相反。
- 办公桌保持 3—6 件有用物品，不堆成杂货铺，也不做空无一物的样板工位。

## 五、独自挑战道具组

- 轻量背包、登山鞋、防风外套、水瓶、能量食品、手电/头灯、登山杖。
- 小面积荧光黄绿可用于反光条、安全带或头灯固定带。
- 背包肩带必须双侧受力正确，水瓶放置位置跨镜稳定。
- 夜间光束从手电或头灯发出，方向与人物视线、台阶位置一致。
- 登山杖触地点、脚落点和身体重心形成合理三点支撑。
- 日出段落不无故丢失背包、外套或安全装备。

## 六、女性友谊道具组

- 餐厅餐具、饮料、甜点、纸巾、菜单（避免正面错误文字）。
- 手机与相机：用于互拍、回看照片、预约或报平安。
- 购物袋：无品牌 Logo，数量与购买行为一致。
- 护理/按摩空间的毛巾、茶杯、储物篮与简洁用品。
- 车钥匙、安全带和车内手机支架；开车时不同时操作手机。
- 关系道具以“双份但不复制”为原则：两个杯子可有差异，两只包区分归属。

## 七、外婆与旧时光道具组

- 旧木桌、红木或深棕柜体、搪瓷/陶瓷碗、旧热水壶、布围裙。
- 新鲜蔬菜、面粉、面条、家常菜与小店纸袋。
- 老照片、缝纫盒、旧梳子、布包、日历等记忆道具按剧情谨慎出现。
- 旧物必须是被长期使用和保存的生活物，不是古董陈列。
- 老照片若出现，不生成可辨认的错误文字；照片内容只作柔和概括。
- 旧厨房的绿色柜门、瓷砖和器具可有掉色、磨痕，但不得肮脏或危险化。

## 八、父母与双向照料道具组

- 行李箱、保温袋、家乡食物、蔬菜、面食材料与收纳盒。
- 行李打开后，物品数量、位置和被拿出的顺序要连续。
- 和面盆、擀面杖、面板、面条、锅与碗构成完整做面链。
- 商场试穿衣物、购物袋、付款手机/银行卡；不展示错误金额和品牌。
- 沙发毯、遥控器、茶杯与电视微光用于家庭收束。
- 女儿主动买单或递衣服时，动作必须完成交接，体现双向照料。

## 九、材质表

| 材质 | 视觉处理 |
|---|---|
| 陶瓷 | 柔和高光、厚度可见、边缘完整，不像塑料 |
| 玻璃 | 透明度与折射克制，杯中液面有水平线 |
| 金属 | 局部硬高光，不做镜面广告质感 |
| 木材 | 暖木纹、边角使用痕迹，现代家居较平整，旧宅更有磨损 |
| 针织与棉布 | 柔软褶皱、纤维方向和重量感 |
| 缎面 | 外婆上衣等局部使用，亮部成带状，不像塑料薄膜 |
| 防风面料 | 轻皱、局部反光、受风响应，避免乳胶感 |
| 食物 | 湿润、切面、热气和容器接触真实，不过度广告级油亮 |
| 屏幕 | 低亮、轻反光，只在剧情必要时可读 |

## 十二、禁令与自检

- 禁止手指错误、手掌穿进杯把、筷子穿过碗、刀刃穿手。
- 禁止道具穿模、突然缩放、左右翻转、内容物瞬间变化。
- 禁止无来源蒸汽、液体违背重力、食物跨镜变品类。
- 禁止手机、菜单、包装、招牌出现乱码或错误品牌。
- 禁止用奢侈品堆叠代替都市女性生活质感。
- 检查关键道具是否真正推动动作或关系；无功能物件应删减。
