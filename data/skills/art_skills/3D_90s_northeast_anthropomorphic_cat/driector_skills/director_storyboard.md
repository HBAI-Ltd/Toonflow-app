# 分镜提示词 · 东北90年代拟人猫电影动画

## 一、适用范围

本 Skill 专用于 1988—1990 年北安市红星机械厂家属院系列的分镜图提示词。输入通常包含镜头序号、画面描述、角色、场景、道具、景别、机位、动作、情绪和光影。

目标不是改写剧情，而是把分镜表转译为图像模型可以执行的单帧画面：

- 谁在画面什么位置。
- 角色此刻保持哪套造型。
- 正在完成哪个动作的哪一瞬间。
- 角色看向哪里，谁能看见谁。
- 光从哪里来，环境有哪些生活痕迹。
- 这一帧的喜剧或温情信息在哪里。

## 二、提示词组织顺序

每条提示词按以下顺序组织：

1. 风格与时代锚定。
2. 9:16 竖屏、景别、机位与构图。
3. 场景固定结构与时段。
4. 角色身份、外形锁和空间站位。
5. 动作瞬间、猫爪交互、尾巴与衣物状态。
6. 耳位、眼神、胡须、嘴角与身体重心。
7. 关键道具及其物理关系。
8. 光源、色温倾向和冷暖对比。
9. 材质、生活使用痕迹与环境动态。
10. 画质、连续性和禁止项。

不得把角色、场景和风格词拆成彼此矛盾的形容词堆。

## 三、固定角色短锚

提示词只要角色入镜，就必须包含其短锚；如有参考图，短锚仍需保留以防漂移。

| 角色 | 固定短锚 |
|---|---|
| 小橘 | 瘦小8岁橘色虎斑拟人猫，左耳轻折，眉心闪电纹，橘棕旧棉袄，军绿斜挎包挂红福袋 |
| 橘爸 | 高大结实成年橘猫，方脸浓眉，蓝灰旧工装棉服，酒红毛衣，黑旧工靴，小厂徽 |
| 花妈 | 利落三花拟人猫，偏长脸，绿色眼睛，低饱和格纹罩衣，米色旧围裙 |
| 猫奶奶 | 矮小银灰狸花老猫，圆框老花镜，深蓝绒线帽，深色棉衣棉坎肩，小手帕 |
| 大勇 | 儿童黑白奶牛拟人猫，鼻梁白纹，小豁牙，宽大蓝灰旧棉服，补丁裤，灰围巾 |

同一场戏如果角色已脱外套或放下书包，后续镜头使用当前造型状态，不机械重复基础全套服饰。

## 四、情绪转译

### 4.1 猫科微表情矩阵

| 情绪 | 眼睑/视线 | 耳位/胡须 | 身体重心 |
|---|---|---|---|
| 得意 | 上眼睑略抬，目光观察别人反应 | 耳朵向前，胡须轻张 | 胸口略挺，尾巴轻扬 |
| 心虚 | 视线短暂侧移后回来 | 耳朵向两侧，胡须略收 | 下巴收回，爪子挡在身前 |
| 馋 | 目光在食物与大人之间来回 | 鼻尖靠近，胡须向食物方向 | 身体不自觉前倾 |
| 犹豫 | 先看风险再看伙伴 | 耳朵微后 | 后脚退半步、前脚仍朝伙伴 |
| 看穿 | 眼睑轻抬，余光锁定 | 耳位稳定 | 手中动作继续，只停半拍 |
| 忍笑 | 眼睛微眯，目光回避 | 胡须轻颤 | 肩部极轻微抖动 |
| 温柔 | 眼睑放松，目光稳定 | 耳位自然 | 身体靠近或把物件推向对方 |
| 担心 | 目光持续跟随对方动作 | 耳朵微向侧后 | 上身前倾，爪子准备接住 |
| 坚定 | 目光直视，瞳孔稳定 | 耳朵向前 | 双脚站稳，肩背不夸张 |
| 失落 | 视线下移，眨眼变慢 | 耳朵略低 | 肩部放松，尾巴垂低 |

### 4.2 禁止表达

- “非常开心”“特别感动”“十分搞笑”等抽象结论不能单独使用。
- 禁止眼球突出、喷泪、嘴张到脸的一半、头顶问号/感叹号。
- 禁止人类式夸张皱眉覆盖猫脸结构。
- 温情不使用大颗泪珠与过曝柔光替代动作。

## 五、动作瞬间选择

单帧分镜应选择动作最可读、角色最稳定的一瞬：

| 动作 | 推荐瞬间 |
|---|---|
| 偷吃 | 猫爪刚夹起食物，鼻尖靠近，另一只爪仍扶着锅盖/盘边 |
| 被抓包 | 动作停在半途，视线先转向门口，藏物仍有一角可见 |
| 递东西 | 两只猫爪同时接触物体但主导权清楚，视线落在对方脸上 |
| 修玩具 | 一只爪固定零件，另一只爪使用工具，工具尖端接触正确位置 |
| 骑自行车 | 双爪握把、脚踩踏板、尾巴保持平衡，不与车轮相交 |
| 写信 | 一爪压纸、一爪握木杆笔，纸张方向与视线一致 |
| 包饺子 | 一爪托皮、一爪捏合边缘，面粉只在接触处 |
| 玩游戏 | 双爪握粗线手柄，线缆通向主机/CRT电视，身体略前倾 |
| 藏东西 | 物件进入柜缝/衣襟/书包一半，爪子与开口位置合理 |
| 推门 | 一爪压/转把手，门按铰链方向开启，身体重心随步伐移动 |

猫爪不得变成人手；抓握可以更灵活，但指节、短绒和肉垫特征应保留。

## 六、角色关系构图

### 6.1 家庭喜剧

- 小橘在前景或中景执行计划，花妈可在背景继续做家务但视线已注意到他。
- 橘爸与小橘结盟时使用同一侧站位或相似小动作；被抓包后两者视线向不同方向逃避。
- 猫奶奶常位于画面边缘或桌边，通过一个小动作掌握信息，不抢占主角视觉中心。
- 背景人物如果承担尾梗，必须保持清楚到能读出反应，不使用过浅景深。

### 6.2 伙伴喜剧

- 小橘位于行动方向前半步，大勇位于后半步或侧后方。
- 大勇提醒风险时身体朝出口，眼睛仍看小橘。
- 遇到外部冲突时大勇可向前挡半步，小橘不躲得过远。

### 6.3 温情

- 通过距离缩短、物件转移和并肩位置表达。
- 不要求角色拥抱；修好玩具、分一半冰棍、把靠窗位让出都可以完成温情。
- 使用中近景保留手部/猫爪动作和双方表情。

## 八、光影词库

### 8.1 时间与地点

| 条件 | 主光 | 辅光/反射 | 画面效果 |
|---|---|---|---|
| 冬晨家中 | 窗外冷蓝漫射 | 厨房/裸灯泡暖黄 | 冷窗暖屋、早餐蒸汽 |
| 白天教室 | 成排窗户中性冷光 | 墙面与木桌暖反射 | 清楚朴素、粉笔灰可见 |
| 冬日院子 | 阴天冷光 | 雪地漫反射 | 蓝灰红砖、毛发边缘清楚 |
| 厂门下班 | 低角度日光 | 门卫室/食堂暖灯 | 自行车剪影但细节可读 |
| 家中夜晚 | 钨丝灯/台灯 | 窗外微弱冷蓝 | 家庭包裹感、暗部有细节 |
| 停电 | 蜡烛/手电 | 窗外冷余光 | 局部可见、适合藏与找 |
| 露天电影 | 幕布中性反光 | 楼道/窗口暖点 | 脸部被幕布照亮、夜色冷 |
| 火车白天 | 车窗自然光 | 车厢米黄/墨绿反射 | 车窗一侧较亮、旅行感 |

### 8.2 光影句法

提示词应说明：

`主光来源 + 画面方向 + 色温倾向 + 软硬 + 被照亮的部位 + 辅助反射来源`

示例：

`窗外冬日冷蓝漫射光从画面左侧绿色木窗进入，柔和照亮小橘左侧脸和棉袄毛边；桌上钨丝灯约3000K暖光从右下方补亮猫爪与搪瓷碗，冷暖交界自然，暗部仍可读。`

禁止只写“电影光影”“温暖氛围”而没有光源。

## 九、材质词库

- 猫毛：真实细短毛流、局部毛缘、胡须与鼻镜自然高光。
- 旧棉袄：厚度真实、袖口磨亮、洗旧褪色、缝线可见。
- 灯芯绒：纵向绒条、膝部轻磨、暗哑反光。
- 木柜/木桌：掉漆、手握处磨亮、边角磕碰、水杯圈。
- 铁暖气/工具：暗哑金属、轻锈、油迹或冷凝水。
- 搪瓷：克制光泽、蓝边、小磕点。
- 水磨石：细石子纹、入口湿脚印、擦洗暗光。
- 红砖：风化、砂浆缝、积雪脏边和煤灰。
- 冰雪：脚印、车辙、冻硬层、融雪灰边。
- 蒸汽：半透明、随热源上升、受侧光可见，不能遮脸。

每镜选 3—5 个与画面有关的材质，不堆叠全部材质词。

## 十三、输出自检

- 是否写明 9:16、景别、机位和空间层次。
- 是否只呈现一个清楚的动作瞬间。
- 是否包含入镜角色固定短锚与当前造型状态。
- 是否能从站位看出人物关系和笑点信息。
- 是否明确主光来源、方向与冷暖关系。
- 是否只加入当前镜头可见且有用的年代元素。
- 是否保留猫科结构、猫爪抓握和尾巴物理。
- 是否没有现代物件、影棚复古、夸张鬼脸、画外字幕和水印。
