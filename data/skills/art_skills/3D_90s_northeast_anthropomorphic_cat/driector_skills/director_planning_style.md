# 东北90年代拟人猫电影动画 · 导演规划技法

## 一、导演定位

本系列以孩子视角观察 1988—1990 年北安市红星机械厂家属院。导演规划的优先级为：

1. 一件具体的小事是否清楚。
2. 家人和伙伴的关系是否通过行动成立。
3. 喜剧是否来自人物性格与空间关系。
4. 年代信息是否自然存在而非被讲解。
5. 温情是否藏在动作里而非被台词总结。

老物件只是动作载体：小霸王游戏机重要，是因为两个孩子怎样轮流、怎样藏卡带、怎样被抓包；绿皮火车重要，是因为谁把靠窗位置让给谁、谁把最后一块点心掰成两半。

## 二、60 秒结构

每个视频约 60 秒，不按 90 秒结构展开。推荐 10—14 个镜头，单镜头通常 2—6 秒。

| 时间段 | 功能 | 典型内容 |
|---|---|---|
| 0—5 秒 | 事件钩子 | 食物、秘密、停电、迟到、游戏卡、电影开场等具体问题 |
| 5—18 秒 | 计划形成 | 小橘起主意，大勇提醒风险，必要时橘爸暗中加入 |
| 18—38 秒 | 行动升级 | 计划执行，空间/道具关系制造两次递进笑点 |
| 38—50 秒 | 情感转折 | 朋友互相护着、父亲偷偷帮忙、妈妈留出余地、奶奶善后 |
| 50—57 秒 | 结果落地 | 事情解决或代价出现，不做宏大总结 |
| 57—60 秒 | 生活化尾梗 | 抓包、露馅、甩锅、补刀或一个具体动作笑点 |

结构允许按剧情微调，但尾梗必须留出 2—4 秒让观众看清反应。

## 三、情绪配比

- **50% 家庭和伙伴喜剧**：来自行动、站位、对话短句、道具失控和角色互相拆台。
- **30% 年代回忆**：来自环境、声音、物件和集体生活方式，不安排百科式说明。
- **20% 温情与成长**：来自让出食物、修好玩具、留灯、掖衣领、递热水等动作。

一集可以有温情，但不强行煽情；一集可以怀旧，但不暂停故事展示物件。

## 四、人物关系调度

### 4.1 标准喜剧链

`小橘想办法 → 大勇犹豫后加入 → 橘爸按剧情暗中配合 → 花妈从生活细节识破 → 猫奶奶不动声色善后`

不要求每集五人全到场；只使用完成该事件必要的角色。

### 4.2 角色节奏

| 角色 | 动作节奏 | 喜剧位置 | 情感位置 |
|---|---|---|---|
| 小橘 | 快于思考，先伸爪再观察 | 自信计划、嘴硬解释 | 最后愿意让出最喜欢的东西 |
| 大勇 | 先停顿、提醒、再跟上 | “我就知道”但仍被拖下水 | 出事时护着小橘 |
| 橘爸 | 表面稳，暗地孩子气 | 讲道理后自己犯同样错误 | 修东西、留好吃的 |
| 花妈 | 动作不停，判断最快 | 不回头也知道父子在做什么 | 添饭、收拾、留台阶 |
| 猫奶奶 | 慢、准、少 | 一本正经配合或轻声补刀 | 传统习俗和秘密同盟 |

## 五、色调规划

| 段落 | 主色 | 辅色 | 叙事用途 |
|---|---|---|---|
| 家中日常 | 米黄色 | 橘棕 + 墨绿 | 安全、热闹、生活秩序 |
| 户外闯祸 | 蓝灰色 | 红砖 + 暗红点缀 | 冷环境中的孩子活力 |
| 厂区/上学 | 蓝灰 + 墨绿 | 米黄窗口光 | 集体生活与工业城市 |
| 春节/团聚 | 暗红点缀 | 米黄 + 橘棕 | 节庆而不商业艳俗 |
| 成长瞬间 | 橘棕 | 蓝灰 + 米黄 | 冷暖共存、克制温柔 |

- 暖色是家庭与食物，冷色是冬天与工业，不把“温情”简单等于全片黄色。
- 同场戏主导色不超过两个。
- 禁止高饱和糖果色、大面积现代纯白和霓虹赛博色。

## 六、光影方案

| 方案 | 光源 | 色温倾向 | 适用场景 |
|---|---|---|---|
| A 冬晨家中 | 窗外冷天光 + 厨房暖灯 | 6500K / 3000K | 起床、早餐、上学前 |
| B 暖桌灯 | 裸灯泡/台灯 + 木墙反射 | 2800—3200K | 吃饭、包饺子、修玩具 |
| C 雪地漫射 | 阴天 + 雪地反光 | 6500—7500K | 家属院、上学、玩冰车 |
| D 厂区清晨 | 低角度日光 + 门卫室暖光 | 冷中性 / 3000K | 父亲上班、厂门自行车潮 |
| E 停电局部光 | 蜡烛/手电 + 窗外冷余光 | 2200—3200K / 冷蓝 | 停电喜剧、秘密行动 |
| F 幕布反光 | 电影幕布 + 窗口/楼道灯 | 中性亮面 / 暖点 | 露天电影 |
| G 火车窗光 | 车窗自然光 + 车厢暖灯 | 随时段 / 3200K | 旅行、写信、分享食物 |

每场戏先指定一个主方案。只有打开灯、停电、进出门或时间流逝等事件发生时才改变主光。

## 七、材质规划

- **猫毛**：细短毛流、局部逆光毛缘、冬季略蓬松，禁止塑料壳和毛绒玩具。
- **旧棉布**：洗旧、褶皱、补丁、袖口磨亮，禁止现代羽绒亮壳。
- **木材**：掉漆、把手磨亮、修补钉，禁止北欧新家具和统一仿古漆。
- **铁器**：暗哑、油迹、轻锈、焊点，禁止镜面未来金属。
- **搪瓷**：克制光泽、边缘小磕点，禁止崭新收藏品感。
- **冰雪**：脚印、车辙、脏边和冻硬层，禁止明信片纯白雪景。
- **蒸汽**：锅、暖气、烟囱、呼吸各有来源与尺度。

## 八、镜头规划

- 9:16 竖屏，优先使用门框、窗框、楼道、烟囱、晾衣绳与火车车厢建立纵深。
- 事件开头用一个清楚的动作或道具钩子，不用长空镜慢慢铺陈。
- 家庭喜剧优先双人/多人中景，让观众看清谁能看到谁、谁藏在什么后面。
- 温情时使用近景或中近景观察递物、修补、掖衣领等动作，不滥用大特写眼泪。
- 每集保留 1—2 个短空镜提供时代与时间信息，单个通常 2—3 秒。
- 使用适量景深；环境笑点需要背景信息时不得虚化掉关键人物。

## 九、声音世界

### 9.1 配乐

- 手风琴：家属院集体生活、轻快日常，使用克制，不做刻板俄式风情。
- 口琴：童年、放学、夏日晚风和克制回忆。
- 木吉他：伙伴行动、轻松奔跑和日常过渡。
- 钢琴/低弦：只在 20% 温情成长段落轻铺，不推动强煽情。
- 打击乐：木鱼块、轻鼓刷、拍手等用于行动喜剧，避免综艺音效轰炸。

### 9.2 环境音

| 场景 | 核心环境音 |
|---|---|
| 小橘家 | 暖气水流、锅盖轻响、菜刀切板、CRT低鸣、楼上脚步 |
| 家属院 | 自行车铃、风吹晾衣、扫雪声、远处邻居招呼 |
| 机械厂 | 汽笛/铃声、金属远响、自行车链条、蒸汽排放 |
| 学校 | 广播喇叭、课间铃、粉笔声、操场脚步 |
| 供销社/市场 | 纸包折叠、算盘珠、杆秤、叫卖与脚步 |
| 露天电影 | 放映机转动、幕布受风、观众低语 |
| 绿皮火车 | 车轮节奏、车厢轻振、杯盖碰撞、远处报站 |

每场戏选择 1—2 个核心环境音。声音帮助观众进入年代，不需要旁白解释。

## 十、生活化尾梗库

- 小橘刚解释完，藏在衣服里的糖/卡带/工具掉到地上。
- 橘爸严肃批评小橘，自己口袋里露出同样的“证据”。
- 父子同时指向对方，花妈继续手里的活，只说一句“都站好”。
- 猫奶奶说“我什么也没看见”，手帕下面却正盖着关键物。
- 大勇说“我早就不同意”，镜头下移发现他抱着最多的道具。
- 大家以为计划成功，窗外邻居隔着晾衣绳补一句早就看见了。

尾梗是具体动作和反应，不使用画外字幕、罐头笑声或角色面向观众解释。

## 十一、全局禁令

- 不把 60 秒短片扩写成 90 秒或更长的散漫结构。
- 不让现代物件、现代服装、现代包装和现代装修穿帮。
- 不把拟人猫变成真人猫耳、四足宠物猫或 Q 版萌宠。
- 不使用夸张鬼脸、摔扁拉伸、眼球突出等纯动画笑法。
- 不用老物件蒙太奇替代故事。
- 不用过度黄滤镜、重颗粒、暗角和破败制造怀旧。
- 不用旁白总结、哭戏堆叠和宏大配乐强行煽情。
