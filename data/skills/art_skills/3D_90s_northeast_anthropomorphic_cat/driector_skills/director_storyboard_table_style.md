# 分镜表约束 · 东北90年代拟人猫电影动画

## 一、分镜表定位

分镜表负责把单集约 60 秒的生活事件拆成可拍、可生成、可连续的视频镜头。它必须在每一行回答：

- 这几秒发生了什么可见动作。
- 角色从哪里移动到哪里。
- 猫爪接触了什么，尾巴与衣物怎样响应。
- 光源、场景和物件是否与上一镜连续。
- 这个镜头承担喜剧、年代还是温情功能。

不使用“气氛很好”“一家人很温暖”“小橘很调皮”等模型不可执行的抽象句替代动作。

## 二、单集规格

| 项目 | 约束 |
|---|---|
| 总时长 | 约 60 秒；不是 90 秒 |
| 画幅 | 9:16 竖屏 |
| 推荐镜头数 | 10—14 镜 |
| 常规镜头时长 | 2—6 秒 |
| 尾梗时长 | 最后 2—4 秒 |
| 情绪比例 | 50% 家庭和伙伴喜剧 / 30% 年代回忆 / 20% 温情与成长 |
| 收尾 | 生活化笑点，不强行煽情 |

镜头数量以动作清楚为准。不能为了凑镜头把一次拿杯子拆成五个无意义特写，也不能把十多个动作塞进一个 5 秒镜头。

## 三、60 秒镜头分配

### 3.1 推荐版本：12 镜

| 镜头 | 时间建议 | 叙事职责 |
|---|---:|---|
| 1 | 0—4s | 具体钩子：食物、秘密、停电、迟到、游戏卡、车票 |
| 2 | 4—8s | 小橘看到机会或问题 |
| 3 | 8—13s | 小橘提出计划，大勇/橘爸给出反应 |
| 4 | 13—18s | 准备行动，明确空间和道具 |
| 5 | 18—24s | 第一次执行与小笑点 |
| 6 | 24—29s | 风险出现，花妈/环境留下识破线索 |
| 7 | 29—35s | 第二次升级，人物关系加深 |
| 8 | 35—41s | 计划失控或秘密即将暴露 |
| 9 | 41—46s | 朋友/家人做出保护性动作 |
| 10 | 46—51s | 温情转折落地，不停留太久 |
| 11 | 51—57s | 表面解决，角色以为安全 |
| 12 | 57—60s | 证据掉出/一句补刀/互相甩锅的生活化笑点 |

### 3.2 调整规则

- 对话多的家庭戏可用 10—12 镜，每镜稍长。
- 追逐、玩耍、市场和火车动作戏可用 12—14 镜，但每镜只保留一个主动作。
- 温情镜头不超过连续 8 秒，避免拖慢尾梗。
- 年代空镜总量建议 4—8 秒，分散在开场、转场或时间变化处。

## 四、分镜行必填信息

每一镜至少包含：

1. 镜头序号与时长。
2. 场景、季节、时段。
3. 景别、机位、镜头高度和运镜。
4. 入镜角色及当前服装状态。
5. 角色水平位置与纵深位置。
6. 动作轨迹、时长和接触物。
7. 耳位、视线、胡须、嘴角和身体重心。
8. 关键道具的位置、朝向和状态。
9. 主光来源、方向和冷暖倾向。
10. 环境动态与核心环境音。
11. 与前后镜头的动作/视线/位置衔接。
12. 本镜叙事功能：喜剧、年代、温情或转场。

## 五、动作具象化

### 5.1 动作句法

`起始姿态 → 发力部位 → 移动轨迹 → 接触/结果 → 用时 → 其他身体部位响应`

### 5.2 常用动作库

| 动作 | 可执行描述 |
|---|---|
| 从盘里夹饺子 | 右爪从胸前向前伸约25厘米，两根可抓握猫科指节夹住盘边一只饺子，向上抬约15厘米，停在嘴前10厘米；左爪扶盘边，全程约2秒 |
| 把东西藏进书包 | 左爪撑开军绿斜挎包口，右爪把铁皮盒沿长边方向推进包内约三分之二，盒角卡住时停顿0.5秒再调整角度，全程约3秒 |
| 推门进入 | 右爪按下/转动旧门把，门按铰链向内转约70度；右脚跨门槛，身体随门进入，尾巴从门边收回避免夹住，全程约2.5秒 |
| 穿棉袄 | 右爪先伸入右袖，左爪把衣领从肩后拉正，再伸入左袖；双肩后展让棉袄落位，尾巴从下摆开口自然穿出，全程约5秒 |
| 骑自行车起步 | 双爪握住车把，左脚踩地稳定，右脚把踏板转到前上方；右脚下压踏板同时左脚离地踩上另一踏板，尾巴向后轻摆保持平衡，全程约3秒 |
| 写信 | 左爪压住信纸左下角，右爪握木杆铅笔沿横向缓慢书写，眼睛随笔尖移动；写完一行后右爪抬起并向左回位，全程约4秒 |
| 把冰棍掰开 | 双爪分别握住冰棍两侧，向相反方向缓慢施力，断开瞬间两臂各回弹约5厘米；小橘看向较大一半再把它递向大勇，全程约3秒 |
| 修玩具 | 左爪固定木轮，右爪用小螺丝刀顺时针旋转两圈，工具尖端始终接触螺丝槽；尾巴自然垂下，全程约4秒 |
| 互相甩锅 | 小橘与橘爸先同时看向花妈，停顿0.3秒，再几乎同时抬爪指向对方；两者耳位向两侧，猫奶奶在背景继续折手帕，全程约2秒 |

动作描述不要求每次写精确厘米，但必须有方向、接触和时长，避免“做了个手势”“忙活起来”。

### 5.3 猫科物理

- 猫爪可以灵活抓握，但保留短绒、圆指节和肉垫；不得变成人手。
- 尾巴用于平衡和微情绪，随转身有轻微滞后，不主动卷起重物。
- 耳朵对声音先反应，转头可晚 0.2—0.5 秒。
- 胡须接近锅、杯和狭窄柜缝时有轻微方向变化。
- 厚棉袄会限制肩肘幅度，儿童动作略笨但不僵硬。
- 雪地脚步会压出脚印，室内湿脚印随步数逐渐变浅。

## 六、空间连续性

### 6.1 坐标写法

每镜使用：

```text
水平位置：画面左/中/右或三分之一位置
纵深位置：前景/中景/背景，距镜头约X米
固定参照：距门、窗、桌、暖气、柜子约X米
角色关系：A与B相距约X米，朝向与视线方向
```

### 6.2 连续性示例

镜头 A 末尾：

`小橘站在餐桌左侧中景，距镜头约2.2米，右爪夹着饺子停在嘴前10厘米；花妈位于右侧门框内，距小橘约1.5米。`

镜头 B 开头：

`保持小橘和花妈站位不变。切到小橘近景，饺子仍在右爪、距嘴约10厘米；小橘只把眼睛先转向画面右侧花妈方向，头部尚未完全转动。`

禁止切镜后饺子换爪、书包换肩、门改变开启方向、角色突然跨越房间。

### 6.3 180 度轴线

- 双人对话先建立人物轴线，后续正反打保持视线方向。
- 小橘位于画面左看向右，则花妈反打位于画面右看向左。
- 需要跨轴时，用角色移动、摄影机绕行或一个新的全景重新建立。

## 七、角色与服装连续性

每场戏开始建立造型状态表：

| 角色 | 外层 | 内层 | 随身物 | 手持物 | 表面状态 |
|---|---|---|---|---|---|
| 小橘 | 是否穿橘棕棉袄 | 毛衣/旧上衣 | 书包是否在肩上 | 当前道具 | 雪屑/面粉/干净 |
| 其他角色 | 同理 | 同理 | 同理 | 同理 | 同理 |

- 脱衣、放包、换鞋和围围巾都需要镜头或明确场间变化。
- 雪屑进入室内会融化，不应十分钟后仍干燥附着。
- 面粉、煤灰和泥点只在触碰/行走后出现。
- 小橘左耳轻折、眉心闪电纹等 L0 特征每镜保持。

## 八、光影连续性

### 8.1 每镜光源栏

```text
主光：{窗/灯泡/炉火/幕布/天空}，从画面{方向}，{冷/暖与约色温}，{软/硬}
辅光：{雪地/墙面/桌面/窗外余光}，从画面{方向}
触发变化：{若无则写“无”}
```

### 8.2 同场规则

- 同一场戏主光位置不变，除非角色打开灯、停电、太阳被遮、进入另一个空间。
- 反打镜头应根据空间翻译光线方向，不能让灯在每个角色同一侧。
- 停电后所有依赖电力的灯和 CRT 电视同时熄灭。
- 露天电影幕布画面亮暗变化可影响角色脸部，但不能改变夜色基础。

### 8.3 冷暖逻辑

- 家中暖灯与窗外冷蓝是主对比。
- 雪地环境冷，门窗和食堂灯是小面积暖点。
- 温情镜头可以略靠近暖源，但不突然把全场改成金色滤镜。
- 暗部保留角色轮廓、猫毛和关键道具。

## 九、环境动态

每 3—4 镜至少有一个来自生活的环境动态：

| 场景 | 动态描述 |
|---|---|
| 厨房 | 锅盖边缘蒸汽持续向上并向窗户方向轻偏；沸腾时锅盖每约1秒轻跳一次 |
| 起居室 | 暖气上的小手帕因热空气轻微颤动；窗霜边缘一滴融水每秒下滑约1厘米 |
| 家属院 | 晾衣物被风向画面右侧鼓起约10厘米后回落；烟囱蒸汽同方向缓慢飘 |
| 学校 | 广播喇叭先出现轻微电流声；粉笔落在槽内扬起少量粉尘 |
| 市场 | 秤砣受放货动作左右摆动三次后逐渐停止；棚布只在有风一侧轻振 |
| 露天电影 | 幕布下缘受风轻摆；放映机光束内微尘缓慢通过 |
| 火车 | 车厢每约1秒轻微横向晃动；搪瓷杯盖随振动发出细小碰声 |

动态不得抢走主动作。没有风、热、水或机械来源时不添加无原因运动。

## 十、喜剧节奏

### 10.1 三拍结构

1. **建立规则**：花妈说饺子要等人齐；橘爸说谁也不许偷吃。
2. **违反规则**：小橘行动，必要时橘爸也暗中加入。
3. **反应落点**：证据同时出现，花妈/奶奶一句短话完成尾梗。

### 10.2 反应镜头

- 反应必须晚于事件 0.2—0.8 秒，给角色看见和理解的时间。
- 同时反应时设置先后：耳朵先动 → 眼睛转 → 头转 → 身体停。
- 尾梗后保留至少 1 秒静止或小动作，不立即切黑。
- 禁止快速变焦、综艺花字、罐头笑声和漫画拟声符号。

## 十一、温情节奏

- 温情由物件或位置改变触发：大的一半被递出去、靠窗位被让出、灯被留着、玩具被修好。
- 给动作 2—4 秒完成，双方反应 1—2 秒即可。
- 不连续使用泪眼特写、拥抱、慢动作和宏大音乐。
- 温情后仍回到生活，通常由一句普通话或小笑点收束。

## 十二、运镜

| 运镜 | 可执行描述 | 适用 |
|---|---|---|
| 固定 | 摄影机固定，人物与环境在画面内行动 | 家庭对话、抓包、尾梗 |
| 缓推 | 2—4秒内向主体推进约0.3—0.8米 | 注意到证据、温情动作 |
| 缓拉 | 3—5秒内后退约0.5—1米 | 揭示旁边一直有人看见 |
| 轻跟拍 | 与孩子保持约1.5—2米距离平稳跟随 | 家属院奔跑、上学、市场 |
| 小幅摇镜 | 原地水平转动15—45度 | 从藏物转向门口、视线转移 |
| 手持微动 | 幅度克制、非连续剧烈晃动 | 玩耍或轻微慌张段落 |

### 运镜禁令

- 无叙事目的的 360 度旋转、无人机俯冲、英雄环绕。
- 快速甩镜、急推急拉、超过画面可读性的手持晃动。
- 在一个 4 秒镜头同时推、摇、变焦和绕行。
- 以现代广告式滑轨炫技代替生活观察。

## 十三、转场

### 允许

- 硬切：同场动作与反应。
- 动作匹配：关柜门切到关教室门，放下搪瓷杯切到火车杯盖。
- 声音先行：厂汽笛、课间铃、火车轮声提前进入。
- 空镜过渡：烟囱蒸汽、楼道灯、车窗外移动景色，2—3 秒。
- 光源触发：停电瞬间切到手电亮起。

### 禁止

- 翻页、百叶窗、星光、旋转、马赛克和短视频模板转场。
- 用大段怀旧蒙太奇跳过人物行动。
- 同一集使用超过两种明显转场花样。

## 十四、音画同步

分镜表对关键同步点标注相对时间：

- `t=1.8s` 搪瓷杯落在木桌，发出轻脆碰声。
- `t=2.2s` 门轴轻响，小橘耳朵先向门口转。
- `t=3.0s` 游戏卡带插到底，CRT 画面随后亮起。
- `t=4.5s` 工厂汽笛响，远处自行车队开始移动。
- `t=2.5s` 绿皮火车接缝声加重，杯中水面随车厢晃动。

对白、动作声与环境音不要互相争抢；尾梗通常让配乐轻停，保留一句话或一个物件落地声。

## 十五、分镜卡片模板

```text
【镜头 X】时长：{X}s｜叙事功能：{喜剧/年代/温情/转场}
场景：{地点}｜季节/时段：{条件}｜画幅：9:16
景别/机位：{景别、镜头高度、朝向、等效视角}

空间：
{角色/道具的水平、纵深、与固定场景物的距离和朝向}

角色状态：
{姓名 + 固定识别 + 当前服装层 + 随身物 + 表面状态}

画面动作：
{起始姿态 → 轨迹 → 接触/结果 → 用时 → 猫爪、尾巴、衣物响应}

微表情：
{视线、眼睑、耳位、胡须、嘴角、身体重心}

光源：
主光：{来源、方向、冷暖、软硬}
辅光：{来源、方向}
触发变化：{无/明确事件}

环境动态：
{来源、轨迹、幅度、速度；无则写“无”}

运镜：
{固定/缓推/缓拉/跟拍/摇镜，具体起止和用时}

声音：
{对白/动作声/1—2个环境音，必要时标t=}

连续性：
承接上一镜：{动作、位置、视线、道具、服装、光线}
交给下一镜：{结束姿态和可切点}
```

## 十六、质量自检

| 检查项 | 通过标准 |
|---|---|
| 时长 | 总计约 60 秒，不是 90 秒；每镜时长与动作量匹配 |
| 画幅 | 所有镜头按 9:16 原生构图 |
| 情绪 | 50% 喜剧、30% 年代回忆、20% 温情成长整体成立 |
| 尾梗 | 最后 2—4 秒是可见的生活化笑点，不强行煽情 |
| 角色 | 毛色、脸标、体型、服装层、身高关系不漂移 |
| 动作 | 每个主动作有轨迹、接触、时长和身体响应 |
| 猫科 | 猫爪不是人手，尾巴、耳朵、胡须响应自然 |
| 空间 | 相邻镜头站位、轴线、门窗和道具位置连续 |
| 光线 | 每镜光源可追溯，同场变化有触发事件 |
| 年代 | 无智能手机、液晶电视、现代羽绒服、现代运动鞋、外卖盒、现代包装和精装修 |
| 材质 | 旧来自使用与修补，不是影棚做旧或贫困奇观 |
| 文字 | 无画外字幕、水印、标题卡和 UI；世界内文字按剧情克制出现 |
