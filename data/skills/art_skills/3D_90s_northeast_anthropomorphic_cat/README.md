# 东北90年代拟人猫电影动画风格说明

本视觉手册服务于发生在 **1988—1990 年东北老工业城市** 的 9:16 竖屏系列短片。主要舞台为虚构单位“北安市红星机械厂家属院”，主角小橘与家人、伙伴在这里经历过年、开学、暑假、停电、露天电影、小霸王游戏机、收废品换冰棍、写信和乘坐绿皮火车等童年事件。

本系列不是老物件陈列，也不是现代影棚里的复古摆拍。核心表达是：

> 用孩子眼中的小事，还原那个物质不丰富、生活却很热闹的年代。

## 一、风格核心

- **一级风格**：轻写实电影级拟人猫动画。
- **二级风格**：东北老工业城市生活质感、国企家属院烟火气、1988—1990 年代真实性。
- **角色形态**：真实猫毛与猫脸结构，能够自然直立、坐下、做饭、骑车和玩耍；猫爪可完成人类动作，但保留毛茸茸的猫科结构。
- **影像气质**：不是纯卡通，不是现实照片，不是穿猫耳的人类演员；介于电影动画与真实生活观察之间。
- **叙事口味**：家庭和伙伴喜剧为主，回忆感为辅，温情克制，不强行煽情。

## 二、单集规格

| 项目 | 固定要求 |
|---|---|
| 画幅 | 9:16 竖屏 |
| 单集时长 | 约 60 秒，不按 90 秒结构展开 |
| 情绪比例 | 50% 家庭和伙伴喜剧 / 30% 年代回忆 / 20% 温情与成长 |
| 结尾方式 | 优先使用生活化反应、误会、抓包或动作笑点 |
| 禁止结尾 | 强行煽情、旁白总结人生、字幕说教、突然宏大升华 |

“90年代”仅表示故事时代，不表示 90 秒视频时长。

## 三、固定世界

- **城市**：北安市，虚构的东北老工业城市。
- **单位**：红星机械厂，厂房、烟囱、大铁门和自行车上下班潮构成城市天际线。
- **核心舞台**：红星机械厂家属院，红砖楼、煤棚、公共水池、晾衣绳、自行车棚、白菜堆、积雪与蒸汽共同构成生活空间。
- **家庭空间**：小橘家、大勇家。
- **公共空间**：红星小学、供销社、露天市场、机械厂外围、露天电影场地、火车站与绿皮火车。

## 四、固定人物

- **小橘**：8 岁左右的橘色虎斑小猫，左耳轻折、眉心闪电形虎斑，瘦小灵活；旧橘棕棉袄、深色灯芯绒裤、旧球鞋、军绿色斜挎包与红色小福袋。
- **橘爸**：高大结实的成年橘猫，方脸浓眉；蓝灰旧工装棉服、酒红毛衣、深色工作裤、黑色旧工靴与小厂徽。
- **花妈**：身形利落的三花猫，长脸、绿色眼睛；格纹罩衣或格纹上衣、米色旧围裙、深色裤子。
- **猫奶奶**：矮小的银灰色狸花老猫，圆框老花镜、深蓝绒线帽、深色棉衣棉坎肩、布鞋和小手帕。
- **大勇**：黑白奶牛猫，鼻梁白纹、小豁牙；宽大的蓝灰旧棉服、补丁裤、灰色旧围巾，常带铁皮盒或自制玩具。

角色识别特征、毛色、脸部标记、年龄感、头身比例与核心服饰不得随镜头漂移。

## 五、视觉语言

- 室内以暖黄色钨丝灯、炉火、蒸汽和食物热气形成家庭包裹感。
- 室外以冷蓝冬日天光、灰白积雪、蓝灰工装和工业烟雾形成时代与地域。
- 冷暖对比必须来自真实光源：窗外冷光与屋内暖灯、雪地反光与门缝灯光、厂区冷晨与食堂热汽。
- 木材、旧棉布、铁器、搪瓷、水磨石、红砖、煤灰、冰雪与蒸汽必须有清楚而克制的材质表现。
- 所有空间要有生活使用痕迹：磨损、补丁、划痕、油渍、褪色、积灰、结霜和反复修补，而不是崭新的复古商品陈列。

## 六、固定色彩体系

| 色系 | 叙事用途 |
|---|---|
| 橘棕色 | 小橘、家庭温度、旧木材、食物暖色 |
| 墨绿色 | 木窗、柜门、书包、公共设施 |
| 蓝灰色 | 工装、冬季、厂房、阴天与工业城市 |
| 暗红色 | 毛衣、春节装饰、红色小福袋与情感点缀 |
| 米黄色 | 室内灯光、旧墙面、面食与暖蒸汽 |

避免高饱和糖果色、大面积现代纯白色、霓虹赛博色与商业摄影式艳丽配色。

## 七、适用范围

- 固定角色基础设定与季节/事件衍生造型。
- 家属院、家庭、学校、机械厂、供销社、市场与铁路等场景资产。
- 1988—1990 年生活道具、节庆道具、学习用品、玩具与交通用品。
- 60 秒竖屏短片的分镜图、视频提示词和导演规划。

## 八、严禁内容

- 智能手机、互联网、平板电脑、液晶电视、电磁炉、微波炉和现代游戏设备。
- 现代羽绒服、现代运动鞋、现代精装修、外卖盒、连锁商店和现代包装食品。
- 把东北年代感简化成土味滤镜、网红复古、港风、日式昭和或苏联宣传画。
- 真人猫耳、猫耳少女、人类面孔贴猫鼻、四足宠物猫、圆胖 Q 版萌宠。
- 夸张动画鬼脸、弹性拉伸肢体、过大眼睛、塑料毛发、蜡像质感和游戏低模。
- 过度怀旧黄滤镜、全片褪色、重颗粒、脏暗曝光与故意做旧到看不清细节。
- 无生活依据的贫困奇观、刻板地域丑化和用杂乱代替真实。

## 九、风格体验

观众应先感到“这家人真热闹”，再认出“这是那个年代”，最后在一个小动作里体会到温暖。画面中的旧不是被展示出来的旧，而是被一家人天天使用、修补、珍惜后留下的旧；情感不是说出来的，而是藏在半个冻梨、一碗热面、修好的玩具和门口亮着的灯里。
