# 东北90年代拟人猫角色基础形象生成 · 约束手册

## 一、任务目标

根据输入的角色信息，生成可长期复用的角色基础设定提示词。基础设定只负责角色的稳定身份、物种、体型、面部识别、基础服装和标准站姿，不替角色添加某一集专属的节庆服装、伤痕、污渍或情绪状态。

输出必须是 **轻写实电影级拟人猫动画角色设定图**，兼顾真实猫科结构与自然人形动作能力。

## 二、共同结构规范

### 2.1 猫科身份

- 头部保留真实家猫的额骨、短吻部、鼻镜、胡须垫、猫耳和下颌结构。
- 眼睛大而灵活，但保持猫眼比例，不放大为日漫式巨眼。
- 胡须自然向两侧伸展，不画成几根硬线，不因表情消失。
- 耳位、眼睑、嘴角和胡须角度共同承担表情，不靠人类夸张嘴型。
- 尾巴长度、毛量和花纹与角色毛色一致；基础设定中自然下垂或轻微弯曲。

### 2.2 拟人身体

- 儿童采用约 4.5—5 头身的瘦小自然比例，成年角色约 5.5—6.5 头身。
- 肩、髋、膝、踝可以完成直立动作，但腿部仍保留猫科轻微跖行/趾行特征。
- 手部是可抓握的毛茸茸猫爪：短绒、圆润指节、可见但不夸张的肉垫；严禁突然变成人类五指手。
- 衣物按拟人身体剪裁，同时为尾巴保留合理出口，不让尾巴穿模。
- 身体不得随镜头忽胖忽瘦；冬装的厚度不能误判为角色变胖。

### 2.3 表情基线

基础设定使用平静、自然、略带角色性格的中性表情：

- 眼睑放松，目光看向正前方。
- 嘴巴自然闭合或嘴角有极轻微倾向。
- 耳朵处于自然警觉位，不完全贴平。
- 不做大笑、嚎哭、吐舌、瞪眼或动画鬼脸。

## 三、固定角色圣经

### 3.1 小橘——核心主角

| 维度 | 固定设定 |
|---|---|
| 身份 | 8 岁左右的小学生 |
| 物种/毛色 | 橘色虎斑小猫，暖橘底毛，深橘棕虎斑 |
| 头部标记 | 左耳轻微折下；眉心有清晰但自然的闪电形虎斑 |
| 体型 | 偏瘦小、四肢灵活，不是圆胖型 |
| 眼神 | 大而灵活，带机灵和馋嘴的观察感 |
| 基础外衣 | 橘棕色旧棉袄，袖口略磨亮，棉花厚度真实 |
| 下装 | 深色灯芯绒裤，膝部有轻微磨损 |
| 鞋 | 旧球鞋，款式符合 1988—1990 年，鞋面有清洁后的旧痕 |
| 随身物 | 军绿色斜挎包，包上挂红色小福袋 |

**表演识别**：

- 想主意时眼睛先快速转动，耳朵微微向前。
- 嘴硬时下巴略抬，尾巴却会不自觉缩向身后。
- 馋时鼻子和胡须先靠近食物，嘴上仍保持“我在检查”的认真神情。

**严禁漂移**：

- 不得改为圆脸胖猫、幼儿萌宠、纯黄色无虎斑或红发人类小孩。
- 左耳轻折与眉心闪电纹必须在可见角度保持。
- 红色小福袋不得变成现代挂件、钥匙扣或卡通玩偶。

### 3.2 橘爸——嘴硬的工人父亲

| 维度 | 固定设定 |
|---|---|
| 身份 | 红星机械厂钳工或设备维修工 |
| 物种/毛色 | 成年橘猫，毛色比小橘更沉稳，虎斑较粗 |
| 面部 | 方脸、浓眉感的额部花纹、下颌结实 |
| 体型 | 高大结实，肩背宽，劳动者体态，不是健身肌肉 |
| 基础外衣 | 蓝灰色旧工装棉服，袖口和肘部有工作磨痕 |
| 内搭 | 酒红色毛衣 |
| 下装 | 深色工作裤 |
| 鞋 | 黑色旧工靴，鞋面有煤灰或机油清洁后的痕迹 |
| 身份物 | 胸前一枚小厂徽，尺寸克制 |

**表演识别**：

- 讲道理时双手背后或一只爪抬起，努力维持父亲威严。
- 被花妈拆穿时先停顿半拍，再把视线转向小橘。
- 修东西时动作熟练、专注，情感常通过递工具、修玩具和留食物表达。

**严禁漂移**：

- 不得变成西装老板、军人、现代汽修工或夸张肌肉英雄。
- 厂徽是小型单位身份点缀，不得成为现代企业 Logo。

### 3.3 花妈——家庭的实际指挥官

| 维度 | 固定设定 |
|---|---|
| 身份 | 机械厂职工或家属院服务站工作人员 |
| 物种/毛色 | 三花猫，黑/橘/米白色块自然分布 |
| 面部 | 脸型偏长，绿色眼睛，神情利落清醒 |
| 体型 | 身形利落，动作麻利，不纤弱也不夸张丰满 |
| 基础上衣 | 格纹罩衣或格纹上衣，颜色低饱和 |
| 围裙 | 米色旧围裙，有洗涤褪色与轻微使用痕迹 |
| 下装 | 深色裤子 |
| 鞋 | 家中布拖鞋；外出换旧棉鞋 |

**表演识别**：

- 一边切菜、收衣或擦桌，一边用余光识破父子。
- 很少停下手里的事专门训人，信息常通过一句短话和一个眼神完成。
- 关心家人时动作比语言先到：添饭、掖衣领、把热水放近。

**严禁漂移**：

- 不得变成浓妆都市女性、旗袍复古模特或刻板泼辣妇女。
- 三花色块在四视图中保持连贯，不得每个角度随机换花纹。

### 3.4 猫奶奶——温柔的秘密同盟

| 维度 | 固定设定 |
|---|---|
| 身份 | 与小橘一家共同生活的长辈 |
| 物种/毛色 | 银灰色狸花老猫，毛色柔和，花纹细密 |
| 面部 | 温和的老年猫脸，眼角自然松弛，不做夸张皱纹 |
| 体型 | 身材矮小，背部轻微自然弯曲，动作稳而慢 |
| 眼镜 | 圆框老花镜，镜片有轻微真实反光 |
| 头部 | 深蓝色绒线帽 |
| 服装 | 深色棉衣和棉坎肩 |
| 鞋 | 旧布鞋 |
| 随身物 | 一块折叠整齐的小手帕 |

**表演识别**：

- 明明看见小橘偷吃，眼睛越过镜框轻轻看一眼，随后继续手里的活。
- 配合撒谎时神情格外一本正经。
- 拿糖或零钱时动作小而隐蔽，体现节俭与疼爱。

**严禁漂移**：

- 不得变成仙侠老者、卡通巫婆或过度衰弱病态形象。
- 老年感来自姿态、毛色、眼神和动作节奏，不靠密集人类皱纹。

### 3.5 大勇——小橘最好的朋友

| 维度 | 固定设定 |
|---|---|
| 身份 | 小橘同学兼邻居，年龄与小橘接近 |
| 物种/毛色 | 黑白奶牛猫 |
| 头部标记 | 鼻梁一道明显白纹 |
| 牙齿 | 一颗小豁牙，仅在张嘴或微笑时自然可见 |
| 体型 | 比小橘略结实，仍是儿童比例 |
| 外衣 | 哥哥留下的宽大蓝灰棉服，肩线略大、袖子略长 |
| 下装 | 深色裤子，膝盖有真实缝补补丁 |
| 围巾 | 灰色旧围巾 |
| 常带物 | 弹弓、铁皮盒或自制玩具；一次只按剧情携带必要物品 |

**表演识别**：

- 小橘提馊主意时，大勇耳朵先向后、身体退半步，再无奈跟上。
- 动手制作玩具或修理小物件时比小橘稳。
- 遇到朋友受欺负时站位自然挡在前面，不做超级英雄姿势。

**严禁漂移**：

- 不得变成呆傻跟班、恶作剧反派或现代潮童。
- 鼻梁白纹与小豁牙是辅助识别点，不得夸张为滑稽畸形。

## 四、毛发与面部渲染

### 4.1 毛发

- 短毛角色以贴合骨相的细短绒为主，颊部、胸口和尾巴有适度蓬松。
- 冬季毛量可略厚，但不能改变脸型、体型和花纹位置。
- 逆光下仅出现细薄毛缘，不形成一圈发光描边。
- 毛发颜色受环境光影响但本色清楚；冷光不能把橘猫染成灰猫。
- 胡须与眉毛区域清晰，不出现人类发型式刘海。

### 4.2 眼睛

- 眼球保持湿润但克制的自然高光。
- 瞳孔随室内外明暗合理变化。
- 不使用美瞳、星形高光、爱心瞳孔或玻璃珠般过亮反射。
- 绿色眼睛仅固定于花妈；其他角色按自然猫眼色域处理并保持连续。

### 4.3 面部表情

| 情绪 | 可执行特征 |
|---|---|
| 机灵 | 上眼睑略抬、瞳孔聚焦、耳朵向前、胡须轻张 |
| 心虚 | 视线短暂侧移、耳朵微向两侧、下巴略收 |
| 温柔 | 眼睑放松、耳位自然、嘴角极轻微上扬 |
| 严肃 | 眉心毛纹收紧、下颌稳定、目光直视 |
| 忍笑 | 嘴角一侧轻抬、眼睛微眯、胡须轻颤 |

禁止把猫脸强行套成人类口型；对白时嘴部开合幅度自然，鼻口结构保持稳定。

## 五、基础服装年代规范

- 冬装厚实但剪裁朴素，以棉布、灯芯绒、粗针织和旧工装布为主。
- 服装色彩以橘棕、墨绿、蓝灰、暗红、深棕和米色为主。
- 领口、袖口、膝部与口袋边缘可有洗旧、磨亮、补线和轻微褪色。
- 补丁形状服务真实修补，不做现代潮流拼贴。
- 服装合身程度反映家庭背景：小橘较合身，大勇的棉服明显是哥哥留下的宽大旧衣。
- 不在基础设定中加入每集才需要的红领巾、节庆帽、雨具或劳动护具。

**禁止**：现代羽绒服亮壳、冲锋衣、连帽卫衣、现代运动鞋、魔术贴童鞋、大品牌 Logo、现代印花 T 恤、紧身时装、影楼民族服装。

## 六、四视图设定图规范

### 6.1 视图

同一画布从左至右排列：

1. 正面全身。
2. 左侧面全身。
3. 背面全身。
4. 右侧 3/4 全身。

### 6.2 画面

- 9:16 竖屏角色设定图，四视图等高、脚底在同一基准线。
- 中性站姿，双爪自然垂落或轻放身体两侧，尾巴不遮挡关键服装结构。
- 全身完整入画，耳尖、鞋底和尾端不裁切。
- 背景使用低饱和米灰纯净背景；不是现代纯白影棚。
- 光线使用柔和中性主光加极轻微冷暖分离，确保毛色和衣料可读。
- 四视图的毛纹、色块、体型、衣物磨损位置和配饰完全一致。
- 不加入场景、家具、文字标签、尺寸线、水印或角色名大字。

## 八、输出自检

### 必守

- 是否能仅凭轮廓和毛色认出角色。
- 是否保留全部固定脸部标记和随身识别物。
- 是否为真实猫科头部与自然拟人身体。
- 是否符合 1988—1990 年东北冬季/日常服装逻辑。
- 是否表现衣物被长期使用、清洗和修补后的状态。
- 是否四视图一致且全身不裁切。

### 严禁

- 真人猫耳、人类五官、假鼻贴、毛绒玩具脸。
- 四足宠物猫、Q 版圆胖萌宠、日漫巨眼。
- 人类手掌、人类裸足、缺失尾巴或尾巴穿模。
- 现代羽绒服、现代运动鞋、现代 Logo 和潮流配饰。
- 角色随机增肥、年龄漂移、花纹换位、左右耳特征颠倒。
- 夸张动画鬼脸、僵硬 T Pose、英雄海报姿势。
