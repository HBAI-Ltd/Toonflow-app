# 东北90年代老工业城市场景衍生资产生成 · 约束手册

## 一、衍生目标

基于已确认的基础场景，生成景别、机位、时段、季节、天候或具体生活事件变体。衍生只能改变观察方式和合理状态，不得重建房间、搬动固定家具、替换建筑或升级年代。

## 二、空间连续性锁

每次衍生必须保持：

- 房间/院落/厂区的平面结构不变。
- 门窗位置、开启方向和尺寸不变。
- 固定家具、暖气、柜子、柜台、楼梯、烟囱和主要设施位置不变。
- 墙面、地面、窗框和家具的基础色与材质不变。
- 可识别的掉漆、修补、划痕和生活收纳位置不变。
- 世界内门牌、招牌和单位文字位置不变。
- 不出现时代升级，不加入现代设备。

允许移动的物件必须解释是谁、在何种事件中移动，并在相邻镜头保持连续。

## 三、景别与机位变体

### 3.1 景别

| 景别 | 用途 | 场景信息保留 |
|---|---|---|
| 大全景 | 建立家属院、厂区、学校、站台 | 地理关系、主要建筑、天气与人流路径 |
| 全景 | 建立房间、院落动作区 | 入口、固定家具、前中后景 |
| 中景环境 | 双人互动、家庭喜剧 | 主体附近家具与关键道具位置 |
| 近景环境 | 手部动作、旧物细节 | 动作接触面、材质与光源方向 |
| 特写 | 抓包证据、温情小物 | 只聚焦一个叙事信息，背景仍能判断地点 |

基础资产衍生近景时，不能凭空创造基础全景中不存在的柜子、门、窗或桌面材质。

### 3.2 推荐机位

- 门口向内：适合花妈进入、父子被抓包和家庭空间建立。
- 餐桌侧面：适合包饺子、偷吃、递饭和多人关系。
- 暖气/柜子前低机位：适合孩子藏东西，但保持自然高度。
- 家属院楼门口向外：适合室内暖光与室外冷蓝对比。
- 煤棚/晾衣物后：适合孩子自以为隐蔽的观察机位。
- 教室后排向讲台：适合课堂与同学关系。
- 厂门斜侧：适合自行车队与父亲下班。
- 火车车窗侧面：适合写信、分享食物和离别克制情绪。

### 3.3 机位禁令

- 无叙事目的的贴地超低机位、英雄仰拍、上帝俯拍。
- 鱼眼、超广角畸变、360 度空间展示。
- 为了 9:16 强行裁掉门窗、烟囱或角色动作落点。
- 相邻镜头跨越轴线却不建立新的空间关系。

## 四、时段变体

### 4.1 清晨

- 室外：冷蓝天光，低角度淡日光，烟囱蒸汽和呼气可见。
- 室内：窗外冷光进入，厨房/灯泡暖光先亮，锅中热汽开始上升。
- 厂区：门卫室和食堂暖灯对比冷晨。

### 4.2 白天

- 冬季阴天以柔和冷漫射为主，雪地反射补亮暗部。
- 夏季窗光更中性，树影和水池反光提供动态。
- 室内无需所有灯都开，暖色主要来自木材、墙面和食物。

### 4.3 黄昏

- 低角度橘棕阳光打在红砖和窗框上，阴影仍偏蓝灰。
- 窗内灯逐渐亮起，形成家庭归属感。
- 不使用现代城市金色天际线和商业广告灯。

### 4.4 夜晚

- 家中：2700—3200K 钨丝灯/台灯为主，窗外冷蓝暗光辅助。
- 家属院：楼道灯、窗口灯、少量路灯有明确位置。
- 停电：主要电灯熄灭，蜡烛/手电形成局部光，窗外仍有微弱冷光。
- 露天电影：幕布反光照亮观众前侧，背后夜色冷蓝。

时段改变只改变光线与可移动生活状态，不改变空间结构和墙面本色。

## 五、季节与天候变体

### 5.1 冬季降雪

- 雪积在朝上表面：窗台、煤棚顶、自行车座、白菜覆盖物、树枝。
- 主要通道被踩实，脚印大小与方向有秩序。
- 屋檐下、门内和遮挡处积雪更少。
- 金属变冷暗，玻璃边缘结霜，门窗内侧可有冷凝。
- 暖气、烟囱、食物和呼气产生不同尺度的蒸汽/白气。

### 5.2 融雪

- 雪堆边缘灰化、塌陷，水沿地势流向排水沟。
- 入口出现湿脚印和少量泥点，室内水磨石局部反光。
- 禁止把整条路变成灾难泥浆。

### 5.3 夏日

- 树叶低饱和绿色，阳光被树冠打散。
- 公共水池、冰棍箱、开窗和薄窗帘提供清凉线索。
- 墙面、红砖和木窗仍保持原色，不套热带黄绿滤镜。
- 室内可有苍蝇拍、纱窗等时代相符生活物件，但按剧情出现。

### 5.4 秋储

- 白菜、土豆、煤或柴按家庭习惯整齐堆放。
- 叶片、土粒和麻袋痕迹集中在搬运路径。
- 色彩以橘棕、白菜绿、红砖和蓝灰为主。

### 5.5 雨天

- 雨水顺屋檐、玻璃和自行车挡泥板流动。
- 地面反射只出现现有光源，不产生霓虹城市倒影。
- 纸张、布棚和衣物受潮程度与遮挡位置一致。

## 六、生活事件变体

### 6.1 过年

- 门窗局部贴红纸福字/窗花，桌面有面粉、盖帘、饺子和年货纸包。
- 暗红与米黄作为点缀，基础家具、墙面和家电不更换。
- 整洁程度提高，像一家人认真收拾过，不像商业春节摄影棚。

### 6.2 开学

- 门边出现书包、铝饭盒、铅笔盒与整理中的课本。
- 学校黑板、课桌和广播设施按新学期略整理，但仍有旧痕。
- 不出现现代开学横幅、塑料礼品袋和新式校服。

### 6.3 停电

- 所有电灯状态统一熄灭，不能某个房间仍出现无解释顶灯。
- 蜡烛/手电的位置与照明范围一致。
- CRT 电视黑屏，家人活动围绕有限光源重新组织。
- 笑点可来自错误摸到物件、藏东西暴露，但物件位置连续。

### 6.4 露天电影

- 幕布、放映机、座位和人流通道固定。
- 放映机光束受空气微尘影响可见，但不做舞台激光。
- 电影结束后幕布暗下，窗口和楼道暖灯重新成为主光。

### 6.5 游戏与儿童活动

- 玻璃球、沙包、自制冰车、铁皮盒等只在动作区域出现。
- 玩耍后产生可解释的脚印、雪痕、尘土或物件位移。
- 禁止把院子布置成现代儿童乐园或道具展。

## 七、环境动态

| 场景 | 可执行动态 |
|---|---|
| 小橘家 | 锅中蒸汽上升、暖气上小衣物轻晃、窗霜边缘融水下滑 |
| 家属院 | 晾衣物被风轻吹、自行车铃被碰后微晃、烟囱蒸汽横向飘 |
| 机械厂 | 大门缓慢开合、远处蒸汽排放、自行车轮转动与停车 |
| 学校 | 广播喇叭轻响、旗帜受风、粉笔灰落下 |
| 供销社 | 门帘被进出带动、算盘珠滑动、纸包折叠 |
| 市场 | 棚布轻振、秤砣摆动、冰棍箱白汽短暂溢出 |
| 火车 | 窗外景物水平后移、车厢轻振、杯中水面细微晃动 |

动态必须有来源、幅度、速度和持续时间；基础静态资产可只暗示，不凭空制造强风和浓烟。

## 九、约束检查

### 必守

- 与基础场景是同一空间，可通过固定锚点识别。
- 光线、天气、积雪和物件位移遵循物理因果。
- 9:16 构图保留动作区和空间地标。
- 同一事件内时段、天气和电力状态统一。
- 新增物件符合 1988—1990 年且有剧情理由。

### 严禁

- 搬动固定家具、改变门窗、重建楼体或替换地面。
- 现代精装修、现代家电、液晶屏、外卖盒和连锁商业元素。
- 雪落在室内、无风布料乱飞、无光源霓虹倒影。
- 用滤镜代替时段变化，用脏乱代替生活痕迹。
- 贫困奇观、灾难污染、旅游明信片雪景。
- 完整角色、人群主体、画外字幕、水印和 UI。
