# 东北90年代拟人猫角色衍生资产生成 · 约束手册

## 一、衍生目标

基于已经确认的角色基础形象，生成特定季节、地点、家庭事件或剧情状态下的服化与状态变体。衍生不是重新设计角色，而是在稳定底模上增加有依据、可回退的生活层。

## 二、不可变层与可变层

### 2.1 不可变层 L0

所有衍生必须满足：

- 身份不变。
- 物种不变。
- 毛色不变。
- 脸部标记不变。
- 年龄感不变。
- 头身比例不变。
- 身高关系不变。
- 猫爪、尾巴与猫脸结构不变。

小橘的左耳轻折、眉心闪电纹、瘦小体型；大勇的鼻梁白纹、小豁牙；花妈的三花色块与绿色眼睛；猫奶奶的银灰狸花与老年体态；橘爸的方脸和高大肩背均属于 L0。

### 2.2 可变层

| 层级 | 内容 | 约束 |
|---|---|---|
| L1 | 天候状态 | 落雪、雨水、汗湿、哈气、轻微风吹，只改变表面状态 |
| L2 | 场景服装 | 家居、上学、工作、市场、旅行，必须符合身份与年代 |
| L3 | 季节叠穿 | 棉帽、围巾、手套、背心、薄外套，不能改变基础体型判断 |
| L4 | 事件配件 | 红领巾、劳动手套、年货网兜、车票、手电筒，只按剧情添加 |
| L5 | 使用痕迹 | 煤灰、面粉、雪屑、泥点、补丁、湿痕，程度克制且有来源 |
| L6 | 情绪/动作 | 心虚、忍笑、担心、得意等瞬时表演，不固化成新脸型 |

## 三、衍生决策顺序

每次生成前按以下顺序判断：

1. 当前时间：冬、春、夏、秋；白天或夜晚。
2. 当前地点：家中、家属院、学校、机械厂外围、供销社/市场、车站/火车。
3. 当前事件：上学、做饭、过年、玩耍、停电、露天电影、旅行等。
4. 当前动作：是否需要围裙、手套、书包、工具或交通物。
5. 当前状态：是否真的会产生雪、煤灰、面粉、汗、雨水或磨损。
6. 是否保留角色识别：新增层不能遮掉关键毛纹、脸部标记和核心随身物。

无剧情依据时，不得为了“好看”额外添加时髦服饰、饰品、浓妆或夸张脏污。

## 四、季节造型矩阵

### 4.1 冬季

| 角色 | 允许叠加 | 固定保留 |
|---|---|---|
| 小橘 | 深色棉帽、旧针织手套、加厚袜、围巾 | 橘棕旧棉袄、军绿斜挎包、红福袋 |
| 橘爸 | 蓝灰工帽、工作手套、厚围巾 | 蓝灰工装棉服、酒红毛衣、厂徽 |
| 花妈 | 旧头巾、深色棉外套、旧棉鞋 | 三花脸、绿色眼睛、格纹元素 |
| 猫奶奶 | 加厚围巾、手套、棉坎肩加层 | 圆框眼镜、深蓝绒线帽、小手帕 |
| 大勇 | 旧棉帽、手套、围巾再绕一圈 | 宽大蓝灰棉服、补丁裤、灰围巾 |

- 雪屑只落在肩、帽顶、鞋边和尾巴外侧。
- 呼气白雾在寒冷室外出现，进入室内后逐渐消失。
- 棉服受压处出现真实折痕，不像充气塑料。

### 4.2 春秋

- 使用旧夹克、毛衣、针织背心、罩衣和单层长裤。
- 颜色仍以蓝灰、墨绿、橘棕、暗红、米黄为主。
- 春季允许泥点、融雪水渍和较薄的围巾。
- 秋季允许网兜、白菜叶、落叶和储煤劳动带来的轻微灰痕。
- 禁止风衣大片飘动、现代学院风、潮流棒球服和鲜亮运动套装。

### 4.3 夏季

- 儿童可穿洗旧短袖衫、背心、薄长裤或朴素短裤，款式符合 1988—1990 年。
- 花妈可使用薄格纹上衣与米色围裙；橘爸使用蓝灰工作衫或洗旧背心但不裸露健身感肌肉。
- 猫奶奶使用薄长袖衫与轻便坎肩，保持长辈朴素感。
- 毛发可有轻微汗湿聚束，额头、颈侧和爪心更明显；不得出现人类皮肤汗珠覆盖全身。
- 禁止现代凉鞋、洞洞鞋、印花潮 T 和防晒服。

## 五、地点造型矩阵

### 5.1 家中

- 小橘/大勇：可脱掉外层棉袄，露出毛衣或旧针织衫；斜挎包放在固定位置后不应仍挂在身上。
- 橘爸：回家后可脱工装外层，保留酒红毛衣；袖口可卷起修东西。
- 花妈：格纹罩衣、米色围裙、布拖鞋。
- 猫奶奶：棉坎肩、布鞋、眼镜和小手帕。

### 5.2 上学

- 小橘与大勇背旧书包或斜挎包；按学校活动需要佩戴红领巾。
- 红领巾为洗过的棉布红，不是高饱和塑料红。
- 可携带铁皮铅笔盒、田字格本、铅笔和铝饭盒。
- 不得出现现代双肩包、拉杆书包、塑料文件夹、运动校服或品牌童鞋。

### 5.3 机械厂

- 橘爸使用蓝灰工装、工帽、棉/帆布手套和基础维修工具。
- 工装可有少量机油、铁锈粉和煤灰，但面部与全身不得被夸张涂黑。
- 非工人角色进入厂区外围必须有剧情与安全边界，不给孩子添加专业工装冒充工人。

### 5.4 供销社与露天市场

- 外出保暖层完整，手持网兜、布袋、纸包或篮子。
- 花妈的围裙通常留在家中，外出可换旧棉外套。
- 购物物件重量会影响手臂和肩膀姿势。

### 5.5 车站与绿皮火车

- 增加布包、网兜、搪瓷缸、纸质车票等必要物件。
- 冬季从室外进入车厢后，帽肩雪屑会融化成小湿点。
- 行李朴素实用，不使用现代拉杆箱、登机箱和旅行颈枕。

## 六、事件造型

### 6.1 过年

- 暗红色只作局部：旧毛衣、福字、红纸、灯笼、小福袋。
- 衣服可以比日常更整洁，但仍是已有衣物被洗净、熨平或翻出保存较好的一件。
- 可有包饺子面粉落在围裙和猫爪毛尖上。
- 禁止全员新中式礼服、影楼唐装、金色堆叠和商业春节海报感。

### 6.2 停电

- 服装不因停电变化；只增加手电筒、蜡烛、火柴等互动物。
- 暖色局部光会改变毛发受光，但不改变本色。
- 黑暗中眼睛可有克制反光，禁止发光魔眼。

### 6.3 玩小霸王

- 儿童在室内可脱外套，坐姿自然，猫爪握粗线手柄。
- 线缆、手柄和 CRT 电视位置符合物理连接。
- 禁止现代电竞服、游戏耳机、LED 灯和无线手柄。

### 6.4 收废品换冰棍

- 手套/爪毛可沾少量铁锈粉、纸灰或灰尘。
- 衣服出现由搬运产生的局部褶皱和轻微脏点。
- 冰棍包装与形态朴素；禁止现代彩印包装和网红冰品。

### 6.5 露天电影

- 夜间外套与坐垫符合季节。
- 幕布反光落在眼睛、鼻梁和前侧毛发上；背后保留冷夜色。
- 不添加现代荧光棒、手机拍摄或折叠露营椅。

## 七、状态痕迹强度

| 等级 | 定义 | 示例 |
|---|---|---|
| S0 | 干净日常 | 洗旧但整洁，无新增污渍 |
| S1 | 轻微事件 | 袖口面粉、鞋边雪屑、膝部一点灰 |
| S2 | 明确劳动/玩耍 | 局部泥点、煤灰、汗湿、衣料压褶 |
| S3 | 剧情事故 | 摔进雪堆、打翻面盆等造成可解释的较大痕迹 |

默认使用 S0—S1。只有剧情明确描述事故时使用 S2—S3。痕迹必须说明来源、位置和程度，且不得遮挡角色识别。

## 八、表情和姿态衍生

| 角色状态 | 耳位/眼神 | 身体动作 |
|---|---|---|
| 小橘得意 | 耳朵向前、眼神发亮 | 胸口略挺、爪子背后、尾巴轻扬 |
| 小橘心虚 | 耳朵向两侧、视线短暂避开 | 下巴收回、斜挎包被爪子挡在身前 |
| 橘爸装严肃 | 耳位稳定、眉部毛纹收紧 | 双爪背后、肩背挺直 |
| 花妈看穿 | 眼睑轻抬、视线不必完全转向 | 手里动作继续，只停半拍 |
| 猫奶奶帮忙 | 镜片上方轻看、嘴角不明显 | 手帕或小物自然遮挡关键证据 |
| 大勇犹豫 | 耳朵微后、目光看小橘再看风险 | 后脚退半步，前脚仍朝小橘 |

禁止超大嘴、喷泪、眼球突出、全身变形、头顶符号、漫画汗滴与文字拟声词。

## 九、四视图衍生规范

- 使用基础角色图作为强参考，角色 L0 完全对齐。
- 正面、左侧面、背面、右侧 3/4 等高排列。
- 如果衍生包含雪、泥、面粉等痕迹，四视图中位置与扩散方向必须一致。
- 服装叠穿应展示领口、袖口、下摆和尾巴出口关系。
- 配件在四视图中数量一致，不得正面有围巾、背面消失。
- 背景为低饱和米灰，不加入剧情场景。

## 十一、约束检查

### 必守

- 所有变化有季节、地点或事件依据。
- 基础角色 L0 完整保留。
- 衣物符合角色家庭、职业、年龄和东北气候。
- 痕迹有物理来源，位置与动作一致。
- 配件数量克制，不遮挡关键脸部标记。
- 衍生结束后能够明确回到基础状态。

### 严禁

- 重新设计角色脸型、毛色、花纹、体型或年龄。
- 为角色增加浓妆、现代首饰、时尚发型和品牌服装。
- 用污渍覆盖全身以制造年代感。
- 现代羽绒服、现代运动鞋、外卖盒、智能设备。
- 节庆造型影楼化、舞台化、民族服装表演化。
- 人手、四足宠物姿态、真人猫耳与夸张动画鬼脸。
