# 东北90年代生活道具图像生成 · 约束手册

## 一、任务目标

根据输入的道具名称和剧情用途，生成符合 **1988—1990 年东北老工业城市国企家属院** 的单体道具设定提示词。道具必须能够被角色真实使用，既有年代识别度，也保留具体家庭、学校或工厂的长期使用痕迹。

道具图不是古董拍卖图、博物馆藏品图或现代复古商品广告。先说明它怎样被使用，再决定它怎样变旧。

## 二、年代判定流程

生成前依次回答：

1. 该物品在 1988—1990 年中国东北是否已经普遍存在。
2. 红星机械厂家属院普通家庭、学校或工人是否合理拥有。
3. 物品的材质、造型、开关、接口、包装与字体是否属于当时。
4. 它是家用、学校用、厂用、市场用还是交通用。
5. 剧情是否需要一个具体品牌；不需要时使用无品牌通用造型。
6. 使用痕迹来自何种动作、存放方式和年限。

无法确认年代时，采用更朴素、更通用、无品牌的方案，不擅自添加现代细节。

## 三、道具分类

| 道具 | 结构与材质 | 使用痕迹 |
|---|---|---|
| 搪瓷杯 | 米白或浅蓝底、蓝边/简朴花纹、金属胎 | 杯沿小磕点、把手磨亮、底部轻微水垢 |
| 搪瓷脸盆 | 圆形浅盆、蓝边或低饱和花纹 | 内壁细划痕、边缘一处露铁 |
| 铝饭盒 | 圆角矩形铝盒、扣盖或套合盖 | 表面细凹痕、擦洗纹、边角磨亮 |
| 暖水瓶 | 金属/塑料外壳、玻璃内胆、提柄 | 壳体褪色、小磕点、把手常握处磨亮 |
| 铁皮饼干盒 | 方/圆形铁皮盒、低饱和彩印 | 边角掉漆、盒盖摩擦圈、局部轻锈 |

### 3.5 工厂与维修

| 道具 | 结构与材质 | 使用痕迹 |
|---|---|---|
| 活扳手 | 暗哑钢材、旋钮结构 | 抓握处油光、细划痕、轻微机油 |
| 钳子 | 钢制钳口、旧胶/裸金属握柄 | 钳口磨损、转轴油迹 |
| 螺丝刀 | 木柄/旧塑料柄、钢杆 | 柄部磨亮、尖端磨损 |
| 铁皮工具箱 | 蓝灰/墨绿铁皮、提手、扣锁 | 掉漆、凹痕、箱底油渍 |
| 工作手套 | 帆布/棉线手套 | 指尖磨薄、油迹、缝补 |
| 厂徽 | 小型金属/搪瓷徽章 | 边缘轻磨，不做现代企业胸牌 |

工具要体现工人长期使用和维护，不展示血腥、危险操作或现代电动工具组合。

### 3.6 供销社与市场

- 玻璃糖罐、散装糖块、纸袋、牛皮纸、棉线、算盘、杆秤、网兜、竹篮。
- 冰棍箱、保温棉被、木牌价签；世界内文字可少量存在。
- 白菜、土豆、大葱、冻梨、瓜子、花生、粉条等东北季节性食物。
- 包装朴素、印刷色有限，禁止现代塑封、二维码、营养标签和连锁品牌视觉。

### 3.7 影音与通讯

| 道具 | 允许结构 | 禁止替代 |
|---|---|---|
| CRT 电视 | 厚重箱体、凸屏、旋钮/按键、拉杆天线或有线连接 | 液晶电视、超薄屏、壁挂屏 |
| 收音机 | 木/塑料箱体、刻度调频窗、旋钮 | 智能音箱、数字触屏 |
| 磁带录音机 | 卡带仓、机械按键、提手、扬声器网罩 | 蓝牙音箱、MP3 |
| 固定电话 | 拨盘或按键式座机，按剧情与家庭条件慎用 | 智能手机、无线触屏电话 |
| 手电筒 | 金属筒身、滑动开关、电池仓 | LED 强光手电、战术灯 |

### 3.8 交通与旅行

- 纸质车票、布旅行包、网兜、搪瓷缸、旧皮箱/木箱、二八自行车、儿童旧自行车。
- 绿皮火车物件：硬座座椅、行李网架、开水杯、车窗插销、折叠小桌。
- 禁止现代拉杆箱、登机箱、电子票、二维码闸机、现代动车设施。

## 四、材质渲染

### 4.1 金属

- 铝：柔和漫反射、细擦洗纹、边缘磨亮。
- 铁：暗哑、局部轻锈、掉漆处露出深灰基底。
- 搪瓷：光泽清楚但不镜面，磕点只在边缘或受撞位置。
- 镀铬：仅少量旧五金使用，反射不应像现代新品。

### 4.2 布料

- 棉布：洗旧、褶皱、细密纤维、缝线。
- 帆布：粗纹理、受力处变白、金属扣附近磨损。
- 毛线：起球、线圈、手织密度轻微不均。
- 包装纸：折痕、纤维感、油印或手掌压痕。

### 4.3 木与玻璃

- 木材：顺纹、边缘磕碰、手握处光滑、非仿古刷漆。
- 玻璃：厚度真实、边缘轻折射、不是水晶商品高光。
- CRT 屏幕：凸面暗玻璃、环境反光克制，不展示现代高清画面。

## 五、单体设定图规范

- 固定 9:16 竖屏。
- 一件核心道具居中，完整入画，尺寸关系明确。
- 默认三视图：正面 3/4 主视图、侧面结构视图、背面/底部关键结构视图。
- 小型简单道具可使用“主视图 + 两个局部细节”，避免无意义重复角度。
- 背景使用低饱和米灰，不使用大面积现代纯白。
- 光线柔和克制，能够读出材质、磨损和结构。
- 不出现角色手持，不出现完整人物，不做场景陈列。
- 不添加画外文字、标签箭头、尺寸标注、水印和品牌 Logo。
- 如道具本身含世界内文字，只需保持位置与年代字体合理，不要求生成大量可读正文。

## 七、约束检查

### 必守

- 年代、家庭条件与使用地点合理。
- 结构和材质先于怀旧装饰。
- 使用痕迹有来源且不影响功能识别。
- 关键交互尺寸适合拟人猫爪。
- 单体完整，视图之间结构一致。

### 严禁

- 智能手机、液晶电视、电磁炉、微波炉、现代电脑和现代游戏设备。
- 外卖盒、奶茶杯、现代塑封、二维码、现代营养标签。
- 崭新收藏品、过度锈蚀废品、无依据的脏乱。
- 现代商品摄影、纯白无影棚、夸张高光、品牌广告构图。
- 把日式昭和、美式复古或港风物件冒充东北 1988—1990。
- 出现人物、人手、四足宠物猫或画外说明文字。
