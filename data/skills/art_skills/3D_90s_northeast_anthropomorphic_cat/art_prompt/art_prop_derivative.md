# 东北90年代生活道具衍生状态生成 · 约束手册

## 一、衍生目标

在已确认的基础道具上生成使用、季节、损伤、维修或叙事状态。衍生状态必须保持道具的年代结构、材质、尺寸、颜色和核心识别不变，只呈现“这件东西刚刚经历了什么”或“它被怎样长期使用”。

## 二、不可变项

- 道具名称、年代、功能和归属不变。
- 主体轮廓、比例和零件数量不变。
- 开关、接口、把手、扣件和结构位置不变。
- 主材质与主色不变。
- 世界内文字的位置、版式和时代属性不变。
- 不因衍生添加现代功能、现代包装或现代替代零件。

## 三、状态类型

### 3.1 使用中状态

| 道具 | 可见状态 |
|---|---|
| 搪瓷杯 | 杯中热水、杯口蒸汽、外壁凝结小水珠、桌面一圈淡水印 |
| 铝饭盒 | 盒盖打开、内有家常饭菜、边缘热汽、扣件自然垂落 |
| 擀面杖/盖帘 | 表面薄薄面粉、面团压痕、饺子排列不完全整齐 |
| 铁皮铅笔盒 | 盒盖打开、铅笔橡皮按真实使用摆放、盒内铅笔灰 |
| 小霸王游戏机 | 卡带插入、粗线手柄连接、线缆通向 CRT 电视 |
| 工具箱 | 箱盖打开、工具按长期习惯摆放、局部机油布 |
| 书包 | 口袋打开、本子一角露出、背带受重量下垂 |
| 网兜 | 装白菜、冻梨或年货后拉伸，提手受力 |

使用状态必须遵循物理连接与交互：热物有蒸汽，湿物有水迹，重物令布袋与猫爪姿态受力。

### 3.2 时间累积状态

- 木把手被反复握持后局部磨亮。
- 棉布反复洗涤后褪色，折痕和缝线仍清楚。
- 金属边缘出现轻微掉漆和浅锈，不整体腐烂。
- 纸本封角卷起、装订处松但仍能使用。
- 游戏机外壳轻微泛黄，标签边缘磨损但结构完整。
- 搪瓷磕点集中在杯沿、盆沿和底部外圈。

### 3.3 轻微损伤

| 状态 | 允许表现 | 禁止表现 |
|---|---|---|
| 磕碰 | 一个或少数凹点、边角掉漆 | 全身凹烂、报废 |
| 开裂 | 木件细裂、塑料外壳发丝裂纹 | 爆裂碎片、危险尖锐 |
| 断线 | 布包一处缝线松开 | 整体散架 |
| 破损 | 纸张撕角、玩具一处松动 | 无法识别原物 |
| 漏水 | 暖水瓶/盆具局部水迹，需剧情说明 | 无原因大量喷射 |

儿童喜剧情境中的损伤应安全、生活化、可修复，不制造危险事故奇观。

### 3.4 维修后状态

- 木玩具用小钉、铁丝或胶布朴素固定。
- 布包、裤兜和沙包使用可见针脚缝补。
- 工具柄重新楔紧，颜色与原件略有差异但结构合理。
- 电线可用当时合理的绝缘胶布局部包扎；不得呈现危险裸线。
- 维修体现橘爸或大勇的动手能力，不把物品升级成现代设备。

### 3.5 季节状态

| 季节/天气 | 状态 |
|---|---|
| 冬季室外 | 雪屑、薄霜、低温金属暗哑、呼气凝结不作用于无生命物 |
| 从室外进屋 | 表面雪屑融化成小水点，金属/玻璃轻微结雾 |
| 夏季 | 杯壁冷凝水、木物略潮、布料汗湿抓握痕 |
| 雨天 | 局部雨滴、泥点、纸包受潮卷边 |
| 秋储 | 白菜叶碎屑、土粒、网兜拉伸与地面摩擦痕 |

### 3.6 叙事状态

- **被藏起来**：铁皮盒塞在柜顶、床下或煤棚角落，灰尘分布符合遮挡。
- **准备送人**：旧物被擦干净、用纸或布仔细包好，不突然变成新品。
- **被分享**：一根冰棍掰成两半、糖块数量减少、饭盒里食物被分开。
- **被抓包**：藏物从衣襟、书包或柜缝露出一角，笑点来自位置关系。
- **留下心意**：修好的玩具、保温的饭盒、折好的手帕，通过使用动作表达温情。

## 四、痕迹的因果规则

每个状态描述必须包含：

1. **来源**：谁做了什么，或受到何种天气影响。
2. **位置**：痕迹具体位于边缘、把手、底部、受力点或接触面。
3. **方向**：水向下流、雪落在朝上表面、划痕顺摩擦方向。
4. **程度**：轻微、局部、可识别，不用“非常破旧”笼统替代。
5. **功能**：损伤后是否仍可用；如不可用，剧情是否明确需要维修。

禁止均匀撒灰、随机锈斑和无来源污渍。

## 五、状态设定图规范

- 9:16 竖屏，基础道具与衍生道具使用相同角度、焦段和大小。
- 默认输出单状态主视图 + 两个关键细节；需要比较时使用左右“基础/衍生”对照。
- 对照图不得加入画外标题和文字标签，可用空间位置区分。
- 背景为低饱和米灰，光线一致，避免光影变化伪装成材质变化。
- 液体、蒸汽、雪和面粉的状态符合重力与接触面。
- 不出现完整角色；如必须说明抓握尺度，只允许局部毛茸茸猫爪且不得变成人手。

## 七、约束检查

### 必守

- 能一眼认出与基础道具是同一件物品。
- 状态有来源、位置、方向和程度。
- 年代结构与功能未被改写。
- 材质变化符合铁、铝、搪瓷、布、纸、木和玻璃的真实反应。
- 喜剧情境安全、生活化、可恢复。

### 严禁

- 为旧道具添加触屏、LED、无线连接、现代插口。
- 把轻微磨损扩大成废墟、垃圾或危险报废品。
- 无来源火焰、烟雾、液体飞溅和爆炸。
- 现代胶带颜色、现代包装、二维码和品牌广告。
- 人手、真人猫耳、四足宠物猫与完整人物入镜。
- 用不同光线、不同角度或不同颜色冒充状态变化。
