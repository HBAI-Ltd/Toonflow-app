# Prop Derived State Generation · Constraint Manual

---

## 1. Derivation principles

1. **Form anchoring** — the prop's core form/silhouette, its core Chinese form elements and its core cyber functional structure must stay clearly recognizable across every state; the fusion relationship between the Guofeng motifs and the cyber structure may not be altered
2. **Readable state** — the difference between states must be obvious at a glance so the audience tells them apart immediately; the state changes of the Guofeng elements and of the cyber functionality must echo each other in step, with no logical conflict
3. **Serving the narrative** — every state variant serves a specific plot beat inside the Guofeng Cyber world (an ancient object awakening, a functional retrofit, an energy overload, spirit energy running out, and so on)
4. **Progressive degradation** — damaged/aged/function-worn states must follow a plausible physical logic and the logic of the cyber world; the material change must obey the property rules of the material in question
5. **The prop is shown alone** — only the prop itself may appear in frame; any person, hand or limb is strictly forbidden, the prop must not be in a held/worn/gripped/mounted state, and it must be presented on its own as a still-life display, with no scene accessory of any kind

## 2. State types

### 2.1 Use states

| State | Description | Applicable props | Prompt |
|---|---|---|---|
| Brand-new | Intact and undamaged, sheen like new | All props | brand-new、intact and undamaged、sheen like new |

## 3. Frame specification for state variants

### Single-state image

| Item | Constraint |
|---|---|
| Background | Plain gray solid color #B8B8B8 (same as the design sheet), no surplus texture or ornament of any kind, so the Guofeng Cyber prop stands out as the subject |
| Light | Even soft-light illumination, no hard shadow, PBR material feel reproduced accurately, the layering of the Guofeng Cyber prop's self-illumination/energy light effects preserved, no blown highlights |
| Angle | Same as the front view of the original design sheet, so the core Chinese motifs, cyber functional structure and core ports are fully shown in every view, unobstructed |
| Proportion | The prop fills 70%+ of the frame, core structure and motifs uncropped, detail complete and legible |

### State comparison image

| Item | Constraint |
|---|---|
| Layout | 2-3 states shown side by side in one frame, each state taking an even share, no deformation or stretching |
| Label | The state name is labeled under each state, in type that does not obscure the prop |
| Consistency | Angle/light/background/proportion perfectly identical, only the prop's state differing, the Guofeng elements and the cyber structure presented in exactly the same way |

## 4. Material state change rules

| Material | Brand-new → everyday | Everyday → aged | Damage expression |
|---|---|---|---|
| Metal | Bright sheen → slight patina | Patina → rust spots | Chips/rolled edge/fracture |
| Jade | Translucent and warm → slight wear | Wear → fine surface cracks | Cracks/shattering/chipped corners |
| Wood | New wood grain → natural patina | Patina → dulled color | Splitting/fracture/worm holes |
| Porcelain | Glaze sheen → fine scratches | Scratches → dulled glaze | Cracks/shattering/chips |
| Cloth/paper | Brand-new and flat → slight creasing | Creasing → yellowing and brittleness | Tearing/scorching/ink bleeding |
| Guofeng Cyber composite metal | Bright plating + Chinese etched motifs intact → plating slightly worn + ports oxidized + motif edges slightly blurred | Plating flaking off over large areas + circuits corroded + motifs worn and blurred | Rolled edge/ports cracked open/circuits severed/structure deformed |
| Spirit-energy crystal jade (cyber jade) | Translucent and warm + embedded spirit-energy circuits intact + even sheen | Fine surface scratches + inner circuits slightly degraded + sheen weakened | Surface wear → fine cracks in the inner circuits | Cracks/shattering/chipped corners/inner circuits severed outright/spirit energy leaking |
| Carbon-fibre wood-grain composite | New wood grain clear + carbon-fibre layer intact and undamaged | Wood grain with natural patina + carbon-fibre layer slightly worn | Wood grain dulled + clear scratches on the carbon-fibre layer | Splitting/fracture/carbon-fibre layer delaminating/fibres exposed |
| Guofeng light-glaze ceramic | Glaze sheen maxed + Chinese underglaze motifs crisp + cyber light-response layer intact | Fine glaze scratches + motifs slightly blurred + light-response layer slightly degraded | Glaze dulled + motifs worn + light-response layer dead | Cracks/shattering/chips/glaze flaking off over large areas |
| Nano-fibre fabric/data paper | Brand-new and flat + nano coating intact + data motifs crisp | Slight creasing + coating slightly worn + data motif edges slightly blurred | Clear creasing + coating flaking off + paper/fabric yellowing and brittle + data motifs blurred | Tearing/scorching/ink bleeding/data layer destroyed/fibres snapped |

## 6. Constraint rules

### Mandatory

| No. | Rule |
|---|---|
| R1 | The prop's core form/silhouette stays recognizable across every state |
| R2 | State changes must follow physical logic |
| R3 | Must use the four-panel grid (2×2) layout: top left front view + top right side view + bottom left back view + bottom right detail close-up |
| R4 | Must specify "plain gray solid-color background", even soft light, no hard shadow |
| R5 | Must preserve the fused unity of the core Chinese form, motifs and cultural elements with the cyber functional structure; in every state the two may not be split apart and may not be misaligned |
| R6 | The cyber functional structure, energy light effects and rune effects must serve the expression of the state and may not obscure the prop's core form or state detail |
| R7 | Every newly added Guofeng Cyber state must fit the logic of the world, with the material change corresponding one-to-one to the state expression |
| R8 | In all four grid views, the prop's core Chinese elements and core cyber structure must be shown in full, uncropped and unobstructed |

### Forbidden

| No. | Forbidden |
|---|---|
| X1 | The prop becoming unrecognizable after the state change |
| X2 | Damage that violates physical logic (jade rusting, and the like) |
| X3 | Excessively gory/horrific depiction of damage |
| X4 | Any human figure appearing, including full body, half body or a part (hand, finger, arm or other limb) |
| X5 | The prop being held, gripped, worn or in use |
| X6 | Elements implying a person's presence (grip marks, a wearer's viewpoint, a posture of use) |
| X7 | Clashing mash-ups of Chinese elements and cyber structure are strictly forbidden, as is any messy element that does not fit the Guofeng Cyber world |
| X8 | Excessive light bleed or blown highlights obscuring the prop's core form, motifs or state detail are strictly forbidden |
| X9 | State changes that do not fit Guofeng Cyber material logic are strictly forbidden (worm holes in spirit-energy crystal jade, paper-like tearing of composite metal, and the like) |
| X10 | Altering the fixed four-panel grid layout is strictly forbidden, as is cropping the prop's core structure or motifs |
| X11 | Adding any surplus element, texture or scene to the background is strictly forbidden — the plain gray solid-color background must be kept |
