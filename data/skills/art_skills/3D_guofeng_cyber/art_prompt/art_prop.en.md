# Guofeng Cyber 3D Prop Image Generation · Constraint Manual
## (fully compatible with both settings: ancient-style xianxia + neo-Chinese urban)

---

## 1. Core design principles (mandatory for both settings)
1.  **Readable function** — the prop's purpose is obvious at a glance and the form serves the core function 100%; classical function and cyber functionality are unified visually, cyber elements such as power ports, functional circuits and smart modules must show the prop's purpose directly, and there is zero tolerance for meaningless elements
2.  **Texture to the maximum** — the material grain must match 8K 3D render precision, covering the full range of **classical base materials** (metal/jade/wood/cloth/paper/porcelain/bronze) and **cyber-only materials** (liquid metal/optical fibre/energy crystal/carbon fibre/holographic medium/glass-ceramic), with complete PBR physical material properties
3.  **Dual-setting compatibility** — every prop must fit BOTH the "ancient-style xianxia setting" AND the "neo-Chinese urban cyber setting", with an Eastern classical form / neo-Chinese design as the core skeleton and cyber functionality as the functional extension; purely Western cyber elements with no Guofeng core are forbidden, and purely ancient-style / purely modern elements with no cyber fusion are forbidden
4.  **Explicit scale** — zero distortion in the 3D modeling proportions; imply the prop's real size precisely through structural proportion, optionally aided by a matching standard reference object, at proportions true to ancient-setting furnishing / everyday urban use
5.  **The prop is shown alone** — only the prop itself may appear in frame; any person, hand or limb is strictly forbidden, the prop must not be in a held/worn/gripped/in-use state, and it must be presented on its own as a still-life display
6.  **3D production compliance** — every form must follow next-gen 3D modeling specifications: no clipping, no triangle-count overrun, no perspective distortion, ready to hand straight into the full 3D modeling pipeline

## 3. 3D multi-angle sheet specification (shared by both settings)

### View definitions (next-gen 3D orthographic view standard)
| Position | View | Angle | Core requirement | Standard prompt |
|---|---|---|---|---|
| Top left | Front view | Front 0° orthographic view | The prop's complete front form, 3D modeling structure with no perspective distortion, all core structures, ornaments and functional parts fully shown | front view, orthographic view, 3D modeling, no perspective distortion |
| Top right | Side view | Side 90° orthographic view | The prop's thickness, silhouette, internal structure and side ornament clear, 3D modeling proportions accurate, functional components fully shown | side view, orthographic view, 3D modeling, no perspective distortion |
| Bottom left | Back view | Rear 180° orthographic view | The prop's back structure, ornament, functional ports and mounting structures fully shown, nothing omitted in the 3D modeling | back view, orthographic view, 3D modeling, no perspective distortion |
| Bottom right | Detail close-up | Local enlargement, orthographic view | Material grain, craft detail, energy circuits, functional components and chip ports utterly clear, at 8K-level precision | detail closeup, orthographic view, ultra high detail, 8K precision |

### Frame specification (shared by both settings, 3D render standard)
| Item | Mandatory constraint | Ancient-setting option | Urban cyber-setting option |
|---|---|---|---|
| Layout | A four-panel grid (2×2) in one frame, the four quadrants matching the view definitions strictly, no misplacement, no cropping, no proportion imbalance | Same as the common constraint | Same as the common constraint |
| Background | Plain gray solid color #B8B8B8, no surplus texture, pattern or scene element of any kind, complex backgrounds forbidden | Option: solid background with a light xuan-paper texture | Option: matte dark gray solid background #333333 |

## 6. Constraint rules (mandatory for both settings + forbidden red lines)
### Mandatory rules (a violation means the output fails)
| No. | Mandatory rule |
|---|---|
| R1 | Must specify "plain gray solid color #B8B8B8 background"; any surplus background element is forbidden, a compliant background matching the setting is optional |
| R2 | Must state the prop's material and craft, with traditional and cyber materials labeled clearly, PBR properties complete and the render standard uniform |
| R3 | The prop's form must take an Eastern classical form / neo-Chinese design as its core skeleton; purely Western cyber / purely modern design with no Guofeng core is forbidden |
| R4 | Must present the multi-angle content as a four-panel grid using orthographic views, with accurate 3D modeling proportions, no perspective distortion, no clipping, no proportion imbalance |
| R5 | Must follow the dual-setting compatibility rule: every prop design must leave room to fit both the ancient setting and the urban setting; binding to a single setting is forbidden |
| R6 | Every cyber functional element must serve the prop's core function and narrative; meaningless pile-up of effects or elements is forbidden |
| R7 | Must follow the core render standard of 8K ultra HD, next-gen 3D rendering and PBR physical materials, with no noise, no aliasing, no blur |

### Forbidden red lines (crossing one voids the output)
| No. | Forbidden |
|---|---|
| X1 | Complex scene backgrounds, scene-style frames with an environment; any background element that is not a compliant solid color is forbidden |
| X2 | The prop and a person in the same frame — this manual specifies prop-only sheets, so any person-related element is forbidden |
| X3 | Any human figure appearing, including full body, half body or a part (hand, finger, arm and every other limb) |
| X4 | The prop being held, gripped, worn or in use; any posture implying a use scenario is forbidden |
| X5 | Elements implying a person's presence (grip marks, a wearer's viewpoint, a posture of use, an ergonomic grip shape) |
| X6 | Purely Western cyberpunk design with no Guofeng core; elements clashing with the Guofeng Cyber world are forbidden |
| X7 | Over-futuristic clashing elements in the ancient setting (urban smart hardware, firearms, Western cyber symbols) |
| X8 | Clashing elements in the urban setting that break from the neo-Chinese core (purely ancient cold weapons, xianxia-fantasy elements with no logic) |
| X9 | Overexposed light effects — light-emitting elements must be natural and soft and must not break the overall material feel or the lighting balance of the frame |
| X10 | Any text, annotation, scale line, watermark, logo or other surplus element appearing in the frame |
| X11 | 3D modeling with perspective distortion — the four grid views must use an orthographic viewpoint so the prop's structural proportions stay accurate and uniform |
| X12 | Pile-up of cyber elements with no functional logic — every functional part must correspond to a reasonable function; ineffective design is forbidden |
