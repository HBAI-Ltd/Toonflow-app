# Video Prompt · Visual Style Constraints

When generating a video prompt, you must inject the following visual style tags:

| Mode | Style tag |
|------|----------|
| **Universal multi-reference mode (English)** | `stop-motion claymation, clay texture, finger imprints, warm tones, soft bokeh, whimsical 3D cartoon` |
| **Universal first/last-frame mode (English)** | `stop-motion claymation, clay texture, finger imprints, warm tones, soft bokeh, whimsical 3D cartoon, shallow depth of field` |
| **Seedance 2.0 (English)** | `stop-motion clay style, clay texture, fingerprint indentations, warm tones, soft shallow depth of field, whimsical 3D cartoon` |
