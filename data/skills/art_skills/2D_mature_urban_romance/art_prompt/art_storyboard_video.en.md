# Video Prompt · Visual Style Constraints

When generating a video prompt, you must inject the following visual style tags:

| Mode | Style tag |
|------|----------|
| **Universal multi-reference mode (English)** | `mature urban romance anime, cel-shaded, cinematic lighting, cool tones, dramatic low-key shadows, clean line art` |
| **Universal first/last-frame mode (English)** | `mature urban romance anime, cel-shaded, cinematic lighting, cool tones, dramatic low-key shadows, clean line art, shallow depth of field` |
| **Seedance 2.0 (English)** | `2D mature urban romance animation, 2D cel shading, cinematic light and shadow, cool tones, dramatic low-key lighting, clean lines` |
