# 分镜表叙事手法 · 东北90年代拟人猫 · 技法参考

---

## 一、分镜表定位与必填信息

分镜表负责把“孩子眼中的东北家属院小事”转化为可生成、可剪辑、可连续表演的镜头。字段可根据项目调整，但每个镜头至少要让执行者明确：**谁在哪里、想做什么、具体怎么动、镜头怎么看、声音从哪里来、前后如何接上**。

### 建议字段

| 字段 | 必须写清的内容 |
|---|---|
| 镜号 / 时间码 / 时长 | 例如 `07｜00:24—00:28｜4s`，总时长约 60 秒 |
| 场景 / 时间 / 天气 | 小橘家厨房、冬日傍晚、窗外蓝灰雪光 |
| 人物与位置 | 小橘前景右侧、橘爸中景暖气旁、花妈后景门口 |
| 景别 / 机位 / 画幅 | 9:16 中景、儿童视线高度、轻微低机位 |
| 动作轨迹 | 起始姿势→接触物→移动路径→落幅姿势 |
| 表情与猫科反应 | 眼神、左耳、尾巴尖、胡须、全身停顿 |
| 台词 / 停顿 | 台词短句、谁抢话、哪里停 0.5 秒 |
| 环境音 / 音效 / 音乐 | 真实声源与远近层次，是否突然静默 |
| 光影与色彩 | 室内暖黄 / 室外冷蓝，暗红点缀位置 |
| 连续性 | 道具在哪只猫爪、衣物状态、雪迹、光向、人物出入方向 |
| 时代检查 | 服装、电器、包装、语言是否属于 1988—1990 |

### 一镜一核心动作

- 一镜只承担一个可读的核心动作或反应，例如“伸爪偷拿→听见脚步→停住”，不要写成“偷吃、撒谎、被发现、跑出门、向大勇解释”。
- 复杂动作拆成物理可执行步骤：看见糖罐→拖凳子→爬上去→猫爪碰到罐盖。每一步都要有支点、方向和结果。
- 同一镜内多人可同时做不同的小动作，但主动作只有一个。背景动作只提供生活感或信息差，不抢主笑点。

## 二、约 60 秒结构、镜头数与时长

### 默认镜头节拍表

| 段落 | 时间 | 建议镜数 | 主要景别 | 分镜任务 |
|---|---:|---:|---|---|
| 冷开场 | 0—4s | 1—2 | 特写 / 近景 | 给欲望、异常动作或画外点名 |
| 目标建立 | 4—14s | 2—3 | 中景为主 | 交代小橘想要什么及年代条件 |
| 拉同伙 | 14—24s | 2—3 | 双人中景 / 对切 | 大勇提醒、橘爸嘴硬参与 |
| 计划升级 | 24—42s | 4—6 | 中景 / 全景 / 动作特写 | 三遍法则、空间障碍、漏洞变大 |
| 抓包反转 | 42—50s | 2—3 | 全景揭示 + 反应镜头 | 花妈落锤，父子或伙伴同时露馅 |
| 温情动作 | 50—56s | 1—2 | 近景 / 手部特写 | 让、修、藏、护、分 |
| 生活尾梗 | 56—60s | 1—2 | 固定中景 / 近景 | 甩锅、嘴硬、道具或画外声收尾 |

- **整集建议 12—18 镜** — 动作清楚比镜头多更重要。少于 10 镜要确保信息持续更新，多于 20 镜要检查是否把完整动作无意义拆碎。
- **日常动作 2—4 秒** — 端碗、递眼色、拖凳子、装作路过等镜头保持轻快。
- **铺垫 3—5 秒** — 让观众看懂小橘的目标和漏洞，否则抓包没有预期。
- **包袱 1.5—2.5 秒** — 花妈一句话、糖纸掉地、铁皮盒自己滚出来，落点要干脆。
- **反应镜头 1.5—3 秒** — 笑点后给小橘、大勇或橘爸一个可读反应，不马上切走。
- **温情 3—4 秒** — 保持克制，让动作完成，不叠加慢动作、泪眼大特写和煽情台词。
- **尾梗 2—3 秒** — 尾梗必须能在最后一镜独立读懂，不能依靠新设定或长解释。
- **长镜头不超过 10 秒** — 只有持续更新的生活动线可放宽；镜头内没有新动作、新关系或新信息时立刻拆短。

### 60 秒自检

1. 前 4 秒能否看出“小橘又想干什么”？
2. 14 秒前是否建立具体目标，而不是只展示年代环境？
3. 42 秒前计划是否至少升级一次？
4. 50 秒前是否完成抓包或反转？
5. 温情是否只通过一个行动落地？
6. 最后 4 秒是否为生活化笑点，而不是旁白总结？

## 三、景别选择与 9:16 竖屏构图

- **中景是主力** — 家庭和伙伴喜剧需要同时看见猫爪动作、身体姿态与表情，中景约占 45%。小橘家餐桌、暖气旁、煤棚边都优先让两到三只猫同框。
- **近景负责嘴硬与露馅** — 小橘临时编理由、橘爸装威严、大勇欲言又止，用近景捕捉眼神、耳朵和尾巴尖的微表情。
- **特写必须承接动作** — 糖纸露出、搪瓷边磕响、卡带没插稳、红色小福袋被柜门夹住。先有角色动作，再切结果特写，不能单独陈列老物件。
- **全景负责抓包和群体失控** — 先用较紧景别让角色自以为安全，再切全景揭示花妈就在后景、邻居全看见或出口被白菜堆堵住。
- **远景只用于空间秩序** — 红星机械厂上下班自行车队、红砖家属院雪后晨景、红星小学操场。远景要有人物或声源把它拉回故事，单镜通常不超过 4 秒。
- **大特写一集最多 2 次** — 用于决定性证据或克制情感：小橘松开想独占的猫爪、橘爸悄悄把修好的玩具推过去。禁止连续泪眼特写。
- **竖屏三层抓包构图** — 前景证据，中景正在撒谎的小橘，后景识破一切的花妈。三层必须都能读清，背景人物不贴边或被字幕区遮挡。
- **竖屏上下关系构图** — 儿童站在下部、成人在上部时表现身高差；需要父子同盟时让橘爸蹲下进入小橘高度，关系变化通过高度而非台词说明。
- **保留字幕安全区** — 关键猫爪、表情和证据避开画面最下方，角色耳朵与帽子不顶画框。核心信息不依赖横向展开。

### 主要空间的景别策略

| 空间 | 定场镜头 | 主力景别 | 关键构图 |
|---|---|---|---|
| 小橘家 | 端着热气的饭菜进入桌面 | 双人/三人中景 | 门框抓包、餐桌前后景、铁暖气旁同谋 |
| 家属院 | 孩子穿过晾衣绳和自行车棚 | 全景 + 跟拍中景 | 红砖楼纵深、白菜堆遮挡、雪地脚印连续 |
| 红星机械厂 | 厂门开启与自行车队 | 远景转儿童近景 | 大尺度机器压住儿童高度，橘爸蹲下连接关系 |
| 红星小学 | 书桌、操场或广播喇叭进入 | 群像中景 | 小橘与大勇同框，老师/同学反应在后景 |
| 供销社 | 玻璃柜台与糖罐 | 过肩中景 | 小橘踮脚、售货员俯视、硬币特写 |
| 露天市场 | 秤杆起落带入人群 | 跟拍中景 | 前景货物擦过、中景交易、远处叫卖声 |
| 大勇家 | 修补过的桌面与整齐物件 | 静止双人中景 | 空间小但人物平等，不用俯拍制造怜悯 |

## 四、运镜节奏与完整动作

- **固定机位约 65%** — 让荒谬计划在一个冷静画框里自己展开。家庭抓包、伙伴犹豫和尾梗优先固定。
- **缓推 = 观众发现** — 缓推露出的糖纸、花妈停住半秒的猫爪、橘爸修好的玩具。画面中必须有可被发现的信息。
- **短急推 = 关键露馅** — 花妈报出证据后急推父子同步僵住；一集 1—2 次。急推前要有稳定铺垫，形成节奏反差。
- **甩镜 = 声源或目光触发** — 小橘听见橘爸咳一声才甩到橘爸；画外花妈说“接着编”才甩到门口。禁止无触发乱甩。
- **轻手持 = 孩子行动失控** — 抱废品追冰棍车、扛板凳抢露天电影位置可轻微手持；一进入家庭温情或大勇家，镜头恢复稳定。
- **横移改为纵深跟移** — 9:16 中优先跟角色从前景走向后景或从门外进到室内，利用纵深连续展示家属院生活。
- **动作前后各留一个落点** — 角色伸爪前先看目标，完成后让猫爪回到可接下一镜的位置。不要在动作中段无理由切断。
- **复杂道具遵守物理过程** — 搪瓷盆有重量，湿手套会滴水，铁皮盒落地会弹，绿皮火车窗需要两只猫爪用力。动作不能“意念完成”。

### 一镜到底（长镜头合并）

- **适用场景** — 花妈从厨房端菜到餐桌并一路拆穿父子；小橘和大勇抱着废品从煤棚绕到公共水池；一家人摸黑找蜡烛直到来电。
- **标注方式** — 明确写出起幅、路径、每次转向的触发和落幅，例如：`一镜到底：起幅灶台近景→跟花妈端盆后退至餐桌→前景父子迅速藏糖纸→花妈不回头报出证据→落幅父子同步僵住`。
- **时长建议 6—10 秒** — 每 2—3 秒必须有新动作、声源或关系变化。只为了炫技的绕场运镜必须拆掉。
- **生成可执行性优先** — 若镜头包含超过三次遮挡穿越、复杂物件交接或角色数量过多，拆为两个镜头并用动作匹配衔接。

## 五、固定喜剧链与多人调度

### 小橘→大勇→橘爸→花妈→猫奶奶

- **小橘提出计划** — 先拍他盯目标，再拍猫爪准备工具，最后才说一句半真半假的理由。计划越认真，漏洞越可见。
- **大勇犹豫后加入** — 用双人同框，大勇先往风险方向看一眼，再看小橘，停半拍，最后卷袖子或接过铁皮盒。不要只用一句“好吧”跳过心理动作。
- **橘爸暗中配合** — 先让橘爸以成人口吻反对，镜头不切，保留他把工具顺手推过去的第二层动作。台词和猫爪动作形成反差。
- **花妈负责识破** — 可在前两镜后景埋入花妈经过或停手，让观众早于父子知道。抓包时她不需要冲进来，只用一个具体证据落锤。
- **猫奶奶负责善后** — 善后不等于替小橘逃避责任。她可以递抹布、补一句圆场、把糖分给两人，同时让小橘完成收拾或道歉的动作。

### 反应镜头规则

- **笑点发生后至少一个反应镜头** — 小橘先僵住，橘爸再假装看别处，大勇缓慢把铁皮盒推远。反应顺序按谁最心虚排列。
- **父子同谋优先同框反应** — 两只橘猫同时挺直、同时否认、同时指向对方，比拆成两个特写更有关系喜感。
- **花妈的反应越小越有力量** — 停半秒、耳朵轻转、继续切菜、报出证据。禁止翻白眼、怒吼和夸张动画鬼脸。
- **猫奶奶的尾梗用正经表情** — 她越一本正经，圆谎或补刀越好笑。镜头保持固定，不配搞笑音效。

### 三遍法则分镜模板

1. **第一遍建立模式**：小橘伸爪→听声收回；中景 3 秒。
2. **第二遍加同伙**：大勇挡视线、小橘再伸爪→橘爸咳嗽预警；双人中景 3 秒。
3. **第三遍打破模式**：父子都以为安全→全景揭示花妈早站在后景；全景 2 秒 + 同框反应 2 秒。

禁止三遍使用完全相同的动作和台词；每遍都要增加人物、风险或空间信息。

## 六、场景动作、空间与连续性

- **小橘家** — 记录谁从哪个门进入、凳子原本在哪、糖罐放多高、花妈的做事路线。绿色木窗、铁暖气、水磨石地面、木柜、搪瓷用品和蓝白格桌布至少有一项参与动作。
- **家属院** — 雪地脚印、晾衣绳高度、自行车停放方向、白菜堆缺口都要前后对应。孩子从煤棚跑到自行车棚时，镜头方向保持一致。
- **红星机械厂** — 机器运转、工具使用和安全距离要可信。儿童不随意钻入危险设备区；与橘爸相处优先在厂门、维修间边缘或下班时段。
- **红星小学** — 课桌座位、书包、广播声和上下课状态保持连续。锅炉房、小卖部、广播室进入剧情必须有明确目的。
- **供销社** — 柜台内外边界明确，糖、铅笔盒、票证和零钱的交接用猫爪特写承接，商品数量不能镜间凭空变化。
- **露天市场** — 叫卖与人流方向建立后不随意反转；废品过秤要拍到放上去、秤杆变化、售货者报数三个动作中的至少两个。
- **大勇家** — 陈设简单但干净，不能为了表现家庭差异突然增加破败墙面、脏乱或阴冷光。人物互动保持平视。
- **季节连续** — 冬季棉服厚度、呼气、积雪与室内湿手套一致；夏季不能残留厚棉帽和结霜窗；雨后鞋底和裤脚状态连续。
- **道具连续** — 红色小福袋始终挂在小橘军绿色斜挎包上；大勇的铁皮盒、弹弓或自制玩具一场戏只选必要物件，不能镜间无故出现。
- **角色外形连续** — 小橘左耳轻折和眉心闪电纹、橘爸厂徽、花妈格纹与围裙、猫奶奶圆框镜和手帕、大勇鼻梁白纹与小豁牙必须稳定。

## 七、拟人猫动作、台词与声音标注

### 动作与表情

- **小橘** — `眼睛先扫花妈位置→猫爪慢慢伸向盘子→左耳更低→被点名后爪子改为擦桌`。用临时改动作表现编理由。
- **橘爸** — `挺胸讲道理→余光看好吃的→猫爪把盘子往自己这边挪一点→花妈看过来时改成整理桌布`。权威和馋同时存在。
- **花妈** — `手上继续切菜→耳朵轻转听见父子动静→不回头说出证据→把多盛的一碗饭推过去`。识破与照顾在同一生活任务里完成。
- **猫奶奶** — `推眼镜→看见小橘偷吃→低头折手帕假装没看见→离场前把糖塞进挎包`。动作小，信息清楚。
- **大勇** — `先看风险→小声提醒→小橘已行动→叹气卷起袖子加入→出事时站到小橘前半步`。老实不等于迟钝。
- **猫科细节** — 耳朵、尾巴、胡须、毛发和猫爪提供微表情，不额外配卡通符号。猫爪必须能看到接触点与受力。

### 台词

- **一句一意图** — 小橘“我没偷吃，我帮你尝咸淡呢”同时完成否认和嘴硬，不再加三句解释。
- **东北口语少量点味** — “干啥呢”“咋整的”“你可拉倒吧”可自然出现，但全场不能变成口音表演。
- **抢话制造关系** — 小橘刚说“我就是——”，橘爸接“学习实践”，花妈停半拍问“你俩统一口径了？”台词节奏服务父子同谋。
- **温情不用说明** — 小橘把冰棍递出后，只说“快点，化了”，不说“因为你是我最好的朋友”。
- **禁止现代网络用语和成年怀旧总结** — 不写“社死、破防、流量、打卡、内卷、点赞、在线”，不写“那是一个物质匮乏却温暖的年代”。

### 声音

- **每镜最多突出一个主音效** — 猫爪碰搪瓷的“当”、铁皮盒滚地、自行车铃、锅炉低鸣、学校广播、厂区下班铃。其余环境音降级为底层。
- **声源必须能定位** — 画外花妈说话前先有切菜声靠近；冰棍车出现前先听到车铃；来电前可先听到电流或邻居欢呼。
- **抓包后留静默** — 0.5—1 秒无配乐，只留铁暖气、锅炉或远处广播，让角色反应变成笑点。
- **温情段落去配乐优先** — 用掰冰棍、修理工具、布料摩擦、呼吸和室内蒸汽声承载情绪。

## 八、转场与生活化结尾

- **同场戏默认硬切** — 动作与反应之间干净硬切，保持喜剧节拍。
- **动作匹配转场** — 小橘在家抬起搪瓷盆→切到院里放上废品秤；橘爸拧螺丝→切到小橘拧小霸王手柄。相似动作连接家庭关系。
- **声音先行转场** — 先听学校广播再切红星小学；先听厂区下班铃再切自行车队；先听绿皮火车汽笛再切站台。
- **季节变化用同角度对比** — 同一绿色木窗外从积雪变成晾衣绳，不使用现代特效时间隧道。
- **年代物件不做炫技擦镜** — 搪瓷盆、红旗、车票等不能为了复古感频繁遮镜转场；只有角色真实拿起并经过镜头时才可使用。
- **生活化笑点结尾四类** —
  - **抓包尾梗**：花妈在画外准确报出藏东西的位置。
  - **甩锅尾梗**：父子同时指向对方，随后又同时把猫爪收回。
  - **嘴硬尾梗**：小橘满嘴碎屑仍说“我在检查质量”。
  - **道具尾梗**：铁皮盒自己滚出柜底、红色小福袋勾住证据、来电照出偷吃姿势。
- **尾梗不破坏温情** — 小橘已经把大半根冰棍让给大勇，尾梗可以是他偷偷量过大小，不能改成他把冰棍抢回来。
- **最后一镜不写总结字幕** — 不出现“亲情最珍贵”“童年再也回不去”等字幕或旁白，让锅炉声、自行车铃、家人一句平常话把生活继续下去。

## 九、时代、表演与生成自检

### 逐镜必查

- **时代**：1988—1990 年范围内，无智能手机、网络、现代电子产品、现代羽绒服、现代运动鞋、外卖盒、连锁商店、液晶电视、电磁炉、微波炉和精装修。
- **语言**：无现代网络用语、短视频主播腔和成年怀旧解说。
- **角色**：五名角色的毛色、脸部标记、体型、服装、随身物与关系功能不漂移。
- **表演**：真实猫脸、毛发、耳朵、尾巴和猫爪参与动作，无真人猫耳、四足宠物猫、Q 版圆胖萌宠和夸张动画鬼脸。
- **空间**：小橘家、家属院、红星机械厂、红星小学、供销社、露天市场、大勇家的固定材质与布局一致。
- **动作**：猫爪有接触点，物件有重量，人物进出方向与道具位置连续。
- **声音**：每个关键声源属于当前空间，配乐没有覆盖抓包停顿和生活声。
- **情绪**：整体仍是 50% 家庭与伙伴喜剧、30% 年代回忆、20% 温情成长。
- **结尾**：不强行煽情，以生活化笑点收尾，笑点不否定人物善意。

### 禁止的分镜写法

- “镜头扫过一屋子 90 年代老物件，旁白介绍当年生活”——这是物件展览，不是故事。
- “花妈暴怒，脸部极度变形，大吼十秒”——破坏人物底色和轻写实表演。
- “小橘突然明白亲情最伟大并发表长篇感言”——成长过量且不符合儿童表达。
- “大勇因家境简单被俯拍、配悲情音乐”——把差异苦情化，伤害角色尊严。
- “为了快节奏把端盆、转身、走路、放桌切成四个无意义特写”——动作碎裂，生成和剪辑都不自然。
- “用现代网感台词解释笑点”——时代穿帮，也削弱角色喜剧。
