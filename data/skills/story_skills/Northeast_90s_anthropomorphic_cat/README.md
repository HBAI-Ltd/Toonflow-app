# 东北90年代拟人猫 · 导演叙事手法技能包

## 简介

本技能包为 **1988—1990 年东北老工业城市拟人猫童年系列** 提供一套完整的导演叙事手法参考，覆盖从单集叙事规划到 9:16 竖屏分镜执行的全流程指导。

故事固定发生在虚构的 **北安市红星机械厂家属院**。每集约 60 秒，从小橘和家人、伙伴经历的过年、开学、暑假、停电、露天电影、小霸王、收废品换冰棍、写信、坐绿皮火车等小事出发，还原物质不丰富却很热闹的童年生活。

本手册与 `3D_90s_northeast_anthropomorphic_cat` 视觉手册配套使用：视觉手册负责角色与年代外观一致性，本手册负责人物关系、喜剧节奏、情感落点、声音、调度和剪辑逻辑。

## 核心理念

- **小事就是大戏** — 不把剧情拍成老物件介绍，而是从“想多吃一块糖”“想抢到露天电影的好位置”“想用废铁换两根冰棍”这样的儿童目标出发，让年代细节自然进入行动。
- **角色关系自己制造笑点** — 固定喜剧链是：**小橘想办法——大勇犹豫后加入——橘爸暗中配合——花妈负责识破——猫奶奶负责善后**。笑点来自性格碰撞，不依赖夸张动画鬼脸。
- **年代存在于生活动作里** — 煤炉要点、铁暖气会响、搪瓷盆会磕碰、自行车链会掉、停电后要找蜡烛。物件必须影响角色选择，不能成为脱离人物的物件展览。
- **温情藏在顺手一做** — 橘爸修好玩具、花妈多盛一勺饭、猫奶奶把糖塞进口袋、大勇把唯一一根冰棍掰开。少说教、少告白，用动作表达爱。
- **成长只向前挪半步** — 小橘不在一集里突然懂事，只是在闯祸后把最好吃的一口让出去，或下次多替朋友想一秒。变化小，才像真实童年。
- **最后一秒还在过日子** — 温情落下后，用一个抓包、甩锅、嘴硬或道具反应收尾。不用旁白总结，不强行煽情，不用“大道理字幕”封口。

## 系列硬锚点

| 项目 | 固定规则 |
|---|---|
| 时间 | 第一季集中在 1988—1990 年，不出现明显超出时代的物品与语言 |
| 地点 | 北安市红星机械厂家属院及其生活半径 |
| 单集 | 约 60 秒，9:16 竖屏 |
| 情绪比例 | 50% 家庭和伙伴喜剧、30% 年代回忆、20% 温情与成长 |
| 叙事视角 | 以 8 岁左右孩子的理解与误解观察成人世界 |
| 表演 | 轻写实拟人猫，真实猫脸与毛发结构，微表情和生活动作优先 |
| 结尾 | 温情不过量，最后通常落在生活化笑点 |

## 固定人物与导演功能

| 人物 | 戏剧功能 | 表演抓手 | 禁止漂移 |
|---|---|---|---|
| 小橘 | 欲望发动机、计划提出者、情感中心 | 先装镇定再露馅；耳朵、眼神和猫爪小动作泄密 | 不能变成恶作剧成瘾或只顾自己的熊孩子 |
| 橘爸 | 半个同谋、父亲权威的喜剧反差 | 讲道理时挺胸，参与后立刻心虚；关心靠修东西和留吃的 | 不能只剩严父或万能英雄功能 |
| 花妈 | 家庭节奏控制者、识破者 | 不必回头就知道父子在做什么；一边干活一边精准拆穿 | 不能刻薄、歇斯底里或停止生活只为训人 |
| 猫奶奶 | 温柔同盟、传统习俗入口、善后者 | 表面批评，手上悄悄递糖；一本正经配合小橘圆谎 | 不能神化成全知旁白或只负责催泪 |
| 大勇 | 风险提醒者、伙伴见证者、行动执行者 | 先皱眉提醒，确认拦不住后卷起袖子一起干 | 不能降格为胆小跟班或工具人 |

## 主要空间的导演用途

- **小橘家**：家庭喜剧主场。绿色木窗、铁暖气、水磨石地面、木柜、搪瓷用品和蓝白格桌布都要进入动作。
- **家属院**：伙伴群戏和季节变化主场。红砖楼、煤棚、公共水池、晾衣绳、自行车棚、白菜堆、积雪与蒸汽形成前中后景。
- **红星机械厂**：成人劳动世界和父子关系背景。厂门、烟囱、车间声、上下班自行车队用于建立时代秩序。
- **红星小学**：第一次犯错、第一次护朋友、第一次承担后果的成长空间。
- **供销社与露天市场**：儿童欲望被价格和票证约束的喜剧空间，适合“钱不够、嘴很硬”的行动。
- **大勇家**：以干净、简单、克制的陈设表现不同家庭处境，避免苦情化凝视。

## 技能文件说明

### 1. 导演规划（`director_planning_narrative.md`）

定义单集主题、60 秒结构、人物喜剧链、典型童年事件、声音系统、9:16 构图、拟人猫表演与时代连续性。

### 2. 分镜表（`director_storyboard_table_narrative.md`）

把导演规划落实为镜头数量、景别、运镜、时长、动作轨迹、角色反应、台词、环境音、转场和生活化结尾。

## 使用方式

1. 先从小橘的一个具体小目标出发，确认它与家庭或伙伴关系有关。
2. 选择一个能够真正参与行动的年代条件或老物件，不用旁白介绍其历史。
3. 按 50% 喜剧、30% 年代回忆、20% 温情成长规划情绪占比。
4. 用固定关系链推进计划、犹豫、配合、识破和善后。
5. 生成 9:16、约 60 秒分镜表，逐镜检查动作、声源、空间和时代连续性。
6. 让情感在动作中落地，再用生活化笑点结束。

## 必守边界

- 禁止智能手机、网络、现代电子产品、现代羽绒服、现代运动鞋、外卖盒、连锁商店、液晶电视、电磁炉、微波炉和精装修进入画面或台词。
- 禁止现代网络用语、短视频口播腔、成年人的怀旧解说替代儿童当下体验。
- 禁止真人猫耳、四足宠物猫、Q 版圆胖萌宠、夸张动画鬼脸、突然无毛猫爪或无法完成动作的人手漂移。
- 禁止把贫乏拍成苦难奇观，把家属院拍成整洁复古影棚，把东北气质简化成吵闹、喝酒或口音笑料。
- 禁止依靠配乐强行催泪；声音应优先来自锅炉、广播、自行车铃、铁暖气、搪瓷碰撞、脚踩积雪和家人做饭。
