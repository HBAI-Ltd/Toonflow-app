# 分镜表叙事手法 · 治愈系都市女性生活与关系 · 技法参考

## 一、分镜表定位

分镜表负责把一个小确幸命题拆成 68—89 秒、20—27 个可生成镜头。每一行必须同时是：

- 一张可生成的分镜画面说明；
- 一个可执行的视频动作说明；
- 一条能与前后镜连续的状态记录；
- 一个有明确时间与叙事职责的剪辑单元；
- 一组可混音的声音提示。

不得用“温馨地互动”“治愈感拉满”“镜头很电影”代替站位、动作、光源和运镜。

## 二、总表固定字段

每个项目在分镜表前建立四张总表。

### 2.1 项目规格表

| 字段 | 内容 |
|---|---|
| 故事模型 | 独居自愈 / 通勤工作 / 独自挑战 / 女性友谊 / 外婆与旧时光 / 父母与双向照料 |
| 核心命题 | 一句可见、可完成的今日愿望 |
| 母版画幅 | 3:4 竖幅 |
| 目标时长 | 68—89 秒，默认约 80 秒 |
| 目标节拍 | 20—27 个，默认 24 个 |
| 时间范围 | 当天具体时段；跨日需明确 |
| 开场动作 | 3—6 秒内可见的动机或异常 |
| 情绪高点 | 抵达、共同完成、互相照料或被理解 |
| 收束动作 | 到家、休息、关灯、报平安、看电视、目送 |

### 2.2 角色连续性表

| 角色 | L0 固定身份 | 当前服装可变层 | 包/鞋/配饰 | 手持物 | 表面状态 |
|---|---|---|---|---|---|
| 小幸 | 栗棕色长卷发、暖白肤、棕眼、修长体型 | 本集造型 | 逐场记录 | 逐镜记录 | 妆、汗、雨、面粉等 |
| 支持角色 | 年龄层、脸部结构、发型色、身高关系 | 本集造型 | 逐场记录 | 逐镜记录 | 逐场记录 |

### 2.3 场景连续性表

| 场景 | 门窗/入口 | 主要家具或路径 | 动作区 | 主光 | 辅光 | 临时物件 |
|---|---|---|---|---|---|---|
| {地点} | {位置与开启方向} | {固定坐标} | {人物可行动范围} | {来源方向} | {来源方向} | {行李/食材等} |

### 2.4 关键道具状态表

| 道具 | 归属 | 初始位置/状态 | 状态变化镜头 | 结束位置/状态 |
|---|---|---|---|---|
| {名称} | {角色} | {关闭、完整、数量} | {镜号和动作} | {开启、减少、交给谁} |

## 三、标准 24 节拍骨架

以下为默认约 80 秒骨架，可在 20—27 镜内调整：

| 镜号 | 建议时间 | 时长 | 叙事职责 |
|---:|---:|---:|---|
| 1 | 00:00—00:03 | 3s | 钩子：时间、地点或今天的具体愿望 |
| 2 | 00:03—00:06 | 3s | 小幸当前状态与第一动作 |
| 3 | 00:06—00:10 | 4s | 准备一：拿取/整理关键道具 |
| 4 | 00:10—00:13 | 3s | 准备二：换装、装备或备菜 |
| 5 | 00:13—00:16 | 3s | 出发/进入主要空间 |
| 6 | 00:16—00:20 | 4s | 第一个完整行动 |
| 7 | 00:20—00:23 | 3s | 细节确认与感官信息 |
| 8 | 00:23—00:27 | 4s | 第二个行动或关系加入 |
| 9 | 00:27—00:30 | 3s | 小满足 |
| 10 | 00:30—00:34 | 4s | 小阻力出现 |
| 11 | 00:34—00:37 | 3s | 人物调整或他人响应 |
| 12 | 00:37—00:41 | 4s | 继续行动 |
| 13 | 00:41—00:44 | 3s | 道具/空间状态变化 |
| 14 | 00:44—00:48 | 4s | 关系共同行动 |
| 15 | 00:48—00:51 | 3s | 反应或轻玩笑 |
| 16 | 00:51—00:55 | 4s | 接近完成/抵达 |
| 17 | 00:55—00:58 | 3s | 情绪高点前的停顿 |
| 18 | 00:58—01:02 | 4s | 共同完成、抵达或被照料 |
| 19 | 01:02—01:05 | 3s | 细节落点 |
| 20 | 01:05—01:09 | 4s | 从高点回到生活 |
| 21 | 01:09—01:12 | 3s | 回程/分别/收拾 |
| 22 | 01:12—01:15 | 3s | 报平安、目送或共享安静 |
| 23 | 01:15—01:18 | 3s | 最后一个具体小满足 |
| 24 | 01:18—01:20 | 2s | 台灯、门口、电视或窗景余韵 |

实际时间戳必须依据镜头累计值计算，不得直接复制表中时间后又改变单镜时长。时间戳必须单调递增，禁止时间戳倒退。

## 四、分镜行必填字段

| 字段 | 必须写什么 |
|---|---|
| 镜号/时间 | 起止时间、单镜时长、累计总时长 |
| 时间戳字幕 | 后期显示时间与 8—16 字日记短句 |
| 叙事功能 | 信息 / 动作 / 感觉 / 关系 / 过渡 |
| 场景 | 地点、时段、天气、与基础场景的衍生状态 |
| 景别机位 | 景别、镜头高度、朝向、视角 |
| 构图站位 | 水平位置、纵深、人物距离、字幕安全区 |
| 角色状态 | 固定身份、当前服装、发型、妆/汗、手持物 |
| 画面动作 | 起始姿态、轨迹、接触、结果、用时、身体响应 |
| 道具状态 | 动作前后位置、开合、数量、归属与剩余量 |
| 表演 | 视线、眼睑、嘴角、呼吸、肩背与停顿 |
| 光线 | 主光、辅光、方向、冷暖、触发变化 |
| 环境动态 | 风、热、水、车、人造成的可见变化 |
| 运镜 | 固定/慢推/缓拉/轻跟拍/小幅摇镜及起止 |
| 声音 | 对白/口播、动作声、1—2 个环境声、配乐状态 |
| 连续性 | 承接上一镜与交给下一镜的精确状态 |
| 禁止项 | 本镜最可能出现的生成错误 |

## 五、分镜卡片模板

```text
【镜头 {X}】{开始时间}—{结束时间}｜时长 {X}s｜功能：{信息/动作/感觉/关系/过渡}

时间戳字幕（后期）：
时间：{HH:MM / 次日 HH:MM}
日记短句：{8—16个汉字，粗白字黑描边}

场景：
{地点、时段、天气、场景状态}｜母版：3:4竖幅

景别/机位：
{景别、镜头高度、视角、朝向}

构图与空间：
{人物在画面左/中/右、前/中/后景、彼此距离、固定参照物}

微表演：
{视线、眼睑、嘴角、呼吸、肩背、停顿}

动作后：{位置、方向、开合、数量、归属}

光线：

{来源、方向、幅度和速度；无则写“无”}

运镜：
{固定/慢推/缓拉/轻跟拍/小幅摇镜，具体起止与用时}

声音：

动作声：{与动作同步点}
环境声：{1—2个}
配乐：{进入/保持/降低/退出}

连续性：
承接上一镜：{站位、视线、用手、服装、道具、光线、时间}
交给下一镜：{结束姿态、道具状态、声音或动作切点}

本镜禁止：
{同脸/年龄漂移/手指错误/道具穿模/重影/错误文字等针对性约束}
```

## 七、时间戳字幕模板

字幕视觉统一：

- 简体中文。
- 时间在上、日记短句在下。
- 粗白字、厚黑描边。
- 默认居中；家庭结尾可左对齐。
- 一屏一条主要语义，不遮挡人物、手部、食物和道具。

可用句式：

| 层次 | 示例 |
|---|---|
| 行动 | “到家先给自己做顿热的” |
| 轻玩笑 | “说好随便吃，最后还是点满了” |
| 感官 | “山风一吹，人也清醒了” |
| 关系 | “她没催，只在门口多等了一会儿” |
| 时间感 | “以前嫌路远，现在更想常回来” |

字幕示例只提供语气，不得机械复用为每集固定文案。

## 八、空间连续性写法

```text
水平：小幸位于画面左三分之一，外婆位于右侧中景。
纵深：两人距镜头约2米，旧木桌横置于两人之间。
参照：小幸距厨房门约0.8米，竹篮固定在桌左下角。
朝向：小幸面向画面右侧，外婆面向左前方。
轴线：摄影机始终位于桌面同一侧；跨轴前先用中全景重新建立。
```

- 镜号变更后，门窗、桌椅和站位不得左右镜像。
- 需要跨轴时，用人物移动、摄影机绕行或新建立镜头完成。
- 双人/三人关系段落不得只写“坐在一起”，要写距离、朝向和分工。

## 九、道具连续性写法

```text
镜12前：行李箱位于玄关右侧，拉链关闭，母亲右手扶把手。
镜12动作：母亲蹲下沿顺时针方向拉开拉链。
镜12后：箱盖向墙侧打开，食物袋仍在箱内左侧。
镜13承接：箱盖、母亲蹲姿与食物袋位置不变；小幸从画面左侧进入。
```

每个关键道具至少在“出现、使用、结束”三个状态中被记录。禁止食材恢复、购物袋提前出现、装备随机消失和手机跨手跳变。

## 十、光线与环境动态栏

### 光线

- 主光有唯一可追溯来源和方向。
- 同场反打按真实空间翻译，不把光源跟着脸移动。
- 开灯、关灯、车灯经过、天色渐亮必须写触发点。
- 夜爬与旧宅暗部仍保留动作信息。

### 环境动态

每镜最多一个主要环境动态：

- 锅边蒸汽向抽风方向偏；
- 窗帘随一阵风向画面右侧鼓起后回落；
- 山路头灯光束随头部转动扫过台阶；
- 旧街树影随风轻移；
- 电视画面亮度变化在人物脸上形成低幅反射。

禁止无来源粒子、无风自动飘发和遍布全片的梦幻光斑。

## 十一、运镜与转场栏

### 运镜选择

- 固定：共同行动与手部操作。
- 慢推：小满足、旧物停顿、抵达。
- 缓拉：门口、客厅、共享空间收束。
- 轻跟拍：通勤、老街、逛街、山路。
- 小幅摇镜：递物和视线移动。

### 转场选择

- 硬切：同场动作/反应。
- 动作匹配：同形动作跨地点。
- 声音先行：门铃、水沸、风、车门、电视。
- 视线匹配：人物所看空间。
- 短溶解：只用于明确时间/地点跳跃。

每次溶解后检查上一镜是否完全消失。禁止过度溶解、重影、双重身体、幽灵手、闪白、旋转与模板转场。

## 十二、声音栏

每镜按优先级选择：

1. 对白/口播是否有必要；
2. 与主动作同步的一个动作声；
3. 一个能定义空间的环境声；
4. 配乐是否进入、降低或退出。

完整成片为立体声，建议约 `-16 LUFS`，真峰值不高于 `-1 dBTP`。旁白清楚时配乐让位；关系停顿保留呼吸、餐具、风或电视等真实声音。

## 十三、全表质量门

### 结构

- 总时长在 68—89 秒，默认约 80 秒。
- 共 20—27 个节拍，单镜动作量与时长匹配。
- 开场 3—6 秒明确动机，结尾有具体生活动作。

### 视觉

- 全部镜头原生按 3:4 构图。
- 半写实二维、柔和网漫、克制赛璐璐和色光体系统一。
- 不生成字幕、水印、错误文字、Logo、UI和 9:16 黑边。

### 角色

- 身份不变、年龄层不变、脸部结构不变、发型色不变、身高关系不变。
- 小幸、短发闺蜜、母亲、父亲、外婆一眼可区分。
- 无同脸、年龄漂移、随机换装和偶像化父亲。

### 动作与道具

- 每个主动作都有起点、轨迹、接触、结果与用时。
- 无手指错误、额外肢体、道具穿模、食物形态漂移和状态回退。
- 时间戳单调递增，无时间戳倒退。

### 关系与情绪

- 关系通过共同行动、并肩、递物、等待、目送和报平安建立。
- 无恋爱、霸总、暧昧误读。
- 外婆与父母线无死亡、疾病和苦情扩写。
- 现代公寓不是样板间，老街旧宅不是贫困奇观。

### 镜头与声音

- 建立镜头、动作镜头、细节镜头比例合理。
- 运镜单纯有目的，无广告炫技。
- 溶解少而明确，无过度溶解、重影和双重身体。
- 环境动态有来源，立体声层次清楚，峰值安全。
