# 治愈系都市女性生活 · 导演叙事手法技能包

## 简介

本技能包用于导演 **3:4 竖幅、68—89 秒、典型约 80 秒** 的治愈系都市女性生活与关系动画 Vlog。它与视觉手册 `2D_healing_urban_women_vlog` 配套：视觉手册负责人物、场景、道具和画面风格，本手册负责叙事命题、时间戳行动链、人物调度、镜头节奏、声音与剪辑连续性。

参考范围来自六类完整生活：

- 下班后的独居自愈；
- 工作日晨间、通勤与可选商业内容；
- 一个人夜爬并等待日出；
- 成年女性朋友见面、分别与报平安；
- 回老街探望外婆、共同做饭与面对时间流逝；
- 父母突然到访，以及女儿开始反向照料父母。

## 核心理念

- **今天只完成一件具体小事**：做顿热饭、准时出门、一个人登顶、陪朋友吃饭、回去看外婆、给父母买件衣服。
- **行动链就是故事**：准备、移动、接触、制作、交接、抵达和收拾都要真实发生，不用大段对白概述。
- **小阻力代替大冲突**：疲惫、时间紧、夜色、路远、选择多、分别舍不得，足以产生节奏。
- **共同行动就是关系**：一起切菜、并肩走路、互拍、递衣、搬行李、报平安，比恋爱剧式正反打更准确。
- **温情落回生活**：情绪高点之后仍要回家、关灯、喝水、装食物、看电视或目送。
- **克制比催泪更长久**：不依赖死亡、疾病、吵架、宏大旁白和煽情配乐。

## 成片硬锚点

| 项目 | 固定规则 |
|---|---|
| 母版画幅 | 原生 3:4 竖幅 |
| 平台适配 | 9:16 只做安全延展或重构，禁止把黑边生成进画面 |
| 总时长 | 68—89 秒，默认约 80 秒 |
| 节拍 | 20—27 个，通常每节拍 3—4 秒 |
| 开场 | 前 3—6 秒明确时间、地点和今天要完成的事 |
| 中段 | 时间戳行动链，小满足与小阻力交替 |
| 高点 | 抵达、共同完成、互相照料或被理解 |
| 结尾 | 到家、休息、报平安、看电视、关灯或门口目送 |
| 字幕 | 简体中文，时间在上、日记短句在下，粗白字黑描边 |
| 声音 | 连续立体声，建议约 `-16 LUFS`，真峰值不高于 `-1 dBTP` |

## 六类故事模型

### 1. 独居自愈

下班/回家动机 → 换鞋放包 → 备菜做饭 → 独自用餐 → 洗漱整理 → 阅读/休息 → 关灯。

重点是主动照料自己，不增加失恋、等人回家或男性来电。

### 2. 通勤工作

时间钩子 → 洗漱化妆 → 穿搭早餐 → 电梯/通勤 → 到工位 → 工作行动 → 下班。

商业内容只有项目明确要求时才进入，建议不超过约 26 秒或全片三分之一；产品动作结束后必须回到人物生活。

### 3. 独自挑战

目标 → 装备检查 → 出发 → 夜路/石阶 → 疲惫 → 喝水调整 → 继续 → 黎明 → 抵达日出 → 回归。

挑战来自真实体力与夜色，不靠事故、险情或男性拯救。

### 4. 女性友谊

约见 → 用餐 → 互拍/回看 → 逛街 → 护理/按摩 → 送别 → 到家 → 报平安 → 各自夜晚。

亲密来自默契与照料，不使用情侣牵手、烛光凝视、恋爱或暧昧编码。

### 5. 外婆与旧时光

返乡 → 老街 → 门口相见 → 一起择菜/做饭 → 共餐 → 旧物/菜园/小店 → 短谈 → 离开/目送。

可以有时间有限的克制感，但不得自动添加死亡、疾病、遗嘱、住院或葬礼。

### 6. 父母与双向照料

突然到访 → 搬行李 → 取出食物 → 一起做饭 → 共餐 → 购物 → 女儿挑衣/买单 → 回家看电视。

父母继续照顾女儿，女儿也用可见行动照顾父母；不增加催婚冲突和霸总化父亲。

## 角色的导演功能

| 角色 | 导演功能 | 表演抓手 | 禁止漂移 |
|---|---|---|---|
| 小幸 | 行动发起者与观察视角 | 先观察再行动，疲惫与满足由呼吸、肩背和嘴角表达 | 不成为被动等待恋爱的空壳 |
| 短发闺蜜 | 平等同伴与生活见证者 | 并肩、互拍、递饮料、等车、报平安 | 不成为恋爱替代品或同脸复制 |
| 母亲 | 熟练照料者 | 拿食物、整理、做饭、观察女儿状态 | 不歇斯底里、不只负责催婚 |
| 父亲 | 稳定帮手 | 搬行李、择菜、摆碗、试衣、安静陪伴 | 不偶像化、不霸总化 |
| 外婆 | 时间与旧日生活的入口 | 动作略慢、择菜、旧物、门口等待与目送 | 不病弱工具化、不负责死亡催泪 |

## 使用顺序

1. 选择六类故事模型之一，写一句今天要完成的具体愿望。
2. 确定 3:4 母版、68—89 秒目标时长与 20—27 个节拍。
3. 建立角色、场景、关键道具和时间戳连续性表。
4. 按“建立镜头 → 动作镜头 → 细节镜头”组织行动链。
5. 关系场面先设计共同行动，再决定是否需要对白或正反打。
6. 标注每镜动作接触、光源、环境动态、声音与前后状态。
7. 检查时间戳单调递增、转场克制、声音峰值安全。
8. 最后排除恋爱、霸总、暧昧、死亡、疾病、同脸、年龄漂移、手指错误、道具穿模、过度溶解、水印、样板间与 9:16 黑边。

## 必守边界

- 禁止把独处写成等待男性拯救，把友情或亲情改写成恋爱、霸总或暧昧。
- 禁止把外婆和父母故事扩写为死亡、疾病、贫困奇观和家庭伦理苦情。
- 禁止用长旁白、连续金句和景物蒙太奇替代人物行动。
- 禁止时间戳倒退、随机跨日、道具状态恢复和人物无依据换装。
- 禁止过度溶解、重影、双重身体、模板转场和无目的运镜。
- 禁止错误招牌、品牌 Logo、字幕烧录、水印、UI 与平台 9:16 黑边进入基础画面。
- 禁止所有家都变成纯白样板间，也禁止把老街旧宅拍成废墟和贫困展示。
